# **Brain Networks and Biological Evidence Algorithm**

MASTER NEUROCOMPUTATIONAL ALGORITHM · VISUAL READING · LANGUAGE NETWORKS · NEURAL DYNAMICS · EXPERIMENTAL VALIDATION

The objective is to transform the 12 proposed processes into one interconnected algorithm that models how visual and auditory information is transformed into linguistic representations, how those representations propagate through biological neural networks, and how the resulting computational model can be compared with actual human brain measurements.

I will call this algorithm:

**BNBEA — Brain Networks and Biological Evidence Algorithm**

The algorithm will have 12 major operations, each with detailed substeps, mathematical operations, a proposed biological implementation, and measurable outputs.

An important scientific distinction: the equations are computational models of possible neural computations. We do not know that the human brain literally calculates Gabor convolutions, matrix multiplications, or explicit probability distributions. Those mathematical operations describe functional properties that biological neural populations may approximate.

# **2. Initial mathematical foundations**

Before describing the operations, we need to define the internal state of the simulated brain.

## **2.1 Global neural state**

At time \\(t\\), define the model state as:

\\[ S_t = \left\\{ V_t,G_t,W_t,A_t,N_t,B_t \right\\} \\]

Where:

| Variable  | Meaning                                   |
| --------- | ----------------------------------------- |
| \\(V_t\\) | Visual representations                    |
| \\(G_t\\) | Grapheme and orthographic representations |
| \\(W_t\\) | Word-level linguistic representations     |
| \\(A_t\\) | Auditory and phonological representations |
| \\(N_t\\) | Neural population activity and dynamics   |
| \\(B_t\\) | Biological measurement predictions        |

We also define an anatomical network:

\\[ \mathcal{G}=(\mathcal{V},\mathcal{E},\mathbf{W}) \\]

Where:

- \\(\mathcal{V}\\): simulated brain regions.
- \\(\mathcal{E}\\): connections between regions.
- \\(\mathbf{W}\\): connection-strength matrix.

Each region has its own internal representation:

\\[ \mathbf{x}\_i(t) \\]

For example:

\\[ \mathbf{x}\_{V1}(t) \\]

represents V1 activity, while:

\\[ \mathbf{x}\_{VWFA}(t) \\]

represents simulated visual word-form processing activity.

The complete network state can be represented as:

\\[ \mathbf{X}(t)= \begin{bmatrix} \mathbf{x}\_{V1}(t)\\\ \mathbf{x}\_{V2}(t)\\\ \mathbf{x}\_{V4}(t)\\\ \mathbf{x}\_{VWFA}(t)\\\ \mathbf{x}\_{MTG}(t)\\\ \mathbf{x}\_{IFG}(t)\\\ \mathbf{x}\_{ATL}(t) \end{bmatrix} \\]

This lets us describe the brain as a collection of interconnected populations instead of treating it as one mathematical function.

## **2.2 Three mathematical levels**

The implementation should distinguish three mathematical levels.

**Level 1 — Representation**

What information does a neural population represent?

Examples:

- Orientation.
- Spatial frequency.
- Letter identity.
- Letter position.
- Word identity.
- Phonological information.
- Semantic concepts.

**Level 2 — Neural dynamics**

How does neural activity evolve?

Examples:

- Membrane voltage.
- Synaptic currents.
- Firing rates.
- Excitation and inhibition.
- Temporal synchronization.
- Recurrent activation.

**Level 3 — Measurement**

How does activity become an experimentally observable signal?

Examples:

- EEG voltage.
- MEG magnetic fields.
- fMRI BOLD response.
- Behavioral reading time.
- Eye movement patterns.

Keeping these levels separate is essential. A representation of a letter is not the same thing as the membrane voltage of a neuron representing that letter.

## **Objective**

Simulate the early visual processing mechanisms that extract fundamental characteristics from written text.

Before recognizing a letter, the brain must process its visual structure.

For example, the letter A consists of:

- Two diagonal strokes.
- One horizontal stroke.
- Several intersections.
- Particular spatial relationships between these features.

The early visual system does not immediately recognize the letter A. It processes local visual characteristics.

Gabor-shaped receptive fields are commonly used as computational approximations of orientation- and spatial-frequency-selective receptive fields in V1.&#x20;

## **Operation 1.1: Receive the visual image**

**Purpose**

Receive an image containing written characters.

Represent the image as:

\\[ I(x,y) \\]

Where:

- \\(x\\): horizontal coordinate.
- \\(y\\): vertical coordinate.
- \\(I(x,y)\\): pixel intensity.

For a grayscale image:

\\[ I(x,y)\in[0,1] \\]

The first operation is to normalize visual intensity.

One possible normalization:

\\[ I_n(x,y)= \frac{I(x,y)-\mu_I} {\sigma_I+\epsilon} \\]

Where:

- \\(\mu_I\\): mean image intensity.
- \\(\sigma_I\\): image intensity standard deviation.
- \\(\epsilon\\): small numerical constant.

**Possible biological implementation**

Retinal photoreceptors encode changes in light intensity. Retinal and LGN circuitry performs contrast-sensitive processing before information reaches primary visual cortex.

The normalization above is a mathematical approximation, not a claim that retinal neurons perform this exact global calculation.

## **Operation 1.2: Construct a bank of Gabor filters**

**Purpose**

Create filters that respond to different visual orientations and spatial frequencies.

A two-dimensional Gabor filter is:

\\[ g(x,y)= \exp\left( -\frac{x'^2+\gamma^2y'^2}{2\sigma^2} \right) \cos(2\pi fx'+\phi) \\]

Where:

\\[ x'=x\cos\theta+y\sin\theta \\]

\\[ y'=-x\sin\theta+y\cos\theta \\]

Parameters:

| Parameter    | Meaning                |
| ------------ | ---------------------- |
| \\(\theta\\) | Orientation            |
| \\(f\\)      | Spatial frequency      |
| \\(\sigma\\) | Gaussian envelope size |
| \\(\gamma\\) | Aspect ratio           |
| \\(\phi\\)   | Phase                  |

Construct multiple filters:

\\[ G=\\{g\_{\theta,f,\phi}\\} \\]

For example:

- Horizontal filters.
- Vertical filters.
- Diagonal filters.
- Different spatial frequencies.
- Different receptive-field sizes.
- Different phases.

This creates a simplified model of a population of visual receptive fields.

## **Operation 1.3: Calculate local filter responses**

**Purpose**

Determine how strongly each filter matches a particular image region.

The mathematical operation is convolution:

\\[ R\_{\theta,f,\phi}(x,y) = (I_n\*g\_{\theta,f,\phi})(x,y) \\]

Expanded:

\\[ R(x,y)= \sum_i\sum_j I_n(x-i,y-j)g(i,j) \\]

This operation multiplies corresponding image and filter values and accumulates their products.

A large response means that the local image resembles the filter's preferred visual pattern.

## **Operation 1.4: Calculate orientation energy**

**Purpose**

Combine phase-sensitive responses into a less phase-sensitive orientation response.

Use a quadrature pair:

\\[ R_e=I\*g_e \\]

\\[ R_o=I\*g_o \\]

Then calculate:

\\[ E\_{\theta,f}= \sqrt{R_e^2+R_o^2} \\]

This provides a measure of local oriented energy.

For example, a diagonal stroke produces strong activity in filters tuned to its orientation.

## **Operation 1.5: Apply neural response nonlinearities**

**Purpose**

Convert filter responses into activity resembling the positive response range of neurons.

A simple rectified response:

\\[ r_i=\max(0,E_i-\theta_i) \\]

Where \\(\theta_i\\) represents the activation threshold.

A more realistic population-level normalization approximation:

\\[ \hat r_i= \frac{r_i} {\sigma+\sum_jw\_{ij}r_j} \\]

This introduces divisive normalization.

The response of one population is affected by the activity of neighboring populations.

## **Operation 1.6: Extract visual feature maps**

Produce:

\\[ F_1= \left[ E\_{\theta_1,f_1}, E\_{\theta_2,f_1}, \ldots, E\_{\theta_n,f_m} \right] \\]

These maps describe:

- Stroke orientation.
- Edge location.
- Local contrast.
- Spatial frequency.
- Edge strength.
- Local texture.

**Output of Operation 1**

**Early visual representation**

- Normalized image.
- Orientation feature maps.
- Spatial-frequency feature maps.
- Edge-energy maps.
- Local contrast information.
- Neural-style activation maps.

## **Objective**

Transform early visual features into distributed neural representations of graphemes.

A critical idea is that a grapheme should not be represented by just one isolated number or one binary code.

Instead, a grapheme activates a population of different feature-sensitive units.

For example, the letter A could activate populations representing:

- Diagonal strokes.
- Intersections.
- Horizontal strokes.
- Upper and lower spatial positions.
- Relative feature arrangements.

Population coding is an established framework in neuroscience. However, the specific prototype architecture described here is an engineering model of population-style representation, not an established literal storage format for graphemes in the human brain.&#x20;

## **Operation 2.1: Divide visual feature maps into candidate grapheme regions**

**Purpose**

Identify local regions containing potentially meaningful letter structures.

Let:

\\[ F_1(x,y) \\]

represent the visual feature maps.

Use spatial segmentation to create candidate regions:

\\[ R=\\{r_1,r_2,\ldots,r_n\\} \\]

Each region represents a potential character or character component.

Possible mathematical operations:

- Connected-component analysis.
- Spatial clustering.
- Local maxima detection.
- Thresholding.
- Region aggregation.

## **Operation 2.2: Construct a feature vector for each candidate**

**Purpose**

Describe each visual region in numerical form.

For region \\(r_j\\), calculate:

\\[ \mathbf{v}\_j= [ f_1,f_2,\ldots,f_d ] \\]

Possible dimensions:

| Feature       | Description              |
| ------------- | ------------------------ |
| \\(f_1\\)     | Horizontal stroke energy |
| \\(f_2\\)     | Vertical stroke energy   |
| \\(f_3\\)     | Diagonal stroke energy   |
| \\(f_4\\)     | Curvature                |
| \\(f_5\\)     | Number of intersections  |
| \\(f_6\\)     | Upper-region activation  |
| \\(f_7\\)     | Lower-region activation  |
| \\(f_8\\)     | Width                    |
| \\(f_9\\)     | Height                   |
| \\(f\_{10}\\) | Edge density             |

The resulting vector represents the visual characteristics of a candidate grapheme.

## **Operation 2.3: Construct population prototypes**

**Purpose**

Create multiple reference representations for each grapheme.

For example:

\\[ P_A= \\{\mathbf{\mu}\_{A,1}, \mathbf{\mu}\_{A,2}, \mathbf{\mu}\_{A,3}\\} \\]

These prototypes represent different visual realizations of A.

Similarly:

\\[ P_B= \\{\mathbf{\mu}\_{B,1}, \mathbf{\mu}\_{B,2}, \ldots\\} \\]

Multiple prototypes are useful because letters can have different fonts, sizes, thicknesses, and visual styles.

A prototype can be learned using:

\\[ \mathbf{\mu}\_{g,k} = \frac{1}{N} \sum\_{i=1}^{N} \mathbf{v}\_{g,k}^{(i)} \\]

Where the feature vectors come from examples of grapheme \\(g\\).

## **Operation 2.4: Calculate population activation**

**Purpose**

Determine the activation of each candidate grapheme population.

A possible radial-basis tuning function:

\\[ a\_{g,k}= \exp\left( -\frac{ (\mathbf{v}-\mathbf{\mu}\_{g,k})^T \Sigma\_{g,k}^{-1} (\mathbf{v}-\mathbf{\mu}\_{g,k}) }{2} \right) \\]

Where:

- \\(\mathbf{v}\\): actual visual feature vector.
- \\(\mathbf{\mu}\_{g,k}\\): reference prototype.
- \\(\Sigma\_{g,k}\\): feature covariance matrix.

The expression measures the distance between the observed grapheme and the population's preferred representation.

A closer match produces a higher response.

## **Operation 2.5: Integrate population responses**

Combine responses from multiple units:

\\[ A_g=\sum_k\alpha_k a\_{g,k} \\]

Where:

- \\(A_g\\): total grapheme population activation.
- \\(\alpha_k\\): unit contribution.

Then normalize competing grapheme activations:

\\[ P(g|\mathbf{v})= \frac{e^{A_g/T}} {\sum_j e^{A_j/T}} \\]

This gives a probability distribution over possible graphemes.

## **Operation 2.6: Preserve relative letter position**

This is particularly important.

Consider:

- FORM
- FROM

Both contain the same four letters, but the third and second letters have different positions.

The model must not lose order information through pooling.

Represent each grapheme with a relative position:

\\[ G_i=(g_i,p_i) \\]

Where \\(p_i\\) represents its ordinal position in the letter sequence.

The population representation becomes:

\\[ \mathbf{G}= \\{ (g_1,p_1), (g_2,p_2), \ldots, (g_n,p_n) \\} \\]

The model can then distinguish different strings even when they contain the same graphemes.

## **Operation 2.7: Update prototypes through experience**

A simple incremental learning rule:

\\[ \mu\_{new}= (1-\eta)\mu\_{old}+\eta v\_{actual} \\]

Where \\(\eta\\) is the learning rate.

This models experience-dependent adaptation to repeated visual forms.

**Output of Operation 2**

- Grapheme population activations.
- Candidate grapheme probabilities.
- Feature vectors.
- Position-preserving grapheme sequences.
- Recognition confidence.
- Updated prototype representations.

## **Objective**

Move beyond static mathematical representations and simulate the time-dependent behavior of neural populations.

Operations 1 and 2 calculate representations.

Operation 3 asks:

**How does the activity of neurons change as visual information arrives and propagates through the network?**

This is a critical distinction.

A real neuron does not simply hold a fixed feature vector. Its membrane voltage and synaptic inputs change over time.

## **Operation 3.1: Initialize simulated neurons**

For each neural population, define:

\\[ N=\\{n_1,n_2,\ldots,n_m\\} \\]

Each neuron receives:

- Membrane resistance.
- Membrane capacitance.
- Resting potential.
- Firing threshold.
- Reset potential.
- Refractory period.
- Synaptic connections.

For example:

\\[ V\_{rest}=-70\text{ mV} \\]

\\[ V\_{threshold}=-50\text{ mV} \\]

These are illustrative engineering parameters, not individually measured constants for the brain region being modeled.

## **Operation 3.2: Calculate synaptic input currents**

A neuron receives inputs from other neurons.

For neuron \\(i\\):

\\[ I_i(t)=I\_{external,i}(t) + \sum_j w\_{ij}s_j(t) \\]

Where:

- \\(I\_{external,i}\\): external sensory input.
- \\(w\_{ij}\\): synaptic connection weight.
- \\(s_j(t)\\): synaptic activity from neuron \\(j\\).

Positive weights can represent excitatory connections.

Negative weights can represent inhibitory connections.

## **Operation 3.3: Calculate membrane dynamics**

Use a leaky integrate-and-fire approximation:

\\[ C_m\frac{dV_i}{dt} = -g_L(V_i-E_L)+I_i(t) \\]

Where:

- \\(C_m\\): membrane capacitance.
- \\(g_L\\): leak conductance.
- \\(E_L\\): resting equilibrium potential.
- \\(V_i\\): membrane potential.
- \\(I_i(t)\\): incoming current.

The leak term causes voltage to move toward the resting potential in the absence of sufficient input.

## **Operation 3.4: Discretize membrane dynamics**

For a Python implementation, use numerical integration.

An Euler approximation:

\\[ V_i(t+\Delta t)= V_i(t)+ \frac{\Delta t}{C_m} \left[ -g_L(V_i-E_L)+I_i(t) \right] \\]

The simulation repeats this calculation over small time intervals.

## **Operation 3.5: Generate spikes**

When:

\\[ V_i(t)\geq V\_{threshold} \\]

The neuron generates a spike.

Then:

\\[ V_i\leftarrow V\_{reset} \\]

And the neuron enters a refractory period.

During that period, its ability to generate another spike is temporarily restricted.

## **Operation 3.6: Maintain synaptic activity**

A simple synaptic activity model:

\\[ \frac{ds_i}{dt} = -\frac{s_i}{\tau_s} + \sum_k\delta(t-t_i^k) \\]

Where:

- \\(\tau_s\\): synaptic decay constant.
- \\(t_i^k\\): times of generated spikes.
- \\(\delta\\): spike event representation.

This describes how synaptic activity rises following a spike and gradually decays.

## **Operation 3.7: Calculate population firing rates**

For a population of \\(m\\) neurons:

\\[ FR(t)= \frac{N\_{spikes}(t,t+\Delta T)} {m\Delta T} \\]

This gives the average firing rate in spikes per second.

We can also calculate:

- Mean membrane voltage.
- Population activation.
- Spike synchrony.
- Recurrent input strength.
- Excitatory/inhibitory balance.

## **Operation 3.8: Simulate recurrent interactions**

The model should not only simulate independent neurons.

Populations must influence each other.

For example:

\\[ V1\rightarrow V2 \\]

\\[ V2\rightarrow V4 \\]

\\[ V4\rightarrow VWFA \\]

But also:

\\[ VWFA\rightarrow V4 \\]

And:

\\[ IFG\rightarrow MTG \\]

These feedback connections make the model recurrent.

A general population model can be written as:

\\[ \tau_i\frac{d\mathbf{x}\_i}{dt} = -\mathbf{x}\_i+ \phi\left( \sum_j W\_{ij}\mathbf{x}\_j+ \mathbf{I}\_i \right) \\]

Where:

- \\(\mathbf{x}\_i\\): activity of region \\(i\\).
- \\(W\_{ij}\\): connection matrix.
- \\(\phi\\): nonlinear activation function.
- \\(\tau_i\\): characteristic activity time constant.

**Output of Operation 3**

**Simulated neural activity**

- Membrane potential traces.
- Spike trains.
- Firing rates.
- Synaptic activity.
- Population activation.
- Recurrent network activity.
- Neural temporal dynamics.

Important: the model should maintain separate functional and biological tracks. The functional recognition result should not automatically be changed just because the simulated neurons fired differently. Biological activity can be compared with functional outputs and eventually used as a constraint when the model is experimentally fitted.

## **Objective**

Organize the simulated visual populations according to the known hierarchical organization of the visual system.

The visual system processes information at several levels.

Early stages represent simple visual properties. Higher stages construct increasingly complex representations.

A useful simplified pathway is:

\\[ Retina\rightarrow LGN\rightarrow V1 \rightarrow V2\rightarrow V4 \rightarrow Ventral\ Temporal\ Cortex \\]

This is not a complete wiring diagram. There are recurrent connections, bypass connections, and interactions between visual pathways.&#x20;

[image](https://www.google.com/s2/favicons?domain=https://jci.org\&sz=32)

## **Operation 4.1: Construct biological visual populations**

Define:

| Population              | Primary computational responsibility                               |
| ----------------------- | ------------------------------------------------------------------ |
| Retina                  | Light and contrast-sensitive encoding                              |
| LGN                     | Visual signal transmission and receptive-field processing          |
| V1                      | Orientation, spatial frequency and local visual features           |
| V2                      | More complex local feature combinations and contextual information |
| V4                      | Shape, contour and more integrated visual properties               |
| Ventral temporal cortex | Higher-level object and visual form representations                |
| Dorsal visual system    | Spatial relationships, attention and visually guided processing    |

These are simplified functional assignments, not exclusive responsibilities.

## **Operation 4.2: Define hierarchical connectivity**

Construct an adjacency matrix:

\\[ \mathbf{W}= \begin{bmatrix} W\_{11}&W\_{12}&\cdots\\\ W\_{21}&W\_{22}&\cdots\\\ \vdots&\vdots&\ddots \end{bmatrix} \\]

Each value represents a modeled connection strength.

A simple feed-forward connection:

\\[ \mathbf{x}\_{V2}= f(W\_{V1,V2}\mathbf{x}\_{V1}) \\]

A recurrent implementation:

\\[ \mathbf{x}\_{V1}(t+1)= f( W\_{V1,V1}\mathbf{x}\_{V1}(t) + W\_{V2,V1}\mathbf{x}\_{V2}(t) ) \\]

This lets higher-level information influence earlier processing.

## **Operation 4.3: Increase receptive-field complexity**

The receptive field generally becomes more complex across hierarchical visual processing.

A simplified progression:

\\[ V1:\text{oriented edges} \\]

\\[ V2:\text{combinations of local features} \\]

\\[ V4:\text{contours and shape properties} \\]

\\[ Ventral\ Temporal:\text{complex visual representations} \\]

Mathematically, each level produces a transformed representation:

\\[ h_l= \phi(W_l\*h\_{l-1}+b_l) \\]

Where:

- \\(h_l\\): representation at level \\(l\\).
- \\(W_l\\): transformation weights.
- \\(b_l\\): bias.
- \\(\phi\\): activation function.

The star denotes convolution for spatially structured inputs.

## **Operation 4.4: Transform retinotopic representations**

Early visual regions encode visual information in relation to retinal location.

Higher-level reading representations increasingly support position-tolerant representations.

The transformation can be approximated as:

\\[ R\_{retinotopic} \rightarrow R\_{position-tolerant} \\]

However, position information is not simply discarded. Letter order and spatial relationships still matter.

Recent research using fMRI and MEG has examined this transition from location-specific visual representations toward more abstract ordinal letter-position coding.&#x20;

pmc.ncbi.nlm.nih.gov+1



## **Operation 4.5: Integrate visual attention**

The model should include spatial attention.

A simple attention-weighted representation:

\\[ \mathbf{x}\_{attention} = \sum_i\alpha_i\mathbf{x}\_i \\]

Where:

\\[ \alpha_i= \frac{e^{s_i}} {\sum_j e^{s_j}} \\]

Higher weights mean that a particular region or visual feature receives greater processing priority.

This is particularly important when the text contains several characters or words.

**Output of Operation 4**

A hierarchical visual representation that preserves:

- Visual feature information.
- Spatial information.
- Increasing feature complexity.
- Recurrent top-down interactions.
- Attention-dependent activity.

# **Operation 5: Biological VWFA hierarchy**

[researchgate.net](https://www.researchgate.net/figure/Regions-of-the-reading-brain_fig2_330325436?utm_source=chatgpt.com)

## **Objective**

Simulate the biological hierarchy involved in transforming visual character sequences into orthographic word representations.

The Visual Word Form Area (VWFA) is associated with visual word recognition and is located in the left ventral occipitotemporal region in typical skilled readers.

Importantly, the VWFA should not be modeled as one homogeneous unit that recognizes every word instantaneously.

Research has identified posterior-to-anterior differences in the complexity of representations along the occipitotemporal reading pathway. The precise representational roles of subregions remain an active research topic.&#x20;

[image](https://www.google.com/s2/favicons?domain=https://pubmed.ncbi.nlm.nih.gov\&sz=32)

pubmed.ncbi.nlm.nih.gov+2



## **Operation 5.1: Construct posterior visual orthographic populations**

**Purpose**

Represent relatively elementary orthographic patterns.

Possible representations:

- Individual strokes.
- Individual letters.
- Letter identity.
- Letter position.
- Local combinations of letters.

Define:

\\[ H\_{posterior}= f(V1,V2,V4) \\]

The posterior representation receives increasingly structured visual information.

## **Operation 5.2: Construct intermediate orthographic populations**

**Purpose**

Combine individual graphemes into larger orthographic units.

Examples:

- Bigrams.
- Trigrams.
- Frequent letter combinations.
- Morpheme-like visual patterns.

For a word:

\\[ WORD \\]

The model can create:

\\[ WO,\ OR,\ RD \\]

And:

\\[ WOR,\ ORD \\]

These are overlapping sublexical representations.

An abstract representation can be calculated using:

\\[ h\_{bigram}(i)= f(W\_{bigram}[g_i,g\_{i+1}]) \\]

This allows the system to recognize repeated combinations of letters.

## **Operation 5.3: Construct anterior lexical representations**

**Purpose**

Integrate orthographic patterns into more complete lexical representations.

For example:

\\[ WOR+ORD \rightarrow WORD \\]

A candidate lexical representation can be calculated as:

\\[ S(w)= \sum_i \alpha_i \operatorname{Match}(h_i,\mu\_{w,i}) \\]

Where:

- \\(h_i\\): activated sublexical representation.
- \\(\mu\_{w,i}\\): learned word template.
- \\(\alpha_i\\): feature importance.

The lexical probability can be calculated as:

\\[ P(w|G)= \operatorname{Softmax}(S(w)) \\]

Here \\(G\\) is the complete grapheme sequence.

## **Operation 5.4: Preserve word order**

This operation is essential for accurate reading.

Compare:

\\[ FORM\quad FROM \\]

Their grapheme inventories are identical.

Their order is different.

Therefore, lexical recognition must evaluate:

\\[ P(g_1,g_2,\ldots,g_n) \\]

Rather than:

\\[ P(\\{g_1,g_2,\ldots,g_n\\}) \\]

The first represents an ordered sequence. The second represents an unordered collection.

## **Operation 5.5: Develop visual invariance**

The system must recognize a familiar word despite changes in:

- Font.
- Character size.
- Letter case.
- Retinal position.
- Minor visual distortion.

A possible mathematical approximation:

\\[ S(w)= \sum\_{T\in\mathcal{T}} P(T) \operatorname{Match}(T(G),\mu_w) \\]

Where \\(\mathcal{T}\\) represents possible transformations of the written input.

The goal is to learn which visual changes preserve the identity of a written word.

## **Operation 5.6: Learn the hierarchy through reading experience**

The model should not assume that the entire reading hierarchy is genetically preconfigured.

It should allow repeated exposure to written words to change the connection weights between visual and linguistic populations.

For example:

\\[ W\_{new}= W\_{old}+\eta\Delta W \\]

A more specific supervised approximation is:

\\[ \Delta W= \eta (\mathbf{y}-\hat{\mathbf{y}}) \mathbf{x}^{T} \\]

Where:

- \\(\mathbf{x}\\): incoming orthographic representation.
- \\(\hat{\mathbf{y}}\\): predicted lexical representation.
- \\(\mathbf{y}\\): target representation.

**Output of Operation 5**

- Posterior orthographic representation.
- Intermediate letter-combination representation.
- Anterior lexical representation.
- Word identity probabilities.
- Invariant orthographic representation.
- Experience-dependent VWFA connection parameters.

## **Objective**

Connect the visual word recognition system to the major language and semantic networks.

The three important anatomical components in this operation are:

- IFG: Inferior Frontal Gyrus.
- MTG: Middle Temporal Gyrus.
- ATL: Anterior Temporal Lobe.

They should be represented as separate but interconnected populations.

The anterior temporal region is strongly associated with an integrative semantic representation, while inferior frontal and posterior temporal regions participate in semantic retrieval, selection, control and combinatorial processing. The precise roles depend on the task and subregion.&#x20;

## **Operation 6.1: Construct the anatomical network**

Create:

\\[ \mathcal{G}\_{language}= (V,E,W) \\]

Where:

\\[ V= \\{ VWFA,MTG,IFG,ATL,STG,AG \\} \\]

Additional nodes may include:

- Posterior superior temporal gyrus.
- Angular gyrus.
- Supramarginal gyrus.
- Inferior parietal regions.

The connections represent communication between regions.

## **Operation 6.2: Construct the VWFA-to-MTG pathway**

**Purpose**

Transmit orthographic and lexical information toward temporal language regions.

For example:

\\[ \mathbf{x}\_{MTG}= f( W\_{VWFA,MTG} \mathbf{x}\_{VWFA} ) \\]

The MTG population may contribute to retrieving relevant lexical information and integrating lexical-syntactic or semantic associations, depending on the specific subregion and model.

## **Operation 6.3: Construct the MTG-to-IFG pathway**

**Purpose**

Transmit linguistic information to frontal control and integration mechanisms.

A possible model:

\\[ \mathbf{x}\_{IFG}= f( W\_{MTG,IFG}\mathbf{x}\_{MTG} + W\_{context}\mathbf{x}\_{context} ) \\]

The IFG can be modeled as a region contributing to:

- Selection among competing interpretations.
- Retrieval regulation.
- Sentence-level integration.
- Unification of information.
- Resolution of linguistic ambiguity.

For example, when a word has multiple possible grammatical or semantic interpretations, this network can influence their relative activation.

## **Operation 6.4: Construct ATL semantic representations**

**Purpose**

Integrate information from multiple conceptual sources.

For instance, the word:

"Knife"

may activate:

- Physical object.
- Cutting tool.
- Kitchen object.
- Instrument.
- Artifact.

The ATL representation combines distributed information associated with the concept.

A computational representation:

\\[ \mathbf{C}\_{ATL} = f( W_1\mathbf{x}\_{visual} + W_2\mathbf{x}\_{auditory} + W_3\mathbf{x}\_{semantic} + W_4\mathbf{x}\_{context} ) \\]

The semantic representation is not limited to its spelling or pronunciation.

## **Operation 6.5: Integrate distributed semantic features**

Represent the concept as:

\\[ C= [c_1,c_2,\ldots,c_n] \\]

For example:

\\[ C\_{knife}= [ physical=1, tool=1, edible=0, cutting=1, artifact=1 ] \\]

A real semantic network would contain much richer representations.

This representation is an interpretable computational approximation.

## **Operation 6.6: Perform recurrent network integration**

Information should travel in both directions.

For example:

\\[ VWFA\rightarrow MTG\rightarrow IFG \\]

But also:

\\[ IFG\rightarrow MTG \\]

\\[ ATL\rightarrow MTG \\]

\\[ MTG\rightarrow VWFA \\]

The last pathway is a simplified functional feedback connection; it should not be interpreted as a claim that all these exact direct anatomical connections have equal strength.

Use a recurrent update:

\\[ \mathbf{x}\_i(t+1)= \phi\left( W\_{ii}\mathbf{x}\_i(t) + \sum_jW\_{ji}\mathbf{x}\_j(t) + I_i(t) \right) \\]

This allows the language network to modify the processing of an incoming word based on previously activated concepts and sentence context.

## **Operation 6.7: Calculate network communication**

For each region, calculate:

- Activity.
- Incoming signal strength.
- Outgoing signal strength.
- Recurrent influence.
- Integration error.
- Functional connectivity.

One possible connectivity measure is:

\\[ FC\_{ij}= \operatorname{Corr}(x_i(t),x_j(t)) \\]

This measures statistical association between activity time series.

For directed network modeling, use an explicit transition model:

\\[ \mathbf{x}\_{t+1}= A\mathbf{x}\_t+B\mathbf{u}\_t \\]

Where \\(A\\) represents modeled network interactions.

A distributed language-network representation containing:

# **Operation 8: EEG/MEG signal modeling**

## **Objective**

Transform simulated neural activity into signals that can be compared with actual EEG and MEG recordings.

This is a major scientific step.

The previous operations model activity inside neural populations.

However, EEG and MEG do not directly record the complete activity of individual simulated neurons.

They measure signals produced by the summed electromagnetic effects of neural currents, with EEG primarily measuring scalp voltage and MEG measuring magnetic fields.

Source estimation requires a forward model and an inverse model.&#x20;

[image](https://www.google.com/s2/favicons?domain=https://pmc.ncbi.nlm.nih.gov\&sz=32)

pmc.ncbi.nlm.nih.gov+1



## **Operation 8.1: Construct neural source signals**

For each simulated region, define:

\\[ s_i(t) \\]

These signals can be derived from the simulated neural dynamics.

For example:

\\[ s_i(t)= \sum_j w_j I\_{syn,j}(t) \\]

Where \\(I\_{syn,j}\\) represents the synaptic current associated with neurons in the region.

For EEG/MEG modeling, the most relevant simplified source is often the synchronized postsynaptic activity of appropriately oriented neuronal populations, rather than simply counting output spikes.

The model should therefore distinguish:

- Spike activity.
- Synaptic currents.
- Population-level source activity.

## **Operation 8.2: Construct a forward model**

**Purpose**

Predict the sensor measurements generated by the simulated neural sources.

For EEG:

\\[ \boxed{ \mathbf{y}\_{EEG}(t)= L\_{EEG}\mathbf{s}(t)+\epsilon(t) } \\]

For MEG:

\\[ \boxed{ \mathbf{y}\_{MEG}(t)= L\_{MEG}\mathbf{s}(t)+\epsilon(t) } \\]

Where:

- \\(\mathbf{s}(t)\\): neural source activity.
- \\(L\\): lead-field or sensor-source transformation matrix.
- \\(\mathbf{y}(t)\\): sensor measurements.
- \\(\epsilon(t)\\): noise.

The lead-field matrix depends on:

- Source locations.
- Source orientations.
- Head geometry.
- Tissue conductivity for EEG.
- Sensor positions and configurations.

## **Operation 8.3: Construct an inverse model**

**Purpose**

Estimate the neural sources from recorded EEG/MEG measurements.

One possible regularized solution:

\\[ \hat{\mathbf{s}}= \arg\min\_{\mathbf{s}} \left[ \\|\mathbf{y}-L\mathbf{s}\\|\_2^2 + \lambda\\|R\mathbf{s}\\|\_2^2 \right] \\]

Where:

- First term: mismatch between predicted and measured signals.
- Second term: regularization.
- \\(\lambda\\): regularization strength.
- \\(R\\): constraint matrix.

This problem is generally ill-posed, so source reconstruction depends on assumptions and model choices.

## **Operation 8.4: Model event-related potentials**

For repeated presentations of a stimulus, align EEG epochs to stimulus onset.

Let:

\\[ E_k(t) \\]

represent trial \\(k\\).

Calculate:

\\[ ERP(t)= \frac{1}{N} \sum\_{k=1}^{N}E_k(t) \\]

This estimates the time-locked neural response.

The model can predict:

- Early visual responses.
- Later orthographic processing.
- Lexical processing.
- Semantic processing.
- Attention-related responses.

For example, visual word processing can be studied through time-locked EEG and MEG responses.

## **Operation 8.5: Model oscillatory activity**

Neural processes also have time-frequency characteristics.

Use a wavelet transform:

\\[ W(f,t)= \int x(\tau)\psi^\*\_{f,t}(\tau)d\tau \\]

Calculate power:

\\[ Power(f,t)=|W(f,t)|^2 \\]

This allows comparisons involving oscillatory power and temporal dynamics.

Possible frequency ranges to investigate include:

- Theta.
- Alpha.
- Beta.
- Gamma.

Their interpretation depends on the task and experimental design.

## **Operation 8.6: Compare predicted and actual electrophysiological signals**

Define:

\\[ L\_{EEG}= \\|\mathbf{y}\_{real}-\mathbf{y}\_{predicted}\\|\_2^2 \\]

Similarly:

\\[ L\_{MEG}= \\|\mathbf{y}\_{real}-\mathbf{y}\_{predicted}\\|\_2^2 \\]

The comparison can also include:

- ERP peak amplitude.
- ERP peak latency.
- Time-frequency power.
- Source activity.
- Cross-region temporal relationships.

**Output of Operation 8**

- Simulated EEG sensor signals.
- Simulated MEG sensor signals.
- Neural source estimates.
- ERP waveforms.
- Time-frequency representations.
- EEG/MEG prediction errors.

# **Operation 9: fMRI comparison**

[What is BOLD fMRI? — American Society of Functional Neuroradiology](https://images.openai.com/static-rsc-4/1p-FUh-M_4lVlIF9wmKrYdy_b7zXsiRaMzUA1mSINRAijgT3_bVDZWz1ANZjybhZwqTEs2LCONkHZV7PP6dOuGG9x3jkNK8LJgI3ollKebd2pVXzSVb2LDNZ1CJx56g55odmc__OaRBsk0VQ1b_IxSc2c9qo4PLHlWa1yOsjKIA?purpose=inline)

[asfnr.org](https://www.asfnr.org/what-is-bold-fmri?utm_source=chatgpt.com)

## **Objective**

Compare the simulated brain networks with the slower hemodynamic responses measured by functional MRI.

EEG and MEG provide information with high temporal resolution.

fMRI provides a different type of evidence: changes in the blood-oxygen-level-dependent signal associated indirectly with neural activity.

Therefore, fMRI cannot be compared directly with simulated membrane voltages or individual spike timings.

The model must transform neural activity into an expected BOLD response.

## **Operation 9.1: Aggregate regional neural activity**

For a given brain region:

\\[ n_r(t)= \frac{1}{N_r} \sum\_{i=1}^{N_r}a_i(t) \\]

Where:

- \\(a_i(t)\\): activity of neuron or model unit \\(i\\).
- \\(N_r\\): number of simulated units in region \\(r\\).

This creates a regional activity signal.

## **Operation 9.2: Construct a hemodynamic response function**

The hemodynamic response function (HRF) describes the temporal relationship between neural activity and the resulting BOLD signal.

The model uses:

\\[ h(t) \\]

as an approximation of the HRF.

## **Operation 9.3: Convolve neural activity with the HRF**

Calculate:

\\[ B_r(t)= (h\*n_r)(t) \\]

Expanded:

\\[ B_r(t)= \int\_{-\infty}^{\infty} h(\tau)n_r(t-\tau)d\tau \\]

This transformation produces a slower regional signal.

It provides a bridge between neural dynamics and fMRI observations.

## **Operation 9.4: Construct an fMRI design matrix**

For an experiment, define regressors corresponding to:

- Letter processing.
- Word recognition.
- Pseudoword recognition.
- Semantic tasks.
- Phonological tasks.
- Sentence comprehension.
- Control conditions.

The design matrix is:

\\[ X= [x_1,x_2,\ldots,x_p] \\]

The predictors are typically convolved with the HRF before fitting the fMRI data.

## **Operation 9.5: Perform general linear model estimation**

A common model is:

\\[ \boxed{ Y=X\beta+\epsilon } \\]

Where:

- \\(Y\\): measured fMRI data.
- \\(X\\): experimental design matrix.
- \\(\beta\\): estimated regression coefficients.
- \\(\epsilon\\): residual noise.

The ordinary least-squares solution is:

\\[ \hat{\beta}= (X^TX)^{-1}X^TY \\]

When the matrix is not invertible or when regularization is needed, alternative estimators are used.

This GLM approach is standard in fMRI analysis.&#x20;

[image](https://www.google.com/s2/favicons?domain=https://www.fil.ion.ucl.ac.uk\&sz=32)

SPM Documentation+1



## **Operation 9.6: Compare regional representations**

Define regions of interest:

- V1.
- V2.
- V4.
- VWFA.
- IFG.
- MTG.
- ATL.
- Auditory cortical regions.

Compare model predictions with measured patterns within each region.

A useful method is representational similarity analysis (RSA).

Construct a model representational dissimilarity matrix:

\\[ D\_{model}(i,j)= d(\mathbf{x}\_i,\mathbf{x}\_j) \\]

Construct a corresponding brain matrix:

\\[ D\_{brain}(i,j)= d(\mathbf{b}\_i,\mathbf{b}\_j) \\]

Then compare:

\\[ r= \operatorname{Corr} \left( D\_{model},D\_{brain} \right) \\]

This tests whether the model represents stimuli with a geometry similar to the geometry observed in the brain.

RSA can be applied to fMRI, EEG, MEG, and other neural measurements.&#x20;

[image](https://www.google.com/s2/favicons?domain=https://pmc.ncbi.nlm.nih.gov\&sz=32)

pmc.ncbi.nlm.nih.gov



**Output of Operation 9**

- Predicted regional BOLD signals.
- GLM estimates.
- Regional activation comparisons.
- Representational similarity matrices.
- Model-to-fMRI discrepancy measures.

## **Objective**

Determine whether the brain regions and connections proposed by the model are actually necessary for specific reading and language functions.

This is different from comparing normal brain activation.

fMRI activity tells us that a region participates in a task, but does not establish by itself that the region is necessary for performing that task.

Lesion studies provide another type of evidence by relating damage to brain tissue or connections to changes in behavior.

Network-based lesion-symptom mapping has been used to investigate reading-related networks in brain-damaged patients.&#x20;

[image](https://www.google.com/s2/favicons?domain=https://pmc.ncbi.nlm.nih.gov\&sz=32)

pmc.ncbi.nlm.nih.gov



## **Operation 10.1: Construct a healthy reference network**

Start with the previously constructed network:

\\[ G=(V,E,W) \\]

For example:

\\[ V= \\{ VWFA,MTG,IFG,ATL,STG \\} \\]

Define expected functional responsibilities.

| Region | Model responsibility                         |
| ------ | -------------------------------------------- |
| VWFA   | Orthographic processing                      |
| MTG    | Lexical retrieval and linguistic integration |
| IFG    | Linguistic integration and control           |
| ATL    | Semantic representation                      |
| STG    | Auditory and phonological processing         |

These are hypotheses to test, not absolute one-region-one-function assignments.

## **Operation 10.2: Represent patient lesions**

For patient \\(i\\), represent lesion status for anatomical location \\(v\\) as:

\\[ L\_{iv}\in\\{0,1\\} \\]

Where:

- 1: damaged.
- 0: undamaged.

For a more detailed model:

\\[ L\_{iv}\in[0,1] \\]

This allows partial lesion involvement.

Also represent damaged white-matter connections.

## **Operation 10.3: Simulate virtual lesions**

The computational model should undergo equivalent interventions.

For example, to model a VWFA lesion:

\\[ \mathbf{x}\_{VWFA}\leftarrow 0 \\]

Or reduce its activation:

\\[ \mathbf{x}\_{VWFA}^{lesion} = (1-\rho)\mathbf{x}\_{VWFA} \\]

Where \\(\rho\\) represents the degree of impairment.

For a connection lesion:

\\[ W\_{ij}\leftarrow 0 \\]

This allows the model to distinguish between damage to a brain region and damage to communication between regions.

## **Operation 10.4: Calculate behavioral consequences**

Run the original reading tasks:

- Single-letter recognition.
- Grapheme recognition.
- Word recognition.
- Pseudoword reading.
- Phonological conversion.
- Semantic comprehension.

After the virtual lesion, calculate:

\\[ \Delta Accuracy= Accuracy\_{normal}-Accuracy\_{lesion} \\]

And:

\\[ \Delta RT= RT\_{lesion}-RT\_{normal} \\]

## **Operation 10.5: Compare with real patient performance**

Collect patient behavioral measurements.

For example:

| Measurement                 | Purpose                     |
| --------------------------- | --------------------------- |
| Letter recognition accuracy | Visual character processing |
| Word-reading accuracy       | Orthographic recognition    |
| Pseudoword reading          | Sublexical decoding         |
| Reading time                | Processing efficiency       |
| Naming performance          | Word retrieval              |
| Comprehension accuracy      | Semantic processing         |

Then examine whether the predicted effects resemble the observed deficits.

## **Operation 10.6: Perform lesion-symptom statistical analysis**

For each patient:

\\[ Y_i= \beta_0+ \sum_v\beta_vL\_{iv} + \mathbf{C}\_i\boldsymbol{\gamma} +\epsilon_i \\]

Where:

- \\(Y_i\\): behavioral score.
- \\(L\_{iv}\\): lesion status.
- \\(\mathbf{C}\_i\\): control variables.
- \\(\beta_v\\): relationship between damage at location \\(v\\) and performance.

For network-level analysis, define graph efficiency:

\\[ E\_{global}= \frac{1}{N(N-1)} \sum\_{i\ne j} \frac{1}{d\_{ij}} \\]

Where \\(d\_{ij}\\) is the shortest path length between regions.

This helps test whether disruption to a network affects reading more than disruption to one isolated anatomical location.

## **Operation 10.7: Validate predicted dissociations**

The model should predict different patterns of impairment following different lesions.

For example:

- Visual orthographic disruption should affect word-form processing.
- Dorsal pathway disruption may affect phonological decoding.
- Semantic network disruption may affect conceptual knowledge.
- Frontal control disruption may affect demanding language selection and integration.

The prediction must be assessed against patient data rather than accepted merely because it seems anatomically plausible.

**Output of Operation 10**

- Virtual lesion results.
- Predicted impairment profiles.
- Real patient impairment profiles.
- Lesion-symptom relationships.
- Network disconnection effects.
- Evidence for necessary versus supporting network components.

# **Operation 11: TMS-based validation**

[rTMS Treatment: Effective TMS Therapy](https://images.openai.com/static-rsc-4/uhRqWBa5gR2xte1m4K2uzzbHaXOfULhiWfSJcxKNhNdligyXH70xNo7mKAjDG3298acuxje_aG1-45TxOMBUjWth1I9EFhKXtPD0WnbmAKqhbnGJCZySE0QaWmcn4fDaGzflYB1LOrMxXkCh8O_RLEmWM7RidDvclr8DiBeXgvA?purpose=inline)

[smarttms.co.uk](https://www.smarttms.co.uk/tms-treatment/?utm_source=chatgpt.com)

## **Objective**

Test the causal contribution of selected brain regions by temporarily perturbing neural activity using transcranial magnetic stimulation.

Lesion studies examine naturally occurring damage.

TMS provides an experimental approach for perturbing a selected cortical area under controlled research conditions.

TMS studies have reported effects on reading behavior following stimulation of ventral visual, dorsal phonological, and anterior semantic-related reading circuitry.&#x20;

[image](https://www.google.com/s2/favicons?domain=https://pmc.ncbi.nlm.nih.gov\&sz=32)

pmc.ncbi.nlm.nih.gov+1



## **Operation 11.1: Select candidate anatomical targets**

Possible targets include:

| Target                     | Hypothesized role                    |
| -------------------------- | ------------------------------------ |
| Left VWFA region           | Visual word processing               |
| Posterior MTG              | Lexical-syntactic retrieval          |
| IFG                        | Linguistic integration and selection |
| Temporal semantic regions  | Semantic retrieval                   |
| Posterior temporal regions | Phonological processing              |

The exact target must be defined using the individual participant's anatomy and the experimental question.

## **Operation 11.2: Define experimental conditions**

Construct at least three comparison conditions:

1. Active stimulation at the target region.
2. Sham stimulation.
3. Active stimulation at a suitable control region.

The model needs these comparison conditions to distinguish specific target effects from nonspecific stimulation effects.

## **Operation 11.3: Define stimulation timing**

If the objective is to determine when a region contributes to processing, use time-sensitive stimulation protocols.

For example, stimulation can be scheduled relative to:

\\[ t\_{stimulus} \\]

The experimental timing should be chosen according to the process being investigated and prior electrophysiological evidence.

Different time windows may correspond to different processing stages.

## **Operation 11.4: Simulate the TMS intervention**

Introduce a perturbation into the computational neural network.

One simple model:

\\[ I_i^{TMS}(t)= I_i(t)+P(t) \\]

Where \\(P(t)\\) represents a perturbation pulse.

Alternatively, perturb population activation:

\\[ x_i^{TMS}(t)= (1-\kappa)x_i(t) \\]

Where:

\\[ 0\leq\kappa\leq1 \\]

This represents a simplified temporary reduction in functional availability.

Important: TMS does not always simply suppress activity. Its effects depend on stimulation parameters, location, brain state and network interactions. The model must allow different perturbation patterns.

## **Operation 11.5: Calculate behavioral changes**

Measure:

- Word recognition accuracy.
- Reading speed.
- Lexical decision reaction time.
- Semantic judgment reaction time.
- Phonological decoding accuracy.
- Eye movement changes.

For example:

\\[ \Delta RT= RT\_{TMS}-RT\_{sham} \\]

And:

\\[ \Delta Accuracy= Accuracy\_{sham}-Accuracy\_{TMS} \\]

## **Operation 11.6: Compare experimental and simulated results**

Use an effect estimate:

\\[ E\_{observed}= \operatorname{Effect}(Target,Control) \\]

\\[ E\_{model}= \operatorname{Effect}(VirtualTarget,VirtualControl) \\]

Then calculate:

\\[ L\_{TMS}= (E\_{observed}-E\_{model})^2 \\]

A more complete statistical model can include subject and stimulus random effects:

\\[ RT\_{ij}= \beta_0+ \beta_1TMS_i+ \beta_2Condition_j+ \beta_3(TMS_i\times Condition_j) +u_i+v_j+\epsilon\_{ij} \\]

Where:

- \\(u_i\\): participant-specific effect.
- \\(v_j\\): item-specific effect.

An important validation example is the examination of IFG and MTG contributions to resolving syntactic ambiguity. A TMS study has reported evidence for IFG involvement in sentence-level unification during online reading.&#x20;

[image](https://www.google.com/s2/favicons?domain=https://pubmed.ncbi.nlm.nih.gov\&sz=32)

pubmed.ncbi.nlm.nih.gov



**Output of Operation 11**

- Simulated perturbation results.
- Experimental TMS effects.
- Region-specific behavioral consequences.
- Timing-dependent processing effects.
- Model-to-experiment causal discrepancy.

TMS experiments require qualified research teams, appropriate participant screening, stimulation safety procedures, and controlled protocols. The software should model experimental effects rather than attempt to prescribe stimulation parameters for individuals.

## **Objective**

Determine whether the completed neurocomputational model actually predicts the behavior and neural measurements of people reading real text.

This is the most important validation operation.

A model should not be considered biologically successful simply because its simulated network contains regions with familiar anatomical names.

It must make measurable predictions that agree with independent human data.

Collect or use previously published data containing human reading measurements.

ZuCo provides simultaneous EEG and eye-tracking measurements while adults read natural sentences. Its newer NEMAR-hosted release includes 128-channel EEG and eye-tracking recordings.&#x20;

## **Operation 12.2: Construct human reading measurements**

The model should predict multiple behavioral quantities.

| Human measurement              | What the model should predict            |
| ------------------------------ | ---------------------------------------- |
| Letter recognition accuracy    | Accuracy of grapheme populations         |
| Word recognition accuracy      | Lexical representation accuracy          |
| Lexical decision reaction time | Difficulty of identifying a word         |
| Reading aloud accuracy         | Orthography-to-phonology mapping         |
| First fixation duration        | Early word-processing difficulty         |
| Gaze duration                  | Continued processing of a word           |
| Regression probability         | Reinspection and processing difficulty   |
| Sentence reading time          | Overall comprehension cost               |
| Comprehension accuracy         | Quality of final sentence interpretation |

For eye movement modeling, a possible empirical relationship is:

\\[ RT\_{word}= \beta_0+ \beta_1Surprisal+ \beta_2Frequency+ \beta_3Length+ \beta_4VisualComplexity+ \epsilon \\]

The model can estimate how these variables contribute to processing difficulty.

However, eye movements require their own attention and oculomotor modeling. They should not be treated as a direct, exact measurement of neural activation.

## **Operation 12.3: Compare predicted reading accuracy**

For \\(N\\) observations:

\\[ Accuracy= \frac{N\_{correct}}{N} \\]

Compare:

\\[ Accuracy\_{human} \\]

With:

\\[ Accuracy\_{model} \\]

For continuous measures such as reading time, use mean absolute error:

\\[ MAE= \frac{1}{N} \sum\_{i=1}^{N} |y_i-\hat y_i| \\]

And root mean squared error:

\\[ RMSE= \sqrt{ \frac{1}{N} \sum_i(y_i-\hat y_i)^2 } \\]

## **Operation 12.4: Compare neural temporal responses**

For EEG and MEG:

Compare:

- Peak latency.
- Peak amplitude.
- ERP shape.
- Time-frequency patterns.
- Source activity.
- Temporal relationships between regions.

A possible waveform loss:

\\[ L\_{waveform}= \frac{1}{T} \sum_t (y\_{human}(t)-y\_{model}(t))^2 \\]

The model should also test whether its predicted signal changes in the correct direction between experimental conditions.

## **Operation 12.5: Compare brain-region representations**

Using fMRI:

Compare the representational dissimilarity matrices:

\\[ RDM\_{model} \\]

And:

\\[ RDM\_{human} \\]

Calculate:

\\[ Similarity= \operatorname{Corr} (RDM\_{model},RDM\_{human}) \\]

This can test whether the model develops visual and linguistic representations that resemble those recorded in the brain.

## **Operation 12.6: Separate training data from validation data**

This is essential.

Divide data into:

\\[ D= D\_{training} \cup D\_{validation} \cup D\_{test} \\]

Where:

- Training: Used to estimate model parameters.
- Validation: Used to select model configurations.
- Test: Used only for independent evaluation.

Also use leave-subject-out validation:

\\[ Subjects\_{training} \cap Subjects\_{test} = \varnothing \\]

This reduces the chance that the model is simply memorizing individual participants.

For cross-linguistic validation, train on selected languages and test on a language not used for parameter fitting.

## **Operation 12.7: Compare against simpler alternative models**

A biological model must outperform appropriate alternatives, or provide additional explanatory value.

Potential comparison models:

1. Gabor features without neural dynamics.
2. Static grapheme prototype recognition.
3. Feed-forward visual hierarchy.
4. Recurrent population model.
5. VWFA hierarchy without IFG/MTG/ATL integration.
6. Complete multimodal network.

This is called an ablation analysis.

For example:

\\[ \Delta L\_{VWFA}= L\_{without\ VWFA}-L\_{complete} \\]

This tests how much explanatory benefit is gained by including the VWFA component.

## **Operation 12.8: Generate a final scientific validation report**

For every experiment, report:

- Human behavioral scores.
- Model behavioral scores.
- Neural measurement correspondence.
- Lesion predictions.
- TMS predictions.
- Generalization to new participants.
- Generalization to new stimuli.
- Generalization to new languages.
- Uncertainty intervals.
- Model limitations.

A model should not be declared biologically accurate merely because it produces a visually convincing simulation.

**Output of Operation 12**

An empirical evaluation of whether the simulated architecture predicts actual human reading behavior and neural measurements.

# **3. Integrating all 12 operations into one master algorithm**

We can now combine the operations into one integrated neurocomputational system.

The overall processing principle is:

\\[ \boxed{ \text{Visual/Auditory Input} \rightarrow \text{Feature Encoding} \rightarrow \text{Population Activation} \rightarrow \text{Neural Dynamics} \rightarrow \text{Hierarchical Representation} \rightarrow \text{Language Integration} \rightarrow \text{Neural Measurements} \rightarrow \text{Biological Validation} } \\]

However, EEG/MEG, fMRI, lesion, and TMS operations are primarily measurement and validation pathways. They are not processing stages that a person must undergo every time they read a sentence.

# **4. Mathematical operations across the complete architecture**

The 12 operations can be understood through nine important mathematical families.

| Mathematical family              | Main applications                       |
| -------------------------------- | --------------------------------------- |
| Convolution                      | Gabor filtering and receptive fields    |
| Feature vectors                  | Grapheme and word representations       |
| Similarity and distance          | Prototype matching and recognition      |
| Population coding                | Distributed neural representations      |
| Differential equations           | Membrane and neural population dynamics |
| Graph theory                     | Anatomical network connectivity         |
| Signal processing                | EEG/MEG and auditory analysis           |
| Statistical modeling             | fMRI and lesion-symptom analysis        |
| Optimization and causal modeling | TMS and independent model validation    |

## **4.1 Convolution**

\\[ R=I\*g \\]

Used to model local visual receptive fields.

## **4.2 Population activation**

\\[ a_i= \exp\left( -\frac{\\|\mathbf{x}-\boldsymbol{\mu}\_i\\|^2} {2\sigma_i^2} \right) \\]

Used to model how visual feature populations respond to different graphemes.

## **4.3 Neural dynamics**

\\[ C_m\frac{dV}{dt} = -g_L(V-E_L)+I(t) \\]

Used to simulate changing membrane potential.

## **4.4 Recurrent network dynamics**

\\[ \tau\frac{d\mathbf{x}}{dt} = -\mathbf{x}+ \phi(W\mathbf{x}+I) \\]

Used to model interactions across neural populations.

## **4.5 Graph-based integration**

\\[ \mathbf{x}\_{t+1} = A\mathbf{x}\_t+B\mathbf{u}\_t \\]

Used to model signal propagation across anatomical regions.

## **4.6 Signal generation**

\\[ \mathbf{y}(t)=L\mathbf{s}(t)+\epsilon(t) \\]

Used to transform neural source activity into EEG/MEG sensor predictions.

## **4.7 Hemodynamic transformation**

\\[ BOLD(t)=h(t)\*n(t) \\]

Used to transform neural activity into expected fMRI responses.

## **4.8 Statistical model fitting**

\\[ Y=X\beta+\epsilon \\]

Used to estimate relationships between experimental conditions and fMRI signals.

## **4.9 Multi-objective validation**

Finally, the entire model can be optimized using:

\\[ \boxed{ \begin{aligned} L\_{total}={}& \lambda_1L\_{visual} +\lambda_2L\_{grapheme} +\lambda_3L\_{dynamics}\\\ &+\lambda_4L\_{EEG} +\lambda_5L\_{MEG} +\lambda_6L\_{fMRI}\\\ &+\lambda_7L\_{lesion} +\lambda_8L\_{TMS} +\lambda_9L\_{human} +\lambda\_{10}L\_{regularization} \end{aligned} } \\]

The coefficients \\(\lambda_i\\) control the importance of different validation objectives.

A critical precaution: not every term should be fitted simultaneously from the same data. Each experimental modality has different measurement properties, and the parameters should be estimated using appropriate independent training and validation datasets.

## **Important architectural decision**

I recommend maintaining three distinct representations throughout the implementation:

**1. Functional representation**

What the computational model believes the visual or linguistic input represents.

**2. Biological representation**

What the simulated neural populations are doing over time.

**3. Experimental representation**

What EEG, MEG, fMRI, lesion, TMS, and behavioral experiments actually measure.

The three representations should be linked, but never treated as interchangeable.

For example:

A model may recognize a letter correctly while its simulated neural population produces an unrealistic firing pattern. That is a functional success but a biological-modeling problem.

Similarly, a model may reproduce an fMRI activation pattern without correctly predicting the timing of neural activity.

Each type of success must be assessed separately.

## **7. Suggested scientific development order**

I would implement the algorithm in four major development phases.

1. **Phase 1 — Visual and neural foundations**

   Operations 1–3.

   Establish visual feature extraction, distributed grapheme populations, and explicit neural dynamics.
2. **Phase 2 — Anatomical and language integration**

   Operations 4–7.

   Establish hierarchical visual processing, VWFA, IFG/MTG/ATL, and auditory streams.
3. **Phase 3 — Experimental measurement models**

   Operations 8–9.

   Construct EEG/MEG forward models, source estimation, and fMRI response models.
4. **Phase 4 — Biological and behavioral validation**

   Operations 10–12.

   Validate against lesion evidence, TMS experiments, and independent human reading measurements.

**My main recommendation:** Do not begin by making the simulated brain as anatomically complicated as possible. First make each neural population mathematically understandable and independently testable. Then connect populations and test whether the additional connections actually improve predictions of human reading.

This gives BNBEA a measurable scientific objective: not simply to recreate the names and locations of brain regions in Python, but to build a computational system whose internal representations, dynamics, and predicted measurements can be tested against independent biological evidence.
