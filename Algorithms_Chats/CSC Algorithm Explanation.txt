# Controlled Semantic Cognition (CSC): A Complete Brain-Inspired Algorithm

## 1. Understanding the architecture

The **Controlled Semantic Cognition (CSC)** framework explains how the human brain retrieves knowledge from semantic memory and controls that retrieval according to the current task, context, and intention.

The central idea is that understanding something and selecting the appropriate knowledge about it are two related but different operations.

Consider the word **bank**:

- In "I deposited money at the bank," the relevant meaning is a financial institution.
- In "We sat beside the river bank," the relevant meaning is the land beside a river.

The brain must access the available meanings, determine which one fits the current context, amplify the relevant meaning, and prevent the competing meaning from dominating the interpretation.

CSC proposes two interacting systems:

1. **Semantic representation system:** Stores and integrates conceptual knowledge. Its architecture consists of modality-specific sensory and motor regions (spokes) interacting with a multimodal integration region, particularly the anterior temporal lobe (ATL).
2. **Semantic control system:** Dynamically controls which parts of semantic knowledge become accessible and influential. Its important regions include the left inferior frontal gyrus (IFG), posterior middle temporal gyrus (pMTG), and other interacting frontal and temporal regions.

These systems are functionally distinct but cooperate. The ATL does not independently determine which interpretation is appropriate; control mechanisms influence how information is retrieved from the representational system. <Cite refs={["turn247020view1","turn247020view3","turn249362search5"]}/>

The architecture must solve a fundamental problem:

**The brain needs to retrieve enough knowledge to understand a concept without allowing every associated piece of knowledge to interfere with the current task.**

This is particularly important when:
- A word has multiple meanings.
- A weak or unusual association must be retrieved.
- The most familiar association is not the correct one.
- A concept must be interpreted according to an unusual context.
- A task requires suppressing an otherwise dominant interpretation.

For example, pairing *ketchup* with *mustard* is relatively familiar, whereas pairing *ketchup* with *fire extinguisher* because both are red requires more controlled retrieval. Research has found increased involvement of semantic control mechanisms and stronger IFG interactions with colour-related sensory regions in the less conventional task. <Cite refs={["turn249362search4","turn249362search3"]}/>

## 2. Mathematical foundation

Before constructing the algorithm, we need a mathematical language for describing its operations.

These equations are proposed computational abstractions of possible neural computations. They are not measurements of exact equations executed by individual neurons.

| Symbol | Meaning |
|---|---|
| \(C\) | Current concept |
| \(X\) | Sensory and contextual input |
| \(T\) | Current task or intention |
| \(M\) | Semantic memory |
| \(H\) | ATL hub representation |
| \(S_i\) | Modality-specific semantic spoke |
| \(A_i\) | Activation of a semantic feature |
| \(G_i\) | Control gain applied to a feature |
| \(I_i\) | Inhibitory influence |
| \(R_i\) | Relevance of a feature to the task |
| \(W_{ij}\) | Connection strength between representations |
| \(D\) | Semantic control demand |

### Mathematical operation A: Activation propagation

Information spreads through interconnected semantic representations:

\[
A_j(t+1)=
f\left(
\sum_i W_{ij}A_i(t)+B_j
\right)
\]

Here, \(W_{ij}\) represents the influence of one neural population on another, \(B_j\) represents additional input or bias, and \(f\) is a nonlinear activation function.

### Mathematical operation B: Selective gain

The semantic control system changes the influence of particular features:

\[
A_i^{controlled}=G_i A_i
\]

A relevant feature receives stronger gain, while an irrelevant feature receives less gain.

### Mathematical operation C: Competition

Different meanings compete for selection:

\[
P(m_i\mid X,T)=
\frac{\exp(z_i)}
{\sum_j\exp(z_j)}
\]

Here, \(z_i\) is the combined contextual, semantic, and task-related evidence for meaning \(m_i\).

### Mathematical operation D: Inhibition

Irrelevant or competing semantic activity can be reduced:

\[
A_i^{new}=
\max(0,A_i-I_i)
\]

These operations give us the basic mathematical components needed to construct a controlled semantic processing algorithm.

## 3. The complete biological-to-computational algorithm

The algorithm below treats semantic cognition as a recurrent distributed process rather than a rigid sequence of independent brain operations.

Some operations happen in parallel. For example, the ATL and sensory spokes can begin activating conceptual knowledge while frontal regions are interpreting the task. The numbered stages represent the logical dependencies of the computation, not a claim that the brain executes them in a strict serial order.

### Stage 1. Sensory and linguistic input encoding

**Biological objective**

Receive information from the external environment and convert it into neural activity that can activate semantic representations.

Input may come from reading, hearing, vision, touch, or other sensory systems.

For example, when hearing:

"The fisherman sat on the bank."

The auditory system extracts acoustic information and identifies linguistic components that can be used by subsequent processing systems.

Potentially involved regions include auditory cortex, visual processing regions for written words, and the language-processing network.

**Possible mathematical operations**

1. Signal transformation:

\[
X(f)=\sum_{t=0}^{N-1}x(t)e^{-i2\pi ft/N}
\]

A Fourier-like transformation illustrates how a signal can be represented in terms of frequency components. Neural sensory processing uses biological mechanisms rather than literally executing this discrete Fourier transform.

2. Feature extraction:

\[
\mathbf{x}=[x_1,x_2,\ldots,x_n]
\]

For an auditory word, features could represent acoustic and phonological properties. For a visual object, they could represent shape, colour, orientation, and spatial properties.

3. Normalization:

\[
\hat{x}_i=\frac{x_i-\mu_i}{\sigma_i+\epsilon}
\]

This provides a computational analogy for adjusting sensitivity to different input scales.

4. Temporal integration:

\[
X_t=\sum_{\tau=0}^{k}\alpha_\tau x_{t-\tau}
\]

This represents accumulation of information across successive moments.

**Output**

A neural representation of the incoming signal that can activate linguistic and conceptual candidates.

### Stage 2. Candidate word and concept activation

**Biological objective**

Identify the word or object and activate possible conceptual representations in semantic memory.

This stage is important because lexical identification is not identical to selecting the correct meaning.

For example, the recognized word *bank* may activate several possible meanings:

| Candidate | Semantic category |
|---|---|
| Financial bank | Financial institution |
| River bank | Geographical feature |
| Bank of switches | Group or arrangement |

At this stage, multiple representations can remain active simultaneously.

**Possible mathematical operations**

1. Candidate matching:

\[
s_i=\operatorname{sim}(X,W_i)
\]

Here, \(W_i\) is a stored word representation, and \(s_i\) is its similarity to incoming input.

2. Frequency-based prior activation:

\[
A_i=P(m_i)
\]

More familiar or frequent meanings may have stronger initial activation.

3. Evidence accumulation:

\[
z_i=\log P(X\mid m_i)+\log P(m_i)
\]

This is a Bayesian-style approximation combining sensory evidence and prior probability.

4. Parallel candidate activation:

\[
\mathbf{A}=
[A_1,A_2,\ldots,A_n]
\]

Rather than immediately discarding alternatives, the system retains a population of potentially relevant candidates.

**Output**

A set of candidate words and concepts with different initial activation levels.

---

### Stage 3. Distributed semantic memory activation

**Biological objective**

Activate the knowledge associated with the recognized concept across the distributed semantic network.

When processing *bank*, semantic knowledge might include:

- Building.
- Money.
- Customers.
- Financial services.
- River.
- Water.
- Shore.
- Geography.

The information is not stored as a single list inside one brain location. It is represented through interactions among distributed modality-specific systems and transmodal semantic regions.

**Possible mathematical operations**

1. Spreading activation:

\[
A_j(t+1)=
f\left(
\sum_i W_{ij}A_i(t)+B_j
\right)
\]

An activated representation influences connected semantic representations.

2. Connection-strength weighting:

\[
I_j=\sum_i W_{ij}A_i
\]

Here, \(I_j\) represents the incoming influence on representation \(j\).

3. Activation decay:

\[
A_i(t)=A_i(0)e^{-\lambda_i t}
\]

This is a simplified model of how activation can diminish over time in the absence of supporting input.

4. Recurrent activation:

\[
\mathbf{A}_{t+1}=F(W\mathbf{A}_t+\mathbf{b})
\]

The network repeatedly updates its activity through recurrent connections.

**Output**

A distributed semantic activation pattern containing information about possible meanings, characteristics, functions, and associations.

---

### Stage 4. ATL hub integration and concept formation

**Biological objective**

Integrate different types of conceptual information into a coherent, relatively modality-independent representation.

The anterior temporal lobes are proposed to serve as a transmodal semantic hub that interacts with sensory, motor, and other modality-specific spokes.

For instance, the concept *bank* can incorporate:

- Visual properties of a building.
- Knowledge of financial transactions.
- Social knowledge about customers and employees.
- Functional knowledge about storing and transferring money.

The hub contributes to the integration of these different features into an accessible concept.

**Possible mathematical operations**

1. Multimodal integration:

\[
H=f\left(
W_vS_v+
W_aS_a+
W_mS_m+
W_fS_f+b
\right)
\]

Where:

- \(S_v\): visual information.
- \(S_a\): auditory information.
- \(S_m\): motor information.
- \(S_f\): functional information.
- \(H\): integrated semantic representation.

2. Feature similarity:

\[
\operatorname{sim}(H,C_i)=
\frac{H\cdot C_i}{\|H\|\|C_i\|}
\]

This measures the similarity between the integrated representation and a stored concept.

3. Pattern completion:

\[
H^*=\arg\max_H P(H\mid S_{\text{available}})
\]

This is an abstract description of reconstructing a coherent concept from incomplete features.

4. Recurrent stabilization:

\[
H_{t+1}=f(W_{HH}H_t+W_{SH}S_t)
\]

Repeated interactions can stabilize a coherent conceptual activation pattern.

**Output**

An integrated semantic representation that can be accessed from different sensory and conceptual entry points.

An important distinction: the ATL contributes the underlying conceptual content, while the semantic control system influences which aspects of that content receive priority.

---

### Stage 5. Context construction and contextual constraint extraction

**Biological objective**

Determine the circumstances in which the concept is being used.

The brain must consider information beyond the word itself.

For example:

"The fisherman sat on the bank."

The terms *fisherman* and *sat* provide contextual evidence that the geographical meaning of *bank* is relevant.

In contrast:

"The fisherman deposited his earnings at the bank."

Here the financial meaning becomes more appropriate.

**Possible mathematical operations**

1. Context feature extraction:

\[
C_t=[c_1,c_2,\ldots,c_n]
\]

2. Context accumulation:

\[
C_t=\alpha C_{t-1}+(1-\alpha)X_t
\]

The context representation combines previous information and new information.

3. Semantic contextual association:

\[
R(m_i,C_t)=
\frac{m_i\cdot C_t}{\|m_i\|\|C_t\|}
\]

4. Contextual probability:

\[
P(m_i\mid C_t)=
\frac{P(C_t\mid m_i)P(m_i)}
{\sum_jP(C_t\mid m_j)P(m_j)}
\]

This estimates the relative suitability of each meaning within the current context.

**Output**

A contextual representation specifying what kinds of meanings and semantic features are likely to be useful.

---

### Stage 6. Task and intention representation

**Biological objective**

Determine what the brain is attempting to accomplish with the semantic information.

The same concept may require different features depending on the task.

Consider the object *keyboard*:

| Task | Relevant semantic information |
|---|---|
| Explain a keyboard | Input device, keys, typing |
| Identify its colour | Visual properties |
| Move a keyboard | Shape, weight, grasping, movement |
| Compare keyboards | Size, layout, functionality |

The semantic representation remains available, but the task changes which parts should be accessed.

This is a critical part of CSC: semantic cognition is not simply retrieving the most familiar information. It is retrieving knowledge appropriate to the current task.

**Possible mathematical operations**

1. Task representation:

\[
T=[t_1,t_2,\ldots,t_n]
\]

2. Task-feature matching:

\[
G_i=\operatorname{sim}(T,F_i)
\]

Where \(F_i\) is a potential semantic feature.

3. Task priority weighting:

\[
Q_i=\omega_iG_i
\]

4. Goal maintenance:

\[
T_t=\gamma T_{t-1}+(1-\gamma)T_{\text{new}}
\]

This represents maintaining the current task while accommodating task updates.

**Output**

A task-specific target representation that defines which semantic information should be retrieved.

---

### Stage 7. Estimation of semantic control demand

**Biological objective**

Determine whether automatic semantic retrieval is sufficient or whether additional controlled processing is necessary.

This stage is particularly important because not every semantic task requires substantial executive involvement.

Compare the following:

**Easy task**

Pair *dog* with *puppy*.

The association is familiar and strongly established. Automatic semantic activation may provide sufficient information.

**Hard task**

Pair *dog* with *bark* when the task specifically asks for something a tree has.

The familiar association between dog and barking must not determine the answer. The system must shift to a different semantic feature and retrieve a less obvious relationship.

**Possible mathematical operations**

Control demand can be estimated using several variables:

1. Semantic uncertainty:

\[
H(M)=-\sum_iP(m_i)\log P(m_i)
\]

Higher entropy means the candidate meanings are more evenly distributed and less certain.

2. Candidate conflict:

\[
K=1-\left(P(m_{\text{best}})-P(m_{\text{second}})\right)
\]

Here, small differences between the leading candidates indicate greater competition.

3. Retrieval weakness:

\[
U=1-A_{\text{target}}
\]

This approximates the difficulty of retrieving a weakly activated target.

4. Task novelty:

\[
N=1-\operatorname{sim}(T,T_{\text{familiar}})
\]

This is an illustrative representation of how unusual task requirements might increase difficulty.

5. Combined control demand:

\[
\boxed{
D=\sigma(
w_hH(M)+w_kK+w_uU+w_nN+b
)
}
\]

Here, \(\sigma\) is a sigmoid function, and the weights determine how much each factor contributes.

The exact biological combination is unknown. This equation is a useful computational model, not an experimentally established neural formula.

**Output**

A control-demand value that determines how strongly semantic control mechanisms should be engaged.

### Stage 8. Recruitment of the semantic control network

**Biological objective**

Engage the control mechanisms necessary to retrieve the appropriate semantic information.

The control network is distributed, rather than being a single executive centre.

Its important components include:

| Brain region | Proposed computational role |
|---|---|
| Left IFG | Selection demands, controlled retrieval, selection between competing semantic information |
| Left pMTG | Semantic retrieval and interaction with conceptual representations |
| Left pITG | Additional posterior temporal involvement in semantic control |
| Dorsomedial PFC | Monitoring and regulation within the semantic control network |
| DLPFC / other frontoparietal regions | Maintenance of task goals and domain-general executive demands |
| IPS / relevant parietal areas | Contributions to attention and selection in some models |

There is an important anatomical qualification: the precise boundaries of the semantic control network are debated. A large 2021 meta-analysis identified a left-focused network involving IFG, pMTG, pITG, and dorsomedial PFC, without finding significant parietal involvement. Other research identifies parietal participation in wider semantic and executive networks. Therefore, a computational implementation should represent parietal involvement as task-dependent rather than mandatory in every semantic operation. <Cite refs={["turn247020view1","turn247020view3","turn249362search8"]}/>

**Possible mathematical operations**

1. Control signal generation:

\[
Q=W_TT+W_CC+W_DD
\]

The control system combines task, context, and estimated difficulty.

2. Regional control activity:

\[
N_r=f(W_rQ+b_r)
\]

Where \(N_r\) is the activity of a control-network node.

3. Network communication:

\[
\frac{d\mathbf{N}}{dt}
=
-\Lambda\mathbf{N}
+
W_N\mathbf{N}
+
Q
\]

This is a simplified recurrent-network model in which control signals propagate between regions.

4. Demand-dependent communication:

\[
W_{ij}^{*}=W_{ij}+\Delta W_{ij}(D)
\]

The effective influence between regions changes according to task demands.

**Output**

An active control-network state that can modify how semantic information is retrieved and processed.

---

### Stage 9. Generation of targeted semantic retrieval signals

**Biological objective**

Determine which specific features, associations, or meanings should be preferentially retrieved.

The control network must translate a general intention into specific retrieval requirements.

For example:

Task: Find the common colour of ketchup and a fire extinguisher.

The brain must:

1. Identify the relevant property: colour.
2. Retrieve the colour representation of ketchup.
3. Retrieve the colour representation of a fire extinguisher.
4. Compare the representations.
5. Identify the shared feature.

Normally, ketchup activates many features, including taste, food, tomato, texture, and colour. The current task requires prioritizing colour rather than the most familiar food-related associations.

**Possible mathematical operations**

1. Construct a semantic feature target:

\[
F_T=[f_1,f_2,\ldots,f_n]
\]

2. Calculate feature relevance:

\[
R_i=\operatorname{sim}(F_i,F_T)
\]

3. Generate a control weight:

\[
G_i=\sigma(kR_i+b)
\]

4. Assign an exploration priority:

\[
E_i=\frac{R_i+\epsilon}{A_i+\epsilon}
\]

This illustrative ratio can prioritize relevant features that currently have low activation.

**Output**

A vector of feature-specific priorities that guides controlled semantic retrieval.

---

### Stage 10. Amplification of task-relevant semantic features

**Biological objective**

Increase the influence of the semantic information needed for the current task.

This process does not require destroying or replacing the original concept representation.

Instead, it changes the relative accessibility of its components.

For example:

When understanding *bank* in a river context, the system should increase the influence of features related to:

- Water.
- River.
- Shore.
- Landscape.

The financial characteristics can remain stored but become less influential in the current interpretation.

**Possible mathematical operations**

1. Multiplicative gain:

\[
A_i'=G_iA_i
\]

2. Additive excitation:

\[
A_i'=A_i+\eta G_i
\]

3. Recurrent amplification:

\[
A_i(t+1)=
f(A_i(t)+G_i+\sum_jW_{ji}A_j(t))
\]

4. Feature-specific modulation:

\[
\mathbf{A}'=\mathbf{G}\odot\mathbf{A}
\]

Where \(\odot\) indicates element-wise multiplication.

**Output**

Task-relevant features become more strongly represented in the active semantic processing state.

---

### Stage 11. Inhibition of task-irrelevant semantic features

**Biological objective**

Reduce the influence of information that could interfere with the intended interpretation.

Consider:

"The fisherman sat beside the bank."

The financial interpretation of *bank* may initially be activated, particularly if it is highly familiar. However, it is not appropriate for the current sentence.

The control system must reduce the influence of this competing interpretation.

It is important to distinguish this from deleting knowledge. The financial meaning remains available in semantic memory; its contribution to the current processing episode is reduced.

**Possible mathematical operations**

1. Subtractive inhibition:

\[
A_i'=A_i-I_i
\]

2. Nonnegative activation:

\[
A_i'=\max(0,A_i-I_i)
\]

3. Competitive suppression:

\[
I_i=\beta\sum_{j\ne i}A_j
\]

4. Task-dependent inhibitory strength:

\[
I_i=\lambda(1-R_i)
\]

Here, \(\lambda\) is the inhibition intensity, and \(R_i\) represents task relevance.

5. Combined excitation and inhibition:

\[
\boxed{
A_i(t+1)=
f\left[
\sum_jW_{ji}A_j(t)
+G_i-I_i
+B_i
\right]
}
\]

**Output**

An active semantic representation in which irrelevant features have reduced influence.

An important biological qualification: selective semantic control is supported by interacting excitation, inhibition, and changes in network sensitivity. The equations above are computational approximations, not proof of a single dedicated inhibitory mechanism for every irrelevant meaning.

---

### Stage 12. Controlled retrieval of weak or non-dominant knowledge

**Biological objective**

Retrieve semantic information that is relevant to the task but is not automatically activated strongly enough.

This is one of the most important contributions of CSC.

A difficult task may require the brain to access knowledge that is:

- Less frequently used.
- Weakly associated with the current concept.
- Unusual in the present context.
- Less dominant than a competing meaning.

Consider the ketchup/fire-extinguisher example.

The obvious associations of ketchup include food, tomato, sauce, and taste.

However, the task requires the colour feature. The control network must direct semantic processing toward this less task-dominant aspect.

**Possible mathematical operations**

1. Directed spreading activation:

\[
A_j(t+1)=
f\left(
A_j(t)+\sum_iG_iW_{ij}A_i(t)
\right)
\]

2. Retrieval prioritization:

\[
P_j=
\frac{\exp(\beta R_jA_j)}
{\sum_k\exp(\beta R_kA_k)}
\]

3. Iterative retrieval:

\[
\mathbf{A}_{t+1}=
F(\mathbf{A}_t,\mathbf{G},\mathbf{W},\mathbf{I})
\]

4. Stopping criterion:

\[
\|\mathbf{A}_{t+1}-\mathbf{A}_t\|<\epsilon
\]

This indicates that the computational network has reached a sufficiently stable state.

**Output**

Relevant but previously weak semantic information becomes sufficiently accessible for evaluation.

---

### Stage 13. Candidate meaning and feature evaluation

**Biological objective**

Evaluate the retrieved candidates against the task and context.

At this stage, the brain must assess whether the information that became active actually satisfies the processing requirements.

For example, consider two interpretations of *bank*:

- Financial institution.
- River edge.

If the sentence includes *deposit*, the financial interpretation receives greater support.

If the sentence includes *fisherman*, the geographical interpretation receives greater support.

**Possible mathematical operations**

1. Semantic match:

\[
M_i=\operatorname{sim}(m_i,C)
\]

2. Task match:

\[
T_i=\operatorname{sim}(m_i,T)
\]

3. Feature relevance:

\[
F_i=\sum_jw_jr_{ij}
\]

4. Integrated candidate score:

\[
\boxed{
Z_i=\alpha M_i+\beta T_i+\gamma F_i+\delta C_i
}
\]

Where \(C_i\) represents contextual compatibility.

5. Probability calculation:

\[
P(m_i\mid X,C,T)=
\frac{e^{Z_i/\tau}}
{\sum_je^{Z_j/\tau}}
\]

The temperature \(\tau\) controls how sharply the candidate scores are differentiated.

**Output**

A collection of evaluated candidates with task- and context-dependent scores.

---

### Stage 14. Competition resolution and semantic selection

**Biological objective**

Determine which candidate meaning or feature should dominate the current semantic interpretation.

This is not merely selecting the most familiar concept.

The selected representation must satisfy the current contextual and task requirements.

**Possible mathematical operations**

1. Winner-take-all approximation:

\[
m^*=\arg\max_i Z_i
\]

2. Confidence margin:

\[
\Delta Z=Z_{\text{best}}-Z_{\text{second}}
\]

3. Selection threshold:

\[
\text{Select }m^*
\quad\text{when}\quad
\Delta Z>\theta
\]

4. Confidence evaluation:

\[
C_{\text{selection}}=
P(m^*\mid X,C,T)
\]

5. Multiple-feature selection:

\[
F^*=\{f_i:R_i>\theta_f\}
\]

The system may need to select several mutually compatible features instead of one winning meaning.

**Output**

A selected semantic interpretation or a coherent set of task-relevant features.

---

### Stage 15. Performance monitoring and control adjustment

**Biological objective**

Monitor whether the current semantic interpretation is sufficiently appropriate.

If the retrieved information does not satisfy the task, the control system must adjust its retrieval strategy.

For example:

Task: Identify a shared feature between a keyboard and a typewriter.

Initial retrieval may produce:

- Keyboard: electronic device.
- Typewriter: mechanical machine.

These initial associations do not fully capture the task-relevant relationship.

The system may need to retrieve another set of features:

- Both contain keys.
- Both are used for entering text.
- Both have a character-input mechanism.

The system therefore needs a feedback loop.

**Possible mathematical operations**

1. Error calculation:

\[
e_t=Z_{\text{required}}-Z_{\text{current}}
\]

2. Control adjustment:

\[
G_{t+1}=G_t+\eta e_t
\]

3. Inhibition adjustment:

\[
I_{t+1}=I_t+\mu e_{\text{interference}}
\]

4. Adaptive demand:

\[
D_{t+1}=
\operatorname{clip}(D_t+\rho e_t,0,1)
\]

5. Iterative correction:

\[
\mathbf{A}_{t+1}=
F(\mathbf{A}_t,\mathbf{G}_{t+1},\mathbf{I}_{t+1})
\]

The general principle is that unsatisfactory retrieval increases the need for additional controlled processing, while successful retrieval allows control intensity to decrease.

**Output**

A corrected semantic retrieval state, or a decision to search for additional information.

---

### Stage 16. Integration of selected semantic information

**Biological objective**

Combine the selected features into a coherent conceptual interpretation.

Selection alone is insufficient. The brain must integrate the retrieved features into a meaningful representation.

For example:

Keyboard:

- Has keys.
- Accepts character input.
- Supports text production.
- Can be connected to a computer.

The task may require the functional relationship rather than simply the object's physical appearance.

**Possible mathematical operations**

1. Feature aggregation:

\[
H^*=\sum_iw_iA_iF_i
\]

2. Relation construction:

\[
R(F_i,F_j)=\operatorname{rel}(F_i,F_j)
\]

3. Conceptual integration:

\[
C_{\text{final}}=
f\left(
\sum_iA_iF_i+
\sum_{i,j}R(F_i,F_j)
\right)
\]

4. Consistency evaluation:

\[
K_c=
\frac{\text{compatible feature relations}}
{\text{total evaluated relations}}
\]

**Output**

A task-specific integrated semantic representation ready for comprehension or expression.

---

### Stage 17. Generation of the appropriate response or behaviour

**Biological objective**

Translate the integrated semantic representation into an appropriate action, interpretation, or verbal response.

The output depends on the task.

For example:

- A linguistic task produces an appropriate word or sentence.
- A decision task produces a semantic judgement.
- A functional task produces an appropriate action.
- A reasoning task produces a conceptual relationship.

**Possible mathematical operations**

1. Response candidate scoring:

\[
O_i=\operatorname{sim}(C_{\text{final}},R_i)
\]

2. Decision:

\[
O^*=\arg\max_iO_i
\]

3. Output threshold:

\[
O^*\text{ is emitted when }C_{\text{selection}}>\theta_o
\]

4. Response generation:

\[
Y=g(C_{\text{final}},T,\text{language context})
\]

**Output**

The selected interpretation, semantic judgement, linguistic response, or appropriate action.

### Stage 18. Adaptive learning and control updating

**Biological objective**

Adjust the system's future retrieval behaviour through experience.

There are two distinct forms of updating that should not be confused.

**A. Temporary control adaptation**

During the current task, the system adjusts the level of amplification, inhibition, and task-related connectivity.

This can be reversed when the task changes.

**B. Longer-term learning**

Repeated experiences can modify semantic associations and neural connection strengths.

For example, learning a new and unusual relationship between two concepts can eventually make that relationship easier to retrieve.

**Possible mathematical operations**

1. Hebbian-like strengthening:

\[
\Delta W_{ij}=\eta A_iA_j
\]

2. Error-driven learning:

\[
\Delta W=-\eta\nabla_W L
\]

3. Reinforcement-based adaptation:

\[
\Delta W_{ij}=\eta r A_iA_j
\]

4. Frequency-dependent accessibility:

\[
A_i^{prior}=g(\text{retrieval frequency},\text{recency})
\]

5. Control strategy adaptation:

\[
\boldsymbol{\theta}_{t+1}
=
\boldsymbol{\theta}_t-\eta\nabla_{\theta}L
\]

Here, \(\boldsymbol{\theta}\) represents learned control parameters.

These are general learning abstractions; biological synaptic plasticity involves much richer mechanisms and timescales.

**Output**

An updated system that can retrieve learned information more efficiently in future situations.

## 4. The central executive control loop

The most important feature of CSC is that semantic control does not simply operate once and disappear. It continuously interacts with the semantic representation system.

The following loop describes this cooperation.

    B --> C["Integrate concept through ATL hub"]
    C --> D["Apply context and task requirements"]

    E --> F{"Is automatic retrieval sufficient?"}
    F -->|Yes| G["Use the accessible semantic representation"]
    F -->|No| H["Recruit semantic control network"]

    I --> J["Amplify relevant semantic features"]

    K --> L["Controlled semantic retrieval"]
    L --> M["Evaluate candidate information"]

    N -->|Yes| O["Integrate selected features"]

### Mathematical formulation of the entire control loop

We can represent the complete system using five major mathematical components.

**1. Semantic representation**

\[
\mathbf{H}_t=F_H(\mathbf{S}_t,\mathbf{H}_{t-1})
\]

This represents integration and updating of semantic content.

**2. Task and context representation**

\[
\mathbf{Q}_t=F_Q(\mathbf{T}_t,\mathbf{C}_t)
\]

This represents what information is needed and why.

**3. Control-demand estimation**

\[
D_t=F_D(H(M),K,U,N)
\]

This estimates whether controlled semantic processing is required.

**4. Semantic control**

\[
\mathbf{G}_t,\mathbf{I}_t=
F_C(\mathbf{Q}_t,D_t,\mathbf{A}_t)
\]

This generates feature-specific amplification and inhibition signals.

**5. Controlled semantic activation**

\[
\boxed{
\mathbf{A}_{t+1}=
f\left(
\mathbf{W}(D_t,\mathbf{Q}_t)\mathbf{A}_t
+\mathbf{G}_t-\mathbf{I}_t
+\mathbf{B}_t
\right)
}
\]

The updated activity is evaluated against the task. If it is insufficient, the system generates new control signals and repeats the process.

## 6. How CSC explains the difference between semantic aphasia and semantic dementia

This distinction is essential because it provides a way to understand what happens when different parts of the architecture are damaged.

CSC proposes that semantic representation and semantic control can be affected independently.

### A. Semantic aphasia (SA): Damage to semantic control

<badge color="warning">Control system impairment</badge>

In semantic aphasia, damage to the left frontal or temporoparietal regions can impair the ability to retrieve and select semantic information according to task requirements.

The underlying semantic knowledge may remain substantially available.

For example, a person might know:

- What a keyboard looks like.
- What a keyboard is used for.
- What its keys do.
- How it relates to a computer.

However, when asked an unusual question about the keyboard, the person might struggle to retrieve the particular feature needed.

**Computational interpretation**

The semantic memory remains relatively intact:

\[
\mathbf{W}_{semantic}\approx \mathbf{W}_{normal}
\]

But the control parameters are impaired:

\[
\mathbf{G}\downarrow,\qquad
\mathbf{I}\downarrow,\qquad
\mathbf{Q}_{control}\downarrow
\]

These downward arrows represent impaired control effectiveness, not necessarily reduced activity in every neural region.

Consequences include:

1. Difficulty retrieving weak associations.
2. Difficulty selecting less frequent meanings.
3. Greater interference from dominant meanings.
4. Difficulty suppressing irrelevant semantic features.
5. Reduced flexibility when the task changes.
6. Difficulty retrieving information according to unusual contextual requirements.

An important characteristic is that performance can vary with context and task demands. This is consistent with a problem in controlled access rather than simple deletion of semantic knowledge. <Cite refs={["turn247020view1","turn249362search2","turn249362search5"]}/>

### B. Semantic dementia (SD): Damage to semantic representation

<badge color="danger">Representation system impairment</badge>

Semantic dementia is associated with progressive deterioration of the anterior temporal lobes and degradation of conceptual knowledge.

Unlike a control impairment, this damages the underlying representations themselves.

A person may lose knowledge of:

- What familiar objects are.
- What they look like.
- What they are used for.
- How they relate to other concepts.
- What particular words mean.

**Computational interpretation**

Semantic representations become degraded:

\[
\mathbf{H}\downarrow
\]

The quality of connections between multimodal semantic information also deteriorates:

\[
\mathbf{W}_{semantic}\downarrow
\]

As a result, even easy semantic tasks can become difficult.

The person may not be able to recover a concept simply by increasing attention, applying more inhibition, or directing retrieval more strongly.

The problem is no longer primarily selecting the right knowledge. Some of the necessary knowledge has itself deteriorated.

The distinction between semantic aphasia and semantic dementia is supported by clinical and neuropsychological evidence. <Cite refs={["turn247020view1","turn247020view3","turn249362search5"]}/>

## 7. Important biological interactions and mathematical interpretations

There are several additional mechanisms that should be considered when turning this algorithm into a more realistic brain-inspired system.

| Biological mechanism | Computational interpretation | Purpose |
|---|---|---|
| Population coding | Distributed activation vectors | Represent concepts using multiple neural populations |
| Recurrent connectivity | Iterative matrix operations | Stabilize and refine semantic activation |
| Excitatory transmission | Positive weighted input | Increase relevant activity |
| Inhibitory transmission | Negative influence or competition | Reduce competing activity |
| Neural gain modulation | Multiplicative scaling | Change processing sensitivity |
| Effective connectivity | Task-dependent connection matrices | Reconfigure communication |
| Neural adaptation | Adaptive parameter updating | Improve future processing |
| Oscillatory coordination | Time-dependent coupling | Coordinate interactions across neural populations |

### Especially important: dynamic connectivity

One of the most interesting aspects of CSC is that the relationship between the representation and control systems can change according to the task.

For example:

**Familiar semantic task:**

Ketchup → Mustard.

The ATL hub and relatively familiar semantic relationships can provide much of the information required.

**Unusual semantic task:**

Ketchup → Fire extinguisher (because both are red).

The system must retrieve colour information, which requires greater engagement of the control network and interactions with relevant visual-processing regions.

This suggests that the brain does not simply switch the semantic control system ON or OFF. It changes how strongly different regions communicate.

Mathematically:

\[
W_{ij}(t)=W_{ij}^{base}+\Delta W_{ij}(T,D)
\]

This allows the architecture to change effective connectivity according to both the task and its difficulty.

Research on dynamic interactions has demonstrated increased IFG involvement and increased connectivity with colour-related occipitotemporal regions during unconventional colour-based semantic pairing. <Cite refs={["turn249362search4","turn249362search5"]}/>

More recent research published in December 2025 also investigated the functional differentiation and interactions of IFG, pMTG, and dmPFC using fMRI, TMS, and computational connectivity modelling. The findings support the importance of interactions between multiple control-network regions rather than treating each region as an isolated processor. <Cite refs={["turn249362search6","turn249362search10"]}/>

## 8. Final integrated pseudocode

The complete conceptual architecture can now be expressed as a single algorithm.

<CodeBlock language="python" editable>
def controlled_semantic_cognition(input_signal, task, context):
    """
    Computational abstraction of Controlled Semantic Cognition.

    Combines distributed semantic representations with
    task-dependent executive semantic control.

    This is a proposed computational model, not a literal
    simulation of every biological neural mechanism.
    """

    # STAGE 1: Sensory and linguistic encoding
    sensory_features = encode_input(input_signal)

    # STAGE 2: Activate possible words and concepts
    candidates = activate_lexical_concepts(sensory_features)

    # STAGE 3: Activate distributed semantic knowledge
    semantic_features = activate_semantic_memory(candidates)

    # STAGE 4: Integrate information through the ATL hub
    hub_state = integrate_semantic_hub(semantic_features)

    # STAGE 5: Construct contextual representation
    context_state = integrate_context(context)

    # STAGE 6: Represent task and intention
    task_state = encode_task(task)

    # STAGE 7: Estimate control requirements
    demand = estimate_control_demand(
        candidates,
        hub_state,
        context_state,
        task_state
    )

    # Initial semantic activation
    activation = semantic_activation(
        hub_state,
        context_state
    )

    # STAGE 8-15: Controlled semantic retrieval
    while not retrieval_is_satisfactory(
        activation, task_state, context_state
    ):

        # Recruit and configure semantic control network
        control_state = recruit_control_network(
            demand,
            task_state,
            context_state
        )

        # Generate semantic retrieval priorities
        relevance = calculate_feature_relevance(
            activation,
            task_state,
            context_state
        )

        # Amplify task-relevant features
        gain = calculate_semantic_gain(
            relevance, control_state
        )

        # Inhibit irrelevant competing features
        inhibition = calculate_semantic_inhibition(
            relevance, control_state
        )

        # Retrieve weak and non-dominant associations
        activation = controlled_retrieval(
            activation,
            gain,
            inhibition,
            control_state
        )

        # Evaluate retrieved information
        evaluation = evaluate_semantic_candidates(
            activation,
            task_state,
            context_state
        )

        # Calculate retrieval error
        error = calculate_retrieval_error(
            evaluation, task_state
        )

        # Adapt control parameters
        demand = update_control_demand(
            demand, error
        )

    # STAGE 16: Integrate selected semantic features
    final_representation = integrate_selected_features(
        activation
    )

    # STAGE 17: Produce interpretation or response
    response = generate_semantic_response(
        final_representation,
        task_state
    )

    # STAGE 18: Update learning and control parameters
    update_semantic_learning(
        final_representation,
        response
    )

    return response
</CodeBlock>

This pseudocode defines the architectural interfaces. Functions such as `integrate_semantic_hub`, `recruit_control_network`, and `controlled_retrieval` would each require their own detailed algorithms and data structures.

## 10. The most important architectural conclusions

There are five fundamental principles that should be preserved when implementing CSC.

**1. Semantic knowledge and semantic control must be separate.**

The system must distinguish between not knowing something and knowing it but failing to retrieve the appropriate information for the task.

**2. The ATL hub should not become an executive controller.**

Its computational responsibility is multimodal conceptual integration. Task-specific selection should be handled by the interacting control system.

**3. Semantic control should be dynamic.**

The system should not apply maximum control to every semantic task. Familiar associations can use relatively automatic processing, whereas difficult tasks require stronger and more targeted control.

**4. Amplification and inhibition must operate together.**

Increasing relevant semantic features is only half the problem. The system must also reduce interference from irrelevant features.

**5. Control must be recurrent and task-dependent.**

The control system must be able to evaluate retrieval, change its retrieval priorities, and repeat processing until it has sufficient information.

**My recommendation:** Treat CSC as a separate, complete computational subsystem that can connect to other language, reading, discourse, and reasoning subsystems. Its most valuable contribution is not simply representing what a concept means, but dynamically determining which knowledge about that concept should influence the current thought.

This distinction is especially important when combining CSC with a larger brain-inspired architecture: semantic memory provides the knowledge, while semantic control determines how that knowledge is used. 

For the next implementation stage, the most useful starting point would be defining the precise data structures and mathematical interfaces connecting the ATL hub, semantic spokes, IFG, and pMTG, before implementing the 18 stages as Python classes and operations.

## 6. How CSC explains the difference between semantic aphasia and semantic dementia

This distinction is essential because it provides a way to understand what happens when different parts of the architecture are damaged.

CSC proposes that semantic representation and semantic control can be affected independently.

### A. Semantic aphasia (SA): Damage to semantic control

<badge color="warning">Control system impairment</badge>

In semantic aphasia, damage to the left frontal or temporoparietal regions can impair the ability to retrieve and select semantic information according to task requirements.

The underlying semantic knowledge may remain substantially available.

For example, a person might know:

- What a keyboard looks like.
- What a keyboard is used for.
- What its keys do.
- How it relates to a computer.

However, when asked an unusual question about the keyboard, the person might struggle to retrieve the particular feature needed.

**Computational interpretation**

The semantic memory remains relatively intact:

\[
\mathbf{W}_{semantic}\approx \mathbf{W}_{normal}
\]

But the control parameters are impaired:

\[
\mathbf{G}\downarrow,\qquad
\mathbf{I}\downarrow,\qquad
\mathbf{Q}_{control}\downarrow
\]

These downward arrows represent impaired control effectiveness, not necessarily reduced activity in every neural region.

Consequences include:

1. Difficulty retrieving weak associations.
2. Difficulty selecting less frequent meanings.
3. Greater interference from dominant meanings.
4. Difficulty suppressing irrelevant semantic features.
5. Reduced flexibility when the task changes.
6. Difficulty retrieving information according to unusual contextual requirements.

An important characteristic is that performance can vary with context and task demands. This is consistent with a problem in controlled access rather than simple deletion of semantic knowledge. <Cite refs={["turn247020view1","turn249362search2","turn249362search5"]}/>

### B. Semantic dementia (SD): Damage to semantic representation

<badge color="danger">Representation system impairment</badge>

Semantic dementia is associated with progressive deterioration of the anterior temporal lobes and degradation of conceptual knowledge.

Unlike a control impairment, this damages the underlying representations themselves.

A person may lose knowledge of:

- What familiar objects are.
- What they look like.
- What they are used for.
- How they relate to other concepts.
- What particular words mean.

**Computational interpretation**

Semantic representations become degraded:

\[
\mathbf{H}\downarrow
\]

The quality of connections between multimodal semantic information also deteriorates:

\[
\mathbf{W}_{semantic}\downarrow
\]

As a result, even easy semantic tasks can become difficult.

The person may not be able to recover a concept simply by increasing attention, applying more inhibition, or directing retrieval more strongly.

The problem is no longer primarily selecting the right knowledge. Some of the necessary knowledge has itself deteriorated.

The distinction between semantic aphasia and semantic dementia is supported by clinical and neuropsychological evidence. <Cite refs={["turn247020view1","turn247020view3","turn249362search5"]}/>

## 7. Important biological interactions and mathematical interpretations

There are several additional mechanisms that should be considered when turning this algorithm into a more realistic brain-inspired system.

| Biological mechanism | Computational interpretation | Purpose |
|---|---|---|
| Population coding | Distributed activation vectors | Represent concepts using multiple neural populations |
| Recurrent connectivity | Iterative matrix operations | Stabilize and refine semantic activation |
| Excitatory transmission | Positive weighted input | Increase relevant activity |
| Inhibitory transmission | Negative influence or competition | Reduce competing activity |
| Neural gain modulation | Multiplicative scaling | Change processing sensitivity |
| Effective connectivity | Task-dependent connection matrices | Reconfigure communication |
| Neural adaptation | Adaptive parameter updating | Improve future processing |
| Oscillatory coordination | Time-dependent coupling | Coordinate interactions across neural populations |

### Especially important: dynamic connectivity

One of the most interesting aspects of CSC is that the relationship between the representation and control systems can change according to the task.

For example:

**Familiar semantic task:**

Ketchup → Mustard.

The ATL hub and relatively familiar semantic relationships can provide much of the information required.

**Unusual semantic task:**

Ketchup → Fire extinguisher (because both are red).

The system must retrieve colour information, which requires greater engagement of the control network and interactions with relevant visual-processing regions.

This suggests that the brain does not simply switch the semantic control system ON or OFF. It changes how strongly different regions communicate.

Mathematically:

\[
W_{ij}(t)=W_{ij}^{base}+\Delta W_{ij}(T,D)
\]

This allows the architecture to change effective connectivity according to both the task and its difficulty.

Research on dynamic interactions has demonstrated increased IFG involvement and increased connectivity with colour-related occipitotemporal regions during unconventional colour-based semantic pairing. <Cite refs={["turn249362search4","turn249362search5"]}/>

More recent research published in December 2025 also investigated the functional differentiation and interactions of IFG, pMTG, and dmPFC using fMRI, TMS, and computational connectivity modelling. The findings support the importance of interactions between multiple control-network regions rather than treating each region as an isolated processor. <Cite refs={["turn249362search6","turn249362search10"]}/>

## 8. Final integrated pseudocode

The complete conceptual architecture can now be expressed as a single algorithm.

<CodeBlock language="python" editable>
def controlled_semantic_cognition(input_signal, task, context):
    """
    Computational abstraction of Controlled Semantic Cognition.

    Combines distributed semantic representations with
    task-dependent executive semantic control.

    This is a proposed computational model, not a literal
    simulation of every biological neural mechanism.
    """

    # STAGE 1: Sensory and linguistic encoding
    sensory_features = encode_input(input_signal)

    # STAGE 2: Activate possible words and concepts
    candidates = activate_lexical_concepts(sensory_features)

    # STAGE 3: Activate distributed semantic knowledge
    semantic_features = activate_semantic_memory(candidates)

    # STAGE 4: Integrate information through the ATL hub
    hub_state = integrate_semantic_hub(semantic_features)

    # STAGE 5: Construct contextual representation
    context_state = integrate_context(context)

    # STAGE 6: Represent task and intention
    task_state = encode_task(task)

    # STAGE 7: Estimate control requirements
    demand = estimate_control_demand(
        candidates,
        hub_state,
        context_state,
        task_state
    )

    # Initial semantic activation
    activation = semantic_activation(
        hub_state,
        context_state
    )

    # STAGE 8-15: Controlled semantic retrieval
    while not retrieval_is_satisfactory(
        activation, task_state, context_state
    ):

        # Recruit and configure semantic control network
        control_state = recruit_control_network(
            demand,
            task_state,
            context_state
        )

        # Generate semantic retrieval priorities
        relevance = calculate_feature_relevance(
            activation,
            task_state,
            context_state
        )

        # Amplify task-relevant features
        gain = calculate_semantic_gain(
            relevance, control_state
        )

        # Inhibit irrelevant competing features
        inhibition = calculate_semantic_inhibition(
            relevance, control_state
        )

        # Retrieve weak and non-dominant associations
        activation = controlled_retrieval(
            activation,
            gain,
            inhibition,
            control_state
        )

        # Evaluate retrieved information
        evaluation = evaluate_semantic_candidates(
            activation,
            task_state,
            context_state
        )

        # Calculate retrieval error
        error = calculate_retrieval_error(
            evaluation, task_state
        )

        # Adapt control parameters
        demand = update_control_demand(
            demand, error
        )

    # STAGE 16: Integrate selected semantic features
    final_representation = integrate_selected_features(
        activation
    )

    # STAGE 17: Produce interpretation or response
    response = generate_semantic_response(
        final_representation,
        task_state
    )

    # STAGE 18: Update learning and control parameters
    update_semantic_learning(
        final_representation,
        response
    )

    return response
</CodeBlock>

This pseudocode defines the architectural interfaces. Functions such as `integrate_semantic_hub`, `recruit_control_network`, and `controlled_retrieval` would each require their own detailed algorithms and data structures.

## 10. The most important architectural conclusions

There are five fundamental principles that should be preserved when implementing CSC.

**1. Semantic knowledge and semantic control must be separate.**

The system must distinguish between not knowing something and knowing it but failing to retrieve the appropriate information for the task.

**2. The ATL hub should not become an executive controller.**

Its computational responsibility is multimodal conceptual integration. Task-specific selection should be handled by the interacting control system.

**3. Semantic control should be dynamic.**

The system should not apply maximum control to every semantic task. Familiar associations can use relatively automatic processing, whereas difficult tasks require stronger and more targeted control.

**4. Amplification and inhibition must operate together.**

Increasing relevant semantic features is only half the problem. The system must also reduce interference from irrelevant features.

**5. Control must be recurrent and task-dependent.**

The control system must be able to evaluate retrieval, change its retrieval priorities, and repeat processing until it has sufficient information.

**My recommendation:** Treat CSC as a separate, complete computational subsystem that can connect to other language, reading, discourse, and reasoning subsystems. Its most valuable contribution is not simply representing what a concept means, but dynamically determining which knowledge about that concept should influence the current thought.

This distinction is especially important when combining CSC with a larger brain-inspired architecture: semantic memory provides the knowledge, while semantic control determines how that knowledge is used. 

For the next implementation stage, the most useful starting point would be defining the precise data structures and mathematical interfaces connecting the ATL hub, semantic spokes, IFG, and pMTG, before implementing the 18 stages as Python classes and operations.
