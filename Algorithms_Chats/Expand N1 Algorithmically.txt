# ORE Neurocomputational Development Roadmap
## Phase N1 — Neural Simulation Foundations: Complete Algorithmic Specification

I reviewed the actual `ORE_NEUROCOMPUTATIONAL_DEVELOPMENT_ROADMAP_v1.0.md` in your Library.

One important clarification: the current roadmap names N1 **Early Visual Processing**. Its purpose is to establish the computational foundations for transforming visual input into neural-like feature representations. I will expand that phase into a much larger algorithm, including the biological mechanisms that motivate each operation and the mathematical equations ORE can use to simulate them. <FileCite ref_id="turn3file0"/>

The central objective is:

**Make ORE transform visual information through a sequence of computational operations inspired by the visual nervous system, rather than treating an image merely as a matrix that gets passed through an ordinary image-processing pipeline.**

There is an important scientific distinction throughout this specification:

- **Biological mechanism:** What neurons and neural circuits are known or hypothesized to do.
- **Mathematical model:** An equation that approximates the computational behavior of that mechanism.
- **ORE implementation:** The actual algorithm that executes the mathematical model.
- **Scientific validation:** Evidence that the implemented model reproduces measured biological or behavioral properties.

These four things must never be treated as equivalent.

# Part I — Understanding the computational objective

This distinction is important.

N1 should not decide whether the image represents `a`, `b`, or `c`. That is the responsibility of subsequent processing.

N1 should extract information that allows later neural-inspired components to make that decision.

## 2. The complete mathematical processing objective

Let the incoming visual image be:

\[
I_0\in[0,1]^{H\times W}
\]

Where:

- \(H\): image height.
- \(W\): image width.
- \(I_0(x,y)\): pixel intensity.
- \(0\): black.
- \(1\): white.

N1 transforms the image through a series of functions:

\[
I_0
\xrightarrow{T_1}
I_1
\xrightarrow{T_2}
I_2
\xrightarrow{T_3}
I_3
\xrightarrow{T_4}
I_4
\xrightarrow{T_5}
I_5
\xrightarrow{T_6}
X
\]

The final representation is:

\[
X\in\mathbb{R}^{d}
\]

Here, \(d\) is the number of extracted visual features.

The algorithm must preserve an inspectable record of the intermediate representations so that we can determine exactly what happened to the original visual information.

# Part II — The biological mechanisms underlying N1

Before specifying the algorithm, we need to identify the biological operations it is intended to approximate.

## 3. Mechanism 1: Photoreceptor signal transformation

<AsyncImage query="human retina photoreceptor rods cones bipolar cells horizontal cells retinal ganglion cell anatomical illustration neuroscience" aspectRatio="16:9" width="100%" maxHeight={210} fit="contain"/>

The first stage takes place in the retina.

Photoreceptors respond to incoming light. Their outputs are transformed by retinal circuits before signals reach the brain.

The important computational properties include:

1. Conversion of light into electrical signals.
2. Sensitivity adaptation to prevailing illumination.
3. Spatial comparison between neighboring visual locations.
4. Separation of luminance increases and decreases.
5. Transmission of visual changes rather than simply copying absolute brightness.

### 3.1.1 Possible mathematical operation: temporal integration

A photoreceptor does not need to respond independently to every individual photon.

A simplified model can represent accumulated light over a time interval:

\[
Q_i(t)=
\int_{-\infty}^{t}
L_i(\tau)h(t-\tau)d\tau
\]

Where:

- \(L_i(t)\): incoming light at location \(i\).
- \(h(t)\): temporal response function.
- \(Q_i(t)\): integrated light signal.

This is a convolution in time.

A simple implementation could use an exponential filter:

\[
Q_i(t)=
(1-\alpha)Q_i(t-1)+\alpha L_i(t)
\]

This allows the system to retain information from previous time steps.

**ORE interpretation:** Instead of treating every image as an isolated event, the neural extension could maintain a temporal visual state.

This is not present in the current static-image N1 implementation.

### 3.1.2 Possible mathematical operation: nonlinear light response

A simplified saturating response is:

\[
R_i=
R_{\max}
\frac{Q_i}{Q_i+K}
\]

Where:

- \(R_{\max}\): maximum response.
- \(K\): half-saturation parameter.

This represents the general principle that responses cannot increase indefinitely with light intensity.

The exact photoreceptor transduction mechanism is more complicated than this equation.

### 3.1.3 Light adaptation

The visual system must handle large variations in overall illumination.

One possible mathematical approximation is to maintain an adaptive estimate of background illumination:

\[
B_i(t)=
(1-\alpha)B_i(t-1)+\alpha L_i(t)
\]

Then calculate relative intensity:

\[
C_i(t)=
\frac{L_i(t)-B_i(t)}
{B_i(t)+\epsilon}
\]

This makes the representation more sensitive to changes relative to the local background.

**Why this matters to ORE:**

A letter should ideally remain recognizable under different brightness conditions.

For example, these images should ideally generate similar structural representations:

- A black letter on a white background.
- A dark-gray letter on a light-gray background.
- A light letter on a dark background, where the appropriate polarity representation is used.

These should become explicit experiments rather than assumed properties.

## 4. Mechanism 2: Retinal center-surround processing

<AsyncImage query="retinal ganglion cell ON center OFF surround OFF center ON surround receptive field diagram" aspectRatio="16:9" width="100%" maxHeight={190} fit="contain"/>

Retinal ganglion cells often have receptive fields consisting of:

- A central region.
- A surrounding region.
- Opposing responses between those regions.

For example, an ON-center cell increases its response when light increases in the center, while illumination in the surround can suppress its response.

A mathematical model uses a Difference of Gaussians (DoG).

### 4.1.1 Gaussian spatial integration

First define a two-dimensional Gaussian:

\[
G_\sigma(x,y)=
\frac{1}{2\pi\sigma^2}
\exp\left(
-\frac{x^2+y^2}{2\sigma^2}
\right)
\]

The central Gaussian has a smaller spatial extent than the surround Gaussian.

### 4.1.2 Center-surround subtraction

\[
R(x,y)=
G_{\sigma_c}*I(x,y)
-
kG_{\sigma_s}*I(x,y)
\]

Where:

- \(\sigma_c\): center receptive-field scale.
- \(\sigma_s\): surround receptive-field scale.
- \(k\): surround strength.
- \(*\): convolution.

Normally:

\[
\sigma_s>\sigma_c
\]

This operation compares local brightness with its surroundings.

It can highlight transitions, edges and local contrast.

### 4.1.3 ON/OFF decomposition

The result can be separated into positive and negative responses:

\[
R_{\text{ON}}(x,y)=\max(0,R(x,y))
\]

\[
R_{\text{OFF}}(x,y)=\max(0,-R(x,y))
\]

This gives ORE two separate representations:

- Evidence for luminance increments.
- Evidence for luminance decrements.

These channels should not immediately be merged because they may provide useful information about edge polarity and stroke structure.

The center-surround model is a well-established computational description of retinal receptive fields, although actual retinal circuits involve additional temporal, nonlinear and cellular mechanisms. <Cite refs={["turn328518search6","turn912957view0"]}/>

<badge color="info">Proposed biological extension</badge>

The current N1 implementation does not implement a retinal DoG stage or separate ON/OFF populations. Its white-to-ink conversion is a simpler engineering operation.

## 5. Mechanism 3: LGN contrast gain control

<AsyncImage query="lateral geniculate nucleus visual pathway retina optic nerve LGN primary visual cortex diagram" aspectRatio="16:9" width="100%" maxHeight={190} fit="contain"/>

The lateral geniculate nucleus (LGN) receives retinal signals and participates in transmitting and modulating visual information.

One relevant property is contrast gain control.

The visual system adjusts its sensitivity depending on the local contrast of the visual stimulus.

### 5.1.1 Local contrast estimation

A possible operation is root-mean-square contrast:

\[
C_{\mathrm{RMS}}=
\sqrt{
\frac{1}{N}
\sum_{i=1}^{N}
(I_i-\bar I)^2
}
\]

### 5.1.2 Gain adjustment

A simplified normalization function is:

\[
R_i=
\frac{U_i}
{\sigma+\gamma C_{\mathrm{RMS}}}
\]

Where:

- \(U_i\): incoming response.
- \(\sigma\): stabilizing constant.
- \(\gamma\): contrast-sensitivity parameter.

This prevents strong local contrast from dominating the representation without limitation.

Experimental work supports contrast-dependent suppression in retinal and LGN processing, including models based on suppressive fields and local contrast estimation. <Cite refs={["turn328518search1","turn420393search8"]}/>

This mechanism is particularly relevant to ORE because letters may be presented under different acquisition conditions.

For example:

- Scanned documents.
- Photographed pages.
- Low-resolution screenshots.
- Faint printed letters.
- Uneven illumination.

A biologically motivated ORE should eventually test whether contrast gain control improves robustness across these conditions.

## 6. Mechanism 4: V1 receptive fields and orientation selectivity

<AsyncImage query="primary visual cortex V1 simple cell oriented receptive field Gabor filter neuroscience illustration" aspectRatio="16:9" width="100%" maxHeight={205} fit="contain"/>

This is where the connection with ORE's current N1 implementation becomes especially important.

Neurons in the primary visual cortex (V1) respond selectively to image properties such as:

- Orientation.
- Spatial frequency.
- Spatial position.
- Stimulus size.
- Other visual features.

A classical explanation of orientation selectivity involves combining appropriately arranged LGN inputs.

The alignment of those inputs makes certain orientations produce stronger and more synchronized excitation. Neural thresholds and other circuit mechanisms further shape the response. <Cite refs={["turn912957view0","turn420393search9"]}/>

The mathematical abstraction most useful for ORE is the Gabor filter.

We will develop this in the main algorithm.

---

## 7. Mechanism 5: Simple cells and complex cells

<AsyncImage query="V1 simple cell complex cell quadrature pair phase invariant energy model neuroscience diagram" aspectRatio="16:9" width="100%" maxHeight={205} fit="contain"/>

A useful distinction is:

**Simple-cell-like response**

A neuron responds to an oriented feature with a particular spatial alignment or phase.

**Complex-cell-like response**

A neuron can respond to a similar oriented feature across a broader range of spatial phases.

A widely used computational model uses two filters whose phases differ by 90 degrees.

Their squared responses are combined to produce phase-tolerant energy.

\[
E(x,y)=
\sqrt{R_e(x,y)^2+R_o(x,y)^2}
\]

This is called quadrature energy.

It provides a particularly useful mathematical foundation for ORE's N1 feature extraction. <Cite refs={["turn420393search1","turn420393search5","turn420393search11"]}/>

# Part III — The complete N1 algorithm

We can now construct the actual algorithm.

It has three types of operations:

1. Operations already implemented in N1.
2. Biological operations that explain why those computations are useful.
3. Proposed extensions that would make the simulation more biologically detailed.

The current implementation is documented in `ore_neuro/core.py`, inside `EarlyVisualEncoder`. <FileCite ref_id="turn3file0"/>

# Algorithm N1 — Early Visual Neural Processing

<badge color="success">Current N1 implementation: software complete</badge>

## Step 0 — Initialize the visual-processing system

**Objective:** Establish the configuration and parameters that control the visual transformation.

### Inputs

- Grayscale image.
- Image dimensions.
- Filter orientations.
- Gabor wavelengths.
- Local normalization settings.
- Pooling configuration.
- Numerical stability constants.
- Random seed, where relevant.

### Mathematical operations

Define:

\[
\Theta=\{\theta_1,\theta_2,\ldots,\theta_m\}
\]

As the set of filter orientations.

Define:

\[
\Lambda=\{\lambda_1,\lambda_2,\ldots,\lambda_n\}
\]

As the set of spatial wavelengths.

These determine the Gabor filter bank.

For example, an initial experimental configuration could use orientations distributed across:

\[
0^\circ,\ 30^\circ,\ 60^\circ,\
90^\circ,\ 120^\circ,\ 150^\circ
\]

These are engineering starting points, not measured universal biological constants.

### Neural interpretation

V1 contains populations with different receptive-field preferences.

A computational population must therefore contain multiple feature-selective units rather than only one filter.

### ORE operation

Create the filter configuration and initialize the encoder.

Store every parameter in a versioned configuration.

## Step 1 — Validate the incoming visual signal

**Objective:** Ensure that the incoming representation is mathematically valid.

### Algorithm

1. Receive the grayscale matrix.
2. Verify that it has two dimensions.
3. Check that every row has the same width.
4. Check that values are finite.
5. Verify that pixel values lie within the allowed range.
6. Reject empty or malformed matrices.
7. Preserve the original input without modification.

### Mathematical conditions

\[
I(x,y)\in[0,1]
\]

\[
I(x,y)\neq NaN
\]

\[
I(x,y)\neq\pm\infty
\]

### Neural interpretation

The brain does not perform software-style validation.

This operation exists because ORE is a computational system that must reject invalid inputs before they contaminate its subsequent calculations.

A biological model could instead represent sensor noise, uncertainty or abnormal signal ranges.

**Important:** Never silently modify the original input to make an invalid input appear valid.

---

## Step 2 — Convert image intensity into ink strength

**Objective:** Make dark visual structures produce stronger feature responses.

The current N1 implementation assumes that the incoming image has a white background.

### Mathematical operation

\[
I_1(x,y)=1-I_0(x,y)
\]

Examples:

| Original intensity | Resulting ink strength |
|---:|---:|
| 0.0 — black | 1.0 |
| 0.2 — dark gray | 0.8 |
| 0.5 — gray | 0.5 |
| 0.8 — light gray | 0.2 |
| 1.0 — white | 0.0 |

### Neural interpretation

The biological visual system does not literally reverse all image intensities to produce an ink-strength matrix.

Rather, it represents luminance increments and decrements using different response channels.

A more biologically detailed version of ORE should preserve both:

\[
I_{\text{ON}}=\max(0,I-\mu)
\]

\[
I_{\text{OFF}}=\max(0,\mu-I)
\]

Here, \(\mu\) is a local or adapted luminance reference.

### Important implementation decision

Keep the current ink transformation for the existing grayscale pipeline.

Add ON/OFF channels as a separate experimental representation instead of silently replacing the original operation.

---

## Step 3 — Spatial resampling

**Objective:** Convert images of different dimensions into a common computational scale.

Consider two glyphs:

- Image A: 20 × 20 pixels.
- Image B: 100 × 100 pixels.

Directly comparing their feature representations would introduce differences caused by input dimensions.

### 3.1. Bilinear interpolation

ORE calculates a standardized image:

\[
I_2\in\mathbb{R}^{S\times S}
\]

For a new pixel coordinate \((u,v)\), it identifies the four nearest source pixels.

Then:

\[
I_2(u,v)=
w_{00}I_1(x_0,y_0)
+
w_{10}I_1(x_1,y_0)
\]

\[
+
w_{01}I_1(x_0,y_1)
+
w_{11}I_1(x_1,y_1)
\]

Where the interpolation weights satisfy:

\[
\sum_{a,b}w_{ab}=1
\]

### 3.2. Why interpolation matters

It creates a consistent input resolution.

Without resampling, the Gabor filter bank would encounter different spatial sampling conditions.

### Neural interpretation

There is a broad conceptual relationship to spatial sampling and receptive-field organization.

However, the brain does not resize each letter into an identical square image.

The retina and visual cortex maintain spatially organized representations, with nonuniform spatial resolution and receptive-field sizes.

Therefore, bilinear resampling is an engineering normalization operation, not a direct simulation of retinal processing.

### Future improvement

Introduce a retinotopic representation with multiple receptive-field sizes rather than relying entirely on a globally resized image.

## Step 4 — Calculate local mean intensity and local variance

<badge color="info">Core normalization preparation</badge>

**Objective:** Determine the local brightness and contrast characteristics of the image.

The brain needs to distinguish relevant local variations from broad changes in illumination.

ORE currently calculates local statistics using a 3 × 3 neighborhood.

### 4.1. Local mean

For each pixel:

\[
\mu(x,y)=
\frac{1}{9}
\sum_{i=-1}^{1}
\sum_{j=-1}^{1}
I_2(x+i,y+j)
\]

This estimates the local average intensity.

### 4.2. Local variance

\[
\sigma^2(x,y)=
\frac{1}{9}
\sum_{i=-1}^{1}
\sum_{j=-1}^{1}
\left[
I_2(x+i,y+j)-\mu(x,y)
\right]^2
\]

This estimates the local variability.

### 4.3. Equivalent computational shortcut

The variance can also be calculated as:

\[
\sigma^2=
E[I^2]-E[I]^2
\]

This allows implementation using local filtering operations.

### Neural interpretation

These calculations approximate aspects of local adaptation and contrast estimation.

Biological contrast-sensitive mechanisms can estimate local contrast through spatial interactions and temporal adaptation.

The exact 3 × 3 window is an ORE design choice, not a biological receptive-field size.

### ORE output

Preserve two feature maps:

\[
M(x,y)=\mu(x,y)
\]

\[
V(x,y)=\sigma^2(x,y)
\]

Both should be available in the diagnostic trace.

## Step 5 — Perform local contrast normalization

<badge color="success">Implemented in N1</badge>

**Objective:** Reduce sensitivity to local brightness changes.

### Mathematical operation

\[
I_n(x,y)=
\frac{
I_2(x,y)-\mu(x,y)
}{
\sqrt{\max(\sigma^2(x,y),\epsilon)}
}
\]

Where \(\epsilon\) prevents division by zero.

### 5.1. Why subtract the local mean?

\[
I_2-\mu
\]

This reduces the influence of the local average brightness.

The system is now more interested in how a pixel differs from its neighbors.

### 5.2. Why divide by the standard deviation?

\[
\frac{I_2-\mu}{\sigma}
\]

This reduces the effect of differences in local contrast magnitude.

For example, the same stroke might appear in an image with relatively high contrast and another image with relatively low contrast.

Normalization helps prevent these variations from unnecessarily changing the representation.

### 5.3. Biological interpretation

This stage is computationally related to contrast gain control.

However, there is a crucial difference.

The current ORE operation is local statistical standardization.

Biological visual normalization is more complex and can involve:

- Receptive-field interactions.
- Inhibitory circuits.
- Population-level normalization.
- Temporal changes in neural sensitivity.

Divisive normalization has substantial experimental and modeling support in V1. <Cite refs={["turn912957view1","turn420393search10","turn420393search12"]}/>

**Important design recommendation:** Preserve the current normalization as the baseline and create separate experimental alternatives for retinal DoG and cortical divisive normalization. That will let us identify which biological approximation actually improves recognition.

## Step 6 — Construct the oriented Gabor filter bank

<badge color="success">Implemented in N1</badge>

This is one of the most important operations in the entire phase.

**Objective:** Extract visual features according to orientation and spatial frequency.

<AsyncImageGroup query={["Gabor filter orientation 0 45 90 135 visual receptive fields visualization","Gabor filter bank multiple spatial frequencies visual neuroscience","even odd Gabor quadrature pair visualization"]} aspectRatio="5:4" layout="carousel"/>

### 6.1. Why orientation matters

Written characters are constructed from visual structures with different orientations.

For example, a glyph can contain:

- Vertical strokes.
- Horizontal strokes.
- Diagonal strokes.
- Curved components.
- Junctions between strokes.

A filter that responds strongly to vertical structures should behave differently from one that responds strongly to horizontal structures.

### 6.2. Mathematical construction

Start with the original spatial coordinates:

\[
(x,y)
\]

Rotate the coordinates to the orientation of the filter:

\[
x_\theta=x\cos\theta+y\sin\theta
\]

\[
y_\theta=-x\sin\theta+y\cos\theta
\]

Now define an oriented Gaussian envelope:

\[
G(x,y)=
\exp\left(
-\frac{x_\theta^2+\gamma^2 y_\theta^2}
{2\sigma^2}
\right)
\]

Where:

- \(\theta\): preferred orientation.
- \(\sigma\): spatial extent.
- \(\gamma\): spatial aspect ratio.

### 6.3. Even-symmetric Gabor filter

\[
g_e(x,y)=
G(x,y)
\cos\left(
\frac{2\pi x_\theta}{\lambda}
\right)
\]

### 6.4. Odd-symmetric Gabor filter

\[
g_o(x,y)=
G(x,y)
\sin\left(
\frac{2\pi x_\theta}{\lambda}
\right)
\]

The two filters are separated by a quarter cycle of phase.

### 6.5. Spatial frequency

\[
f=\frac{1}{\lambda}
\]

Smaller wavelengths represent higher spatial frequencies.

Larger wavelengths represent lower spatial frequencies.

This means that ORE can have different filters responding to different stroke scales and patterns.

### Neural interpretation

The Gabor family approximates important properties of V1 receptive fields, including orientation and spatial-frequency selectivity.

It is a functional model, not a direct reconstruction of an individual biological neuron.

The relationship between oriented receptive fields and Gabor-like filters is well established in visual-cortex modeling. <Cite refs={["turn420393search1","turn912957view1"]}/>

### ORE operation

For every configured orientation:

1. Generate the even filter.
2. Generate the odd filter.
3. Generate filters at all configured wavelengths.
4. Store their mathematical parameters.
5. Preserve filter identifiers for diagnostic tracing.

## Step 7 — Calculate neural-like feature responses through convolution

**Objective:** Determine how strongly each oriented filter matches different locations in the image.

### 7.1. Convolution

For the even filter:

\[
R_e(x,y)=
\sum_{u,v}
I_n(x-u,y-v)g_e(u,v)
\]

For the odd filter:

\[
R_o(x,y)=
\sum_{u,v}
I_n(x-u,y-v)g_o(u,v)
\]

Each convolution calculates a weighted combination of neighboring image values.

The result is a feature-response map.

### 7.2. What does convolution accomplish?

Imagine a vertical Gabor filter.

When it encounters a vertical structure, the weighted sum may become large.

When it encounters a horizontal structure, the response may be smaller.

Each filter therefore acts as a detector for a particular visual pattern.

### 7.3. Biological interpretation

This approximates the integration of excitatory and inhibitory synaptic inputs across a neuron's receptive field.

A simplified membrane-potential model is:

\[
V_j=
\sum_i w_{ij}S_i
\]

Where:

- \(S_i\): incoming neural signal.
- \(w_{ij}\): connection strength.
- \(V_j\): resulting membrane-potential change.

Actual neurons have temporal dynamics, nonlinear synaptic currents and membrane properties.

Priebe and Ferster discuss how receptive-field properties arise through combinations of thalamic input, synaptic mechanisms, threshold and membrane time constants. <Cite refs={["turn912957view0","turn980652view3"]}/>

### 7.4. A more realistic neural simulation

Eventually, we should replace the purely static filter-response calculation with a neuron model such as leaky integrate-and-fire.

\[
\tau_m\frac{dV}{dt}
=
-(V-E_L)+R_m I_{\mathrm{syn}}(t)
\]

Where:

- \(\tau_m\): membrane time constant.
- \(E_L\): resting potential.
- \(R_m\): membrane resistance.
- \(I_{\mathrm{syn}}\): total synaptic input.

When:

\[
V(t)\geq V_{\mathrm{threshold}}
\]

The neuron produces a spike, after which its membrane state is reset according to the model.

This introduces an important difference between the current implementation and a true neural simulation:

**Current N1 computes continuous feature responses. A more biologically detailed N1 would simulate changing neuronal states and potentially discrete spike events.**

I would not replace the current implementation yet. First, we should establish whether the additional temporal and neuronal mechanisms provide measurable benefits.

## Step 8 — Calculate quadrature energy

<badge color="success">Implemented in N1</badge>

**Objective:** Produce a feature representation that is less sensitive to the exact phase or alignment of the stimulus.

We have two responses:

\[
R_e(x,y)
\]

\[
R_o(x,y)
\]

Combine them:

\[
E(x,y)=
\sqrt{
R_e(x,y)^2+
R_o(x,y)^2
}
\]

This is the quadrature energy calculation.

### 8.1. Why square the responses?

Squaring makes both positive and negative filter responses contribute to the energy.

### 8.2. Why add them?

The two responses provide complementary information because the filters differ in phase.

### 8.3. Why calculate the square root?

The square root converts squared energy into a magnitude-like response.

### 8.4. What does this accomplish?

A visual edge shifted slightly within the receptive field may produce substantially different even and odd responses.

However, their combined energy can remain relatively stable.

That is valuable for recognizing visual structures despite small differences in alignment.

### Neural interpretation

This is inspired by complex-cell energy models, in which quadrature filter responses are combined to obtain a more phase-tolerant representation.

It does not mean that an individual neuron literally evaluates a software square-root instruction.

It represents the computational relationship between multiple neural responses. <Cite refs={["turn420393search5","turn420393search11"]}/>

## Step 9 — Apply population-level divisive normalization (proposed extension)

<badge color="info">Not implemented in current N1</badge>

Although current N1 already normalizes image contrast before Gabor filtering, it does not implement a separate V1 population normalization stage.

This distinction matters because neural normalization can operate on the responses of multiple neurons, not merely on raw input pixels.

### 9.1. Calculate the activity of neighboring feature-selective units

For a population of units:

\[
D_i=
\sum_j w_{ij}E_j^p
\]

Where:

- \(E_j\): activity of neighboring units.
- \(w_{ij}\): normalization-pool weights.
- \(p\): exponent.

### 9.2. Calculate normalized activity

\[
R_i=
\frac{E_i^p}
{\sigma^p+D_i}
\]

This is a simplified divisive-normalization equation.

### 9.3. Why does it matter?

Suppose a particular image region contains many strong visual responses.

Without normalization, these responses could dominate the feature representation.

With normalization, each response is evaluated relative to the broader activity of the relevant population.

This can stabilize responses across different contrast conditions.

Divisive normalization models have been used to explain multiple physiological response properties in V1. The precise biological circuit implementing each normalization effect is not necessarily settled by the mathematical equation itself. <Cite refs={["turn912957view1","turn420393search10"]}/>

### ORE experiment

Add an independently switchable normalization mechanism.

Compare:

- No normalization.
- Input-level local normalization only.
- Gabor-response normalization.
- Both forms of normalization.

This will help identify whether the additional operation is beneficial or redundant.

## Step 10 — Spatial pooling

<badge color="success">Implemented in N1</badge>

**Objective:** Summarize nearby feature responses into a more compact spatial representation.

Each energy map is divided into 2 × 2 cells.

For each cell, ORE calculates two quantities.

### 10.1. Mean pooling

\[
P_{\mathrm{mean}}=
\frac{E_1+E_2+E_3+E_4}{4}
\]

This captures the average response.

### 10.2. Maximum pooling

\[
P_{\max}=
\max(E_1,E_2,E_3,E_4)
\]

This captures the strongest local response.

### 10.3. Why use both?

They provide different information.

| Operation | Information |
|---|---|
| Mean pooling | Overall response strength in the region |
| Maximum pooling | Strongest response in the region |

Combining them provides a richer description of the local feature distribution.

### Neural interpretation

Pooling has a connection to the convergence of multiple local feature responses onto later neural populations.

For example, a complex-cell-like population can pool responses from similarly tuned simple cells.

However, conventional maximum pooling is a computational approximation. It should not be confused with a demonstrated universal neural mechanism.

---

## Step 11 — Construct the final feature vector

**Objective:** Combine the extracted feature maps into one vector.

Suppose each orientation and wavelength combination generates a pooled vector.

Concatenate all those vectors:

\[
F=
[
P_{\theta_1,\lambda_1},
P_{\theta_1,\lambda_2},
\ldots,
P_{\theta_m,\lambda_n}
]
\]

This creates a multidimensional visual representation.

### 11.1. L2 normalization

Calculate its Euclidean norm:

\[
\|F\|_2=
\sqrt{
\sum_{i=1}^{d}F_i^2
}
\]

Then:

\[
X=
\frac{F}
{\|F\|_2+\epsilon}
\]

The resulting vector is normalized.

### 11.2. Why is normalization useful?

It reduces sensitivity to the overall magnitude of the response.

Two similar patterns with different absolute activation strengths can therefore have more comparable representations.

### Neural interpretation

There is a broad connection to population-activity normalization.

However, global L2 normalization of a software feature vector is not a literal description of a known biological computation.

It is an engineering choice.

## Step 12 — Generate the diagnostic neural activity record

**Objective:** Make the processing sequence inspectable.

N1 should not simply return a vector.

It should return the intermediate evidence that produced that vector.

For every patch, preserve:

| Diagnostic field | Description |
|---|---|
| Original image | Unmodified incoming grayscale matrix |
| Ink representation | White-to-ink transformed matrix |
| Resampled image | Standardized image dimensions |
| Local mean | Local brightness estimate |
| Local variance | Local contrast estimate |
| Normalized image | Contrast-normalized matrix |
| Gabor configuration | Orientations and wavelengths |
| Even responses | Even-filter response maps |
| Odd responses | Odd-filter response maps |
| Energy maps | Quadrature energy outputs |
| Pooled maps | Mean and maximum summaries |
| Final vector | Normalized feature representation |

Also record:

- N1 version.
- Configuration fingerprint.
- Input fingerprint.
- Numerical parameters.
- Runtime diagnostics.
- Numerical warnings.
- Execution status.

This provides the foundation for future experiments.

## Step 13 — Transfer the representation to N2

N1 now produces:

\[
X_i\in\mathbb{R}^d

This representation is passed to N2.

N2 uses labeled reference glyphs to construct grapheme-selective prototypes and calculates candidate similarity.

The interface should be:

\boxed{

N1 must not make a final grapheme decision.

It should not use learned word probabilities to modify its raw visual evidence.

# Part IV — The complete algorithm in pseudocode

The following is the unified algorithm corresponding to the current N1 implementation.

The optional biological extensions are identified separately so that they cannot accidentally be mistaken for currently implemented functionality.

<CodeBlock language="python" editable>
ALGORITHM N1_EARLY_VISUAL_PROCESSING

INPUT:
    grayscale_image
    N1_configuration

OUTPUT:
    normalized_visual_feature_vector
    visual_processing_diagnostics

INITIALIZE:

    orientations = configuration.orientations
    wavelengths = configuration.wavelengths
    image_size = configuration.image_size
    epsilon = configuration.epsilon

    diagnostic_record = {}

STEP 1: VALIDATE INPUT

    validate grayscale_image

    require:
        image is rectangular
        image has valid dimensions
        every pixel is finite
        every pixel lies in [0, 1]

    preserve original_image

STEP 2: CONVERT INTENSITY TO INK STRENGTH

    ink_image = 1 - original_image

    preserve ink_image

STEP 3: STANDARDIZE SPATIAL DIMENSIONS

    resized_image = bilinear_resize(
        ink_image,
        image_size,
        image_size
    )

STEP 4: CALCULATE LOCAL STATISTICS

    local_mean = mean_filter(
        resized_image,
        kernel_size = 3
    )

    local_variance = variance_filter(
        resized_image,
        kernel_size = 3
    )

STEP 5: NORMALIZE LOCAL CONTRAST

    local_std = sqrt(
        maximum(local_variance, epsilon)
    )

    normalized_image = (
        resized_image - local_mean
    ) / local_std

STEP 6: INITIALIZE FEATURE COLLECTION

    all_feature_maps = []
    all_filter_diagnostics = []

STEP 7: GENERATE ORIENTED FILTER RESPONSES

    FOR each wavelength IN wavelengths:

        FOR each orientation IN orientations:

            even_filter = generate_even_gabor(
                orientation,
                wavelength
            )

            odd_filter = generate_odd_gabor(
                orientation,
                wavelength
            )

            even_response = convolve(
                normalized_image,
                even_filter
            )

            odd_response = convolve(
                normalized_image,
                odd_filter
            )

STEP 8: COMPUTE QUADRATURE ENERGY

            energy_map = sqrt(
                even_response ** 2
                +
                odd_response ** 2
            )

STEP 9: SPATIAL POOLING

            mean_features = mean_pool(
                energy_map,
                cell_size = 2
            )

            max_features = max_pool(
                energy_map,
                cell_size = 2
            )

            combined_features = concatenate(
                mean_features,
                max_features
            )

            append combined_features
                to all_feature_maps

            save filter responses
                and energy diagnostics

STEP 10: CONCATENATE FEATURE REPRESENTATIONS

    feature_vector = concatenate(
        all_feature_maps
    )

STEP 11: L2 NORMALIZATION

    vector_norm = sqrt(
        sum(feature_vector ** 2)
    )

    normalized_feature_vector = (
        feature_vector
        /
        (vector_norm + epsilon)
    )

STEP 12: BUILD DIAGNOSTIC RECORD

    save:
        original_image
        ink_image
        resized_image
        local_mean
        local_variance
        normalized_image
        filter_configurations
        even_responses
        odd_responses
        energy_maps
        pooled_features
        final_feature_vector

STEP 13: VALIDATE OUTPUT

    require all features are finite

    require output dimension is correct

    verify numerical normalization

STEP 14: RETURN

    return:
        normalized_feature_vector
        diagnostic_record

END ALGORITHM
</CodeBlock>

### 14.1. Why these extensions matter

There is a difference between:

\[
\text{Filter response}
\]

And:

\[
\text{Neuronal activity evolving over time}
\]

A Gabor filter can approximate the response characteristics of a simple cell.

But a biological neuron has:

- Membrane potential.
- Synaptic conductances.
- Excitatory inputs.
- Inhibitory inputs.
- Threshold mechanisms.
- Refractory periods.
- Temporal integration.
- Variability.

A sufficiently detailed simulation must represent at least some of these properties explicitly.

The full neural model does not necessarily need to simulate every ion channel. A hierarchy of increasingly detailed models is more practical.

For example:

| Simulation level | Mathematical representation |
|---|---|
| Level 1 | Linear filters |
| Level 2 | Filters + nonlinear activation |
| Level 3 | Population activity |
| Level 4 | Continuous-time membrane dynamics |
| Level 5 | Spiking neurons |
| Level 6 | Recurrent excitatory/inhibitory networks |

ORE should be able to compare these levels experimentally.

# Part VI — Scientific experiments required for N1

A neural-inspired algorithm should not be accepted merely because it produces reasonable-looking feature vectors.

We need to determine whether its operations produce the expected computational properties.

## 15. Required N1 experiments

| Experiment | Question being tested | Measurement |
|---|---|---|
| N1-E01 | Does orientation selectivity work? | Response versus stimulus orientation |
| N1-E02 | Does wavelength selectivity work? | Response versus spatial frequency |
| N1-E03 | Is phase sensitivity reduced by quadrature energy? | Response variance across phase shifts |
| N1-E04 | Does local normalization improve illumination robustness? | Performance across brightness changes |
| N1-E05 | Does contrast normalization improve contrast robustness? | Performance across contrast levels |
| N1-E06 | Does pooling preserve useful structure? | Feature stability under small translations |
| N1-E07 | Does normalization improve population stability? | Response saturation and sensitivity |
| N1-E08 | Does the system generalize to unseen glyphs? | Held-out feature and recognition metrics |
| N1-E09 | Are the response maps consistent with the model's biological predictions? | Neural-response model comparison |
| N1-E10 | Does temporal neural simulation improve processing? | Accuracy and response dynamics |

### 15.1. Experiment example: orientation selectivity

Generate a series of synthetic images with the same spatial frequency and contrast but different orientations.

For each image, calculate the response of a selected Gabor unit.

Let:

\[
R(\theta)
\]

Be the response at stimulus orientation \(\theta\).

We expect the filter to respond most strongly around its preferred orientation.

A Gaussian approximation can be fitted to the response:

\[
R(\theta)=
A\exp\left(
-\frac{d(\theta,\theta_0)^2}
{2\sigma_\theta^2}
\right)+b
\]

Where:

- \(\theta_0\): preferred orientation.
- \(\sigma_\theta\): orientation bandwidth.
- \(A\): response amplitude.
- \(b\): baseline.

We can then compare this response profile against experimental measurements of V1 orientation tuning.

### 15.2. Experiment example: phase invariance

Generate the same oriented grating with several different phases.

Calculate:

\[
E_\phi=
\sqrt{
R_{e,\phi}^{2}
+
R_{o,\phi}^{2}
}
\]

Measure response stability:

\[
CV=
\frac{\operatorname{std}(E_\phi)}
{\operatorname{mean}(E_\phi)+\epsilon}
\]

A smaller coefficient of variation indicates greater phase stability.

This experiment directly tests whether quadrature energy achieves the intended property.

### 15.3. Experiment example: illumination robustness

Generate multiple versions of the same glyph.

Apply:

- Brightness changes.
- Contrast changes.
- Background variation.
- Low contrast.
- Additive image noise.

Then compare the corresponding feature vectors:

\[
S(X_a,X_b)=
\frac{X_a\cdot X_b}
{\|X_a\|_2\|X_b\|_2+\epsilon}
\]

The similarity should remain relatively high when the underlying visual structure is unchanged.

Importantly, this similarity must not be confused with correct recognition. N2 and later recognition experiments remain necessary.

# Part IX — Final scientific and engineering interpretation

There is one broader idea I want to emphasize because it affects the direction of the entire ORE project.

**The goal should not be to make ORE use mathematical operations that merely resemble biological equations. The goal should be to make ORE reproduce computational properties that the biological visual system actually demonstrates.**

For example:

- Orientation selectivity is a measurable property.
- Spatial-frequency selectivity is measurable.
- Phase tolerance is measurable.
- Contrast adaptation is measurable.
- Population normalization is measurable.
- Neural temporal responses are measurable.

Each property gives us an independent experimental target.

We can then construct a model, test it, identify where it fails and refine the architecture.

This is much more scientifically meaningful than adding increasingly complicated neural terminology to conventional image-processing operations.

The current roadmap already protects the project from treating successful software execution as biological validation, and N8 explicitly requires independent real-corpus and neurocognitive evidence. <FileCite ref_id="turn3file0"/>

**My recommended next development decision:** Keep the current N1 as the reproducible computational baseline, and introduce the biological simulation pathway incrementally, beginning with retinal ON/OFF processing and center-surround mechanisms, followed by explicit temporal neural dynamics.

That will give ORE a progression from a useful visual feature extractor toward an experimentally testable model of the neural computations underlying early visual processing.
