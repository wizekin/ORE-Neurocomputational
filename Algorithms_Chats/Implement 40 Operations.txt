# Master Algorithm: Contextual Prediction in Human Orthographic Processing

The objective is to explain how the human brain uses linguistic context and expectations to predict letters and letter combinations while reading, then continuously compares those expectations with incoming visual evidence.

The central principle is:

**The brain does not simply recognize each letter independently. It combines incoming visual information with expectations derived from neighboring letters, learned spelling patterns, words and context. It then revises its interpretation as new evidence arrives.**

We can represent the process as a recurrent Bayesian inference system:

\[
\boxed{
P(H\mid E,C,A)
\propto
P(E\mid H,A)\,
P(H\mid C)
}
\]

Where:

- \(H\): a hypothesis about the identity of a character, grapheme or orthographic sequence.
- \(E\): incoming visual evidence.
- \(C\): linguistic and orthographic context.
- \(A\): attentional state.
- \(P(E\mid H,A)\): sensory likelihood, influenced by attention.
- \(P(H\mid C)\): contextual prior probability.

The seven requested operations form a larger algorithm with feedback loops, rather than seven completely independent steps.

A scientific qualification is important: Bayesian inference and predictive processing provide useful computational explanations of reading, but the brain is not known to execute these exact equations literally. The equations below are candidate computational models of the underlying neural computations.

## 1. Mathematical foundation and neural representations

Before constructing the algorithm, we need to define what information the brain is working with.

Assume the brain is processing a written sequence:

\[
W=(g_1,g_2,\ldots,g_n)
\]

Each \(g_i\) represents a grapheme at position \(i\).

A grapheme is not necessarily one character. Depending on the writing system, it may consist of multiple characters representing one orthographic unit.

For every position, the brain maintains several representations.

| Representation | Meaning |
|---|---|
| \(X_i\) | Observed visual features |
| \(G_i\) | Possible grapheme identities |
| \(B_i\) | Bottom-up sensory evidence |
| \(T_i\) | Orthographic transition evidence |
| \(N_i\) | Evidence from neighboring graphemes |
| \(P_i\) | Prior probability distribution |
| \(\pi_{s,i}\) | Sensory precision |
| \(\pi_{p,i}\) | Prior precision |
| \(Q_i\) | Posterior grapheme probability distribution |
| \(\epsilon_i\) | Prediction error |

The central computational objective is to estimate:

\[
Q_i(g)=P(g_i=g\mid X_1,\ldots,X_n,C)
\]

This represents the probability that the grapheme at position \(i\) has identity \(g\), given the visual evidence and the available context.

Importantly, the brain does not have to choose one grapheme immediately. It can maintain several competing possibilities.

For example:

\[
Q_i=
\begin{cases}
P(g_i=t)=0.55\\
P(g_i=r)=0.30\\
P(g_i=f)=0.15
\end{cases}
\]

These probabilities are illustrative, not measured neural values.

# Stage 1 — Bottom-up character evidence

<badge color="info">Operation group 1</badge>

## Objective

The brain receives visual information from the written stimulus and extracts evidence about which graphemes may be present at each position.

At this stage, the brain should not assume that it already knows the word.

It must first establish what the visual stimulus actually supports.

### Step 1.1 — Identify character positions

The incoming visual signal is divided into spatially distinguishable regions.

For example:

\[
I=(I_1,I_2,I_3,I_4,I_5)
\]

Each region corresponds approximately to a potential grapheme position.

The processing system must estimate:

- Where each character or grapheme is located.
- Its boundaries and spatial dimensions.
- Its relative position within the sequence.
- Whether neighboring characters interfere with its visual identification.

The positions do not necessarily have perfectly sharp boundaries. Overlapping visual information can create uncertainty about which grapheme belongs to which position.

**Possible mathematical operations**

Spatial position estimation:

\[
P(i\mid x,y)
\]

Bounding-region estimation:

\[
R_i=(x_{\min},y_{\min},x_{\max},y_{\max})
\]

Position uncertainty:

\[
\sigma_{\text{position},i}^2
\]

These quantities describe a computational approximation of the spatial information available to the visual system.

### Step 1.2 — Extract visual features

The visual system processes information such as:

- Horizontal and vertical orientations.
- Curves.
- Corners and intersections.
- Stroke endings.
- Closed and open contours.
- Relative distances between visual components.
- Spatial frequency information.

Represent the resulting information as a feature vector:

\[
X_i=
[x_{i1},x_{i2},\ldots,x_{im}]
\]

For example, a hypothetical visual representation might include:

\[
X_i=
[
\text{vertical strokes},
\text{curvature},
\text{junctions},
\text{horizontal edges}
]
\]

These are computational feature categories, not a claim that the brain stores exactly this vector.

**Possible mathematical operations**

Feature extraction:

\[
X_i=\Phi(I_i)
\]

Feature activation:

\[
a_{ik}=f(X_i,w_k)
\]

Here, \(w_k\) represents the sensitivity of a hypothetical feature detector.

A simple activation function could be:

\[
a_{ik}=\max(0,w_k^TX_i+b_k)
\]

This resembles rectified neural activation.

### Step 1.3 — Generate candidate grapheme identities

The visual features activate multiple possible grapheme representations.

Suppose the visual stimulus could represent either \(t\), \(r\), or \(f\).

The candidate set becomes:

\[
G_i=\{t,r,f\}
\]

Each candidate receives support based on its compatibility with the observed features.

One possible mathematical model is a Gaussian likelihood:

\[
P(X_i\mid g)=
\frac{1}{Z}
\exp\left[
-\frac{1}{2}
(X_i-\mu_g)^T
\Sigma_i^{-1}
(X_i-\mu_g)
\right]
\]

Where:

- \(\mu_g\) represents the expected feature pattern of grapheme \(g\).
- \(\Sigma_i\) represents uncertainty in the observed features.
- \(Z\) is a normalization constant.

This equation measures how closely the observed visual features resemble the expected visual pattern of each candidate.

### Step 1.4 — Accumulate sensory evidence over time

The brain does not necessarily identify a grapheme from one instantaneous sample.

New visual evidence can strengthen or weaken existing hypotheses.

A simple leaky accumulation model is:

\[
\frac{da_g}{dt}
=
-\frac{a_g}{\tau}
+
kE_g(t)
\]

Where:

- \(a_g\): activation of candidate grapheme \(g\).
- \(\tau\): decay time constant.
- \(E_g(t)\): incoming evidence.
- \(k\): sensory gain.

This produces a temporal accumulation process.

When incoming evidence repeatedly supports a particular grapheme, its activation increases.

When supporting evidence disappears, activation gradually declines.

### Stage 1 output

\[
B_i(g)=P(X_i\mid g)
\]

This is the bottom-up evidence distribution for each position.

<text color="secondary" size="xs">Biological interpretation: visual feature-sensitive populations in early visual cortex contribute to the representation of letter features. Later orthographic representations interact with these signals. Heilbron et al. demonstrated context-related enhancement of letter representations in early visual cortex. <Cite refs={["turn594105view0","turn594105view1"]}/></text>

# Stage 2 — Orthographic transition probabilities

<badge color="info">Operation group 2</badge>

## Objective

The brain uses previously acquired knowledge of written language to estimate which grapheme combinations are likely to occur.

For example, some letter combinations occur frequently in English, whereas others are uncommon or structurally restricted.

This knowledge helps constrain uncertain visual interpretations.

Importantly, these probabilities are not necessarily computed consciously. They can be represented through learned connection strengths in distributed neural networks.

### Step 2.1 — Retrieve learned orthographic statistics

The system retrieves information about grapheme sequences encountered during previous reading experiences.

For example:

\[
P(g_i\mid g_{i-1})
\]

This is the probability of observing a grapheme given the preceding grapheme.

A more advanced system uses two preceding graphemes:

\[
P(g_i\mid g_{i-2},g_{i-1})
\]

This provides trigram-level information.

The statistical representation can also include word-position information:

\[
P(g_i\mid i)
\]

For example, the distribution of possible first letters may differ from the distribution of possible final letters.

### Step 2.2 — Calculate transition strength

For each possible transition between two graphemes:

\[
T(a,b)=P(g_i=b\mid g_{i-1}=a)
\]

The probability may be estimated computationally from previous exposure statistics:

\[
T(a,b)=
\frac{N(a,b)+\alpha}
{\sum_j N(a,j)+\alpha K}
\]

Where:

- \(N(a,b)\): observed number of transitions from \(a\) to \(b\).
- \(K\): number of possible grapheme categories.
- \(\alpha\): smoothing parameter.

This is a mathematical approximation of how learned orthographic regularities constrain expectations.

### Step 2.3 — Construct sequence-level predictions

The transition probabilities combine to describe the likelihood of an entire grapheme sequence:

\[
P(G)=P(g_1)\prod_{i=2}^{n}P(g_i\mid g_{i-1})
\]

A higher-order model can replace the bigram probabilities with trigram probabilities.

The system can also combine:

- Grapheme position.
- Word frequency.
- Known spelling patterns.
- Morphological regularities.
- Previously learned word representations.

A combined prior might be:

\[
P_{\text{orth}}(G)
\propto
P_{\text{transition}}(G)
P_{\text{lexical}}(G)
\]

This prior supplies expectations before the uncertain visual evidence has been fully resolved.

### Step 2.4 — Convert transition probabilities into neural support

A convenient computational representation is:

\[
S_{\text{transition}}(g_i)
=
\log P(g_i\mid context_i)
\]

Logarithms convert multiplication of probabilities into addition.

This is useful because neural network models often combine several sources of excitatory and inhibitory influence through weighted summation.

For example:

\[
u_i(g)=
w_1S_{\text{previous letter}}+
w_2S_{\text{word position}}+
w_3S_{\text{orthographic frequency}}
\]

### Stage 2 output

A context-conditioned orthographic distribution:

\[
P_{\text{orth}}(g_i\mid C_{\text{orth}})
\]

This becomes an important source of top-down evidence.

<text color="secondary" size="xs">Biological interpretation: learned orthographic regularities influence letter and word-form representations. Computational word-recognition models incorporate letter-order constraints, word frequencies and competition between alternatives. <Cite refs={["turn766703search5","turn594105view2"]}/></text>

# Stage 3 — Predictions from neighboring grapheme beliefs

<badge color="info">Operation group 3</badge>

## Objective

The brain does not treat every grapheme position as an isolated unit.

The identity of one grapheme can influence predictions about neighboring graphemes.

At the same time, neighboring positions can provide information that helps resolve an ambiguous character.

This creates a bidirectional information exchange.

### Step 3.1 — Retrieve neighboring grapheme beliefs

Suppose the current sequence contains:

\[
G=(g_1,g_2,g_3,g_4,g_5)
\]

The brain maintains beliefs about each position:

\[
Q_i(g)=P(g_i=g)
\]

For position \(i=3\), the relevant neighbors include:

\[
Q_2(g),\quad Q_4(g)
\]

The neighboring beliefs may each contain multiple competing graphemes.

For example:

\[
Q_2(a)=0.9,\quad Q_2(o)=0.1
\]

\[
Q_4(t)=0.7,\quad Q_4(r)=0.3
\]

These values are illustrative.

### Step 3.2 — Generate predictions from the left neighbor

The left neighbor contributes a probability distribution based on learned orthographic transitions.

\[
M_{L,i}(g)=
\sum_h Q_{i-1}(h)T(h,g)
\]

This equation means:

1. Consider each possible identity of the preceding grapheme.
2. Retrieve its probability.
3. Determine how likely the current candidate is after that grapheme.
4. Combine the contributions.

Thus, the prediction does not depend exclusively on the most likely preceding letter.

It incorporates uncertainty across all plausible alternatives.

### Step 3.3 — Generate predictions from the right neighbor

The right neighbor also provides information.

\[
M_{R,i}(g)=
\sum_k Q_{i+1}(k)T(g,k)
\]

The system asks:

*If the current grapheme were \(g\), how compatible would it be with the possible graphemes to its right?*

This permits backward as well as forward constraints.

### Step 3.4 — Combine neighboring evidence

A combined neighboring prediction can be represented by:

\[
N_i(g)=
M_{L,i}(g)^{\lambda_L}
M_{R,i}(g)^{\lambda_R}
\]

Where:

- \(\lambda_L\): left-neighbor influence.
- \(\lambda_R\): right-neighbor influence.

The result can be normalized:

\[
\widehat N_i(g)=
\frac{N_i(g)}
{\sum_{g'}N_i(g')}
\]

A particularly important detail is that the model should not assume both neighbors have equal reliability. Their contributions can change with position, visual uncertainty and the writing system.

### Step 3.5 — Transmit contextual information to grapheme populations

In an interactive neural architecture, neighboring letter populations and higher-level orthographic representations influence activation at the current position.

A simplified model is:

\[
A_i(g)=
B_i(g)+
\lambda_LM_{L,i}(g)+
\lambda_RM_{R,i}(g)
\]

This models the combined bottom-up and neighboring support.

The actual biological network would involve distributed recurrent excitation, inhibition and feedback rather than a literal arithmetic operation.

### Step 3.6 — Preserve uncertainty in neighboring positions

A critical requirement is avoiding premature decisions.

Suppose the preceding letter has:

\[
Q_{i-1}=
\{a:0.55,o:0.45\}
\]

The system should use both alternatives when generating its prediction.

This prevents an early uncertain decision from becoming an unquestioned assumption throughout the entire sequence.

### Stage 3 output

\[
N_i(g)=
P(g_i=g\mid
\text{neighboring grapheme beliefs})
\]

<text color="secondary" size="xs">Biological interpretation: interactive-activation models and predictive-coding implementations allow word-level and letter-level representations to exchange information. Heilbron et al. found enhanced letter representations in word contexts and increased functional coupling with reading-network regions. <Cite refs={["turn594105view0","turn549830view3"]}/></text>

# Stage 4 — Attention-dependent sensory precision

<badge color="success">Precision regulation</badge>

## Objective

The brain must determine how much confidence to place in incoming visual evidence.

Not all visual evidence is equally reliable.

For example:

- A clearly visible letter may provide reliable sensory information.
- A blurred letter may provide uncertain information.
- A letter outside the current attentional focus may be processed less efficiently.
- Crowded neighboring characters may interfere with identification.

Attention changes the influence of sensory information in perceptual processing.

This is an important distinction: attention does not simply identify the correct letter. It can change how strongly visual evidence contributes to the interpretation.

### Step 4.1 — Estimate attentional distribution

Let:

\[
a_i=P(\text{attention allocated to position }i)
\]

The attention distribution may depend on:

- Current gaze position.
- Attentional focus.
- Target location.
- Word length.
- Visual difficulty.
- Task requirements.

A simplified attentional distribution is Gaussian:

\[
a_i=
\frac{
\exp\left[-\frac{(i-\mu_A)^2}{2\sigma_A^2}\right]
}{
\sum_j
\exp\left[-\frac{(j-\mu_A)^2}{2\sigma_A^2}\right]
}
\]

Where:

- \(\mu_A\): center of attentional focus.
- \(\sigma_A\): attentional dispersion.

A narrow distribution concentrates attention on fewer positions. A broad distribution spreads it over more positions.

This is a computational model, not a universal description of the actual shape of attention.

The 2025 BRAID Bayesian word-recognition model specifically incorporates attentional distribution, visual acuity and lateral interference in letter identification. <Cite refs={["turn594105view2","turn549830view2"]}/>

### Step 4.2 — Estimate sensory uncertainty

For every position, estimate uncertainty in the visual observations:

\[
\sigma_{s,i}^2
\]

Possible contributors include:

- Image blur.
- Contrast.
- Visual noise.
- Spatial resolution.
- Crowding.
- Uncertainty in character boundaries.

### Step 4.3 — Calculate sensory precision

In Bayesian models, precision is often defined as inverse variance:

\[
\pi_{s,i}=
\frac{1}{\sigma_{s,i}^2}
\]

High precision means the visual evidence is relatively reliable.

Low precision means the visual evidence is relatively uncertain.

### Step 4.4 — Modulate precision through attention

A simplified model is:

\[
\boxed{
\pi_{s,i}^{eff}
=
\pi_{s,0}\,a_i\,r_i
}
\]

Where:

- \(\pi_{s,0}\): baseline sensory precision.
- \(a_i\): attentional allocation.
- \(r_i\): visual reliability at position \(i\).

The model can also include a baseline gain:

\[
\pi_{s,i}^{eff}
=
\pi_{s,0}
[1+\alpha_Aa_i]r_i
\]

The precise functional relationship must be calibrated rather than assumed.

### Step 4.5 — Modulate the influence of visual prediction errors

The consequences of sensory precision become especially important during prediction-error processing.

A simplified gain operation is:

\[
E_{s,i}=
\pi_{s,i}^{eff}
(X_i-\widehat X_i)
\]

Thus, a mismatch in an attended, reliable visual region receives greater influence than a mismatch in a poorly observed region.

### Stage 4 output

\[
\pi_{s,i}^{eff}
\]

This determines how much authority bottom-up visual evidence receives in the subsequent posterior calculation.

<text color="secondary" size="xs">Biological interpretation: attention can enhance processing of selected visual information, while its distribution affects letter identification. The exact neural implementation of precision control in reading remains an active research question. <Cite refs={["turn549830view2","turn789428view1"]}/></text>

# Stage 5 — Prior precision modulation

<badge color="success">Precision regulation</badge>

## Objective

The brain must estimate how strongly it should trust its existing expectations.

This operation is different from calculating prior probabilities.

There are two separate questions:

1. Which graphemes are expected?
2. How confident should the brain be in those expectations?

The first concerns prior probability.

The second concerns prior precision.

### Step 5.1 — Retrieve the prior distribution

The brain combines available contextual expectations:

\[
P_i^0(g)=
P(g_i=g\mid C)
\]

These expectations may be derived from:

- Orthographic transition probabilities.
- Neighboring grapheme beliefs.
- Previously activated word candidates.
- Word-position constraints.
- Linguistic context.

For example:

\[
P_i^0=
\begin{cases}
P(t)=0.70\\
P(r)=0.20\\
P(f)=0.10
\end{cases}
\]

This distribution represents what the system expects before fully incorporating the current visual evidence.

### Step 5.2 — Estimate contextual reliability

The system must estimate whether its contextual predictions are reliable.

One possible approach uses entropy.

\[
H(P_i^0)=
-\sum_gP_i^0(g)\log P_i^0(g)
\]

Entropy measures uncertainty in the prediction.

A low-entropy distribution indicates that one or a few candidates dominate.

A high-entropy distribution indicates that many possibilities remain.

We can define a normalized contextual reliability:

\[
R_{c,i}=
1-
\frac{H(P_i^0)}
{\log K_i}
\]

Where \(K_i\) is the number of candidate graphemes.

This gives a value between zero and one.

A low value means the context provides weak discrimination.

A high value means the context provides a more concentrated expectation.

However, low entropy does not automatically mean that the expectation is correct. A confidently wrong prediction is possible.

### Step 5.3 — Estimate prior precision

A simplified computational model is:

\[
\boxed{
\pi_{p,i}=
\pi_{p,\min}
+
(\pi_{p,\max}-\pi_{p,\min})R_{c,i}R_{learned,i}
}
\]

Where:

- \(\pi_{p,\min}\): minimum prior precision.
- \(\pi_{p,\max}\): maximum prior precision.
- \(R_{c,i}\): contextual reliability.
- \(R_{learned,i}\): reliability of the learned orthographic expectation.

The learned reliability factor allows the model to distinguish established orthographic regularities from poorly supported expectations.

### Step 5.4 — Adjust prior influence

The prior can be represented in the posterior calculation using its precision:

\[
P_{\text{prior}}(g)
\propto
[P_i^0(g)]^{\pi_{p,i}}
\]

For a normalized distribution, we use:

\[
\widetilde P_{\text{prior}}(g)=
\frac{[P_i^0(g)]^{\pi_{p,i}}}
{\sum_{g'}[P_i^0(g')]^{\pi_{p,i}}}
\]

This operation sharpens or flattens the prior distribution.

- Greater prior precision increases the influence of established expectations.
- Lower prior precision allows sensory evidence to have a greater influence.

This is a model of how confidence in expectations can regulate perceptual inference.

### Step 5.5 — Balance sensory and prior reliability

The brain should not always trust the prior.

For example:

| Situation | Expected influence |
|---|---|
| Clear visual character, uncertain context | Sensory evidence dominates |
| Blurred character, strong orthographic context | Prior influence increases |
| Clear visual character, strong context agreement | Both sources reinforce one another |
| Blurred character, ambiguous context | Multiple hypotheses remain active |

These are qualitative computational predictions, not absolute rules.

### Stage 5 output

\[
\pi_{p,i}
\]

And:

\[
\widetilde P_{\text{prior}}(g)
\]

These determine the strength of top-down contextual influence.

<text color="secondary" size="xs">Biological interpretation: predictive-coding theories propose that cortical networks represent predictions, prediction errors and precision-related gain. The precise microcircuit implementation is not fully established. <Cite refs={["turn549830view0","turn789428view1"]}/></text>

# Stage 6 — Iterative posterior updates

<badge color="info">Core inference mechanism</badge>

## Objective

This is the central computational stage.

The brain combines the available visual evidence with orthographic expectations, neighboring grapheme predictions, sensory precision and prior precision.

It then updates its interpretation repeatedly until the competing representations become sufficiently stable or additional evidence is needed.

This is not simply a one-time Bayesian calculation. In recurrent predictive-processing models, predictions and prediction errors repeatedly modify each other's representations.

## Step 6.1 — Construct the initial posterior distribution

We now have:

- Bottom-up evidence \(B_i(g)\).
- Orthographic expectations \(P_i^0(g)\).
- Left-neighbor messages \(M_{L,i}(g)\).
- Right-neighbor messages \(M_{R,i}(g)\).
- Sensory precision \(\pi_{s,i}\).
- Prior precision \(\pi_{p,i}\).

We combine them:

\[
\boxed{
Q_i^{*}(g)=
\frac{
B_i(g)^{\pi_{s,i}}
P_i^0(g)^{\pi_{p,i}}
M_{L,i}(g)
M_{R,i}(g)
}{
Z_i
}
}
\]

Where \(Z_i\) normalizes the distribution:

\[
Z_i=
\sum_g
B_i(g)^{\pi_{s,i}}
P_i^0(g)^{\pi_{p,i}}
M_{L,i}(g)
M_{R,i}(g)
\]

This gives the updated probability of each grapheme candidate.

For an implementation using logarithms:

\[
\begin{aligned}
S_i(g)=&
\pi_{s,i}\log(B_i(g)+\epsilon)\\
&+\pi_{p,i}\log(P_i^0(g)+\epsilon)\\
&+\log(M_{L,i}(g)+\epsilon)\\
&+\log(M_{R,i}(g)+\epsilon)
\end{aligned}
\]

Then:

\[
Q_i^*(g)=softmax_g(S_i(g))
\]

Here, \(\epsilon\) is a small positive constant preventing logarithms of zero.

**Important:** the prior and neighboring messages must be constructed so that the same transition evidence is not counted twice. In a probabilistic factor-graph implementation, individual messages should exclude evidence already received through the same factor.

## Step 6.2 — Compare the new posterior with the previous beliefs

The brain maintains a previous estimate:

\[
Q_i^{(t)}(g)
\]

The newly calculated estimate is:

\[
Q_i^*(g)
\]

The system compares the two.

A simple difference is:

\[
\Delta Q_i=
Q_i^*(g)-Q_i^{(t)}(g)
\]

This indicates whether the confidence in a particular grapheme increased or decreased.

For example:

| Candidate | Previous belief | New belief |
|---|---:|---:|
| t | 0.55 | 0.75 |
| r | 0.30 | 0.20 |
| f | 0.15 | 0.05 |

The evidence has strengthened the interpretation of \(t\).

These values are illustrative.

## Step 6.3 — Apply recurrent feedback

The updated grapheme beliefs are transmitted back into the neighboring-position prediction system.

\[
Q_i^{(t+1)}=
F\left(
X_i,
P_i^0,
Q_{i-1}^{(t)},
Q_{i+1}^{(t)}
\right)
\]

This allows one position's improved interpretation to influence other positions.

For example:

1. The system becomes more confident about the first grapheme.
2. The new belief modifies predictions about the second grapheme.
3. The second grapheme's updated belief influences the third.
4. The newly integrated sequence modifies the overall orthographic interpretation.
5. That interpretation sends further feedback to individual grapheme representations.

This creates an iterative recurrent network.

## Step 6.4 — Control the magnitude of posterior updates

An abrupt change in beliefs can produce unstable oscillations between competing candidates.

A damped update is therefore useful:

\[
Q_i^{(t+1)}
=
(1-\eta)Q_i^{(t)}
+
\eta Q_i^*
\]

Where:

\[
0<\eta\leq1
\]

- Small \(\eta\): slower, more conservative updating.
- Large \(\eta\): faster, more responsive updating.

The parameter is an algorithmic approximation of how strongly new evidence influences the current representation.

## Step 6.5 — Repeat the inference process

At every iteration:

1. Retrieve current grapheme beliefs.
2. Recalculate neighboring predictions.
3. Recombine sensory evidence and contextual expectations.
4. Adjust the posterior probabilities.
5. Update the recurrent neural representation.

The process continues until the system reaches an acceptable stopping condition.

One mathematical stopping rule is:

\[
\max_i D_{KL}
\left(
Q_i^{(t+1)}
\parallel
Q_i^{(t)}
\right)
<\delta
\]

Here, \(\delta\) is a small convergence threshold.

Another option is:

\[
\max_i
\left\|
Q_i^{(t+1)}-Q_i^{(t)}
\right\|_1
<\delta
\]

The first measures distributional divergence; the second measures absolute changes in probabilities.

A maximum iteration limit is also needed.

## Step 6.6 — Retain alternative interpretations when necessary

The brain does not need to force a decision when its evidence is insufficient.

For example:

\[
Q_i=
\begin{cases}
P(t)=0.43\\
P(r)=0.40\\
P(f)=0.17
\end{cases}
\]

The leading candidate is only slightly stronger than the second.

The system can retain both candidates and continue processing instead of committing prematurely.

This is especially important when:

- The image is degraded.
- The orthographic pattern is ambiguous.
- Neighboring letters provide conflicting predictions.
- Attention has not adequately processed the relevant position.

## Step 6.7 — Generate an updated orthographic representation

Once sufficient evidence has accumulated, the system constructs a refined representation of the entire sequence:

\[
\widehat G=
(\hat g_1,\hat g_2,\ldots,\hat g_n)
\]

However, it should also preserve the posterior probabilities:

\[
Q(G)=
\{Q_1,Q_2,\ldots,Q_n\}
\]

This allows subsequent lexical recognition to receive uncertainty information rather than just a sequence of hard character decisions.

### Stage 6 output

The updated posterior distribution:

\[
Q_i^{(t+1)}(g)
\]

This is the current best estimate of the identity of each grapheme.

<text color="secondary" size="xs">Biological interpretation: recurrent cortical interactions, feedback predictions and ascending prediction errors are central elements of predictive-coding models. Heilbron et al. also implemented a predictive-coding version of an interactive-activation model to explain context-dependent letter representations. <Cite refs={["turn789428view1","turn766703search11"]}/></text>

# Stage 7 — Prediction divergence and feature-space residual diagnostics

<badge color="warning">Error evaluation and feedback control</badge>

## Objective

The system must determine whether its expectations successfully explain the visual stimulus.

It is not enough to generate predictions and update probabilities.

It must also measure:

- How much the observed visual stimulus differs from the expected stimulus.
- Whether the contextual predictions were reliable.
- Whether the posterior changed substantially.
- Whether multiple competing interpretations remain.
- Which visual features have not yet been explained.

This stage is extremely important because it tells the preceding stages whether more processing is needed.

We can divide it into six operations.

### Step 7.1 — Reconstruct the expected visual feature representation

Suppose the system currently believes that a position contains several possible graphemes.

Each grapheme has an expected feature representation:

\[
\mu_g=
[\mu_{g1},\mu_{g2},\ldots,\mu_{gm}]
\]

We can reconstruct the expected visual pattern by weighting each representation with its posterior probability:

\[
\boxed{
\widehat X_i=
\sum_g Q_i(g)\mu_g
}
\]

For example:

If the system is uncertain between \(t\) and \(r\), the expected feature representation combines the anticipated features of both letters.

This provides a predicted feature vector against which incoming visual information can be compared.

### Step 7.2 — Calculate feature-space prediction residuals

Compare the observed features with the predicted features:

\[
\boxed{
R_i=X_i-\widehat X_i
}
\]

Each component of this residual represents a different feature mismatch.

For example:

\[
R_i=
[
r_{\text{vertical}},
r_{\text{curve}},
r_{\text{junction}},
r_{\text{horizontal}}
]
\]

Possible interpretations:

- A positive residual indicates that a feature is stronger in the incoming signal than predicted.
- A negative residual indicates that the predicted feature is stronger than the incoming signal.
- A residual near zero indicates that the predicted and observed feature representations agree.

This is more informative than merely asking whether the selected letter was right or wrong.

It tells the system *which aspects of the visual input remain unexplained*.

### Step 7.3 — Calculate precision-weighted residuals

Not every feature mismatch has equal importance.

The residuals must be weighted according to sensory reliability.

For a feature covariance matrix \(\Sigma_i\):

\[
\boxed{
E_i=
\pi_{s,i}^{eff}
\Sigma_i^{-1}R_i
}
\]

Here, \(E_i\) is the precision-weighted sensory prediction error.

For independent features, a simpler implementation is:

\[
E_{ik}=
\frac{R_{ik}}{\sigma_{ik}^{2}}
\]

This means:

- A mismatch in a highly reliable visual feature receives stronger influence.
- A mismatch in a noisy visual feature receives weaker influence.

This is the connection between Stage 4 and Stage 7.

### Step 7.4 — Calculate divergence between prior predictions and posterior beliefs

The system also evaluates how much the new evidence changed its original expectations.

One useful measure is Kullback–Leibler divergence:

\[
\boxed{
D_{KL}(Q_i\parallel P_i^0)
=
\sum_g
Q_i(g)
\log
\frac{Q_i(g)}{P_i^0(g)}
}
\]

Interpretation:

- Low divergence: the visual evidence and contextual expectations largely agree.
- High divergence: the visual evidence substantially changed the expected grapheme distribution.

This is important because a high-confidence posterior does not necessarily mean that the original prediction was accurate.

A new interpretation may have emerged precisely because incoming visual information contradicted the original expectation.

### Step 7.5 — Calculate uncertainty and confidence

The system should also measure remaining uncertainty.

Posterior entropy:

\[
H(Q_i)=
-\sum_gQ_i(g)\log Q_i(g)
\]

Maximum posterior confidence:

\[
C_i=\max_gQ_i(g)
\]

Confidence margin:

\[
M_i=Q_i(g_1)-Q_i(g_2)
\]

Where \(g_1\) and \(g_2\) represent the two highest-probability candidates.

These measures provide different information:

| Diagnostic | What it indicates |
|---|---|
| Residual magnitude | How much visual information remains unexplained |
| KL divergence | How much the posterior changed relative to its prior |
| Entropy | How uncertain the current interpretation remains |
| Maximum probability | Confidence in the leading candidate |
| Confidence margin | Separation between the leading candidates |

We can also calculate the sequence-level surprisal:

\[
S(X\mid C)=
-\sum_i
\log P(X_i\mid C,\text{other positions})
\]

A high surprisal indicates that the observed sequence is poorly predicted by the current model.

### Step 7.6 — Diagnose the source of prediction failure

The different diagnostics can now be combined to decide what needs to change.

| Diagnostic situation | Possible interpretation | Computational response |
|---|---|---|
| High residual, high sensory precision | Current visual prediction may be wrong | Revise grapheme beliefs |
| High residual, low sensory precision | Visual information may be unreliable | Increase sampling or redirect attention |
| High KL divergence | Evidence strongly contradicted expectations | Reconsider prior confidence |
| High posterior entropy | Multiple alternatives remain | Retain candidates and continue inference |
| Low residual, low entropy | Predictions explain the input reasonably well | Allow processing to settle |
| High surprisal across positions | Current orthographic model poorly explains the sequence | Re-evaluate the sequence-level hypotheses |

These are possible computational responses rather than established one-to-one neural rules.

### Stage 7.7 — Return diagnostics to the prediction system

The error signal is sent back into the recurrent inference process.

The system may:

- Increase attention to an uncertain character position.
- Reduce the influence of an unreliable prior.
- Increase the influence of reliable visual evidence.
- Reconsider a neighboring grapheme hypothesis.
- Recalculate transition-based predictions.
- Maintain multiple competing interpretations.
- Accumulate further visual information.

The feedback process can be expressed as:

\[
\pi_{s,i}^{(t+1)}
=
F_s(\pi_{s,i}^{(t)},R_i,E_i)
\]

\[
\pi_{p,i}^{(t+1)}
=
F_p(\pi_{p,i}^{(t)},D_{KL},R_{c,i})
\]

\[
Q_i^{(t+1)}
=
F_Q(Q_i^{(t)},E_i,N_i,\pi_{s,i},\pi_{p,i})
\]

The functions \(F_s,F_p,F_Q\) represent model-specific update rules. They should be calibrated rather than assumed to be fixed biological equations.

### Stage 7 output

The system produces:

\[
\mathcal D_i=
\{
R_i,E_i,D_{KL},H(Q_i),C_i,M_i,S_i
\}
\]

This is a diagnostic representation of how well the system's predictions explain the incoming visual information.

<text color="secondary" size="xs">Biological interpretation: predictive-coding accounts describe descending predictions and ascending prediction-error signals that iteratively modify higher-level representations. Research on orthographic prediction error has also proposed that prior visual word knowledge helps extract the informative parts of the visual stimulus during early visual processing. <Cite refs={["turn789428view1","turn766703search4"]}/></text>

# 3. The complete integrated algorithm

We can now combine all seven stages into a single recurrent algorithm.

The following is a mathematical description of the entire proposed processing system.

## Algorithm 1 — Contextual Orthographic Prediction and Bayesian Refinement

**Inputs**

- Visual image \(I\).
- Candidate grapheme inventory \(G\).
- Learned orthographic transition statistics \(T\).
- Learned grapheme feature representations \(\mu_g\).
- Existing lexical and orthographic knowledge.
- Initial attention distribution \(A\).
- Current contextual information \(C\).

**Initialization**

1. Determine potential grapheme positions.
2. Extract initial visual feature vectors.
3. Initialize grapheme probability distributions.
4. Retrieve learned orthographic transition probabilities.
5. Initialize sensory and prior precision.
6. Initialize recurrent neural activity.

**Execution**

<CodeBlock language="text" editable>

INPUT:
    Visual image I
    Grapheme inventory G

    Initial attention A

INITIALIZE:
    Character positions

    Initial beliefs Q[i]

    For each character position i:
        Extract visual features X[i]
        Generate candidate graphemes

    Estimate visual reliability
    Estimate attentional distribution

    Retrieve contextual prior probabilities

## 4. Global mathematical formulation

The entire system can be represented using a probabilistic model over the complete grapheme sequence.

Let:

\[
G=(g_1,g_2,\ldots,g_n)
\]

The posterior sequence probability is:

\[
\boxed{
P(G\mid X,C)
\propto
P(C\mid G)
\prod_{i=1}^{n}
P(X_i\mid g_i)^{\pi_{s,i}}
\prod_{i=2}^{n}
P(g_i\mid g_{i-1})^{\pi_{p,i}}
}
\]

This equation represents:

- Sensory evidence for each grapheme.
- Learned orthographic transition probabilities.
- Contextual constraints.
- Reliability-dependent weighting.

A more advanced version could incorporate trigram dependencies and word-level predictions:

\[
\begin{aligned}
P(G\mid X,C)\propto{}&
P(C\mid G)
\prod_i P(X_i\mid g_i)^{\pi_{s,i}}\\
&\times
\prod_i
P(g_i\mid g_{i-1},g_{i-2})^{\pi_{p,i}}
\end{aligned}
\]

This is a sequence-level probabilistic model. The individual-position posterior distributions can be estimated using approximate message passing rather than enumerating every possible sequence.

### The error-minimization formulation

The same architecture can be expressed as minimizing a computational objective:

\[
\boxed{
\mathcal L=
\frac12\sum_i
\pi_{s,i}
\|X_i-\widehat X_i\|_{\Sigma_i^{-1}}^2
+
\sum_i
\pi_{p,i}
[-\log P_i^0(g_i)]
+
\lambda\mathcal R_{\text{orth}}
}
\]

Where:

- The first term measures sensory prediction error.
- The second term penalizes interpretations inconsistent with prior expectations.
- \(\mathcal R_{\text{orth}}\) penalizes implausible grapheme sequences.
- \(\lambda\) controls the influence of orthographic regularities.

Here:

\[
\|v\|_{\Sigma^{-1}}^2=v^T\Sigma^{-1}v
\]

The optimization attempts to find an interpretation that explains the visual input while respecting learned orthographic regularities.

This is a candidate predictive-processing objective, not an established single objective function used literally by neurons.

# 5. Biological implementation: possible neural mechanisms

The mathematical architecture needs to correspond to plausible neural operations.

The important distinction is that the brain uses distributed populations and recurrent interactions. We should not imagine seven isolated brain structures executing seven instructions.

The following is a functional correspondence, not a claim of exclusive anatomical localization.

| Processing mechanism | Possible biological implementation |
|---|---|
| Visual feature extraction | Feature-sensitive populations in early visual cortex |
| Grapheme identification | Distributed letter-selective representations |
| Orthographic transitions | Learned synaptic connection strengths between orthographic representations |
| Neighbor predictions | Recurrent excitation and distributed positional interactions |
| Attention-dependent precision | Attentional modulation of sensory responses and neural gain |
| Prior precision | Modulation of the influence of descending predictions |
| Posterior updating | Recurrent excitation, inhibition and integration of incoming evidence |
| Prediction-error calculation | Populations carrying mismatch-related signals |
| Error minimization | Recurrent feedback between hierarchical processing levels |

## 5.1 Sensory and orthographic populations

The visual system provides the initial character evidence.

In the reading network, orthographic representations interact with lower-level visual representations.

This is particularly important because letter recognition is not completely independent of word context.

A study by Heilbron and colleagues found that word contexts enhanced individual-letter representations in early visual cortex, supporting a top-down perceptual contribution to word recognition. <Cite refs={["turn594105view0","turn549830view3"]}/>

## 5.2 Recurrent excitatory and inhibitory connections

A simplified neural activation equation is:

\[
\frac{da_i}{dt}
=
-\frac{a_i}{\tau}
+
I_{\text{sensory}}
+
I_{\text{context}}
-
I_{\text{inhibition}}
\]

Where:

- \(I_{\text{sensory}}\): incoming visual evidence.
- \(I_{\text{context}}\): neighboring and higher-level predictions.
- \(I_{\text{inhibition}}\): competition between alternative representations.

This provides a possible way of implementing iterative posterior refinement through neural population dynamics.

## 5.3 Prediction and prediction-error populations

A predictive-coding interpretation distinguishes two functional signals.

<grid columns={2} gap={2}>
  <grid-item>
    <box border radius="lg" padding={3} gap={1}>
      **Prediction populations**

      <text color="secondary" size="xs">Generate expected graphemes and expected visual features.</text>
      \[
      \widehat X
      \]
    </box>
  </grid-item>
  <grid-item>
    <box border radius="lg" padding={3} gap={1}>
      **Error populations**

      <text color="secondary" size="xs">Represent discrepancies between expected and observed features.</text>
      \[
      X-\widehat X
      \]
    </box>
  </grid-item>
</grid>

The predictions travel through descending connections, while prediction-error information is proposed to travel through ascending connections.

The relative gain of prediction-error signals can be modulated by precision. The exact cellular implementation remains a subject of neuroscience research. <Cite refs={["turn789428view1","turn766703search2"]}/>

To make this architecture sufficiently sophisticated for computational implementation, I would include the following operations as part of its mathematical toolkit.

| Mathematical operation | Purpose |
|---|---|
| Bayesian likelihood estimation | Evaluate visual evidence |
| Bigram and trigram probability estimation | Model orthographic transitions |
| Matrix multiplication | Transmit learned interactions between grapheme populations |
| Softmax normalization | Convert activation scores into probabilities |
| Logarithmic probability transformation | Combine probabilistic evidence |
| Gaussian probability estimation | Model visual uncertainty |
| Covariance estimation | Represent correlations between visual features |
| Inverse variance | Calculate precision |
| Entropy | Estimate uncertainty |
| KL divergence | Measure changes in probability distributions |
| Vector subtraction | Calculate feature residuals |
| Weighted squared error | Calculate prediction-error magnitude |
| Recurrent state updates | Exchange information between grapheme positions |
| Exponential damping | Control stability of iterative updates |

There is an important distinction between these mathematical operations:

- Some describe how a computational model represents neural information.
- Some describe plausible neural dynamics.
- Some are mathematical tools for evaluating the model.

They should not all be interpreted as literal biochemical calculations performed inside individual neurons.

# 7. Critical design principle: two different timescales

One additional distinction will be essential when turning this algorithm into a functioning model.

**A. Online contextual inference**

These operations occur while processing the current visual stimulus:

- Generating grapheme predictions.
- Combining neighboring beliefs.
- Modulating precision.
- Updating posterior probabilities.
- Calculating prediction errors.

**B. Long-term orthographic learning**

These operations modify the underlying knowledge used for future reading:

- Learning grapheme transition statistics.
- Strengthening familiar spelling patterns.
- Learning word-specific orthographic representations.
- Improving predictions through repeated reading experience.

We should not confuse updating the current interpretation with permanently learning a new orthographic rule.

A new visual experience can change the current posterior without necessarily changing long-term orthographic knowledge.

Mathematically:

\[
\underbrace{Q_t(G)}_{\text{Current inference}}
\neq
\underbrace{T_{t+1}}_{\text{Learned transition model}}
\]

The second changes through a slower learning mechanism, supported by repeated evidence and appropriate plasticity rules.

For the ORE computational architecture, I recommend treating this as a separate **Contextual Orthographic Prediction Engine**.

# 3. The complete integrated algorithm

We can now combine all seven stages into a single recurrent algorithm.

The following is a mathematical description of the entire proposed processing system.

## Algorithm 1 — Contextual Orthographic Prediction and Bayesian Refinement

**Inputs**

- Visual image \(I\).
- Candidate grapheme inventory \(G\).
- Learned orthographic transition statistics \(T\).
- Learned grapheme feature representations \(\mu_g\).
- Existing lexical and orthographic knowledge.
- Initial attention distribution \(A\).
- Current contextual information \(C\).

**Initialization**

1. Determine potential grapheme positions.
2. Extract initial visual feature vectors.
3. Initialize grapheme probability distributions.
4. Retrieve learned orthographic transition probabilities.
5. Initialize sensory and prior precision.
6. Initialize recurrent neural activity.

**Execution**

INPUT:

    Initial attention A

## 4. Global mathematical formulation

The entire system can be represented using a probabilistic model over the complete grapheme sequence.

Let:

\[
G=(g_1,g_2,\ldots,g_n)
\]

The posterior sequence probability is:

\[
\boxed{
P(G\mid X,C)
\propto
P(C\mid G)
\prod_{i=1}^{n}
P(X_i\mid g_i)^{\pi_{s,i}}
\prod_{i=2}^{n}
P(g_i\mid g_{i-1})^{\pi_{p,i}}
}
\]

This equation represents:

- Sensory evidence for each grapheme.
- Learned orthographic transition probabilities.
- Contextual constraints.
- Reliability-dependent weighting.

A more advanced version could incorporate trigram dependencies and word-level predictions:

\[
\begin{aligned}
P(G\mid X,C)\propto{}&
P(C\mid G)
\prod_i P(X_i\mid g_i)^{\pi_{s,i}}\\
&\times
\prod_i
P(g_i\mid g_{i-1},g_{i-2})^{\pi_{p,i}}
\end{aligned}
\]

This is a sequence-level probabilistic model. The individual-position posterior distributions can be estimated using approximate message passing rather than enumerating every possible sequence.

### The error-minimization formulation

The same architecture can be expressed as minimizing a computational objective:

\[
\boxed{
\mathcal L=
\frac12\sum_i
\pi_{s,i}
\|X_i-\widehat X_i\|_{\Sigma_i^{-1}}^2
+
\sum_i
\pi_{p,i}
[-\log P_i^0(g_i)]
+
\lambda\mathcal R_{\text{orth}}
}
\]

Where:

- The first term measures sensory prediction error.
- The second term penalizes interpretations inconsistent with prior expectations.
- \(\mathcal R_{\text{orth}}\) penalizes implausible grapheme sequences.
- \(\lambda\) controls the influence of orthographic regularities.

Here:

\[
\|v\|_{\Sigma^{-1}}^2=v^T\Sigma^{-1}v
\]

The optimization attempts to find an interpretation that explains the visual input while respecting learned orthographic regularities.

This is a candidate predictive-processing objective, not an established single objective function used literally by neurons.

# 5. Biological implementation: possible neural mechanisms

The mathematical architecture needs to correspond to plausible neural operations.

The important distinction is that the brain uses distributed populations and recurrent interactions. We should not imagine seven isolated brain structures executing seven instructions.

The following is a functional correspondence, not a claim of exclusive anatomical localization.

| Processing mechanism | Possible biological implementation |
|---|---|
| Visual feature extraction | Feature-sensitive populations in early visual cortex |
| Grapheme identification | Distributed letter-selective representations |
| Orthographic transitions | Learned synaptic connection strengths between orthographic representations |
| Neighbor predictions | Recurrent excitation and distributed positional interactions |
| Attention-dependent precision | Attentional modulation of sensory responses and neural gain |
| Prior precision | Modulation of the influence of descending predictions |
| Posterior updating | Recurrent excitation, inhibition and integration of incoming evidence |
| Prediction-error calculation | Populations carrying mismatch-related signals |
| Error minimization | Recurrent feedback between hierarchical processing levels |

## 5.1 Sensory and orthographic populations

The visual system provides the initial character evidence.

In the reading network, orthographic representations interact with lower-level visual representations.

This is particularly important because letter recognition is not completely independent of word context.

A study by Heilbron and colleagues found that word contexts enhanced individual-letter representations in early visual cortex, supporting a top-down perceptual contribution to word recognition. <Cite refs={["turn594105view0","turn549830view3"]}/>

## 5.2 Recurrent excitatory and inhibitory connections

A simplified neural activation equation is:

\[
\frac{da_i}{dt}
=
-\frac{a_i}{\tau}
+
I_{\text{sensory}}
+
I_{\text{context}}
-
I_{\text{inhibition}}
\]

Where:

- \(I_{\text{sensory}}\): incoming visual evidence.
- \(I_{\text{context}}\): neighboring and higher-level predictions.
- \(I_{\text{inhibition}}\): competition between alternative representations.

This provides a possible way of implementing iterative posterior refinement through neural population dynamics.

## 5.3 Prediction and prediction-error populations

A predictive-coding interpretation distinguishes two functional signals.

<grid columns={2} gap={2}>
  <grid-item>
    <box border radius="lg" padding={3} gap={1}>
      **Prediction populations**

      <text color="secondary" size="xs">Generate expected graphemes and expected visual features.</text>
      \[
      \widehat X
      \]
    </box>
  </grid-item>
  <grid-item>
    <box border radius="lg" padding={3} gap={1}>
      **Error populations**

      <text color="secondary" size="xs">Represent discrepancies between expected and observed features.</text>
      \[
      X-\widehat X
      \]
    </box>
  </grid-item>
</grid>

The predictions travel through descending connections, while prediction-error information is proposed to travel through ascending connections.

The relative gain of prediction-error signals can be modulated by precision. The exact cellular implementation remains a subject of neuroscience research. <Cite refs={["turn789428view1","turn766703search2"]}/>

# 6. Additional mathematical operations the algorithm should support

To make this architecture sufficiently sophisticated for computational implementation, I would include the following operations as part of its mathematical toolkit.

| Mathematical operation | Purpose |
|---|---|
| Bayesian likelihood estimation | Evaluate visual evidence |
| Bigram and trigram probability estimation | Model orthographic transitions |
| Matrix multiplication | Transmit learned interactions between grapheme populations |
| Softmax normalization | Convert activation scores into probabilities |
| Logarithmic probability transformation | Combine probabilistic evidence |
| Gaussian probability estimation | Model visual uncertainty |
| Covariance estimation | Represent correlations between visual features |
| Inverse variance | Calculate precision |
| Entropy | Estimate uncertainty |
| KL divergence | Measure changes in probability distributions |
| Vector subtraction | Calculate feature residuals |
| Weighted squared error | Calculate prediction-error magnitude |
| Recurrent state updates | Exchange information between grapheme positions |
| Exponential damping | Control stability of iterative updates |
| Convergence testing | Determine when inference should stop |

There is an important distinction between these mathematical operations:

- Some describe how a computational model represents neural information.
- Some describe plausible neural dynamics.
- Some are mathematical tools for evaluating the model.

They should not all be interpreted as literal biochemical calculations performed inside individual neurons.

# 7. Critical design principle: two different timescales

One additional distinction will be essential when turning this algorithm into a functioning model.

**A. Online contextual inference**

These operations occur while processing the current visual stimulus:

- Generating grapheme predictions.
- Combining neighboring beliefs.
- Modulating precision.
- Updating posterior probabilities.
- Calculating prediction errors.

**B. Long-term orthographic learning**

These operations modify the underlying knowledge used for future reading:

- Learning grapheme transition statistics.
- Strengthening familiar spelling patterns.
- Learning word-specific orthographic representations.
- Improving predictions through repeated reading experience.

We should not confuse updating the current interpretation with permanently learning a new orthographic rule.

A new visual experience can change the current posterior without necessarily changing long-term orthographic knowledge.

Mathematically:

\[
\underbrace{Q_t(G)}_{\text{Current inference}}
\neq
\underbrace{T_{t+1}}_{\text{Learned transition model}}
\]

The second changes through a slower learning mechanism, supported by repeated evidence and appropriate plasticity rules.
