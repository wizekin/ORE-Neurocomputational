# Master Biological Neurocomputational ORE Algorithm

The nine components can be organized into one large, sequential neurocomputational algorithm that starts with the simulation of neurons, reconstructs the biological processing of visual and orthographic information, develops recurrent neural representations, learns from experience, makes predictions, and finally validates its behavior against real brain data.

The central objective is to develop a computational architecture in which **each software operation has an explicit functional responsibility, a mathematical implementation, and a biologically motivated neural counterpart.**

I will organize the architecture into nine major stages, with smaller numbered algorithmic operations inside each stage.

### Important mathematical principle

The equations below describe computational models of neural mechanisms. The brain does not necessarily perform symbolic arithmetic or execute these exact equations. They are mathematical approximations of processes such as synaptic integration, neuronal excitation and inhibition, population coding, plasticity and recurrent information processing.

For example, the weighted sum

\[
I_i(t)=\sum_j w_{ij}s_j(t)
\]

represents the combined influence of incoming synaptic activity on neuron \(i\). It does not imply that a biological neuron literally runs a software multiplication-and-addition instruction.

## Mathematical notation used throughout the algorithm

Before defining the operations, establish common mathematical objects.

| Symbol | Meaning |
|---|---|
| \(V_i(t)\) | Membrane potential of neuron \(i\) |
| \(I_i(t)\) | Total input current |
| \(s_i(t)\) | Neural spike or activity signal |
| \(w_{ij}\) | Synaptic weight from neuron \(j\) to neuron \(i\) |
| \(W\) | Synaptic connectivity matrix |
| \(x_i(t)\) | Continuous population activity |
| \(r_i(t)\) | Population firing rate |
| \(E\) | Neural prediction error |
| \(P\) | Prediction or prior |
| \(\eta\) | Learning rate |
| \(\phi\) | Neuronal activation function |
| \(\tau\) | Time constant |

A useful general representation is:

\[
\boxed{
\text{Sensory Input}
\rightarrow
\text{Neural Encoding}
\rightarrow
\text{Population Activity}
\rightarrow
\text{Network Integration}
\rightarrow
\text{Learning}
\rightarrow
\text{Prediction}
\rightarrow
\text{Behavior}
}
\]

# Stage 1 — Neural simulation foundations

<AsyncImageGroup query={["biological neuron dendrites soma axon synapse anatomical neuroscience illustration","leaky integrate and fire neuron membrane potential action potential scientific diagram","excitatory inhibitory neural circuit population neuroscience diagram"]} aspectRatio="5:4" layout="carousel"/>

### Objective

Establish the basic computational units needed to construct a biologically motivated neural system.

This stage defines how neurons receive signals, integrate synaptic inputs, change their membrane voltage, produce spikes, communicate with other neurons and form populations.

The key idea is that all subsequent stages should use a common neural simulation framework rather than independently inventing their own neural behavior.

### Subsystem A — Neuron construction and electrical behavior

**Operation 1.1 — Define individual biological neuron models**

Create neurons with the following variables:

- Membrane potential.
- Resting potential.
- Excitatory synaptic inputs.
- Inhibitory synaptic inputs.
- Membrane resistance and capacitance.
- Firing threshold.
- Refractory state.
- Current produced by synaptic activity.

Represent neuron \(i\) as:

\[
N_i(t)=
\left[
V_i(t),I_i(t),\theta_i,\tau_i,R_i,C_i
\right]
\]

Where \(\theta_i\) is its firing threshold.

**Possible mathematical operations:**

1. State-vector construction.
2. Parameter initialization.
3. Dimensional consistency validation.
4. Time-dependent state updates.

The model should distinguish between the actual biological units and their simulation parameters.

**Operation 1.2 — Model incoming synaptic transmission**

A neuron receives signals from multiple presynaptic neurons.

Each incoming signal contributes to the postsynaptic current.

A simplified model is:

\[
I_i(t)=\sum_j w_{ij}s_j(t)
\]

For a more biologically detailed conductance-based representation:

\[
I_i(t)=
\sum_j g_{ij}(t)
\left(E_j-V_i(t)\right)
\]

Where:

- \(g_{ij}\) is synaptic conductance.
- \(E_j\) is the synaptic reversal potential.
- \(V_i\) is postsynaptic membrane potential.

**Mathematical operations:**

- Weighted multiplication.
- Summation of synaptic inputs.
- Conductance-dependent current calculation.
- Time-dependent exponential decay.

For example, a simple synaptic response can decay according to:

\[
g(t)=g_0e^{-t/\tau_s}
\]

This captures the fact that synaptic influence develops and decays over time rather than remaining permanently active.

**Operation 1.3 — Calculate excitatory and inhibitory influences**

The neuron must integrate both excitatory and inhibitory activity.

Separate the input:

\[
I_i(t)=I_i^{exc}(t)+I_i^{inh}(t)+I_i^{ext}(t)
\]

In a simplified current convention, excitatory and inhibitory influences have opposite signs:

\[
I_i(t)=
\sum_j w_{ij}^{exc}s_j(t)
-
\sum_k w_{ik}^{inh}s_k(t)
+
I_i^{ext}(t)
\]

This allows the neural network to regulate its own activity.

**Mathematical operations:**

- Positive and negative weighted summation.
- Signal cancellation.
- Gain adjustment.
- Threshold-dependent response.

An important biological qualification: excitation and inhibition are not merely positive and negative software numbers. They involve different neurotransmitter systems, reversal potentials, conductances and circuit effects.

**Operation 1.4 — Calculate membrane-potential changes**

Use a leaky integrate-and-fire model as an initial computational reference.

\[
C_m\frac{dV_i}{dt}
=
-g_L(V_i-E_L)+I_i(t)
\]

Where:

- \(C_m\): membrane capacitance.
- \(g_L\): leak conductance.
- \(E_L\): resting or leak reversal potential.
- \(I_i\): total synaptic current.

This equation combines incoming electrical influence and membrane leakage.

Using forward Euler integration:

\[
V_i(t+\Delta t)=
V_i(t)+
\frac{\Delta t}{\tau_m}
\left[
E_L-V_i(t)+R_mI_i(t)
\right]
\]

Here:

\[
\tau_m=\frac{C_m}{g_L}
\]

**Mathematical operations:**

1. Calculate voltage difference from resting potential.
2. Multiply current by membrane resistance.
3. Combine current and leak contributions.
4. Multiply by the time-step ratio.
5. Update the membrane state.

This is a fundamental operation that should be reusable across every biological subsystem.

LIF models are simplified reference models used in computational neuroscience, not complete descriptions of neuronal electrophysiology. <Cite refs={["turn788860search3","turn788860search8"]}/>

**Operation 1.5 — Generate neural spikes**

When membrane potential reaches the firing threshold:

\[
V_i(t)\geq V_{threshold}
\]

The neuron generates a spike.

The simulation records:

\[
s_i(t)=
\begin{cases}
1,&\text{if a spike occurs}\\
0,&\text{otherwise}
\end{cases}
\]

Then reset:

\[
V_i(t)\leftarrow V_{reset}
\]

**Mathematical operations:**

- Threshold comparison.
- Binary event generation.
- State resetting.
- Event timestamp recording.

**Operation 1.6 — Implement the refractory period**

After firing, the neuron enters a temporary period during which its ability to fire another spike is reduced or unavailable, depending on the refractory model.

\[
R_i(t+\Delta t)=
\max(0,R_i(t)-\Delta t)
\]

When:

\[
R_i(t)>0
\]

The neuron is prevented from generating another ordinary spike.

This introduces temporal restrictions into the simulation.

**Operation 1.7 — Calculate firing rate**

Instead of only representing individual spikes, calculate the firing rate over a time window.

\[
r_i(t)=\frac{N_i(t,t+\Delta T)}{\Delta T}
\]

Where \(N_i\) is the number of spikes during the interval.

**Mathematical operations:**

- Event counting.
- Time-window aggregation.
- Division by elapsed time.
- Optional temporal smoothing.

This creates two useful representations:

- Spike-based activity.
- Continuous firing-rate activity.

Both should be preserved because later algorithms may require different temporal resolutions.

### Subsystem B — Neural populations

**Operation 1.8 — Construct specialized neural populations**

A population represents a group of neurons with related computational responsibilities.

Examples:

| Population | Functional responsibility |
|---|---|
| Visual population | Responds to visual input |
| Orientation population | Responds to preferred edge orientations |
| Grapheme population | Responds to letter features |
| Orthographic population | Responds to ordered letter patterns |
| Semantic population | Represents conceptual features |
| Control population | Regulates competing representations |

Represent population \(p\) as:

\[
P_p(t)=\{N_1(t),N_2(t),...,N_n(t)\}
\]

Calculate average population activity:

\[
A_p(t)=\frac{1}{n}\sum_{i=1}^{n}r_i(t)
\]

**Operation 1.9 — Implement population competition**

Different populations may respond to the same stimulus.

To simulate competitive activity, introduce lateral inhibition.

\[
u_i(t)=
I_i(t)+
\sum_j w_{ij}^{exc}A_j(t)
-
\lambda\sum_k w_{ik}^{inh}A_k(t)
\]

Then:

\[
A_i(t+1)=\phi(u_i(t))
\]

The function \(\phi\) could be a rectified-linear function or sigmoid.

This enables competing neural representations to influence one another.

**Operation 1.10 — Introduce neural noise and variability**

Biological neurons do not respond identically every time.

A simplified model:

\[
I_i^{actual}(t)=I_i^{input}(t)+\epsilon_i(t)
\]

Where:

\[
\epsilon_i(t)\sim\mathcal{N}(0,\sigma_i^2)
\]

This allows the simulation to represent variation in neuronal responses and test whether its behavior remains stable under noise.

**Operation 1.11 — Establish the neural time engine**

The entire neural simulation should advance in discrete time steps.

At every step:

1. Collect incoming signals.
2. Calculate synaptic currents.
3. Update membrane voltages.
4. Determine which neurons spike.
5. Update refractory periods.
6. Update synaptic state.
7. Calculate population activity.
8. Record the complete neural state.

The time engine becomes the shared biological execution layer for all remaining stages.

<badge color="success">Stage 1 output</badge>

A reusable neural simulation foundation containing individual neurons, neural populations, synaptic connections, electrical dynamics, spikes, firing rates, inhibition and temporal state.

# Stage 2 — Biological visual processing

<AsyncImageGroup query={["human retina photoreceptors bipolar ganglion cells ON OFF pathway diagram","lateral geniculate nucleus retinal visual pathways neuroscience diagram","primary visual cortex V1 orientation selective simple complex cells Gabor receptive fields scientific diagram"]} aspectRatio="5:4"/>

### Objective

Reproduce the functional sequence through which visual information is transformed into neural representations.

The major biological pathway is:

\[
\text{Retina}
\rightarrow
\text{LGN}
\rightarrow
\text{V1}
\]

This stage concentrates on early sensory processing rather than full object recognition.

The actual visual system contains parallel pathways and extensive interactions; the sequence below is a useful computational decomposition, not a claim that all processing follows one strictly serial path. <Cite refs={["turn317998search0","turn317998search4"]}/>

### Subsystem A — Retinal processing

**Operation 2.1 — Simulate photoreceptor input**

Light entering the eye produces changes in photoreceptor activity.

For the computational model, begin with an image:

\[
I(x,y)
\]

Apply a spatial sensitivity model.

For example:

\[
R(x,y)=f(I(x,y),A(x,y))
\]

Where \(A(x,y)\) is local adaptation.

One possible approximation:

\[
A(x,y)=G_{\sigma}*I(x,y)
\]

Here \(G_\sigma\) is a Gaussian smoothing kernel.

The result represents an estimate of the local illumination environment.

**Mathematical operations:**

- Spatial convolution.
- Local averaging.
- Contrast normalization.
- Nonlinear response compression.

**Operation 2.2 — Implement light adaptation**

The visual system must accommodate changing illumination.

A computational approximation:

\[
R(x,y)=
\log\left(
1+\frac{I(x,y)}{A(x,y)+\epsilon}
\right)
\]

This makes the output depend on both local intensity and surrounding illumination.

The logarithm is a convenient mathematical approximation, not a complete phototransduction model.

**Operation 2.3 — Implement retinal ON and OFF pathways**

The retina processes increments and decrements of visual input through different pathways.

First calculate a local contrast signal:

\[
C(x,y)=I(x,y)-(G_\sigma*I)(x,y)
\]

Then separate:

\[
ON(x,y)=\max(C(x,y),0)
\]

\[
OFF(x,y)=\max(-C(x,y),0)
\]

**Mathematical operations:**

- Spatial filtering.
- Subtraction.
- Positive rectification.
- Negative rectification.

This produces separate signals for brightness increments and decrements.

**Operation 2.4 — Simulate center-surround receptive fields**

Many retinal and LGN neurons respond to contrast between a central region and its surrounding region.

A difference-of-Gaussians model:

\[
DOG(x,y)=
G_{\sigma_c}(x,y)
-
\alpha G_{\sigma_s}(x,y)
\]

Where:

\[
\sigma_s>\sigma_c
\]

The resulting receptive field can have ON-center/OFF-surround or OFF-center/ON-surround characteristics.

Convolve the image with the receptive field:

\[
R(x,y)=I*DOG
\]

This emphasizes local contrast boundaries.

**Operation 2.5 — Implement retinal spatial and temporal response**

Retinal processing is dynamic.

A basic temporal model:

\[
R(t)=
\alpha R(t-\Delta t)+
(1-\alpha)I(t)
\]

The difference between current input and the adapted state can provide a simplified temporal-change signal.

**Mathematical operations:**

- Exponential smoothing.
- Temporal subtraction.
- Adaptive gain.
- State updating.

### Subsystem B — LGN processing

**Operation 2.6 — Transform retinal signals into LGN inputs**

The lateral geniculate nucleus receives organized retinal input and transmits it toward visual cortex.

Build separate ON and OFF channels:

\[
L_{ON}=W_{ON}R_{ON}
\]

\[
L_{OFF}=W_{OFF}R_{OFF}
\]

Here the weights represent modeled pathway transmission.

The channels should remain separate instead of being prematurely combined.

**Operation 2.7 — Calculate contrast gain control**

Neural responses often depend on the strength of surrounding activity.

A divisive normalization approximation:

\[
r_i=
\frac{f_i}
{\sigma+\sum_jw_{ij}|f_j|}
\]

Where:

- \(f_i\): feature drive.
- \(w_{ij}\): pooling weights.
- \(\sigma\): stabilizing constant.

This allows the system to regulate its response when many visual channels are simultaneously active.

### Subsystem C — Primary visual cortex

**Operation 2.8 — Construct orientation-selective populations**

Create a population of artificial receptive fields, each responding preferentially to a specific orientation.

For orientation \(\theta\), a Gabor filter can be defined as:

\[
G(x,y)=
\exp\left(
-\frac{x'^2+\gamma^2y'^2}{2\sigma^2}
\right)
\cos(2\pi fx'+\psi)
\]

Where:

\[
x'=x\cos\theta+y\sin\theta
\]

The response is:

\[
R_\theta=I*G_\theta
\]

Repeat for different orientations.

For example:

\[
\theta\in
\{0^\circ,45^\circ,90^\circ,135^\circ\}
\]

This creates different channels for edge orientations.

**Operation 2.9 — Simulate simple-cell-like responses**

Create separate ON and OFF responses to filter outputs.

\[
S_{ON}=\max(R_\theta,0)
\]

\[
S_{OFF}=\max(-R_\theta,0)
\]

This preserves phase-sensitive information about the visual input.

**Operation 2.10 — Simulate complex-cell-like responses**

Combine quadrature filter responses.

\[
E_\theta=
\sqrt{
R_{\theta,even}^{2}
+
R_{\theta,odd}^{2}
}
\]

This produces an energy response that is less sensitive to the precise phase of the local pattern.

**Operation 2.11 — Perform orientation population normalization**

Combine activity across orientation-selective populations.

\[
N_\theta=
\frac{E_\theta}
{\epsilon+\sum_{\phi}w_{\theta\phi}E_\phi}
\]

This regulates responses according to activity in other channels.

**Operation 2.12 — Extract local visual feature maps**

For each spatial location, record:

- Orientation.
- Contrast.
- Edge strength.
- Spatial frequency.
- Local energy.
- Feature position.

Represent the resulting visual state as:

\[
F(x,y)=
[f_1(x,y),f_2(x,y),...,f_n(x,y)]
\]

This becomes the input to the higher visual hierarchy.

<badge color="success">Stage 2 output</badge>

A collection of spatially organized visual feature maps representing orientation, contrast, edges, frequency and local image structure.

# Stage 3 — Hierarchical visual architecture

<AsyncImageGroup query={["visual cortex hierarchy V1 V2 V4 inferior temporal ventral stream scientific diagram","dorsal ventral visual pathways brain anatomy neuroscience illustration","hierarchical receptive fields visual cortex feedforward feedback connections diagram"]} aspectRatio="5:4"/>

### Objective

Transform local visual features into increasingly complex representations by integrating activity across different neural populations and cortical levels.

Stage 2 produces local sensory features.

Stage 3 combines them into structured representations of visual objects, shapes and patterns.

The visual cortex is not merely a stack of independent processing layers: feedforward, horizontal and feedback connections influence processing across the hierarchy. <Cite refs={["turn317998search0","turn317998search1","turn317998search8"]}/>

### Subsystem A — Feedforward hierarchical construction

**Operation 3.1 — Define hierarchical visual levels**

Establish a computational representation of:

| Biological reference | Computational responsibility |
|---|---|
| Retina/LGN | Initial visual signal |
| V1 | Local orientation and spatial features |
| V2 | Combinations of edges and contours |
| V4 | More complex shape, surface and color features |
| Inferior temporal cortex | Higher-level object representations |
| Posterior parietal regions | Spatial and action-related representations |

These are approximate functional correspondences, not exclusive assignments of individual functions to individual regions.

**Operation 3.2 — Integrate neighboring receptive fields**

Take nearby feature responses and combine them.

\[
H_i=
\sum_jw_{ij}F_j
\]

The combination allows a higher-level population to respond to a larger visual pattern instead of only an individual edge.

**Mathematical operations:**

- Weighted summation.
- Convolution.
- Local feature integration.
- Nonlinear activation.

**Operation 3.3 — Increase receptive-field complexity**

Combine simple features into more complex structures.

For example:

\[
\text{Edges}
\rightarrow
\text{Corners}
\rightarrow
\text{Contours}
\rightarrow
\text{Shapes}
\]

The model can use feature compositions:

\[
H_k=\phi\left(\sum_iw_{ki}F_i+b_k\right)
\]

Different populations respond to different combinations.

**Operation 3.4 — Perform spatial pooling**

Combine local information to produce more general representations.

For example:

\[
P_k=
\max_{(x,y)\in\Omega_k}
H_k(x,y)
\]

Or average pooling:

\[
P_k=
\frac{1}{|\Omega_k|}
\sum_{(x,y)\in\Omega_k}H_k(x,y)
\]

Biologically, pooling should be treated as a computational analogy for integration across receptive fields and populations.

**Operation 3.5 — Develop partial visual invariance**

Learn to recognize a pattern despite changes in:

- Position.
- Size.
- Font or shape details.
- Local contrast.
- Minor image distortion.

A simplified invariant representation:

\[
Z=T(F)
\]

Where \(T\) is a learned transformation designed to preserve task-relevant structure across nuisance variations.

Do not discard all spatial information. Exact position remains important for reading and other visual tasks.

### Subsystem B — Parallel visual pathways

**Operation 3.6 — Construct the ventral visual stream**

Develop a pathway that progressively integrates information for visual identification.

\[
V_1\rightarrow V_2\rightarrow V_4\rightarrow IT
\]

The functional representation becomes increasingly sensitive to complex visual combinations.

**Mathematical operations:**

- Feature composition.
- Hierarchical weighted integration.
- Nonlinear transformation.
- Similarity computation.
- Population competition.

**Operation 3.7 — Construct the dorsal visual stream**

Build a separate pathway for spatial relationships and visual guidance.

\[
V_1\rightarrow V_2\rightarrow MT/\text{parietal}
\]

It can represent:

- Position.
- Direction.
- Motion.
- Spatial relationships.
- Visual attention.

For motion:

\[
M(x,y,t)=I(x,y,t)-I(x,y,t-\Delta t)
\]

This gives a simplified temporal-change measurement.

**Operation 3.8 — Integrate ventral and dorsal information**

The two pathways should exchange information without losing their separate functional responsibilities.

\[
Z_{integrated}=
W_vZ_{ventral}+W_dZ_{dorsal}
\]

This can help combine object identity and spatial context.

### Subsystem C — Recurrent hierarchical visual processing

**Operation 3.9 — Introduce descending visual feedback**

Higher visual populations provide contextual information to lower populations.

\[
F_{lower}^{new}
=
F_{lower}^{bottom-up}
+
\lambda F_{higher}^{feedback}
\]

This allows the current interpretation to influence subsequent visual processing.

**Operation 3.10 — Resolve competing visual interpretations**

Suppose the input could represent two visual patterns.

Maintain competing population activations:

\[
A_i(t+1)=
\phi\left(
D_i+
\sum_jw_{ij}A_j-
\lambda\sum_{k\neq i}A_k
\right)
\]

This produces competition rather than prematurely committing to a single interpretation.

**Operation 3.11 — Implement visual attention**

Introduce a spatial and feature-based attentional modulation signal.

\[
A_{attended}(x,y)=
G(x,y)F(x,y)
\]

Where \(G(x,y)\) describes attention allocation.

A softmax allocation can be used as a computational approximation:

\[
G_i=
\frac{e^{a_i/T}}
{\sum_je^{a_j/T}}
\]

This directs more processing resources toward selected features or spatial positions.

**Operation 3.12 — Construct integrated hierarchical visual representations**

Combine the resulting layers:

\[
Z_v=
\operatorname{Integrate}
(V_1,V_2,V_4,IT,MT,\text{Attention})
\]

Preserve both:

1. Local visual information.
2. Global structured visual information.

This is particularly important because the next stage must identify the visual structures that correspond to letters.

<badge color="success">Stage 3 output</badge>

A hierarchical visual representation containing local features, complex shapes, spatial relationships, attention signals and higher-level visual candidates.

# Stage 4 — Neural orthographic representations

<AsyncImageGroup query={["human visual word form area VWFA location ventral occipitotemporal cortex brain illustration","neural letter recognition letter position coding brain visual word recognition scientific diagram","orthographic processing letter bigrams trigrams neural population coding illustration"]} aspectRatio="5:4"/>

### Objective

Transform hierarchical visual representations into neural representations of written language.

This is the stage where the visual system begins to represent letters, graphemes, ordered letter combinations and word forms.

The important distinction is that recognizing a shape is not the same as recognizing a letter.

For example:

- A visual system can detect two vertical lines.
- A more advanced system can recognize a particular letter.
- An orthographic system can recognize a sequence of letters.
- A lexical system can activate a stored word representation.

Reading research describes a progression from early retinotopic visual representations toward more abstract representations of letter order in higher-level visual word-processing regions. <Cite refs={["turn317998search2","turn788860search11","turn317998search10"]}/>

### Subsystem A — Individual grapheme representation

**Operation 4.1 — Extract candidate grapheme regions**

Take the output from Stage 3 and identify spatially separate candidate character regions.

For each candidate, calculate:

- Bounding box.
- Width and height.
- Edge distribution.
- Orientation distribution.
- Stroke density.
- Relative spatial position.
- Local feature statistics.

Represent a candidate as:

\[
G_i=[x_i,y_i,w_i,h_i,F_i]
\]

Where \(F_i\) contains its visual characteristics.

**Mathematical operations:**

- Connected-component analysis.
- Thresholding.
- Spatial segmentation.
- Feature extraction.
- Geometric normalization.

Important: segmentation does not establish letter identity. A candidate region can contain multiple letters or only part of a letter.

**Operation 4.2 — Construct neural grapheme populations**

Create separate neural populations for different possible graphemes.

For example:

\[
P_A,P_B,P_C,\ldots,P_Z
\]

Each population contains neurons with different preferences for:

- Stroke arrangement.
- Curvature.
- Junctions.
- Open and closed regions.
- Orientation combinations.
- Local spatial relationships.

A feature vector for a candidate grapheme:

\[
\mathbf{g}=[g_1,g_2,\ldots,g_n]
\]

A prototype representation:

\[
\boldsymbol{\mu}_k=
[\mu_{k1},\mu_{k2},\ldots,\mu_{kn}]
\]

**Operation 4.3 — Calculate grapheme population similarity**

Compare incoming features against the learned prototype of each grapheme population.

One possible model is a Mahalanobis-like distance:

\[
d_k^2=
(\mathbf{g}-\boldsymbol{\mu}_k)^T
\Sigma_k^{-1}
(\mathbf{g}-\boldsymbol{\mu}_k)
\]

Convert distances into activation strengths:

\[
a_k=\exp\left(-\frac{d_k^2}{2}\right)
\]

Then normalize:

\[
P(G_k|\mathbf{g})=
\frac{\exp(-d_k^2/2T)}
{\sum_j\exp(-d_j^2/2T)}
\]

Where \(T\) controls the sharpness of competition.

These are candidate computations for population coding, not proven equations used by biological grapheme-selective neurons.

**Operation 4.4 — Preserve uncertainty between grapheme candidates**

Do not immediately select the candidate with the highest activation.

Maintain the competing representations.

For example:

| Candidate | Activation |
|---|---:|
| O | 0.46 |
| Q | 0.39 |
| D | 0.15 |

Calculate the uncertainty:

\[
H(G)=-\sum_iP(G_i)\log P(G_i)
\]

High entropy means the candidate is ambiguous.

Low entropy means one candidate dominates.

This is important because visual ambiguity should be resolved using additional context rather than arbitrary classification.

### Subsystem B — Letter-position coding

**Operation 4.5 — Establish retinotopic letter positions**

Retinotopic representations preserve spatial location.

For each grapheme, record:

\[
L_i=(G_i,x_i,y_i)
\]

The system must retain where a grapheme appeared in the visual field.

**Operation 4.6 — Transform spatial positions into ordinal positions**

Determine the position of each grapheme within a candidate word.

For example:

\[
W=[C,A,T]
\]

Represent it as:

\[
W=\{(C,1),(A,2),(T,3)\}
\]

Calculate normalized ordinal positions:

\[
p_i=\frac{i-1}{n-1}
\]

For \(n>1\).

The distinction matters because position invariance should not mean losing letter order.

The distinction between early retinotopic representations and higher-level ordinal coding is supported by recent visual word-recognition research using fMRI and MEG. <Cite refs={["turn317998search2","turn317998search9"]}/>

**Operation 4.7 — Construct letter combinations**

Combine individual grapheme representations into overlapping combinations.

For:

\[
W=[C,A,T]
\]

The system can construct:

- Unigrams: C, A, T.
- Bigrams: CA, AT.
- Trigram: CAT.

For a sequence of length \(n\), the number of overlapping n-grams of size \(k\) is:

\[
N_k=\max(0,n-k+1)
\]

Each combination is represented by a population of neurons sensitive to that ordered pattern.

**Operation 4.8 — Compute ordinal sequence similarity**

Compare the incoming ordered sequence with stored patterns.

One mathematical approximation is normalized edit similarity:

\[
S(A,B)=
1-\frac{D_{edit}(A,B)}
{\max(|A|,|B|)}
\]

This must preserve ordering.

For example, `FORM` and `FROM` contain the same letters but are different sequences.

The neural system must not treat their representations as identical.

### Subsystem C — VWFA hierarchy

**Operation 4.9 — Construct posterior orthographic representations**

Create populations for relatively simple combinations of visual letter features.

These populations should remain sensitive to spatial detail.

**Operation 4.10 — Construct intermediate orthographic populations**

Integrate neighboring letter features into increasingly complex ordered combinations.

\[
H_k=
\phi\left(
\sum_iw_{ki}G_i
\right)
\]

The representation can include letter pairs, triplets and larger combinations.

**Operation 4.11 — Construct anterior lexical-form representations**

Create more integrated word-form representations.

For candidate word \(w\):

\[
A_w=
f(
\text{letters},
\text{positions},
\text{ngrams},
\text{visual evidence}
)
\]

The resulting activity represents the degree to which the incoming visual sequence matches the learned word form.

**Operation 4.12 — Introduce visual invariance**

The system should recognize familiar letter sequences despite changes in:

- Font.
- Size.
- Case.
- Visual position.
- Moderate distortions.

A transformation-invariant matching objective could be:

\[
S(w,I)=
\max_{T\in\mathcal{T}}
\operatorname{Similarity}(w,T(I))
\]

Where \(\mathcal{T}\) contains the allowed visual transformations.

Do not make this invariance absolute: different visual and orthographic properties can remain relevant to discrimination.

**Operation 4.13 — Connect orthography to phonological representations**

The neural architecture should include connections between visual word-form populations and phonological populations.

For a grapheme sequence:

\[
G=[g_1,g_2,\ldots,g_n]
\]

The system can activate corresponding sound representations:

\[
P(\Phi|G)
\]

The mapping can be learned through repeated paired exposure between written and spoken forms.

It must support:

- Individual grapheme-to-phoneme mappings.
- Multi-letter grapheme units.
- Context-dependent pronunciations.
- Competing pronunciation hypotheses.

**Operation 4.14 — Produce an orthographic output representation**

The output should contain:

1. Individual graphemes.
2. Grapheme positions.
3. Ordered letter combinations.
4. Visual confidence.
5. Orthographic candidate activations.
6. Lexical candidate links.
7. Phonological activation links.
8. Unresolved visual ambiguity.

<badge color="success">Stage 4 output</badge>

A neural-inspired orthographic representation that preserves visual features, individual graphemes, letter order, word-form candidates and phonological associations.

# Stage 5 — Neural connectivity and recurrence

<AsyncImageGroup query={["brain structural connectivity connectome white matter tractography scientific illustration","recurrent neural circuit excitatory inhibitory feedback loop diagram","cortical neural network feedforward feedback horizontal connections illustration"]} aspectRatio="5:4"/>

### Objective

Connect all specialized populations into an interacting neural network.

Up to this point, we have established visual, hierarchical and orthographic populations.

However, independent populations cannot adequately model the distributed interactions underlying brain processing.

We therefore construct a neural network in which information can move forward, backward and laterally.

Cortical research identifies feedforward selectivity, recurrent gain control and interactions across hierarchical levels as important candidate computations. <Cite refs={["turn317998search1","turn317998search7"]}/>

### Subsystem A — Anatomical connectivity

**Operation 5.1 — Define neural network nodes**

Each neural population becomes a node.

Example:

\[
V=
\{
V1,V2,V4,VWFA,MTG,IFG,ATL,STG,AG
\}
\]

The regions have specialized computational responsibilities, but those responsibilities overlap and depend on their network interactions.

**Operation 5.2 — Construct the connectivity matrix**

Create a matrix:

\[
W=
\begin{bmatrix}
w_{11}&w_{12}&\cdots\\
w_{21}&w_{22}&\cdots\\
\vdots&\vdots&\ddots
\end{bmatrix}
\]

Where:

\[
w_{ij}
\]

describes the modeled connection from population \(j\) to population \(i\).

The model must distinguish:

- Structural connectivity: anatomical pathways.
- Functional connectivity: statistical dependence in measured activity.
- Effective connectivity: modeled directed influence between neural populations.

These are not interchangeable measurements.

**Operation 5.3 — Initialize connection properties**

For each connection, define:

- Strength.
- Direction.
- Delay.
- Excitatory or inhibitory influence.
- Adaptation parameters.
- Learning eligibility.

A connection becomes:

\[
C_{ij}=
(w_{ij},d_{ij},q_{ij},e_{ij})
\]

Where the fields represent weight, delay, connection type and plasticity eligibility.

**Mathematical operations:**

- Matrix construction.
- Directed graph creation.
- Connection weighting.
- Parameter initialization.
- Graph connectivity checks.

### Subsystem B — Signal propagation

**Operation 5.4 — Implement feedforward information propagation**

Allow lower-level neural populations to transmit information to higher-level populations.

\[
x^{FF}_{t+1}=W_{FF}x_t
\]

The receiving populations integrate the incoming activity.

**Operation 5.5 — Implement feedback propagation**

Allow higher-level populations to influence lower-level populations.

\[
x^{FB}_{t+1}=W_{FB}x_t
\]

This is important for contextual perception and prediction.

**Operation 5.6 — Implement lateral connections**

Connect populations within the same processing level.

\[
x^{LAT}_{t+1}=W_{LAT}x_t
\]

Lateral connections can support:

- Competition.
- Cooperative activation.
- Contextual integration.
- Spatial continuity.
- Pattern completion.

**Operation 5.7 — Combine all incoming neural signals**

The general input to population \(i\) becomes:

\[
I_i(t)=
I_i^{FF}(t)+
I_i^{FB}(t)+
I_i^{LAT}(t)+
I_i^{EXT}(t)
\]

The population then converts its combined input into activity:

\[
x_i(t+1)=\phi(I_i(t))
\]

This becomes the common communication framework for subsequent processing stages.

### Subsystem C — Recurrent dynamics

**Operation 5.8 — Implement recurrent neural loops**

A population's activity affects other populations, whose outputs can eventually return to the original population.

A simplified recurrent network:

\[
\tau\frac{dx}{dt}=
-x+\phi(Wx+Bu)
\]

Where:

- \(x\): population activity.
- \(W\): recurrent connectivity.
- \(u\): external input.
- \(B\): input projection.
- \(\tau\): time constant.

**Operation 5.9 — Stabilize recurrent activity**

Strong recurrent excitation can produce unstable or excessive activity.

Introduce inhibitory feedback:

\[
I_i^{net}=
I_i^{exc}-\lambda I_i^{inh}
\]

The network should monitor:

- Activity growth.
- Oscillations.
- Persistent activation.
- Suppression.
- Saturation.

**Operation 5.10 — Introduce neural synchronization**

Model relationships between population activity rhythms.

A possible mathematical measurement is phase coherence:

\[
R=
\left|
\frac{1}{N}
\sum_{j=1}^{N}e^{i\theta_j}
\right|
\]

Where \(\theta_j\) is the phase of the oscillatory signal of population \(j\).

A larger \(R\) indicates stronger phase alignment in this representation.

Do not assume that every cognitive process requires complete synchronization.

**Operation 5.11 — Introduce recurrent competitive selection**

Allow the network to maintain several possible interpretations while one gradually becomes more strongly represented.

\[
x_i(t+1)=
\phi\left(
I_i(t)+
\sum_jw_{ij}x_j(t)
-
\lambda\sum_{k\neq i}v_{ik}x_k(t)
\right)
\]

This provides a foundation for resolving:

- Ambiguous letters.
- Competing word forms.
- Alternative pronunciations.
- Multiple semantic interpretations.

**Operation 5.12 — Calculate network-level activity**

Calculate the state of the network as a whole:

\[
X(t)=
[x_1(t),x_2(t),...,x_n(t)]
\]

Then measure:

\[
A_{network}(t)=
\frac{1}{n}\sum_i x_i(t)
\]

Also track:

- Population-level activity.
- Connection-level influence.
- Information flow.
- Recurrent convergence.
- Network stability.

**Operation 5.13 — Introduce dynamic connection modulation**

Allow connection effectiveness to change according to the current network state.

For example:

\[
w_{ij}^{effective}(t)=
w_{ij}^{base}g_{ij}(t)
\]

Where \(g_{ij}(t)\) represents task-dependent or state-dependent modulation.

This allows the same anatomical network to support different computational configurations.

<badge color="success">Stage 5 output</badge>

A recurrent, distributed neural architecture with weighted connectivity, feedforward and feedback pathways, lateral interactions, inhibition, synchronization and network-wide state tracking.

# Stage 6 — Biological learning and memory

<AsyncImageGroup query={["synaptic plasticity long term potentiation depression dendritic spine neuroscience diagram","spike timing dependent plasticity STDP pre post spike timing graph","hippocampal neocortical memory consolidation replay diagram"]} aspectRatio="5:4"/>

### Objective

Enable the neural network to change its representations through experience.

Without this stage, the architecture remains a fixed neural simulator.

The biological nervous system can modify synaptic efficacy and circuit activity through different plasticity mechanisms. These include Hebbian and spike-timing-dependent plasticity, LTP, LTD, homeostatic mechanisms and changes associated with memory consolidation. <Cite refs={["turn126122view3","turn370436search0","turn370436search7","turn370436search10"]}/>

### Subsystem A — Activity-dependent learning

**Operation 6.1 — Record neural co-activation**

When two connected populations become active, record their joint activity.

For neurons \(i\) and \(j\):

\[
C_{ij}=
\frac{1}{T}
\int_0^T
r_i(t)r_j(t)\,dt
\]

This measures their average co-activation over an observation period.

**Operation 6.2 — Implement Hebbian learning**

A simplified Hebbian update:

\[
\Delta w_{ij}=
\eta x_i x_j
\]

Then:

\[
w_{ij}^{new}=
w_{ij}^{old}+\Delta w_{ij}
\]

The connection becomes stronger when its pre- and postsynaptic components are jointly active, within this simplified rule.

**Operation 6.3 — Implement spike-timing-dependent plasticity**

The relative timing of pre- and postsynaptic spikes can affect synaptic modification.

Define:

\[
\Delta t=t_{post}-t_{pre}
\]

A simplified STDP window:

\[
\Delta w=
\begin{cases}
A_+e^{-\Delta t/\tau_+},
&\Delta t>0\\
-A_-e^{\Delta t/\tau_-},
&\Delta t<0
\end{cases}
\]

This represents a simplified timing-dependent learning hypothesis.

The biological effect depends on more than spike ordering, including synapse type, dendritic location and other modulatory conditions. <Cite refs={["turn788860search2","turn126122view3"]}/>

**Operation 6.4 — Simulate long-term potentiation**

LTP represents persistent increases in synaptic transmission efficacy under appropriate conditions.

The computational model can accumulate repeated potentiation:

\[
w_{ij}(t+1)=
w_{ij}(t)+\eta_{LTP}E_{ij}(t)
\]

Where \(E_{ij}\) measures the qualifying activity pattern.

**Operation 6.5 — Simulate long-term depression**

LTD represents persistent reductions in synaptic transmission efficacy under appropriate conditions.

\[
w_{ij}(t+1)=
w_{ij}(t)-\eta_{LTD}D_{ij}(t)
\]

Where \(D_{ij}\) measures the relevant depression-driving activity.

These mechanisms should coexist rather than implementing learning solely as weight strengthening.

**Operation 6.6 — Introduce weight constraints**

Prevent unrestricted weight growth.

One simplified implementation:

\[
w_{ij}\leftarrow
\operatorname{clip}(w_{ij},w_{min},w_{max})
\]

Alternatively, use normalization:

\[
w_{ij}^{new}=
\frac{w_{ij}}
{\sqrt{\sum_jw_{ij}^{2}+\epsilon}}
\]

This is an engineering stabilization rule, not a claim that all biological synapses follow this normalization.

### Subsystem B — Homeostatic regulation

**Operation 6.7 — Monitor average neuronal activity**

Calculate a moving average:

\[
\bar r_i(t)=
(1-\alpha)\bar r_i(t-1)+\alpha r_i(t)
\]

Compare it with a target activity level:

\[
e_i(t)=r_i^{target}-\bar r_i(t)
\]

**Operation 6.8 — Implement homeostatic synaptic adjustment**

A simplified adjustment:

\[
w_{ij}^{new}=
w_{ij}^{old}
+\eta_h e_iw_{ij}
\]

This models proportional scaling of synaptic input as one possible stabilization strategy.

**Operation 6.9 — Implement metaplasticity**

Allow the learning threshold to depend on previous neural activity.

\[
\theta_i(t)=f(\bar r_i(t))
\]

Then update the learning rule according to the difference between incoming activity and the adaptive threshold.

This allows the same activity pattern to have different learning effects depending on the history of the neuron.

Homeostatic and Hebbian plasticity operate at different timescales and help address the stability problem created by changing synaptic weights. <Cite refs={["turn370436search7","turn370436search9"]}/>

### Subsystem C — Memory formation

**Operation 6.10 — Encode new neural representations**

When a new pattern is processed, construct an experience representation:

\[
M_{new}=
(X_{visual},X_{orthographic},X_{phonological},X_{semantic},C)
\]

Where \(C\) contains contextual information.

Store the relationships between its components.

**Operation 6.11 — Establish fast associative memory**

Create a fast-learning memory system that can temporarily bind the components of an experience.

A simplified associative memory:

\[
M=W_mX
\]

The matrix \(W_m\) stores learned associations between active representations.

The hippocampal system and neocortex have different roles in memory formation and consolidation; this should be represented through distinct model components rather than one undifferentiated memory array. <Cite refs={["turn370436search10","turn370436search1"]}/>

**Operation 6.12 — Implement memory retrieval**

Given a partial cue \(Q\), retrieve stored patterns:

\[
M^*=
\arg\max_{M_i}
\operatorname{Similarity}(Q,M_i)
\]

The system should preserve multiple candidates when retrieval is uncertain.

**Operation 6.13 — Implement memory replay**

Reactivate previous neural sequences using stored activity patterns.

A replay sequence can be represented as:

\[
X^{replay}=
[x_1,x_2,\ldots,x_T]
\]

The model can reactivate these patterns in a separate simulation phase, allowing previously learned relationships to be revisited.

Replay has been investigated in relation to hippocampal memory retrieval and consolidation, but its exact functions are not fully settled. <Cite refs={["turn370436search6","turn370436search4"]}/>

**Operation 6.14 — Implement systems consolidation**

Develop a fast-learning component and a slower-learning distributed cortical component.

The process can be represented as:

\[
W_{cortex}(t+1)=
W_{cortex}(t)+
\eta_sX^{replay}(t)
\]

The slowly updated network gradually incorporates information previously represented by the fast memory system.

**Operation 6.15 — Implement memory interference and forgetting**

New experiences may interfere with old ones.

The model can represent gradual forgetting through:

\[
w_{ij}(t+1)=
(1-\lambda)w_{ij}(t)
\]

However, forgetting should not be implemented as uniform deletion. Some information is strengthened through continued use, while other associations become less accessible.

**Operation 6.16 — Separate memory timescales**

Maintain distinct memory components:

| Memory system | Computational responsibility |
|---|---|
| Immediate neural state | Current processing |
| Working memory | Temporary maintenance |
| Fast associative memory | Rapid binding |
| Long-term synaptic memory | Learned neural relationships |
| Semantic memory | Generalized conceptual representations |
| Episodic memory | Experience-specific associations |

This is a model architecture. Its memory components should not be interpreted as exact one-to-one anatomical replicas.

<badge color="success">Stage 6 output</badge>

A plastic neural network with associative learning, STDP-inspired timing rules, LTP/LTD, homeostatic regulation, memory storage, retrieval, replay, consolidation and forgetting.

# Stage 7 — Predictive and contextual processing

<AsyncImageGroup query={["predictive coding hierarchical brain feedback prediction error neuroscience model diagram","Bayesian brain perception prior likelihood prediction error neural hierarchy diagram","top down bottom up neural information processing cortical circuit scientific illustration"]} aspectRatio="5:4"/>

### Objective

Enable the neural architecture to predict incoming information, compare predictions against sensory evidence, and update its internal representations.

This is a particularly important stage because human perception is not simply the passive reception of sensory information.

The brain can use previously acquired knowledge, contextual information and learned associations to influence the processing of incoming information.

Predictive processing theories describe a hierarchical architecture in which higher-level representations generate predictions that interact with lower-level sensory information. The resulting differences can be represented as prediction errors. This is an influential theoretical framework, not an established universal explanation of every cortical computation. <Cite refs={["turn788860search10","turn317998search8"]}/>

### Subsystem A — Generative neural representations

**Operation 7.1 — Construct hierarchical generative models**

Create representations that can generate expectations about incoming information.

For example:

- Visual context predicts possible letter shapes.
- Letter sequences predict possible words.
- Words predict possible meanings.
- Sentence structure predicts possible grammatical categories.
- Discourse context predicts possible upcoming events.

Represent the generative network as:

\[
P(X|Z)
\]

Where:

- \(X\): expected sensory information.
- \(Z\): higher-level latent representation.

The network attempts to infer the hidden representation that best explains the available information.

**Operation 7.2 — Retrieve learned contextual priors**

Use the memory system from Stage 6 to retrieve information relevant to the current input.

\[
P(Z|C)
\]

Where \(C\) represents context.

Context may include:

- Previously recognized words.
- Learned linguistic patterns.
- Previously encountered visual patterns.
- Sentence structure.
- Semantic associations.
- Discourse history.

**Mathematical operations:**

- Similarity retrieval.
- Weighted memory lookup.
- Probability estimation.
- Prior normalization.
- Context-dependent activation.

**Operation 7.3 — Generate top-down predictions**

Use higher-level information to predict lower-level representations.

For instance, a candidate word might generate expectations about its constituent letters.

\[
\hat X_{lower}=f(Z_{higher})
\]

The predicted representation is transmitted to the lower-level processing populations.

**Operation 7.4 — Maintain predictions at multiple hierarchical levels**

Each level should generate predictions about the level immediately below it.

\[
\hat X_1=f_1(Z_2)
\]

\[
\hat X_2=f_2(Z_3)
\]

\[
\hat X_3=f_3(Z_4)
\]

This produces a hierarchical generative system.

Predictions should remain linked to the neural populations responsible for the information they predict.

### Subsystem B — Prediction-error processing

**Operation 7.5 — Compare predictions with incoming sensory evidence**

For each predicted feature:

\[
E_i=X_i-\hat X_i
\]

Where:

- \(X_i\): actual sensory representation.
- \(\hat X_i\): predicted representation.
- \(E_i\): prediction error.

For visual processing, the error can represent differences between predicted and observed visual features.

For orthographic processing, it can represent mismatches in expected graphemes or positions.

**Operation 7.6 — Calculate precision-weighted prediction errors**

Not all prediction errors should have equal importance.

For example, the system may have greater confidence in a clear visual letter than in a blurred or occluded one.

Introduce precision:

\[
\Pi_i=\frac{1}{\sigma_i^2+\epsilon}
\]

Then:

\[
E_i^{weighted}=\Pi_iE_i
\]

Precision represents the estimated reliability of information.

The system can therefore distinguish between:

- A large but unreliable error.
- A small but reliable error.
- A large and reliable error.
- A small and unreliable error.

**Operation 7.7 — Transmit prediction-error signals**

Send weighted prediction errors through recurrent pathways.

\[
I_i^{error}=
\sum_jw_{ij}^{error}E_j^{weighted}
\]

These signals influence the relevant higher-level representations.

The exact identities and roles of biological prediction-error populations remain subjects of research.

**Operation 7.8 — Update internal representations**

Modify the current interpretation according to the prediction error.

A generic gradient-based approximation is:

\[
Z(t+1)=
Z(t)-\eta
\nabla_Z\mathcal{L}(Z)
\]

Where \(\mathcal{L}\) represents prediction mismatch.

One possible objective is:

\[
\mathcal{L}=
\frac{1}{2}
\sum_i
\Pi_i(X_i-\hat X_i)^2
\]

This establishes a mathematical mechanism for changing internal beliefs based on incoming evidence.

### Subsystem C — Bayesian inference

**Operation 7.9 — Calculate posterior probabilities**

Combine previous expectations with current sensory evidence.

Using Bayes' rule:

\[
P(H|E,C)=
\frac{P(E|H,C)P(H|C)}
{P(E|C)}
\]

Where:

- \(H\): candidate interpretation.
- \(E\): observed evidence.
- \(C\): context.
- \(P(H|C)\): contextual prior.
- \(P(E|H,C)\): likelihood.

For example, if a visual character could be either `O` or `Q`, the system evaluates both interpretations using visual and contextual evidence.

**Operation 7.10 — Calculate candidate prediction costs**

For each hypothesis:

\[
Cost(H_i)=
-\log P(E|H_i,C)
-\log P(H_i|C)
\]

Then:

\[
H^*=\arg\min_i Cost(H_i)
\]

Keep the other hypotheses available.

This provides a coherent probabilistic selection mechanism.

### Subsystem D — Language and contextual prediction

**Operation 7.11 — Predict upcoming lexical candidates**

Use the current sequence and learned linguistic patterns to calculate:

\[
P(w_t|w_1,\ldots,w_{t-1},C)
\]

This predicts possible next words.

The model can combine:

- Word frequency.
- Previous words.
- Syntactic structure.
- Semantic relationships.
- Discourse context.
- Learned language regularities.

**Operation 7.12 — Calculate word-level surprisal**

Measure how unexpected an incoming word is.

\[
S(w_t)=
-\log P(w_t|Context)
\]

For example:

A highly predictable word receives lower surprisal.

An unusual word in the same context receives higher surprisal.

This provides a mathematical measure of contextual expectation.

**Operation 7.13 — Resolve lexical competition**

Suppose several words are partially compatible with the same visual sequence.

Maintain:

\[
A_i(t)=
f(
V_i,
P_i,
C_i,
F_i
)
\]

Where:

- \(V_i\): visual evidence.
- \(P_i\): phonological evidence.
- \(C_i\): contextual support.
- \(F_i\): learned frequency or familiarity.

Allow the populations to compete through recurrent excitation and inhibition.

**Operation 7.14 — Integrate semantic and world knowledge**

Use learned semantic representations to constrain candidate interpretations.

For example, a word describing an animal should activate different related concepts from a word describing a financial institution.

Represent semantic features as:

\[
Z_{semantic}=
[f_1,f_2,\ldots,f_n]
\]

Calculate compatibility:

\[
S_{semantic}(H_i,C)=
\frac{
Z_{H_i}\cdot Z_C
}{
\|Z_{H_i}\|\|Z_C\|+\epsilon
}
\]

This provides an approximate semantic compatibility score.

**Operation 7.15 — Revise previous interpretations**

When new evidence contradicts the current interpretation, update the representation.

\[
P_{new}(H_i)
\propto
P(E_{new}|H_i,E_{old})P_{old}(H_i)
\]

This allows incremental reanalysis instead of permanently committing to an earlier interpretation.

**Operation 7.16 — Estimate processing confidence and ambiguity**

Calculate uncertainty:

\[
H(P)=
-\sum_iP(H_i)\log P(H_i)
\]

Also calculate the difference between the highest and second-highest candidates:

\[
M=P(H_1)-P(H_2)
\]

A decision can be made only if the confidence and margin criteria are satisfied.

Otherwise, preserve competing candidates.

**Operation 7.17 — Direct attention toward informative evidence**

Prioritize information that is expected to reduce uncertainty.

A simplified information-gain objective:

\[
IG=
H(P_{before})-H(P_{after})
\]

This gives the architecture a way to allocate processing resources toward features that could resolve uncertainty.

**Operation 7.18 — Update the predictive network through experience**

When prediction errors persist, the learning system can update its predictive associations.

\[
W_{predictive}^{new}=
W_{predictive}^{old}
-
\eta\nabla_W\mathcal{L}
\]

This connects prediction error with Stage 6 learning mechanisms.

However, real synaptic learning involves several mechanisms and does not necessarily perform gradient descent as implemented in software.

<badge color="success">Stage 7 output</badge>

A predictive neural system with contextual priors, hierarchical feedback, prediction errors, Bayesian candidate evaluation, lexical surprisal, semantic integration, ambiguity resolution and adaptive expectations.

# Stage 8 — Brain-data validation

<AsyncImageGroup query={["EEG cap electrophysiology brain measurement laboratory scientific photograph","fMRI scanner human brain functional MRI image","magnetoencephalography MEG helmet brain research measurement","brain neural network computational model to experimental data comparison visualization"]} aspectRatio="5:4"/>

### Objective

Determine whether the proposed computational and biological models actually correspond to measurable brain behavior.

This stage is essential.

A neural simulation may be mathematically sophisticated while still failing to reproduce biological processing.

Therefore, the architecture needs to make testable predictions and compare them with independent human behavioral and neural measurements.

Neuroimaging research distinguishes between statistical models of observed responses and mechanistic models that explain how neuronal activity generates those responses. <Cite refs={["turn132590view3","turn126122view4"]}/>

### Subsystem A — Experimental data construction

**Operation 8.1 — Define experimental tasks**

Construct experiments corresponding to the capabilities being tested.

Examples:

| Experiment | Main purpose |
|---|---|
| Single-letter recognition | Visual character processing |
| Grapheme discrimination | Grapheme representation |
| Word recognition | Orthographic and lexical processing |
| Pseudoword reading | Sublexical processing |
| Word-frequency comparison | Familiarity effects |
| Sentence comprehension | Linguistic integration |
| Ambiguous sentence interpretation | Reanalysis and prediction |
| Contextual reading | Predictive processing |

For every experiment define:

- Input stimuli.
- Experimental conditions.
- Participant groups.
- Behavioral measurements.
- Expected model outputs.

**Operation 8.2 — Construct a synchronized data representation**

Organize the actual data into a common format.

\[
D=
\{
S,B,E,M,F,P
\}
\]

Where:

- \(S\): stimuli.
- \(B\): behavioral results.
- \(E\): EEG recordings.
- \(M\): MEG recordings.
- \(F\): fMRI measurements.
- \(P\): participant and experimental metadata.

Maintain trial identifiers, participant identifiers, stimulus identifiers and accurate timing.

**Operation 8.3 — Preprocess experimental measurements**

For each modality, apply appropriate preprocessing.

EEG/MEG may require:

- Filtering.
- Artifact rejection.
- Channel inspection.
- Trial alignment.
- Baseline correction.
- Source-model preparation.

fMRI may require:

- Motion correction.
- Spatial preprocessing.
- Temporal preprocessing.
- Registration.
- Hemodynamic modeling.

Behavioral data may require:

- Response-time validation.
- Accuracy calculation.
- Outlier analysis.
- Trial-condition matching.

The procedures must be chosen according to the actual dataset, not assumed to be identical across experiments.

### Subsystem B — Neural measurement models

**Operation 8.4 — Generate EEG predictions**

The simulated neural populations produce time-dependent source activity:

\[
S(t)
\]

A measurement model projects this activity into sensor space:

\[
Y_{EEG}(t)=L_{EEG}S(t)+\epsilon(t)
\]

Where:

- \(L_{EEG}\): EEG lead-field matrix.
- \(S(t)\): modeled neural sources.
- \(\epsilon(t)\): measurement noise.

The lead field depends on the anatomical and electrical properties of the head.

**Operation 8.5 — Generate MEG predictions**

Likewise:

\[
Y_{MEG}(t)=L_{MEG}S(t)+\epsilon(t)
\]

The MEG and EEG forward models must be distinct because they describe different sensor measurements.

**Operation 8.6 — Estimate neural sources from measurements**

The inverse problem attempts to estimate source activity from sensor recordings.

A regularized least-squares example:

\[
\hat S=
\arg\min_S
\left[
\|Y-LS\|_2^2+
\lambda\|S\|_2^2
\right]
\]

This produces a regularized estimate:

\[
\hat S=
(L^TL+\lambda I)^{-1}L^TY
\]

This is an important but simplified inverse solution.

The inverse problem is underdetermined and sensitive to anatomical assumptions, sensor geometry and regularization. <Cite refs={["turn788860search0","turn788860search4"]}/>

**Operation 8.7 — Compare event-related neural responses**

Align individual trials around an event, such as the presentation of a word.

Calculate:

\[
ERP(t)=
\frac{1}{N}\sum_{i=1}^{N}Y_i(t)
\]

Compare modeled and recorded ERP waveforms.

For example, inspect:

- Early sensory responses.
- Word-related responses.
- Semantic mismatch responses.
- Later reanalysis-related responses.

Do not interpret a single ERP component as a unique measurement of one neural mechanism.

**Operation 8.8 — Analyze time-frequency representations**

Calculate spectral power over time.

For a signal \(x(t)\), a simplified short-time Fourier transform:

\[
X(\tau,f)=
\int x(t)w(t-\tau)e^{-i2\pi ft}dt
\]

Then:

\[
P(\tau,f)=|X(\tau,f)|^2
\]

This allows comparison of modeled and experimental neural oscillatory activity.

### Subsystem C — fMRI validation

**Operation 8.9 — Convert neural activity into a hemodynamic prediction**

fMRI BOLD measurements are indirect consequences of neurovascular processes.

A simplified model:

\[
BOLD(t)=h(t)*N(t)
\]

Where:

- \(h(t)\): hemodynamic response function.
- \(N(t)\): modeled neural activity.
- \(*\): convolution.

The model should not compare raw membrane voltage directly with BOLD measurements.

**Operation 8.10 — Fit regional response models**

Use the general linear model:

\[
Y=X\beta+\epsilon
\]

Estimate:

\[
\hat\beta=
(X^TX)^{-1}X^TY
\]

Or use a suitable regularized or generalized estimator where necessary.

This estimates regional response associations under the specified design.

**Operation 8.11 — Compare representational similarity**

Compare the patterns represented by the model with patterns measured in the brain.

Construct a model representational dissimilarity matrix:

\[
RDM_{model}(i,j)=
d(Z_i,Z_j)
\]

Construct an experimental RDM:

\[
RDM_{brain}(i,j)=
d(B_i,B_j)
\]

Then calculate their correspondence:

\[
\rho=
\operatorname{corr}
\left(
RDM_{model},
RDM_{brain}
\right)
\]

A high correlation indicates similarity in representational geometry. It does not by itself prove that the model implements the same biological mechanism.

### Subsystem D — Causal and behavioral validation

**Operation 8.12 — Conduct lesion-based model comparisons**

Simulate disruption of an individual population.

For region \(i\):

\[
x_i^{lesion}=(1-\rho_i)x_i
\]

Where \(\rho_i\) represents model disruption.

Then calculate the behavioral difference:

\[
\Delta Accuracy=
Accuracy_{normal}-Accuracy_{lesion}
\]

\[
\Delta RT=
RT_{lesion}-RT_{normal}
\]

Compare the predicted impairment patterns with independent lesion-patient observations.

**Operation 8.13 — Evaluate perturbation-based predictions**

Create virtual perturbations of selected network populations.

Compare:

- Normal model behavior.
- Perturbed model behavior.
- Available experimental intervention results.

The model must allow perturbations to increase, decrease or redistribute activity rather than assuming that every intervention simply suppresses a brain region.

**Operation 8.14 — Compare behavioral outputs**

For each task calculate:

Accuracy:

\[
Accuracy=
\frac{N_{correct}}{N_{total}}
\]

Mean absolute error:

\[
MAE=
\frac{1}{N}\sum_i|y_i-\hat y_i|
\]

Root mean squared error:

\[
RMSE=
\sqrt{
\frac{1}{N}\sum_i(y_i-\hat y_i)^2
}
\]

Reaction-time error:

\[
\Delta RT=
RT_{model}-RT_{human}
\]

Perform these comparisons separately for each experiment and participant group.

### Subsystem E — Statistical validation

**Operation 8.15 — Perform held-out evaluation**

Separate the data into:

- Training set.
- Validation set.
- Independent test set.

Where possible, separate participants and stimuli rather than randomly dividing individual trials from the same participants into all groups.

This reduces the risk of information leakage.

**Operation 8.16 — Quantify uncertainty**

Calculate:

- Confidence intervals.
- Bootstrap distributions.
- Parameter sensitivity.
- Participant variability.
- Trial-level variability.
- Measurement uncertainty.

For example:

\[
CI_{95\%}=
[Q_{0.025},Q_{0.975}]
\]

Using a suitable sampling procedure.

**Operation 8.17 — Conduct ablation studies**

Disable one subsystem at a time.

Examples:

- Remove recurrent connections.
- Disable contextual prediction.
- Remove the orthographic hierarchy.
- Disable synaptic learning.
- Remove semantic integration.
- Replace LIF dynamics with a rate-only model.

Then calculate:

\[
\Delta L_i=
L_{ablated_i}-L_{complete}
\]

This identifies which components are necessary for the model's measured performance.

**Operation 8.18 — Evaluate biological correspondence**

Organize evidence into distinct categories:

| Evidence | What it can establish |
|---|---|
| Similar behavior | Behavioral correspondence |
| Similar EEG/MEG responses | Electrophysiological correspondence |
| Similar fMRI patterns | Hemodynamic/representational correspondence |
| Similar connectivity | Network-organization correspondence |
| Lesion-related deficits | Evidence about necessity and network dependence |
| Perturbation effects | Evidence about causal contributions |

No single category establishes complete biological equivalence.

**Operation 8.19 — Determine whether the model is supported or rejected**

For every operation, compare its predicted measurements with the experimental evidence.

Assign a result:

- Supported under the tested conditions.
- Partially supported.
- Contradicted.
- Inconclusive.
- Not yet tested.

The algorithm must be allowed to reject its own assumptions.

<badge color="success">Stage 8 output</badge>

A research-validation system containing experimental comparisons, EEG/MEG and fMRI predictions, behavioral evaluations, representational similarity, causal testing, statistical uncertainty and falsifiable hypotheses.

# Stage 9 — Integrated neurocomputational ORE

<AsyncImageGroup query={["large distributed brain neural networks connectome multiregion scientific illustration","modular artificial neural network interconnected specialized modules architecture visualization","human brain computational neuroscience whole brain network visualization"]} aspectRatio="5:4"/>

### Objective

Integrate all eight previous stages into one coordinated neurocomputational architecture.

The objective is not to create nine independent simulations that run without communicating.

Instead, construct a distributed architecture whose modules have specialized responsibilities but share information, neural states, memory, predictions and control signals.

This is consistent with the distinction between functional specialization and functional integration in neuroscience: complex functions depend on both specialized regions and their interactions. <Cite refs={["turn132590view3","turn317998search1"]}/>

I would organize this stage into the following subsystems.

### Subsystem A — Master architecture construction

**Operation 9.1 — Construct the master ORE controller**

Create one central controller responsible for coordinating all subsystems.

Its responsibilities:

1. Receive processing requests.
2. Identify required processing stages.
3. Initialize the necessary neural populations.
4. Dispatch computations to specialized modules.
5. Maintain the global processing state.
6. Coordinate recurrent interactions.
7. Collect module outputs.
8. Handle unresolved information.
9. Return the final result.

Represent the controller:

\[
ORE_{controller}=
\{M_1,M_2,\ldots,M_9\}
\]

Where each \(M_i\) is a major subsystem.

**Operation 9.2 — Construct specialized subsystem controllers**

Each major stage should have its own controller.

For example:

| Controller | Responsibility |
|---|---|
| Neural Simulation Controller | Neurons and neural populations |
| Visual Controller | Retina, LGN and V1 |
| Visual Hierarchy Controller | Higher visual representations |
| Orthographic Controller | Letters, graphemes and words |
| Connectivity Controller | Recurrent network communication |
| Learning Controller | Plasticity and memory |
| Predictive Controller | Prediction and contextual integration |
| Validation Controller | Experimental comparisons |
| Master Integration Controller | Coordination of the complete ORE system |

Each controller should expose an explicit input/output contract.

**Operation 9.3 — Construct shared computational contracts**

Define common representations that all compatible modules can exchange.

For example:

\[
State=
\{

NeuralState,
MemoryState,
ContextState,
PredictionState,

\]

Each component must describe:

- Data type.
- Dimensions.
- Units.
- Processing origin.
- Timestamp.
- Confidence.
- Provenance.
- Version.

This prevents incompatible representations from being passed between modules.

### Subsystem B — Integrated processing coordination

**Operation 9.4 — Initialize the complete neural network**

Construct the neural populations and their connections.

\[
G=(V,E,W)
\]

Where:

- \(V\): populations.
- \(E\): connections.
- \(W\): synaptic weights.

Initialize:

- Neural electrical parameters.
- Connectivity.
- Learning parameters.
- Memory structures.
- Recurrent states.
- Predictive models.
- Experimental measurement models.

**Operation 9.5 — Initialize the sensory input**

Receive an image, audio input or another supported stimulus.

Store its original representation.

Generate the initial sensory-state object:

\[
S_0=
\{
I_{visual},
I_{auditory},
I_{other}
\}
\]

The original input must remain distinguishable from derived neural representations.

**Operation 9.6 — Execute biological sensory processing**

Send the sensory information through the appropriate neural populations.

For visual input:

\[
S_0
\rightarrow
Retina
\rightarrow
LGN
\rightarrow
V1
\]

For auditory input, initialize the corresponding auditory sensory populations.

The two sensory streams may converge later through shared higher-level network representations.

**Operation 9.7 — Execute hierarchical visual processing**

Send early visual outputs through hierarchical populations.

\[
V1\rightarrow V2\rightarrow V4\rightarrow IT
\]

In parallel, process spatial and attentional information through the dorsal pathway.

**Operation 9.8 — Generate orthographic neural representations**

When the stimulus contains written language, process:

LetterPositions
\rightarrow
Ngrams

Preserve ambiguity and uncertainty at every level.

**Operation 9.9 — Activate the language network**

\[
MTG\leftrightarrow ATL

\[
STG\leftrightarrow MTG
\]

\[

These are illustrative network relationships, not a complete anatomical connectivity specification.

**Operation 9.10 — Integrate all neural activity**

Collect the population activity and calculate the current global state.

X(t)=

Do not simply average all representations.

Preserve their separate dimensions and allow each subsystem to operate on the information relevant to its task.

### Subsystem C — Distributed neural control

**Operation 9.11 — Coordinate recurrent communication**

m_{ij}(t)=f_{ij}(X_i(t),W_{ij})

X_i(t+1)=
\phi\left(

\sum_jm_{ij}(t)

**Operation 9.12 — Coordinate biological simulation and functional computation**

Where \(E_i\) represents an error from a particular subsystem and \(\lambda_i\) determines its contribution.

**Operation 9.16 — Monitor the integrated network**

Continuously monitor:

- Neural activity.
- Recurrent stability.
- Prediction uncertainty.
- Memory state.
- Population competition.
- Processing completion.

The controller should detect unstable neural activity and invalid module outputs.

**Operation 9.17 — Allocate computational resources**

- \(U_i\): uncertainty.
- \(E_i\): prediction error.
- \(R_i\): task relevance.
- \(G_i\): goal relevance.

**Operation 9.18 — Maintain persistent neural and cognitive states**

Preserve:

- Learned connections.
- Neural population state.
- Orthographic memory.
- Semantic knowledge.
- Contextual representations.
- Previous processing results.

The system should distinguish temporary simulation states from persistent learned parameters.

**Operation 9.19 — Detect processing completion**

The system should determine whether sufficient information is available for a final interpretation.

A simplified completion criterion:

\[
Complete=
V\land O\land L\land S\land C
\]

Where:

- \(V\): required visual evidence is available.
- \(O\): orthographic processing is sufficiently complete.
- \(L\): required lexical processing is complete.
- \(S\): semantic interpretation is sufficiently resolved.
- \(C\): no blocking contextual or control conflict remains.

Not every task requires all these components.

The architecture must allow partial processing and abstention.

### Subsystem E — Integrated brain validation and governance

**Operation 9.20 — Collect the complete execution trace**

Every operation must report:

- Operation identifier.
- Processing input.
- Processing output.
- Mathematical operation.
- Biological reference.
- Execution time.
- Neural population activity.
- Confidence.
- Prediction error.
- Validation status.

Connect the integrated output with Stage 8.

This distinction is essential.

**Operation 9.23 — Update the system under controlled learning**

1. Record the evidence.

- Visual representations.
- Orthographic representations.
- Lexical and semantic representations.
- Neural activity traces.
- Learned connection changes.
- Predictive state.
- Prediction errors.
- Processing confidence.
- Experimental correspondence.
- Validation diagnostics.

# 11. How the nine stages interact

Although the stages are numbered sequentially, a biologically motivated implementation must not assume that every process executes only once in a strict forward direction.

Some stages represent foundational capabilities, while others operate continuously during processing.

For example:

- Neural dynamics continue throughout the entire computation.
- Recurrent connectivity operates while visual and linguistic processing takes place.
- Learning modifies representations across experiences.
- Memory retrieval can influence early sensory and orthographic interpretation.
- Predictive signals can return from higher to lower processing levels.
- Brain-data validation evaluates the architecture rather than acting as another perceptual stage.

The correct overall model is therefore a combination of sequential processing and recurrent interaction.

## 14. Important implementation principle

I recommend that the master ORE architecture have three independent but interacting layers:

**Layer A — Functional computational layer**

Implements what the system needs to accomplish: visual processing, orthographic recognition, memory retrieval, contextual reasoning and prediction.

**Layer B — Biological simulation layer**

Implements proposed neural mechanisms: membrane dynamics, synaptic transmission, spikes, neural connectivity, recurrence and plasticity.

**Layer C — Experimental validation layer**

Determines whether the first two layers make predictions that agree with actual human behavior and neural measurements.

This separation is important because a functional system can succeed without using biologically realistic computations, while a biologically detailed simulation can still fail to recognize words or understand sentences.

The purpose of ORE should be to investigate how these three layers can be connected and progressively validated.

# Stage 9 — Integrated neurocomputational ORE

### Objective

Integrate all eight previous stages into one coordinated neurocomputational architecture.

The objective is not to create nine independent simulations that run without communicating.

Instead, construct a distributed architecture whose modules have specialized responsibilities but share information, neural states, memory, predictions and control signals.

This is consistent with the distinction between functional specialization and functional integration in neuroscience: complex functions depend on both specialized regions and their interactions. <Cite refs={["turn132590view3","turn317998search1"]}/>

I would organize this stage into the following subsystems.

### Subsystem A — Master architecture construction

**Operation 9.1 — Construct the master ORE controller**

Create one central controller responsible for coordinating all subsystems.

Its responsibilities:

1. Receive processing requests.
2. Identify required processing stages.
3. Initialize the necessary neural populations.
4. Dispatch computations to specialized modules.
5. Maintain the global processing state.
6. Coordinate recurrent interactions.
7. Collect module outputs.
8. Handle unresolved information.
9. Return the final result.

Represent the controller:

\[
ORE_{controller}=
\{M_1,M_2,\ldots,M_9\}
\]

Where each \(M_i\) is a major subsystem.

**Operation 9.2 — Construct specialized subsystem controllers**

Each major stage should have its own controller.

For example:

| Controller | Responsibility |
|---|---|
| Neural Simulation Controller | Neurons and neural populations |
| Visual Controller | Retina, LGN and V1 |
| Visual Hierarchy Controller | Higher visual representations |
| Orthographic Controller | Letters, graphemes and words |
| Connectivity Controller | Recurrent network communication |
| Learning Controller | Plasticity and memory |
| Predictive Controller | Prediction and contextual integration |
| Validation Controller | Experimental comparisons |
| Master Integration Controller | Coordination of the complete ORE system |

Each controller should expose an explicit input/output contract.

**Operation 9.3 — Construct shared computational contracts**

Define common representations that all compatible modules can exchange.

For example:

\[
State=
\{
SensoryState,
NeuralState,
MemoryState,
ContextState,
PredictionState,
ConfidenceState
\}
\]

Each component must describe:

- Data type.
- Dimensions.
- Units.
- Processing origin.
- Timestamp.
- Confidence.
- Provenance.
- Version.

This prevents incompatible representations from being passed between modules.

### Subsystem B — Integrated processing coordination

**Operation 9.4 — Initialize the complete neural network**

Construct the neural populations and their connections.

\[
G=(V,E,W)
\]

Where:

- \(V\): populations.
- \(E\): connections.
- \(W\): synaptic weights.

Initialize:

- Neural electrical parameters.
- Connectivity.
- Learning parameters.
- Memory structures.
- Recurrent states.
- Predictive models.
- Experimental measurement models.

**Operation 9.5 — Initialize the sensory input**

Receive an image, audio input or another supported stimulus.

Store its original representation.

Generate the initial sensory-state object:

\[
S_0=
\{
I_{visual},
I_{auditory},
I_{other}
\}
\]

The original input must remain distinguishable from derived neural representations.

**Operation 9.6 — Execute biological sensory processing**

Send the sensory information through the appropriate neural populations.

For visual input:

\[
S_0
\rightarrow
Retina
\rightarrow
LGN
\rightarrow
V1
\]

For auditory input, initialize the corresponding auditory sensory populations.

The two sensory streams may converge later through shared higher-level network representations.

**Operation 9.7 — Execute hierarchical visual processing**

Send early visual outputs through hierarchical populations.

\[
V1\rightarrow V2\rightarrow V4\rightarrow IT
\]

In parallel, process spatial and attentional information through the dorsal pathway.

**Operation 9.8 — Generate orthographic neural representations**

When the stimulus contains written language, process:

\rightarrow
GraphemePopulations
\rightarrow
LetterPositions
\rightarrow
Ngrams

Preserve ambiguity and uncertainty at every level.

**Operation 9.9 — Activate the language network**

\[

\]

\[
STG\leftrightarrow MTG
\]

\[
AG\leftrightarrow ATL

These are illustrative network relationships, not a complete anatomical connectivity specification.

**Operation 9.10 — Integrate all neural activity**

Collect the population activity and calculate the current global state.

X(t)=
\begin{bmatrix}
X_{visual}(t)\\
X_{orthographic}(t)\\
X_{phonological}(t)\\
X_{semantic}(t)\\
X_{contextual}(t)\\
X_{control}(t)

Do not simply average all representations.

Preserve their separate dimensions and allow each subsystem to operate on the information relevant to its task.

### Subsystem C — Distributed neural control

**Operation 9.11 — Coordinate recurrent communication**

At each processing cycle, allow each subsystem to exchange messages with connected subsystems.

\[
m_{ij}(t)=f_{ij}(X_i(t),W_{ij})

The receiving subsystem integrates the received message into its own state:

\[
X_i(t+1)=
\phi\left(
X_i(t)+
\sum_jm_{ij}(t)
\right)
\]

This creates a distributed recurrent architecture.

**Operation 9.12 — Coordinate biological simulation and functional computation**

The learning controller receives information about the processing experience.

It determines:

- Which representations were activated.
- Which connections participated.
- Which predictions were incorrect.
- Which patterns were successfully recognized.

It then updates the appropriate learning system.

The predictive controller uses:

- Current sensory information.
- Learned neural representations.
- Contextual information.
- Previous processing states.

It generates predictions and sends them to the relevant processing populations.

**Operation 9.15 — Implement cross-module error propagation**

Prediction errors should be transmitted to the modules that contributed to the incorrect prediction.

For example:

An orthographic error may require:

- Reconsidering grapheme identity.
- Reconsidering letter position.
- Re-evaluating lexical candidates.
- Revising the predicted word form.

The corresponding system-level error can be:

\[
E_{ORE}=
\sum_i\lambda_iE_i
\]

Where \(E_i\) represents an error from a particular subsystem and \(\lambda_i\) determines its contribution.

This is a software-level aggregation rule, not a single biological error signal.

### Subsystem D — Global stability and control

**Operation 9.16 — Monitor the integrated network**

Continuously monitor:

- Neural activity.
- Recurrent stability.
- Prediction uncertainty.
- Memory state.
- Population competition.
- Processing completion.

The controller should detect unstable neural activity and invalid module outputs.

**Operation 9.17 — Allocate computational resources**

Give processing priority to modules with relevant unresolved tasks.

One possible model:

\[
Priority_i=
w_1U_i+
w_2E_i+
w_3R_i+
w_4G_i
\]

Where:

- \(U_i\): uncertainty.
- \(E_i\): prediction error.
- \(R_i\): task relevance.
- \(G_i\): goal relevance.

This is an engineering scheduling mechanism motivated by neural attention and control.

**Operation 9.18 — Maintain persistent neural and cognitive states**

Preserve:

- Learned connections.
- Neural population state.
- Orthographic memory.
- Semantic knowledge.
- Contextual representations.
- Previous processing results.

The system should distinguish temporary simulation states from persistent learned parameters.

**Operation 9.19 — Detect processing completion**

The system should determine whether sufficient information is available for a final interpretation.

A simplified completion criterion:

\[
Complete=
V\land O\land L\land S\land C
\]

Where:

- \(V\): required visual evidence is available.
- \(O\): orthographic processing is sufficiently complete.
- \(L\): required lexical processing is complete.
- \(S\): semantic interpretation is sufficiently resolved.
- \(C\): no blocking contextual or control conflict remains.

Not every task requires all these components.

The architecture must allow partial processing and abstention.

### Subsystem E — Integrated brain validation and governance

**Operation 9.20 — Collect the complete execution trace**

Every operation must report:

- Operation identifier.
- Processing input.
- Processing output.
- Mathematical operation.
- Biological reference.
- Execution time.
- Neural population activity.
- Confidence.
- Prediction error.
- Validation status.

**Operation 9.21 — Generate the integrated neural report**

Combine functional and biological reports without mixing their meanings.

\[
Report=
\{
R_{functional},
R_{biological},
R_{experimental},
R_{diagnostics}
\}
\]

**Operation 9.22 — Compare all stages against experimental evidence**

Connect the integrated output with Stage 8.

Evaluate the complete architecture rather than validating only isolated components.

For example:

Does improvement in visual recognition result from a biologically plausible orthographic mechanism, or is the final accuracy improvement caused entirely by a non-biological shortcut?

This distinction is essential.

**Operation 9.23 — Update the system under controlled learning**

If validation or authorized learning provides new evidence:

1. Record the evidence.
2. Identify the affected subsystem.
3. Generate a proposed update.
4. Check compatibility with shared contracts.
5. Test the update independently.
6. Compare against the previous model.
7. Preserve the previous version.
8. Promote the update only if it passes acceptance criteria.

This creates a controlled, auditable research architecture.

**Operation 9.24 — Produce the complete neurocomputational output**

The master controller returns:

- Visual representations.
- Orthographic representations.
- Lexical and semantic representations.
- Neural activity traces.
- Learned connection changes.
- Predictive state.
- Prediction errors.
- Processing confidence.
- Experimental correspondence.
- Validation diagnostics.

## 14. Important implementation principle

I recommend that the master ORE architecture have three independent but interacting layers:

**Layer A — Functional computational layer**

Implements what the system needs to accomplish: visual processing, orthographic recognition, memory retrieval, contextual reasoning and prediction.

**Layer B — Biological simulation layer**

Implements proposed neural mechanisms: membrane dynamics, synaptic transmission, spikes, neural connectivity, recurrence and plasticity.

**Layer C — Experimental validation layer**

Determines whether the first two layers make predictions that agree with actual human behavior and neural measurements.

This separation is important because a functional system can succeed without using biologically realistic computations, while a biologically detailed simulation can still fail to recognize words or understand sentences.

The purpose of ORE should be to investigate how these three layers can be connected and progressively validated.
