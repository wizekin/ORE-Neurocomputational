## Implementation

The subsystem contains five stages and 30 registered operations, with six operations per stage.

| Stage | Implemented functionality |
|---|---|
| S1 — Linguistic working-memory buffers | Separate phonological, lexical, syntactic, semantic, and discourse buffers; activation, decay, capacity limits, rehearsal, and retrieval |
| S2 — Incomplete syntactic structures | Nested phrase/clause frames, unresolved argument slots, dependency maintenance, retrieval scoring, and evidence-based slot binding |
| S3 — Executive control | Conflict monitoring, control-demand estimation, goal compatibility, top-down bias, and attentional selection |
| S4 — Semantic interpretation | Evidence integration, softmax probabilities, recurrent competition, entropy, confidence margins, and abstention |
| S5 — Cognitive task switching | Task-set representation, switch detection, estimated switch costs, control reconfiguration, interference, and task resumption |

Operation IDs run from `WMC-001` to `WMC-030`. Every operation records its mathematical formulation, functional output, and biological reference in the execution trace.

## Biological and mathematical implementation

The optional biological-reference model uses coupled current-based leaky integrate-and-fire populations:

- Phonological-loop and lexical-maintenance populations.
- Syntactic and semantic workspace populations.
- Parietal attention and prefrontal control.
- Conflict monitoring and task-set networks.

The implementation includes membrane-voltage integration, recurrent excitation, global inhibition, threshold crossings, refractory periods, spike counts, and firing-rate measurements.

The functional algorithms also implement exponential activation decay, cosine similarity, weighted evidence integration, softmax normalization, damped recurrent competition, entropy, posterior margins, and task-switch cost estimation.

These biological components are computational hypotheses, not a validated simulation of human neural circuitry.

## Implementation details

- **Working memory:** five separate functional buffers, chunking, activation decay, rehearsal, capacity limits, attention, and content-addressable retrieval.
- **Syntax:** grammatical expectations, nested structures, unresolved dependencies, supported slot binding, and dependency-linked memory.
- **Executive control:** goal maintenance, processing monitoring, conflict detection, attention allocation, lateral competition, and provisional interpretation acceptance.
- **Semantic resolution:** separate evidence channels, knowledge retrieval, grammatical/contextual compatibility, recurrent competition, abstention, and interpretation revision.
- **Task switching:** switch detection, preserved task checkpoints, interference management, task resumption, observed transition-cost learning, and processing-completion evaluation.
- **Biological reference:** eight coupled leaky integrate-and-fire populations, advanced once per operation. This is a computational hypothesis, not a validated simulation of the human brain.
