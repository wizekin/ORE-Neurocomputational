# Part 1 — Linguistic working-memory buffers

## 1.1 What this stage accomplishes

The brain receives linguistic information from previous processing systems and temporarily maintains the information needed for ongoing comprehension.

Consider:

"The scientist who discovered the new material believes that it will change medicine."

To understand this sentence, the brain must temporarily maintain several things:

- The identity of the scientist.
- The relationship between the scientist and the discovery.
- The fact that the discovery concerns a material.
- The incomplete relationship between the material and the pronoun "it".
- The developing main proposition about changing medicine.

These pieces of information must remain accessible even while additional words arrive.

Working memory therefore needs to maintain several different types of information simultaneously.

Research on language and working memory describes interactions among phonological, prefrontal, temporal, parietal and other networks, with recruitment changing according to linguistic complexity and task demands. <Cite refs={["turn655059view2","turn264485search3"]}/>

## 1.2 Detailed algorithmic operations

### Operation 1 — Receive processed linguistic information

**Functional operation**

Receive information from the upstream language-processing systems:

- Lexical representations.
- Phonological representations.
- Syntactic structures.
- Semantic representations.
- Discourse context.
- Current cognitive goals.

Each representation should have an identity, content, source, timestamp and confidence value.

For example:

**Possible mathematical operations**

Represent each linguistic item as a feature vector:

\[
\mathbf{x}_i =
[x_1,x_2,\ldots,x_n]
\]

Each feature represents a characteristic of the information.

The system can calculate the similarity between two representations using cosine similarity:

\[
Similarity(A,B)=
\frac{\mathbf{A}\cdot\mathbf{B}}
{\|\mathbf{A}\|\|\mathbf{B}\|+\epsilon}
\]

This allows related information to be associated and retrieved.

**Biological interpretation**

Distributed linguistic representations become available to working-memory and attention networks. Relevant candidates interact with prefrontal and posterior language-related systems.

### Operation 2 — Encode information into temporary memory representations

**Functional operation**

Transform incoming information into representations suitable for temporary maintenance.

Different information types require different representational formats.

| Information | Temporary representation |
|---|---|
| Spoken words | Phonological sequence |
| Written words | Orthographic representation |
| Word meanings | Semantic features |
| Syntax | Hierarchical structural representation |
| Entities | Entity-reference records |
| Propositions | Predicate-argument relationships |
| Task goals | Task-control representation |

The system should preserve connections between these representations rather than storing everything as unrelated items.

**Possible mathematical operations**

Feature concatenation:

\[
\mathbf{m}_i =
[\mathbf{x}_{lexical},
\mathbf{x}_{syntactic},
\mathbf{x}_{semantic}]
\]

Weighted integration:

\[
\mathbf{m}_i =
w_l\mathbf{x}_{lexical}
+w_s\mathbf{x}_{syntactic}
+w_m\mathbf{x}_{semantic}
\]

Here the weights determine the relative contribution of each information channel.

**Biological interpretation**

Phonological maintenance involves interactions among inferior frontal and posterior temporal-parietal language systems. Semantic and episodic information recruits additional distributed cortical networks.

The traditional phonological-loop and episodic-buffer concepts are useful functional models, not literal separate storage compartments in the brain. <Cite refs={["turn655059view2","turn264485search8"]}/>

### Operation 3 — Maintain temporary linguistic activation

**Functional operation**

Maintain recently processed information so that it remains accessible during subsequent processing.

Information should not disappear immediately after a word is recognized.

However, not all representations should receive equal maintenance priority.

For example:

- The main subject of a sentence may remain highly active.
- A recently encountered grammatical dependency may need maintenance.
- An irrelevant adjective may gradually lose priority.
- A task-relevant entity may remain active throughout a longer discourse.

**Possible mathematical operations**

A useful computational approximation is leaky activation:

\[
A_i(t+\Delta t)=
A_i(t)e^{-\Delta t/\tau_i}
\]

Where:

- \(A_i\): activation of memory item \(i\).
- \(\tau_i\): effective retention time constant.
- \(\Delta t\): elapsed time.

This models gradual loss of activation.

To preserve important information, introduce rehearsal or recurrent refresh:

\[
A_i(t+\Delta t)=
A_i(t)e^{-\Delta t/\tau_i}
+\alpha R_i(t)
\]

Where \(R_i(t)\) represents the refresh signal.

The refresh signal may depend on relevance and attention.

\[
R_i =
Attention_i \times Relevance_i
\]

These equations describe possible computational mechanisms, not an established universal biological decay law.

**Biological interpretation**

Recurrent neural activity, attentional prioritization and potentially temporary changes in synaptic efficacy can support the maintenance of information.

The exact neural mechanisms of working-memory maintenance remain an active research question.

### Operation 5 — Prioritize important information

Not everything can be maintained with equal strength.

The system must identify which information is essential for current comprehension.

For example, while interpreting a sentence, an unresolved subject-verb relationship may be more important than retaining an incidental descriptive word.

A priority function could be:

\[
P_i =
w_1R_i+
w_2D_i+
w_3C_i+
w_4G_i
\]

Where:

- \(R_i\): relevance to current interpretation.
- \(D_i\): dependency importance.
- \(C_i\): contextual importance.
- \(G_i\): relevance to current goals.

Information with higher priority receives more maintenance and retrieval resources.

**Biological interpretation**

Attentional selection and prefrontal control help preserve task-relevant information while reducing interference from irrelevant information.

### Operation 6 — Retrieve information from working memory

When a new word arrives, the system may need to retrieve information encountered several words earlier.

For example:

"The book that the editor praised was expensive."

When processing "praised", the brain needs to retrieve "book" as the potential object of the verb.

**Possible mathematical operations**

Calculate retrieval strength:

\[
S_i =
A_i+
\sum_k w_k M_{ik}
-\lambda d_i
-\mu I_i
\]

Where:

- \(A_i\): current memory activation.
- \(M_{ik}\): match between retrieval cue \(k\) and memory item \(i\).
- \(d_i\): retrieval distance.
- \(I_i\): interference from competing memory items.
- \(\lambda,\mu\): weighting factors.

Retrieval probability can then be represented as:

\[
P(i\mid cues)=
\frac{e^{S_i/T}}
{\sum_j e^{S_j/T}}
\]

This is a useful computational approach to cue-based retrieval.

**Functional operation**

After retrieving information, update the existing working-memory state.

The system must:

1. Strengthen relevant representations.
2. Remove obsolete predictions.
3. Update entity and proposition relationships.
4. Maintain unresolved dependencies.
5. Reduce irrelevant information.
6. Preserve information needed for upcoming processing.

\mathbf{B}_{t+1}=
(1-\alpha)\mathbf{B}_t+
\alpha\mathbf{B}_{new}

This is a simplified state-update equation.

Importantly, the previous state should not be completely overwritten because unfinished sentence structures and discourse information may still be necessary.

# Part 2 — Maintain incomplete syntactic structures

## 2.1 What this stage accomplishes

Language comprehension often requires maintaining grammatical relationships that cannot yet be completed.

Consider:

"The book that the editor who hired the author praised was expensive."

The sentence contains several nested relationships.

The brain must remember:

- The book is the main subject.
- The book is also the missing object of "praised".
- The editor hired the author.
- The embedded relative clause must be completed.
- The main clause still needs its predicate.

The important feature is that grammatical relationships can remain unresolved while other structures are being processed.

This creates a requirement for temporary structural memory and later retrieval.

Research supports the involvement of working-memory retrieval and argument reordering in complex syntactic comprehension, although the precise neural mechanisms are not completely settled. <Cite refs={["turn962183view4","turn658443view2"]}/>

- \(E_i\): expected completion.

It compares:

- Grammatical category.
- Expected thematic role.
- Grammatical agreement.
- Position.
- Semantic compatibility.

# Part 3 — Executive control over sentence interpretations

## 3.1 What this stage accomplishes

This is the control mechanism that supervises the interpretation process.

The brain does not simply accept every activated linguistic interpretation.

Consider:

"The cat was chased by the mouse."

There are two relevant information sources:

- Grammatical evidence indicates that the mouse is the agent.
- General knowledge might initially favor cats chasing mice.

The system must evaluate the competing evidence rather than allowing familiar expectations to automatically dominate.

Cognitive control has been proposed to send top-down signals that strengthen interpretations supported by reliable linguistic and contextual evidence. Importantly, the evidence suggests interaction between language knowledge and a distinct control mechanism. <Cite refs={["turn655059view0","turn658443view0"]}/>

## 3.2 Detailed algorithmic operations

### Operation 15 — Load the current cognitive objective

Identify the current task.

Possible objectives:

- Read the sentence.
- Understand the sentence.
- Identify its grammatical structure.
- Determine the speaker's intention.
- Answer a question about it.
- Translate it.
- Summarize it.

These tasks can require different processing priorities.

Represent the task as:

\[
G_t =
[goal_1,goal_2,\ldots,goal_n]
\]

Each goal has an associated priority.

For example:

### Operation 16 — Monitor processing conflicts

Measure the degree of competition among active representations.

Potential sources include:

- Different syntactic parses.
- Different word meanings.
- Conflicting thematic roles.
- Different discourse interpretations.
- Conflicts between literal meaning and contextual evidence.
- Conflicts between the current goal and distracting information.

One possible measure uses entropy:

\[
H(X)=-\sum_i P(x_i)\log P(x_i)
\]

Higher entropy indicates a more distributed probability across competing candidates.

Another measure uses the difference between the strongest and second-strongest interpretations:

\[
M=P(h_1)-P(h_2)
\]

A small margin can indicate substantial competition.

A conflict score could combine both:

\[
C_t =
\alpha H_t+
\beta(1-M_t)+
\gamma E_t
\]

Where \(E_t\) is prediction error.

### Operation 17 — Estimate required control strength

The control system decides whether additional executive resources are needed.

For example:

- Simple sentence: low conflict and low control demand.
- Ambiguous sentence: elevated control demand.
- Contradictory sentence: high control demand.
- Sentence with multiple nested clauses: increased maintenance and retrieval demand.

Possible mathematical operation:

\[
g_{t+1}=
\operatorname{clip}
\left(
g_t+\eta(C_t-\bar C_t),
0,1
\right)
\]

Where:

- \(g_t\): current control strength.
- \(\eta\): adaptation rate.
- \(C_t\): current conflict.
- \(\bar C_t\): expected conflict.

This models adaptive control, not an experimentally established neural equation.

### Operation 18 — Identify which information should receive executive support

This is particularly important.

Executive control cannot simply strengthen every representation simultaneously.

It must identify which evidence is relevant to the current task and which interpretation has the strongest reliable support.

A possible bias function is:

\[
B_i =
g_t \times Reliability_i \times GoalFit_i
\]

This produces a bias signal for each candidate interpretation.

The control mechanism can then enhance task-relevant representations.

### Operation 19 — Protect relevant information from interference

Suppose two interpretations are active.

The system should:

- Strengthen the interpretation with more reliable evidence.
- Reduce the relative influence of unsupported alternatives.
- Maintain alternatives when they remain plausible.
- Prevent unrelated information from dominating the active task.

One important theoretical distinction: some computational accounts model control as excitatory top-down enhancement of the supported representation, while competition and lateral inhibition between representations suppress weaker alternatives. Thus, executive control need not directly inhibit every incorrect interpretation. <Cite refs={["turn962183view3"]}/>

### Operation 20 — Coordinate different processing systems

Executive control must coordinate:

- Working-memory buffers.
- Syntactic parsing.
- Semantic interpretation.
- Discourse context.
- Attention.
- Long-term memory retrieval.

It should also ensure that one module's output does not overwrite evidence from another module.

For example, if syntactic evidence and semantic expectations disagree, the system should preserve both evidence channels until there is sufficient support for a decision.

### Operation 21 — Evaluate the consequences of the current interpretation

The control system evaluates whether the current sentence interpretation satisfies the task.

Possible criteria:

\[
Q(h)=
w_1 SyntaxFit(h)+
w_2 SemanticFit(h)+
w_3 ContextFit(h)+
w_4 GoalFit(h)
\]

A poor result may trigger additional retrieval, interpretation revision or an uncertainty signal.

# Part 4 — Resolve competing semantic interpretations

## 4.1 What this stage accomplishes

This stage receives multiple possible meanings and determines which meaning is best supported.

It is closely connected to the previous stage, but its responsibility is different.

- Executive control determines how processing resources should be allocated.
- Semantic resolution evaluates and settles the competing interpretations using available evidence.

Consider:

"I saw the man with the telescope."

Possible interpretations:

1. I used a telescope to see the man.
2. The man had a telescope.

The system must maintain the competing analyses until sufficient contextual or grammatical evidence becomes available.

Research on ambiguity processing describes the involvement of working memory, inferior frontal regions, insular systems and basal ganglia, although precise functional assignments remain debated. <Cite refs={["turn658443view2","turn655059view0"]}/>

## 4.2 Detailed algorithmic operations

### Operation 22 — Generate semantic interpretation candidates

Receive the candidate meanings from lexical, syntactic and semantic composition.

Generate separate interpretation records.

Each candidate needs:

- Candidate identifier.
- Predicate-argument structure.
- Entity relationships.
- Word-sense decisions.
- Syntactic support.
- Contextual support.
- Confidence.
- Unresolved assumptions.

### Operation 23 — Collect evidence for each candidate

Retrieve evidence from different systems.

| Evidence source | Information |
|---|---|
| Lexical | Word meanings and grammatical categories |
| Syntactic | Phrase attachment and grammatical relationships |
| Semantic | Argument compatibility and event meaning |
| Contextual | Previously established discourse information |
| Episodic | Relevant previous experiences |
| World knowledge | Known event and entity relationships |
| Task | What the current comprehension objective requires |

### Operation 24 — Calculate candidate scores

Combine evidence using weighted scoring.

\[
S(h_i)=
w_lL_i+
w_sS_i+
w_mM_i+
w_cC_i+
w_eE_i+
w_gG_i
\]

Where:

- \(L_i\): lexical fit.
- \(S_i\): syntactic fit.
- \(M_i\): semantic fit.
- \(C_i\): contextual fit.
- \(E_i\): episodic or experiential fit.
- \(G_i\): task-goal fit.

The individual channels should remain observable.

This is important because a high overall score might otherwise hide the fact that one candidate is supported by syntax but contradicted by context.

### Operation 25 — Calculate probability distributions over interpretations

Convert candidate scores into a normalized distribution.

\[
P(h_i)=
\frac{\exp(S(h_i)/T)}
{\sum_j\exp(S(h_j)/T)}
\]

The temperature \(T\) controls how concentrated or distributed the alternatives are.

A low temperature produces stronger competition around the highest-scoring interpretation.

A high temperature allows a more distributed representation.

These probabilities are model quantities, not calibrated probabilities of what a human brain believes.

### Operation 26 — Perform competitive activation

The competing interpretations can interact recurrently.

A computational model can represent the activation of each hypothesis using:

\[
a_i^{t+1} =
f\left(
I_i+
\sum_j W_{ij}a_j^t+
B_i-
\lambda a_i^t
\right)
\]

Where:

- \(I_i\): bottom-up input.
- \(W_{ij}\): connections between candidate representations.
- \(B_i\): executive bias.
- \(\lambda\): decay.
- \(f\): activation function.

For mutually exclusive interpretations, connections between candidates can represent competition through negative effective interaction.

The strongest supported interpretation may gradually become dominant.

However, the brain can maintain more than one interpretation. Competition does not always mean immediate elimination of alternatives.

### Operation 27 — Integrate contextual evidence

Evaluate whether each candidate is compatible with the previously established meaning.

For example:

"The telescope was broken. I saw the man with the telescope."

The preceding sentence can make the instrument interpretation less plausible, depending on the context.

Calculate contextual compatibility:

\[
C_i =
Similarity(
ContextFeatures,
CandidateFeatures_i
)
\]

Then update:

\[
S_i' = S_i + \lambda_c C_i
\]

The same procedure can incorporate discourse and situation-model information.

### Operation 28 — Evaluate semantic prediction errors

Compare the expected interpretation with newly arriving information.

\[
\delta_i =
ActualEvidence_i-ExpectedEvidence_i
\]

Large prediction errors can indicate that the current semantic interpretation needs revision.

Possible consequences:

- Retrieve another lexical meaning.
- Reconsider a syntactic attachment.
- Change a thematic role.
- Reinterpret a pronoun.
- Revise a previously constructed proposition.

### Operation 29 — Select, preserve or revise the interpretation

A selection mechanism can use two criteria:

**Confidence:**

\[
P(h_1)>\theta_c
\]

**Margin:**

\[
P(h_1)-P(h_2)>\theta_m
\]

Where:

- \(h_1\): strongest candidate.
- \(h_2\): second strongest candidate.
- \(\theta_c\): minimum confidence threshold.
- \(\theta_m\): minimum separation threshold.

Three outcomes are possible:

<box border radius="lg" padding={3} gap={3}>
  <row align="center" gap={2}>
    <badge color="success">Outcome A</badge>
    **Select**
  </row>
  The strongest interpretation has sufficient support. Send it to the proposition and discourse systems.
  <divider color="subtle"/>
  <row align="center" gap={2}>
    <badge color="warning">Outcome B</badge>
    **Preserve alternatives**
  </row>
  Two or more interpretations remain plausible. Maintain them for future evidence.
  <divider color="subtle"/>
  <row align="center" gap={2}>
    <badge color="danger">Outcome C</badge>
    **Reanalyze**
  </row>
  New evidence conflicts with the current interpretation. Reopen the relevant syntactic or semantic processing structures.
</box>

### Operation 30 — Consolidate the selected interpretation

When an interpretation becomes sufficiently reliable:

1. Update the semantic working-memory representation.
2. Update the relevant proposition.
3. Resolve the corresponding syntactic dependencies.
4. Update discourse entities and relationships.
5. Preserve provenance and confidence.
6. Release memory resources that are no longer necessary.

The system should retain unresolved alternatives when the available evidence is insufficient.

# Part 5 — Cognitive task switching

## 5.1 What this stage accomplishes

This stage enables the brain to move between different cognitive activities.

For example, while reading a sentence, a person may suddenly need to:

- Answer a question.
- Recall an earlier statement.
- Identify a grammatical error.
- Translate a word.
- Follow an instruction.
- Return to the original sentence.

The system must change its active processing objective without unnecessarily destroying previous information.

A task set is a representation of the current goal and associated processing rules.

Importantly, cognitive stability (protecting the current task) and cognitive flexibility (being able to switch tasks) should not be treated as a single opposing control variable. Research supports partly independent mechanisms for these functions. <Cite refs={["turn655059view1","turn658443view1"]}/>

## 5.2 Detailed algorithmic operations

### Operation 31 — Maintain the current task representation

Create a representation of the current task.

For example:

Mathematically:

\[
T_t =
[G_t,R_t,A_t,P_t]
\]

Where:

- \(G_t\): goals.
- \(R_t\): processing rules.
- \(A_t\): active modules.
- \(P_t\): priority.

### Operation 32 — Detect task-changing signals

A switching trigger may originate from:

- External instruction.
- Unexpected stimulus.
- New conversational requirement.
- Internal goal completion.
- Conflict in the current task.
- Memory retrieval.
- A newly important event.

The system evaluates the incoming signal and determines whether the current task should continue.

A switching-evidence function could be:

\[
D_t =
w_1CueStrength+
w_2GoalChange+
w_3Urgency+
w_4RewardChange
\]

### Operation 33 — Evaluate whether switching is necessary

Compare the expected utility of continuing with the expected utility of switching.

\[
\Delta U =
U_{new}-U_{current}-C_{switch}
\]

Where:

- \(U_{new}\): expected value of the new task.
- \(U_{current}\): expected value of continuing.
- \(C_{switch}\): cost of switching.

A possible switching probability is:

\[
P(switch)=
\frac{1}{1+\exp(-\Delta U/T_g)}
\]

This provides a decision model rather than a claim that the brain explicitly calculates utility in this form.

### Operation 34 — Retrieve the new task set

If the switching decision is accepted, retrieve the relevant task representation.

For example:

The task can be retrieved using contextual cues and previous experience.

### Operation 35 — Open the working-memory updating gate

The system must allow new task information into active working memory.

An important proposed neural mechanism involves interactions between:

- Lateral prefrontal cortex.
- Basal ganglia.
- Thalamocortical circuits.

The basal ganglia are implicated in selective gating of working-memory updates, while prefrontal systems are associated with maintaining task rules and goals. <Cite refs={["turn658443view1"]}/>

A simplified mathematical gating operation:

\[
z_t =
\sigma(W_gX_t-\theta_g)
\]

Where:

- \(z_t\): gate activation.
- \(X_t\): task-changing evidence.
- \(W_g\): gating weights.
- \(\theta_g\): switching threshold.

The system then updates the task state:

\[
T_{active}' =
(1-z_t)T_{old}+z_tT_{new}
\]

This is a simplified continuous representation of a selective update.

### Operation 36 — Preserve unfinished cognitive work

This operation is especially important for language processing.

Suppose someone is halfway through understanding:

"The scientist who discovered..."

A phone rings, and the person answers it.

The unfinished sentence should not necessarily be erased.

The system can retain:

The task-switching system changes the active task while leaving selected memory representations available for later retrieval.

### Operation 37 — Reconfigure processing priorities

After switching, the system changes resource allocation.

For example:

Before switching:

\[
R_{syntax}=0.35
\]

\[
R_{semantic}=0.35
\]

\[
R_{discourse}=0.20
\]

\[
R_{response}=0.10
\]

After switching to answering a question:

\[
R_{syntax}=0.10
\]

\[
R_{semantic}=0.30
\]

\[
R_{discourse}=0.35
\]

\[
R_{response}=0.25
\]

These numbers are illustrative resource-allocation values.

A normalized allocation can be expressed as:

\[
R_i =
\frac{e^{s_i}}
{\sum_j e^{s_j}}
\]

### Operation 38 — Re-establish the previous task when appropriate

When the new task finishes:

1. Retrieve the suspended task representation.
2. Restore its active goal.
3. Retrieve the unfinished linguistic structures.
4. Refresh relevant memory items.
5. Continue processing from the last reliable state.

This avoids restarting sentence comprehension from the beginning.

### Operation 39 — Learn from previous switching demands

The brain can adapt its readiness to switch tasks based on previous experience.

A simple learning model:

\[
G_{t+1}=G_t+\eta(\delta_t)
\]

Where:

- \(G_t\): current switching-readiness parameter.
- \(\eta\): learning rate.
- \(\delta_t\): difference between expected and observed switching demands.

Research also discusses recency-based adaptation and episodic reinstatement of previously learned task contexts. <Cite refs={["turn655059view1"]}/>

# Part 6 — Integrating all five stages into one algorithm

Now we can connect the five systems.

The important architectural principle is that working memory is not merely storage. It provides the shared temporary state upon which syntactic processing, semantic interpretation and cognitive control operate.

## 6.1 Integrated processing algorithm

<CodeBlock language="python" editable>
# ORE: Working Memory and Cognitive Control
#
# Conceptual neurocomputational pseudocode.
# This is an architectural specification, not a biological simulation.

def working_memory_and_cognitive_control(input_stream, task_context):

    # 1. Initialize the cognitive state.
    state = initialize_working_memory(
        phonological_buffer=True,
        lexical_buffer=True,
        syntactic_buffer=True,
        semantic_buffer=True,
        discourse_buffer=True,
        executive_buffer=True
    )

    state.active_task = task_context
    state.pending_dependencies = []
    state.semantic_candidates = []
    state.suspended_tasks = []

    while input_stream.has_next():

        # 2. Receive and encode new linguistic information.
        item = input_stream.next()
        representation = encode_linguistic_information(item)

        # 3. Update working-memory representations.
        state = maintain_and_refresh_buffers(
            state,
            representation
        )

        # 4. Detect unfinished syntactic structures.
        pending = detect_incomplete_dependencies(
            state
        )

        # 5. Update syntactic working memory.
        state.pending_dependencies = update_dependencies(
            pending,
            representation
        )

        # 6. Retrieve relevant previous grammatical elements.
        retrieved = cue_based_dependency_retrieval(
            state.pending_dependencies,
            representation
        )

        # 7. Update the current syntactic structure.
        syntax = integrate_retrieved_dependencies(
            state,
            retrieved,
            representation
        )

        # 8. Generate candidate semantic interpretations.
        candidates = generate_semantic_candidates(
            syntax,
            state.semantic_buffer,
            state.discourse_buffer
        )

        # 9. Measure competing activation and uncertainty.
        conflict = calculate_interpretation_conflict(
            candidates
        )

        # 10. Estimate executive control demand.
        control = estimate_control_strength(
            conflict,
            state.active_task,
            state
        )

        # 11. Apply top-down control.
        candidates = apply_executive_bias(
            candidates,
            control
        )

        # 12. Compare semantic alternatives.
        candidates = evaluate_semantic_evidence(
            candidates,
            state
        )

        # 13. Perform recurrent competition.
        candidates = settle_competing_interpretations(
            candidates,
            control
        )

        # 14. Select or preserve interpretations.
        decision = select_or_preserve_alternatives(
            candidates
        )

        # 15. Update semantic and discourse working memory.
        state = update_semantic_and_discourse_state(
            state,
            decision
        )

        # 16. Detect task-switching signals.
        switch_signal = detect_task_change(
            item,
            state.active_task
        )

        # 17. Evaluate task-switching necessity.
        if evaluate_switch_requirement(
            switch_signal,
            state
        ):

            # 18. Preserve unfinished processing.
            state = suspend_current_task(state)

            # 19. Retrieve the new task set.
            new_task = retrieve_new_task_set(
                switch_signal,
                state
            )

            # 20. Gate the new task into working memory.
            state = selectively_update_task_state(
                state,
                new_task
            )

            # 21. Reconfigure cognitive resource allocation.
            state = reallocate_processing_resources(
                state,
                new_task
            )

        # 22. Re-evaluate working-memory priorities.
        state = update_memory_priorities(state)

        # 23. Refresh task-relevant information.
        state = refresh_relevant_representations(state)

        # 24. Detect and correct prediction errors.
        state = revise_inconsistent_representations(state)

        # 25. Release information no longer needed.
        state = release_obsolete_memory_items(state)

    # 26. Finalize the current interpretation.
    result = finalize_cognitive_representation(state)

    return result
</CodeBlock>

# Part 8 — The most important architectural principles for ORE

There are five principles I would strongly recommend preserving when this algorithm is eventually implemented in Python.

**1. Working memory must preserve separate information channels.**

Do not merge phonological, lexical, syntactic, semantic and executive information into one undifferentiated vector. Keep their representations and relationships separately accessible.

**2. Incomplete structures must remain retrievable.**

An unfinished grammatical relationship is not a failed interpretation. It is a legitimate pending state that may be completed by future input.

**3. Executive control must supervise rather than replace linguistic knowledge.**

The control system should adjust which information receives priority. It should not invent sentence meanings independently of the lexical, syntactic and semantic systems.

**4. Semantic competition must preserve uncertainty.**

The algorithm should be capable of retaining two or more interpretations rather than always forcing an immediate decision.

**5. Task switching must not destroy unfinished processing.**

Suspended tasks should retain their relevant working-memory representations and resume from an appropriate previous state.
