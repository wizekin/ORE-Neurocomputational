### What was implemented

| Stage | Main implementation |
|---|---|
| 1. Stored word identity | Lexical lookup, orthographic similarity, frequency priors and identity probabilities |
| 2. Word meaning | Meaning retrieval, semantic feature vectors, contextual compatibility and sense competition |
| 3. Grammatical category | Lexical category retrieval, syntactic priors and category probabilities |
| 4. Morphological decomposition | Prefix/stem/suffix boundary hypotheses and exact reconstruction |
| 5. Stems and affixes | Component retrieval, frequency, productivity and semantic feature composition |
| 6. Morphological alternatives | Alternative scoring, posterior probabilities, confidence and ambiguity handling |
| 7. Incremental lexical activation | Character-by-character evidence, recurrent excitation, lateral inhibition and top-down feedback |

### Biological implementation
