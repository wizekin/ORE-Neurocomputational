# ORE Neurocomputational Development Roadmap
## Phase N2 — Biological Visual Processing
<badge color="success">Algorithm specification drafted</badge> <badge color="info">Design phase — not yet implemented</badge>

## 1. Purpose of N2

N1 established a computational approximation of early visual processing: light adaptation, retinal ON/OFF pathways, center-surround filtering, LGN-like contrast processing, V1-like orientation responses, simple- and complex-cell responses, normalization, pooling and feature-vector construction.

N2 should take those early visual signals and transform them into **organized visual structures**.

In other words:

- N1 asks: *What visual signals and local features are present?*
- N2 asks: *How do those features belong together, what contours and shapes do they form, and which parts constitute a coherent visual object?*

This transition is consistent with the biological visual hierarchy. Responses generally become more complex and selective as information passes through successive cortical areas. The ventral visual pathway includes V2, V4 and inferior temporal cortex, while the dorsal pathway has important roles in spatial information, motion and visually guided action. These pathways also exchange information through feedback connections; they are not simply two independent pipelines. <Cite refs={["turn911244view0","turn561511view2","turn269897search4"]}/>

For ORE, the primary target is the visual structure of written characters and other visual forms. N2 should not yet attempt to understand words, assign meanings, or use linguistic knowledge to correct visual evidence.

# 2. Input and output definitions

Before defining the steps, we need to specify exactly what N2 receives and what it must preserve.

## 2.1 Input from N1

Let the N1 output be a spatially organized feature tensor:

\[
F_1(x,y,\theta,s,p)
\]

Where:

- \(x,y\): position in the visual image.
- \(\theta\): orientation preference.
- \(s\): spatial scale or wavelength.
- \(p\): feature channel, such as quadrature energy or ON/OFF-related activity.

A simplified representation might be:

\[
F_1 \in \mathbb{R}^{H\times W\times O\times S\times C}
\]

N2 should receive these spatial maps, not only a flattened feature vector.

**This is an important integration requirement for the existing N1 implementation.**

N1 includes spatial pooling and final feature-vector construction. However, if we give N2 only that final vector, we lose much of the spatial arrangement necessary for contour integration and shape construction.

Therefore:

1. Preserve the N1 intermediate spatial feature maps.
2. Pass those maps to N2 before destructive spatial flattening.
3. Retain N1's final feature vector as an additional input or diagnostic.
4. Never reconstruct missing spatial information by guessing from the vector.

## 2.2 Expected N2 output

Define:

\[
Z_2 = N2(F_1)
\]

The result should contain:

| Output | Meaning |
|---|---|
| Multiscale maps | Features integrated across different spatial areas |
| Contour map | Connected and partially completed contours |
| Boundary map | Likely object or region boundaries |
| Border ownership | Which side of a boundary belongs to a figure |
| Segmentation hypotheses | Possible figure-ground arrangements |
| Junction features | Corners, endpoints, crossings and intersections |
| Curvature features | Straight, curved, concave and convex shape information |
| Shape graph | Parts and their spatial relationships |
| Ventral representation | Integrated visual form features |
| Dorsal representation | Location and optional motion information |
| Uncertainty | Confidence and unresolved visual ambiguity |

N2 should produce a visual representation, not force a final character identity.

# 3. The complete N2 algorithm

I propose dividing N2 into 17 algorithmic steps.

## N2-01 — Establish the spatial coordinate system

**Biological motivation**

Visual information is organized according to where stimulation occurs in the visual field. This organization is called retinotopy.

A neuron has a receptive field: a region of visual space where stimulation influences its activity. Receptive fields and their properties change across the visual hierarchy. <Cite refs={["turn561511view2","turn911244view4"]}/>

**Algorithm**

1. Receive N1 feature maps.
2. Obtain the image coordinate system.
3. Record the center position of each detected feature.
4. Establish an optional fixation point.
5. Calculate the distance of each position from the fixation point.
6. Preserve the original coordinates alongside any transformed coordinates.

For feature position \(i\):

\[
\mathbf r_i=(x_i,y_i)
\]

If the fixation point is:

\[
\mathbf r_f=(x_f,y_f)
\]

Then eccentricity is:

\[
e_i=\|\mathbf r_i-\mathbf r_f\|_2
\]

This represents the distance from the fixation point.

An optional cortical magnification approximation is:

\[
u_i=k\log\left(1+\frac{e_i}{e_0}\right)
\]

where \(k\) and \(e_0\) are configurable parameters.

This logarithmic transformation is a possible computational representation of nonuniform spatial mapping. It is not a claim that all cortical coordinates follow this exact equation.

**Output**

A spatial map containing:

- Original image coordinates.
- Relative position coordinates.
- Optional fixation-relative eccentricity.
- Optional transformed cortical-like coordinates.

---

## N2-02 — Build multiscale receptive-field representations

<badge color="info">V1 → V2-inspired</badge>

**Biological motivation**

As visual processing progresses through cortical areas, receptive fields generally become larger and responses integrate information from broader portions of the image.

This allows later stages to respond to combinations of local features rather than isolated edges. <Cite refs={["turn911244view4","turn269897search11"]}/>

**Algorithm**

For every orientation channel, construct several spatial integration scales.

For example:

- Small receptive fields: local features.
- Medium receptive fields: combinations of nearby contours.
- Large receptive fields: larger shapes and configurations.

Let the initial activity be \(F_1\).

For each scale \(s\):

\[
R_s(x,y,\theta)=
\sum_{u,v}
G_s(u,v)F_1(x+u,y+v,\theta)
\]

Here, \(G_s\) is a spatial integration kernel, such as a Gaussian.

A Gaussian kernel is:

\[
G_s(u,v)=
\frac{1}{2\pi\sigma_s^2}
\exp\left(
-\frac{u^2+v^2}{2\sigma_s^2}
\right)
\]

The parameter \(\sigma_s\) determines the spatial extent.

**What this accomplishes**

A small local edge response can contribute to a larger spatial pattern.

For example, the separate edges of a letter may begin to contribute to a representation of the entire letter shape.

**Important distinction:** N2 should preserve the different scales separately. Immediately averaging all scales would discard potentially useful information.

---

## N2-03 — Integrate locally aligned contours

<badge color="info">Contour integration</badge>

**Biological motivation**

Visual perception does not treat every detected edge as an unrelated element. Nearby contours with compatible orientations and trajectories tend to be grouped.

The visual system can integrate locally detected contour elements into larger continuous contours.

**Algorithm**

1. Detect local oriented feature elements.
2. Find nearby elements.
3. Calculate their orientation differences.
4. Estimate how well their positions and orientations support a continuous contour.
5. Increase their mutual association when the evidence is compatible.
6. Preserve competing contour hypotheses when the evidence is ambiguous.

Let feature elements \(i\) and \(j\) have orientations \(\theta_i\) and \(\theta_j\).

Their orientation difference, accounting for the fact that an undirected contour has period \(\pi\), is:

\[
\Delta\theta_{ij}
=
\min(
|\theta_i-\theta_j|,
\pi-|\theta_i-\theta_j|
)
\]

Let \(d_{ij}\) denote their spatial separation.

A possible association strength is:

\[
g_{ij}=
\exp\left(-\frac{d_{ij}^2}{2\sigma_d^2}\right)
\exp\left(-\frac{\Delta\theta_{ij}^2}{2\sigma_\theta^2}\right)
\]

We can add a curvature compatibility term:

\[
g_{ij}^{*}
=
g_{ij}
\exp\left(
-\frac{(\kappa_i-\kappa_j)^2}{2\sigma_\kappa^2}
\right)
\]

Here, \(\kappa_i,\kappa_j\) are local curvature estimates.

The resulting contour activity can be:

\[
C_i=
\operatorname{ReLU}
\left(
a_i+
\lambda\sum_j g_{ij}^{*}a_j-b
\right)
\]

Where:

- \(a_i\): original feature activity.
- \(\lambda\): integration strength.
- \(b\): activation threshold.

**Output**

A more organized contour activity map.

This step is essential for recognizing shapes whose components are separated by small gaps, noise or imperfect imaging.

---

## N2-04 — Detect boundaries from multiple visual cues

**Biological motivation**

An object boundary is not necessarily identical to a simple luminance edge.

The visual system can use combinations of visual information, including:

- Differences in brightness.
- Differences in texture.
- Differences in color.
- Contour continuity.
- Spatial configuration.

V2 and later areas show processing of contours defined by more than simple luminance differences. <Cite refs={["turn331957search4","turn331957search5"]}/>

**Algorithm**

Construct separate evidence maps.

\[
B_L(x,y)=\text{luminance boundary evidence}
\]

\[
B_T(x,y)=\text{texture boundary evidence}
\]

\[
B_C(x,y)=\text{contour continuity evidence}
\]

An optional color channel can be added later:

\[
B_{color}(x,y)=\text{color boundary evidence}
\]

Combine them:

\[
B(x,y)=
w_LB_L+
w_TB_T+
w_CB_C+
w_{color}B_{color}
\]

The weights should be configurable.

For the first ORE implementation, grayscale and contour cues should be sufficient. Color should remain optional.

**Output**

A boundary probability map:

\[
B(x,y)\in[0,1]
\]

This map represents the estimated likelihood that a location belongs to a visual boundary.

---

## N2-05 — Complete interrupted and illusory contours

**Biological motivation**

The visual system can sometimes perceive a continuous shape even when some of its edges are not physically drawn.

This is associated with illusory contours and contour completion. V2 neurons have been found to respond to contours implied by surrounding visual configurations. <Cite refs={["turn331957search4","turn331957search9"]}/>

**Algorithm**

1. Detect contour endpoints.
2. Determine the orientation of each endpoint.
3. Search for compatible endpoints nearby.
4. Estimate whether joining them would produce a geometrically plausible contour.
5. Calculate a closure score.
6. Create a candidate completed contour if its score is sufficiently high.
7. Retain a distinction between observed and inferred contour segments.

For two endpoints \(i,j\):

\[
S_{ij}=
\exp\left(-\frac{d_{ij}^2}{2\sigma_d^2}\right)
\exp\left(-\frac{\Delta\theta_{ij}^2}{2\sigma_\theta^2}\right)
\]

A further curvature-consistency penalty can be applied.

**Important requirement**

ORE must not treat an inferred edge as if it were directly observed.

Every contour segment should have a provenance label:

- `OBSERVED`
- `INFERRED`
- `UNCERTAIN`

This distinction will later help prevent the model from hallucinating missing parts of a character.

---

## N2-06 — Determine border ownership

<badge color="info">V2-inspired computation</badge>

**Biological motivation**

When two regions meet at a boundary, the visual system must determine which side of that boundary belongs to the figure.

This is called border ownership.

Research has found neurons in V2 that respond selectively to the side of an edge assigned to a figure. Their responses can incorporate global contour configuration and other visual cues. <Cite refs={["turn331957search5","turn331957search9"]}/>

**Algorithm**

For each boundary, calculate two competing hypotheses:

- The left side belongs to the figure.
- The right side belongs to the figure.

Construct evidence vectors:

\[
\Phi_L=
[
\text{closure},
\text{contour continuity},
\text{junction evidence},
\text{region properties}
]
\]

\[
\Phi_R=
[
\text{closure},
\text{contour continuity},
\text{junction evidence},
\text{region properties}
]
\]

Calculate:

\[
s_L=\mathbf w_L^\top\Phi_L
\]

\[
s_R=\mathbf w_R^\top\Phi_R
\]

Convert these into probabilities:

\[
P(L)=
\frac{e^{s_L}}
{e^{s_L}+e^{s_R}}
\]

\[
P(R)=1-P(L)
\]

A tie should be retained when the evidence is insufficient.

**Output**

A boundary ownership representation:

\[
O(x,y,\theta)=
[P(L),P(R),P(Unknown)]
\]

The model must not always choose a winner.

## N2-07 — Separate figure from background

**Biological motivation**

Visual perception requires more than detecting boundaries. It must also organize the visual field into regions that belong together.

Figure-ground segregation combines boundary information and region-level organization. <Cite refs={["turn269897search6","turn331957search5"]}/>

**Algorithm**

1. Begin with the boundary probability map.
2. Identify candidate regions.
3. Estimate the likelihood that neighboring pixels belong to the same region.
4. Use border ownership to constrain region assignment.
5. Produce one or more figure-ground segmentation hypotheses.
6. Preserve uncertainty around ambiguous boundaries.

One mathematical representation is an energy function:

\[
E(z)=
\sum_p U_p(z_p)
+
\lambda
\sum_{(p,q)}
w_{pq}[z_p\neq z_q]
\]

Where:

- \(z_p\): label assigned to pixel or region element \(p\).
- \(U_p\): cost of assigning that label.
- \(w_{pq}\): compatibility between adjacent elements.
- \([z_p\neq z_q]\): one if the labels differ, otherwise zero.
- \(\lambda\): grouping strength.

A possible pairwise weight is:

\[
w_{pq}=
\exp\left(
-\frac{\|f_p-f_q\|^2}{\sigma^2}
\right)
\]

where \(f_p\) and \(f_q\) are local visual feature vectors.

This encourages visually compatible neighboring regions to share a label, while allowing strong boundaries to separate them.

An implementation could solve this with graph cuts, mean-field inference or another suitable optimization method.

**Output**

One or more segmentation hypotheses:

\[
S_1,S_2,\ldots,S_n
\]

For ORE, these may represent different possible interpretations of a character's foreground and background.

---

## N2-08 — Extract corners, junctions and geometric discontinuities

**Biological motivation**

A visual shape is not adequately described by its orientation histogram alone.

The relationships between edges are also important. The locations where contours terminate, intersect, turn or change curvature contain useful information about shape.

**Algorithm**

Detect:

- Line endpoints.
- Corners.
- T-junctions.
- L-junctions.
- X-junctions.
- Y-junctions.
- Curvature maxima and minima.
- Closed contour connections.

For a continuous contour parameterized by arc length \(s\), orientation is \(\theta(s)\).

Curvature is:

\[
\kappa(s)=\frac{d\theta(s)}{ds}
\]

A sharp change in orientation over a short distance can indicate a corner.

A discrete approximation is:

\[
\kappa_i\approx
\frac{\theta_{i+1}-\theta_i}
{\Delta s}
\]

Junction classification can be performed using local combinations of orientation, position and edge continuity:

\[
J_i=f(
\theta_1,\theta_2,\ldots,
\kappa_1,\kappa_2,\ldots,
\text{local geometry}
)
\]

**Output**

A collection of geometric landmarks with:

- Coordinates.
- Type.
- Orientation.
- Curvature.
- Confidence.
- Source contour references.

These features will later help ORE distinguish characters with similar local edges but different overall structures.

## N2-09 — Construct intermediate shape fragments

<badge color="info">V4-inspired computation</badge>

**Biological motivation**

In the ventral visual pathway, area V4 contributes to the representation of more complex shape properties. Research has described responses to contour angles and curvature combinations, including sensitivity to the placement of curvature within a shape. <Cite refs={["turn331957search4","turn269897search4"]}/>

**Algorithm**

Combine the outputs of N2-08 and N2-03.

Instead of representing an image only through local edges, construct shape fragments such as:

- Straight segments.
- Curved segments.
- Concave boundaries.
- Convex boundaries.
- Corners at different angles.
- Enclosed loops.
- Intersecting strokes.
- Connected and disconnected components.

For every shape-fragment detector \(k\):

\[
a_k=
\operatorname{ReLU}
(\mathbf w_k^\top\mathbf f+b_k)
\]

Where \(\mathbf f\) is the local geometric feature vector.

A spatial pooling operation can then be applied within a limited receptive field:

\[
a_k^{pool}=
\max_{r\in\mathcal R}a_k(r)
\]

Alternatively, use soft pooling:

\[
a_k^{soft}=
\tau\log
\sum_{r\in\mathcal R}
\exp\left(\frac{a_k(r)}{\tau}\right)
\]

The parameter \(\tau\) controls how closely the soft pooling resembles maximum pooling.

**Output**

A shape-fragment representation:

\[
P=
[p_1,p_2,\ldots,p_m]
\]

Each feature records a possible shape component and its evidence.

---

## N2-10 — Build structural relationships between shape fragments

**Biological motivation**

Recognizing a visual form requires combining parts into a coherent configuration.

Two characters may contain similar fragments but differ in the spatial arrangement of those fragments.

**Algorithm**

Represent the image as a graph:

\[
G=(V,E)
\]

Where:

- \(V\): detected shape fragments.
- \(E\): relationships between fragments.

Each node can contain:

\[
v_i=
[
type_i,
x_i,
y_i,
\theta_i,
\kappa_i,
scale_i,
confidence_i
]
\]

Each relationship can contain:

\[
e_{ij}=
[
\Delta x_{ij},
\Delta y_{ij},
\Delta\theta_{ij},
d_{ij},
connectivity_{ij}
]
\]

For example, the model can distinguish:

- Two lines that cross.
- Two lines that merely approach each other.
- A line that touches a curve.
- A line that passes through a closed region.
- A component located above another component.

This is especially useful in scripts where small differences in the arrangement of strokes can change character identity.

**Possible additional mathematical descriptors**

For binary or segmented shapes, ORE could calculate:

- Number of connected components.
- Number of enclosed holes.
- Skeleton branch count.
- Relative position of connected components.

For example, the Euler characteristic is:

\[
\chi=\beta_0-\beta_1
\]

where \(\beta_0\) is the number of connected components and \(\beta_1\) is the number of holes.

These are useful engineering descriptors. We should not claim that the brain explicitly calculates Betti numbers or Euler characteristics.

**Output**

A graph-based visual structure that preserves the relationships between parts.

---

## N2-11 — Estimate interference from neighboring visual elements (crowding)

**Biological motivation**

A character may be recognizable in isolation but difficult to recognize when surrounded by other characters, especially outside central vision.

This phenomenon is called visual crowding.

It is particularly relevant to reading because nearby letters can interfere with the correct identification and localization of one another. The critical spacing tends to increase with the target's eccentricity. <Cite refs={["turn510141search0","turn510141search7","turn510141search5"]}/>

**Algorithm**

1. Estimate the position of a target.
2. Find neighboring visual elements.
3. Calculate distances between their centers.
4. Estimate the target's eccentricity, when fixation information is available.
5. Estimate the critical spacing for interference.
6. Calculate a crowding score.
7. Increase uncertainty when neighboring elements are likely to interfere.

A useful approximation to Bouma-style spacing is:

\[
d_{critical}\approx bE+w
\]

Where:

- \(E\): target eccentricity.
- \(b\): empirical spacing coefficient, often approximately 0.4–0.5 in common formulations.
- \(w\): target width when using center-to-center distance.

This is an empirical approximation, not a universal biological constant.

For ORE, define:

\[
C_i=
\sum_{j\neq i}
sim(f_i,f_j)
\exp\left(
-\frac{d_{ij}^2}{2d_{critical}^2}
\right)
\]

Then uncertainty could be increased using:

\[
U_i'=U_i+\lambda_c C_i
\]

This does not mean the character disappears. It means its recognition evidence becomes less reliable.

**Output**

A crowding/interference map that describes how surrounding visual elements influence each target.

---

## N2-12 — Develop tolerance to position and scale changes

**Biological motivation**

Visual representations become progressively more tolerant to transformations such as position and size changes along the ventral visual pathway.

Importantly, this is not achieved by simply eliminating all spatial information. Object selectivity and tolerance can both increase. <Cite refs={["turn269897search8","turn269897search7","turn269897search4"]}/>

**Algorithm**

1. Generate representations at different spatial scales.
2. Evaluate small spatial shifts.
3. Compare the resulting shape-fragment activations.
4. Aggregate evidence across nearby transformations.
5. Preserve a separate position representation.
6. Measure whether the transformation has destroyed useful distinguishing information.

For a visual feature detector \(k\), let \(a_k(gI)\) be its response to image \(I\) under transformation \(g\).

A transformation-tolerant response can be:

\[
z_k=
\tau\log
\sum_{g\in\mathcal G}
\exp\left(\frac{a_k(gI)}{\tau}\right)
\]

Where \(\mathcal G\) contains the transformations being tested.

Small translations and moderate scale changes may initially be included.

However, the following transformations should not automatically be treated as identity-preserving:

- Mirror reversal.
- Arbitrary rotation.
- Reflection.
- Reversal of stroke order or spatial arrangement.

These can change the identity of written characters.

**Critical requirement**

ORE needs two separate signals:

\[
z_{shape}=\text{transformation-tolerant shape information}
\]

\[
z_{position}=\text{spatial position information}
\]

Do not collapse them into one representation.

This preserves useful spatial information while allowing some tolerance to normal imaging variation.

---

## N2-13 — Construct a higher-level distributed visual representation

<badge color="info">Inferotemporal cortex-inspired computation</badge>

**Biological motivation**

Inferior temporal cortex participates in representing complex visual forms and objects. Responses can be selective for complex shapes, and higher-level representations can tolerate certain changes in size and position. <Cite refs={["turn269897search3","turn911244view4","turn269897search8"]}/>

**Algorithm**

1. Collect the shape-fragment responses.
2. Collect their structural relationships.
3. Collect the multiscale contour representation.
4. Combine them into a higher-dimensional feature description.
5. Activate a population of feature-selective units.
6. Preserve the pattern of population activity rather than selecting only one maximum response.

One possible population model is:

\[
r_k=
\phi\left(
\beta(
sim(z,\mu_k)-\tau_k
)
\right)
\]

Where:

- \(z\): integrated visual feature vector.
- \(\mu_k\): preferred feature configuration of unit \(k\).
- \(\tau_k\): activation threshold.
- \(\beta\): response sensitivity.
- \(\phi\): nonlinear activation function.

The overall representation is:

\[
Z_{ventral}=[r_1,r_2,\ldots,r_K]
\]

This is a computational approximation of distributed visual feature coding.

**Important distinction**

A unit in this model should not be described as an actual biological neuron with a known corresponding receptive field. It is a simulated feature-selective unit.

Also, do not make the assumption that the visual word-form area is a single isolated character-recognition module. Contemporary research describes a wider, distributed visual-word-processing network, and recent work reports individual variability in VWFA organization. <Cite refs={["turn269897search13","turn269897search5"]}/>

**Output**

A higher-level representation of the visual form that can be passed to later orthographic processing.

---

## N2-14 — Construct a parallel spatial and motion representation

<badge color="info">Dorsal pathway-inspired</badge>

**Biological motivation**

The visual system has a major spatial/action-related pathway, including MT/V5 and parietal regions.

It contributes to processing motion, position and spatial relationships, alongside the ventral pathway's important role in form and object discrimination. <Cite refs={["turn911244view0","turn331957search1"]}/>

For ORE, this should be a parallel branch rather than a mandatory stage for every static character image.

**Algorithm**

For static input, calculate:

- Shape location.
- Relative location of components.
- Spatial extent.
- Distance between visual regions.
- Position relative to the larger text region.

For a sequence of images, an optional motion branch can be enabled.

A motion-energy approximation uses spatiotemporal filters:

\[
E_d=
(I*h_{d,1})^2+
(I*h_{d,2})^2
\]

Then direction-selective activity can be estimated using opponent channels:

\[
M_d=
\max(0,E_d-E_{-d})
\]

Where \(d\) denotes one motion direction and \(-d\) its opposite.

These motion-energy models are widely used to study cortical motion computation, including V1-to-MT processing. However, measured cortical responses also show nonlinear and stimulus-dependent properties that simple motion-energy models cannot fully reproduce. <Cite refs={["turn331957search1","turn331957search2"]}/>

**Output**

Two related but separately retained representations:

\[
Z_{ventral}=\text{visual form information}
\]

\[
Z_{dorsal}=\text{spatial and optional motion information}
\]

For static written-character processing, the motion component should normally remain disabled.

---

## N2-15 — Apply bounded local recurrent refinement

**Biological motivation**

The visual cortex contains horizontal and feedback connections. Information does not travel exclusively in one direction from lower to higher areas. Higher-level visual regions can also influence earlier processing stages. <Cite refs={["turn911244view0","turn911244view1"]}/>

**Algorithm**

Use a limited recurrent loop to refine:

- Contour continuity.
- Border ownership.
- Figure-ground separation.
- Shape-part consistency.

A simplified activity equation is:

\[
A^{t+1}=
\phi(
W_{ff}F+
W_{lat}A^t+
W_{fb}H^t-
b
)
\]

Where:

- \(F\): feed-forward visual input.
- \(A^t\): current activity.
- \(H^t\): available higher-level shape information.
- \(W_{ff}\): feed-forward weights.
- \(W_{lat}\): lateral connection weights.
- \(W_{fb}\): feedback weights.
- \(b\): threshold or bias.

The procedure becomes:

1. Initialize activity from the feed-forward shape representation.
2. Calculate the support provided by connected contours.
3. Send compatible shape information to local feature maps.
4. Recalculate boundary and segmentation evidence.
5. Compare the new output with the previous output.
6. Stop when the change is sufficiently small or the iteration limit is reached.

A convergence measure is:

\[
\Delta_t=
\frac{\|A^{t+1}-A^t\|_2}
{\|A^t\|_2+\epsilon}
\]

Stop when:

\[
\Delta_t<\delta
\]

**Important architectural boundary**

This step performs local visual refinement. It should not introduce a learned lexical prior or use word meanings to change visual features.

More elaborate orthographic prediction and prediction-error inference should remain separately switchable in a later processing phase.

---

## N2-16 — Integrate the N2 representations without destroying their differences

At this point, N2 has several types of evidence.

They should be combined in a controlled way.

**Algorithm**

Create an integrated representation containing:

\[
Z_2=
[
Z_{contour},
Z_{boundary},
Z_{junction},
Z_{curvature},
Z_{shape},
Z_{position},
Z_{ventral},
Z_{dorsal}
]
\]

Not all channels need to be active in every experiment.

We can use a weighted combination for a particular downstream task:

\[
Z_{combined}=
\sum_{k=1}^{K}w_kZ_k
\]

But the original channels must remain accessible.

For example, if a candidate visual representation has high shape similarity but poor contour support, later stages should be able to see that disagreement.

**Required diagnostics**

For each processing channel, retain:

- Feature magnitude.
- Normalized activation.
- Uncertainty.
- Source map.
- Processing scale.
- Transformation settings.
- Whether the feature was observed or inferred.

This avoids creating a single opaque vector whose contents are difficult to interpret.

---

## N2-17 — Produce the final structured visual output

The final output should be a structured object rather than merely a single array.

Conceptually:

<CodeBlock language="python" editable>
N2Result = {
    "spatial_representation": ...,
    "multiscale_features": ...,
    "contour_map": ...,
    "completed_contours": ...,
    "boundary_map": ...,
    "border_ownership": ...,
    "segmentation_hypotheses": ...,
    "junction_features": ...,
    "curvature_features": ...,
    "shape_fragments": ...,
    "shape_graph": ...,
    "crowding_estimates": ...,
    "position_tolerant_features": ...,
    "ventral_representation": ...,
    "dorsal_representation": ...,
    "recurrent_history": ...,
    "uncertainty": ...,
    "diagnostics": ...
}
</CodeBlock>

The output should retain the original N1 evidence and link each N2 feature to its source.

This allows later ORE stages to examine not only what visual structure was identified, but also how the system arrived at that representation.

# 4. Master N2 algorithm

The following pseudocode combines all 17 steps into one sequence.

<CodeBlock language="python" editable>
ALGORITHM ORE_N2_BIOLOGICAL_VISUAL_PROCESSING

INPUT:
    N1 spatial feature maps
    Original image metadata
    Optional fixation coordinates
    Optional image sequence
    N2 configuration

OUTPUT:
    Structured visual representation
    Spatial and shape features
    Contour and segmentation hypotheses
    Uncertainty and diagnostics

BEGIN

    N2-01:
        Validate N1 maps.
        Preserve original spatial coordinates.
        Establish visual coordinate system.

    N2-02:
        Calculate optional fixation-relative eccentricity.
        Generate spatial coordinate representations.

    N2-03:
        Construct multiscale receptive-field maps.
        Preserve responses at all configured scales.

    N2-04:
        Detect neighboring oriented feature elements.
        Calculate position, orientation and curvature compatibility.
        Construct contour-association strengths.

    N2-05:
        Integrate compatible contour elements.
        Detect possible interrupted contours.
        Generate completed-contour hypotheses.

    N2-06:
        Construct boundary evidence maps using:
            luminance,
            texture,
            contour continuity,
            optional color.

    N2-07:
        Calculate border-ownership hypotheses.
        Preserve left-side, right-side and unknown probabilities.

    N2-08:
        Generate figure-ground segmentation hypotheses.
        Preserve uncertain region assignments.

    N2-09:
        Detect geometric landmarks:
            endpoints,
            corners,
            junctions,
            intersections,
            curvature extrema.

    N2-10:
        Construct intermediate shape fragments.
        Calculate their activations and spatial locations.

    N2-11:
        Create a graph of visual fragments.
        Calculate relationships between graph nodes.
        Preserve connectivity and topological descriptors.

    N2-12:
        Estimate neighboring-feature interference.
        Calculate crowding scores.
        Increase uncertainty where appropriate.

    N2-13:
        Generate position- and scale-tolerant descriptors.
        Preserve separate spatial-position information.
        Test invariance against discrimination.

    N2-14:
        Construct higher-level ventral visual representation.
        Preserve distributed feature activations.

    N2-15:
        Construct dorsal spatial representation.
        If temporal input exists:
            calculate motion-sensitive features.
        Otherwise:
            retain static spatial information only.

    N2-16:
        Apply bounded local recurrent refinement.
        Recalculate contour and segmentation support.
        Stop at convergence or iteration limit.

    N2-17:
        Integrate visual information.
        Preserve independent feature channels.
        Calculate uncertainty and diagnostics.
        Serialize N2Result.

RETURN N2Result

END
</CodeBlock>

# 5. The mathematical operations involved

The following table summarizes the principal computational operations in N2.

| Biological function being approximated | Mathematical operation |
|---|---|
| Receptive-field expansion | Gaussian convolution, local weighted summation |
| Spatial coordinate representation | Euclidean distance, coordinate transformation |
| Contour integration | Orientation differences, distance kernels, weighted summation |
| Contour completion | Geometric interpolation, continuity scoring |
| Boundary detection | Gradient and texture differences, feature combination |
| Border ownership | Competing evidence scores, softmax |
| Figure-ground organization | Graph optimization, pairwise potentials |
| Region filling | Diffusion or constrained propagation |
| Corner detection | Local orientation derivatives |
| Curvature detection | First and second spatial derivatives |
| Shape-fragment detection | Nonlinear feature detectors |
| Shape binding | Graph construction, relational descriptors |
| Topological analysis | Connected components and hole counting |
| Crowding | Eccentricity-dependent spatial interference |
| Transformation tolerance | Multiscale pooling and transformation aggregation |
| Visual population representation | Nonlinear tuning and distributed activation |
| Motion detection | Spatiotemporal filtering and opponent energy |
| Recurrent refinement | Iterative state updates |
| Convergence detection | Norm differences and stopping criteria |
| Evidence integration | Weighted vector combination and uncertainty propagation |

Notice that several operations are repeated in different contexts. Convolution, nonlinear activation, normalization, weighted summation and iterative updating are general computational tools that can support different neural functions.

# 6. Biological research basis

These are the scientific foundations most relevant to the proposed N2 architecture.

| Research area | What it contributes to the design |
|---|---|
| Visual cortical hierarchy | Increasing feature complexity and larger receptive fields across processing stages |
| V2 contour processing | Illusory contours and border ownership |
| V4 shape processing | Curvature and combinations of local contour information |
| Inferotemporal cortex | More complex shape-selective and transformation-tolerant visual representations |
| Figure-ground processing | Separating boundaries, regions and background |
| Visual crowding | Modeling interference between neighboring visual elements |
| Dorsal visual pathway | Spatial and motion representations |
| Recurrent cortical connections | Feedback and local refinement |

Some particularly useful references:

1. **Blumberg & Kreiman (2010), [How cortical neurons help us see: visual recognition in the human brain](https://www.jci.org/articles/view/42161).** A useful overview of the ventral/dorsal pathways, receptive fields, and recurrent visual connections. <Cite refs={["turn561511view2","turn911244view4"]}/>

2. **Nielsen & Connor (2024), [How Shape Perception Works, in Two Dimensions and Three Dimensions](https://doi.org/10.1146/annurev-vision-112823-031607).** Reviews how successive ventral-stream processing stages represent increasingly useful shape information. <Cite refs={["turn269897search4"]}/>

3. **Qiu & von der Heydt (2005), [Figure and Ground in the Visual Cortex: V2 Combines Stereoscopic Cues with Gestalt Rules](https://pmc.ncbi.nlm.nih.gov/articles/PMC1564069/).** Relevant to contour ownership and figure-ground organization. <Cite refs={["turn331957search5"]}/>

4. **Rust & DiCarlo (2010), [Selectivity and tolerance ("invariance") both increase as visual information propagates from V4 to IT](https://doi.org/10.1523/JNEUROSCI.0179-10.2010).** Relevant to transformation-tolerant visual representations. <Cite refs={["turn269897search8"]}/>

5. **Clark & Fitzgerald (2024), [Optimization in Visual Motion Estimation](https://doi.org/10.1146/annurev-vision-101623-025432).** Reviews mathematical models for motion processing and their relationships to biological circuits. <Cite refs={["turn561511view4"]}/>

6. **The Bouma law of crowding, revised and tested (2023), [The Bouma law accounts for crowding in 50 observers](https://pmc.ncbi.nlm.nih.gov/articles/PMC10408772/).** Useful for constructing eccentricity-dependent crowding experiments. <Cite refs={["turn510141search7"]}/>

# 7. N2 experimental validation

A functioning implementation is not enough. N2 needs a set of experiments that test whether every proposed mechanism actually contributes something useful.

I recommend building the following experiments.

| Experiment | Input | What should be tested |
|---|---|---|
| N2-E01: Multiscale integration | Same shape at different scales | Whether larger-scale features preserve useful structure |
| N2-E02: Contour continuity | Broken and continuous contours | Whether contour grouping improves continuity detection |
| N2-E03: Illusory contours | Shapes with missing boundaries | Whether completion produces plausible hypotheses |
| N2-E04: Border ownership | Ambiguous overlapping figures | Whether the system identifies competing figure sides |
| N2-E05: Figure-ground | Foreground/background reversals | Whether segmentation follows the evidence |
| N2-E06: Curvature discrimination | Shapes differing in curvature | Whether local curvature representations distinguish them |
| N2-E07: Junction discrimination | Similar strokes with different intersections | Whether junction structure improves differentiation |
| N2-E08: Shape graph | Shapes containing reordered components | Whether spatial relations are preserved |
| N2-E09: Crowding | Characters at varying spacing/eccentricities | Whether interference increases under crowded conditions |
| N2-E10: Transformation tolerance | Translated and scaled shapes | Whether useful invariance emerges |
| N2-E11: Identity preservation | Visually similar but distinct shapes | Whether tolerance destroys distinguishing information |
| N2-E12: Dorsal branch | Moving visual sequences | Whether motion and location features are extracted |
| N2-E13: Recurrent refinement | Ambiguous and interrupted contours | Whether local iterations improve structure without inventing unsupported evidence |

## Required numerical measurements

I recommend these metrics:

- Contour precision, recall and F1.
- Boundary detection F1.
- Segmentation intersection-over-union.
- Junction classification accuracy.
- Curvature estimation error.
- Shape retrieval accuracy.
- Transformation-tolerance measurements.
- Minimal-pair discrimination accuracy.
- Crowding sensitivity as a function of spacing and eccentricity.
- Recurrent convergence rate.
- Inferred-contour false-positive rate.
- Processing time and memory use.

**An especially important acceptance rule:** any improvement in transformation tolerance must be evaluated alongside the model's ability to distinguish similar but genuinely different shapes.

A system that recognizes more shapes across transformations because it has discarded their distinguishing details should fail that test.

# 9. What N2 will and will not accomplish

<box border radius="lg" padding={3} gap={2}>
  **N2 should accomplish**
  <list marker="bullet" gap={1}>
    <list-item>Transform early visual features into organized contours and shapes.</list-item>
    <list-item>Distinguish boundaries, regions and object parts.</list-item>
    <list-item>Represent spatial relationships between parts.</list-item>
    <list-item>Produce more stable visual representations across reasonable imaging variations.</list-item>
    <list-item>Preserve visual uncertainty and alternative interpretations.</list-item>
  </list>
  <divider color="subtle"/>
  **N2 should not yet attempt**
  <list marker="bullet" gap={1}>
    <list-item>Final orthographic or grapheme recognition.</list-item>
    <list-item>Word-level or sentence-level recognition.</list-item>
    <list-item>Phonological conversion.</list-item>
    <list-item>Semantic interpretation.</list-item>
    <list-item>Unrestricted predictive correction using learned language knowledge.</list-item>
  </list>
</box>

The distinction is important because each of these later abilities may depend on different mechanisms and should be tested independently.

## 10. Final position in the ORE development sequence

The resulting architecture would look like this:

| Phase | Main computational responsibility |
|---|---|
| N1 — Early visual processing | Extract and normalize elementary visual features |
| **N2 — Biological visual processing** | Organize features into contours, regions, shapes and spatial representations |
| Later orthographic-processing phases | Convert structured visual forms into candidate grapheme representations |
| Predictive-processing phases | Exchange higher-level predictions and lower-level error information |
| Learning/plasticity phases | Adapt representations through controlled experience |

One final scientific qualification: a successful N2 implementation would demonstrate that ORE can reproduce selected computational properties inspired by biological vision. It would not demonstrate that it reproduces the actual human visual cortex. That stronger conclusion would require independent comparisons against behavioral and neural measurements.

**My recommendation:** Treat this specification as the full N2 algorithmic blueprint. Its most important architectural decision is to preserve N1's spatially organized intermediate outputs, because contour integration, shape construction and figure-ground organization cannot be adequately implemented from a flattened feature vector alone.
