# ORE Neurocomputational Development Roadmap
## Phase N3 — Hierarchical Visual Architecture

**N3’s purpose is to transform the visual structures produced by N1 and N2 into increasingly complex, hierarchical shape representations.** Instead of treating every edge, contour, or fragment independently, N3 should progressively combine them into boundary patterns, shape parts, part relationships, and finally whole-shape representations.

The biological inspiration is the hierarchy of the primate visual system, particularly the progression from early visual areas through V2 and V4 to posterior and anterior regions of the inferior temporal cortex (IT). At successive stages, receptive fields generally cover larger regions, and neural populations can represent more complex combinations of visual features. The representation also becomes increasingly tolerant of changes in an object's position, size, and visual context. citeturn699953search2turn715200view1

The key architectural decision is that **N3 must preserve both detailed spatial information and increasingly abstract representations**. It must not discard the original positions of features merely because it has created a more invariant representation.

One important limitation: the brain does not literally execute Python-style stages or necessarily calculate the exact equations below. The equations are candidate computational models of neural operations. Some have substantial experimental support—such as divisive normalization, curvature-sensitive V4 responses, and increasing transformation tolerance along the ventral stream—while others are explicit engineering hypotheses that N3 should test. citeturn699953search0turn499662search1turn715200view1turn715200view2

## 1. Mathematical foundation and input representation

Before defining the operations, we need a common representation for all the stages.

### N3 input

N3 should receive the complete spatial N2 result, not merely a flattened feature vector.

Define the following conceptual input:

\[
\mathcal I_{N3}=
\left\{
F,B,O,S,K,P,G,V,D
\right\}
\]

Where:

| Symbol | Meaning |
|---|---|
| \(F\) | N1 orientation and normalized-energy maps |
| \(B\) | N2 completed boundary and contour evidence |
| \(O\) | Border-ownership information |
| \(S\) | Figure–ground probabilities |
| \(K\) | Curvature and junction information |
| \(P\) | Detected shape fragments |
| \(G\) | Structural shape graph |
| \(V\) | Ventral form-related feature population |
| \(D\) | Dorsal spatial-feature population |

These are conceptual names for the information N3 needs. The implementation should map them to the actual `N2Result` fields rather than assume that every field is stored under precisely these names.

The processing system will use three coordinate systems:

1. **Retinotopic coordinates:** where a feature occurs in the image.
2. **Part-relative coordinates:** where a feature occurs relative to its containing shape part.
3. **Object-relative coordinates:** where a part occurs relative to the entire candidate shape.

This is important because the visual system needs to recognize both the identity of a shape and the arrangement of its constituent features.

For example, a curved boundary is not sufficient to describe a shape. Its position relative to the rest of the shape can change its interpretation. Experiments on V4 neurons demonstrate sensitivity to boundary curvature and the position of that curvature relative to an object's center. citeturn499662search1turn499662search3

### General mathematical notation

Let:

- \(x,y\): spatial coordinates.
- \(\theta\): orientation.
- \(s\): spatial scale.
- \(l\): hierarchical processing level.
- \(i,j\): neuron-like feature populations.
- \(t\): recurrent processing iteration.

A feature activation can be represented as:

\[
h_{i}^{(l)}(x,y,s,\theta,t)
\]

It describes the activation of feature population \(i\), at hierarchical level \(l\), at a particular position, scale, orientation, and iteration.

N3 will progressively transform these activations into increasingly complex representations.

# Level A — Intermediate visual features

## N3-01 — Receive and validate the N2 visual representation

**Purpose:** Establish a reliable connection between N2's output and N3's hierarchical processing system.

N2 has already identified many local structures. N3 must not repeat the entire N1 and N2 pipeline.

Instead, it receives their outputs and prepares them for more complex processing.

**Operations:**

1. Receive the N2 result.
2. Retrieve the orientation-energy maps.
3. Retrieve multiscale information.
4. Retrieve boundaries and figure–ground evidence.
5. Retrieve shape fragments and their structural graph.
6. Retrieve the ventral and dorsal populations.
7. Preserve the association between each feature and its original spatial position.
8. Validate array dimensions and numerical values.
9. Reject missing or incompatible mandatory information.

**Possible mathematical operations**

Input validation:

\[
F \in \mathbb R^{C\times H\times W}
\]

where \(C\) is the number of orientation channels.

Numerical validation:

\[
\forall i,j,k:\quad \operatorname{isfinite}(F_{ijk})
\]

Spatial alignment:

\[
(x,y)_{N1} \longleftrightarrow (x,y)_{N2}
\]

The relationship between every N2 fragment and its corresponding location in N1 must remain available.

**Biological interpretation:** This step represents the transmission and integration of activity between connected visual cortical populations. It does not imply that the brain performs explicit software-style validation.

**Result:** A validated N3 input structure with preserved spatial provenance.

## N3-02 — Establish a multilevel receptive-field hierarchy

**Purpose:** Allow different neural populations to process different spatial extents of the same visual input.

Early visual processing is dominated by relatively localized receptive fields. As information propagates through the visual hierarchy, progressively larger regions can contribute to a neuron's response.

N3 should reproduce this principle algorithmically.

Instead of maintaining only one representation of a contour, it should create several representations at different spatial scales.

**Possible mathematical operations**

Gaussian scale-space:

\[
F_s=G_{\sigma_s}*F
\]

Where:

- \(F\) is the original feature map.
- \(G_{\sigma_s}\) is a Gaussian kernel.
- \(*\) denotes convolution.
- \(\sigma_s\) determines the spatial scale.

A larger \(\sigma_s\) produces a representation that incorporates information from a larger neighborhood.

We can define a hierarchy:

\[
F_0=F
\]

\[
F_1=D_1(G_{\sigma_1}*F_0)
\]

\[
F_2=D_2(G_{\sigma_2}*F_0)
\]

\[
F_3=D_3(G_{\sigma_3}*F_0)
\]

Here \(D_s\) is a spatial downsampling operation.

**Possible neural operations:**

- Spatial integration through converging neural inputs.
- Excitatory and inhibitory interactions.
- Receptive-field summation.
- Spatial-frequency sensitivity.
- Local and broader contextual integration.

N2 already provides multiscale processing. N3 should expand this into a hierarchy of receptive-field populations rather than simply repeat N2's scale-space calculation.

**Result:** A multiscale visual representation:

\[
\mathcal F=\{F_0,F_1,F_2,F_3,\ldots\}
\]

---

## N3-03 — Combine elementary features into more complex feature responses

**Purpose:** Detect combinations of local orientations, edges, and other elementary signals.

A single orientation-selective response describes only one component of a visual structure.

But more complex visual features can depend on several elementary responses occurring together.

For example:

- Two orientations can form a corner.
- A sequence of orientations can form a curve.
- Two approximately parallel boundaries can represent a bar.
- Several boundaries can form a contour junction.

Neurons in intermediate visual areas receive converging inputs from earlier visual populations. Recent modeling work demonstrates that combinations of V1 inputs can account for important aspects of V2 receptive-field responses. citeturn699953search2

**Possible mathematical operations**

Linear combination:

\[
u_i^{(l)}(x,y)=
\sum_j w_{ij}^{(l)}
h_j^{(l-1)}(x,y)
\]

Nonlinear activation:

\[
h_i^{(l)}(x,y)=
\max(0,u_i^{(l)}(x,y)-b_i)
\]

Where:

- \(w_{ij}\) is the connection strength.
- \(b_i\) is a threshold.
- \(h_j\) represents input feature activation.

This creates a new population that responds to a combination of earlier features.

Another possible operation is multiplicative feature conjunction:

\[
r_{ij}(x,y)=
h_i(x,y)\cdot h_j(x,y)
\]

This produces a strong response when both inputs are active.

**Biological interpretation:** Convergent synaptic inputs, nonlinear integration, thresholding, and interactions between excitation and inhibition.

**Result:** A population of more complex local visual features.

**Purpose:** Transform combinations of orientations into recognizable geometric configurations.

The system should distinguish between different ways in which boundaries meet.

For example:

These configurations are useful for describing how different contour segments are connected.

**Possible mathematical operations**

Let \(E_\theta(x,y)\) denote the activation of the orientation channel \(\theta\).

A two-orientation conjunction could be:

\[
J_{\theta_1,\theta_2}(x,y)=
E_{\theta_1}(x,y)E_{\theta_2}(x,y)
\]

A spatially separated combination could be:

\[
J(x,y)=
E_{\theta_1}(x,y)
E_{\theta_2}(x+\Delta x,y+\Delta y)
\]

We can use different spatial arrangements to represent different junction types.

A coincidence measure can also be applied:

\[
J=\min(E_{\theta_1},E_{\theta_2})
\]

This is another possible approximation to the requirement that several inputs be active simultaneously.

**Biological interpretation:** Orientation conjunctions, end-stopped responses, nonlinear summation, and local competition between differently tuned neural populations.

**Result:** Local geometric primitives that describe how boundaries meet.

## N3-05 — Calculate boundary curvature and signed curvature

**Purpose:** Detect whether contours bend, how strongly they bend, and in which direction.

This operation is important because shape recognition cannot depend only on straight-line boundaries.

A visual object may contain:

- Convex regions.
- Concave regions.
- Rounded protrusions.
- Sharp corners.
- Gradual curves.
- Changes in curvature.

V4 research has identified neural selectivity for curvature and boundary features, including their positions relative to the object. citeturn499662search1turn499662search8

**Possible mathematical operations**

First, calculate the tangent orientation:

\[
\theta(s)
\]

Where \(s\) represents distance along the contour.

Then calculate curvature:

\[
\kappa(s)=\frac{d\theta(s)}{ds}
\]

A discrete approximation is:

\[
\kappa_i\approx
\frac{\theta_{i+1}-\theta_i}
{\Delta s}
\]

Signed curvature helps distinguish different bending directions.

For a parameterized contour \(x(t),y(t)\):

\[
\kappa(t)=
\frac{x'(t)y''(t)-y'(t)x''(t)}
{(x'(t)^2+y'(t)^2)^{3/2}}
\]

The sign convention must be consistent with contour traversal direction.

**Additional operations**

- First-order spatial differentiation.
- Second-order differentiation.
- Directional derivative calculation.
- Curvature smoothing.
- Local maximum and minimum detection.
- Convexity/concavity classification.

**Result:** A curvature map containing magnitude, sign, and location information.

---

## N3-06 — Detect contour endings and shape-boundary characteristics

**Purpose:** Determine how a contour behaves at its endpoints and along its local boundary.

This operation complements curvature detection.

A contour can have:

- A sharp endpoint.
- A smooth continuation.
- An abrupt orientation change.
- A boundary that bends toward or away from a region.
- A boundary that appears to terminate against another boundary.

**Possible mathematical operations**

Contour endpoint detection:

\[
T(x,y)=
\mathbb{1}
\left[
\text{local contour connectivity}<\tau
\right]
\]

Local direction change:

\[
\Delta\theta_i=
\theta_{i+1}-\theta_i
\]

Boundary strength:

\[
B(x,y)=
\sum_\theta
w_\theta E_\theta(x,y)
\]

End-stopping can be approximated using a comparison between shorter and longer contour responses:

\[
R_{\text{end}}=
\max(0,R_{\text{short}}-\lambda R_{\text{long}})
\]

This is an engineering approximation, not a claim that all biological end-stopped neurons implement that precise subtraction.

**Biological interpretation:** Selectivity for line endings, contour termination, and more complex local boundary configurations.

**Result:** More complete geometric descriptions of the contour fragments.

---

## N3-07 — Integrate boundaries with figure–ground information

**Purpose:** Determine which contours belong to a candidate figure and how their local structure relates to its surrounding region.

N2 already estimates figure–ground organization and border ownership. N3 should use that evidence while constructing larger shape representations.

A contour should not be interpreted independently of the region that it bounds.

For example, an identical curved boundary can represent:

- A convex external boundary.
- A concave indentation.
- A boundary partly hidden by another object.

**Possible mathematical operations**

Combine boundary strength and ownership:

\[
R_{\text{boundary}}=
B(x,y)\cdot O(x,y)
\]

Combine shape probability and contour evidence:

\[
R_{\text{figure}}=
S(x,y)\cdot R_{\text{boundary}}(x,y)
\]

A more general combination is:

\[
R=
w_1B+w_2O+w_3S
\]

The weights determine how much each source contributes.

**Biological interpretation:** Interactions between contour representations, surface representations, and figure–ground signals.

**Result:** Boundaries associated with their candidate regions rather than isolated contour fragments.

---

## N3-08 — Extract local surface and texture statistics

**Purpose:** Describe the visual characteristics inside a region, not just its boundary.

Two regions can have similar outlines but different internal appearances.

For example:

- A uniformly filled region.
- A region containing repeated lines.
- A textured region.
- A region with strong orientation structure.

Since the current N1 input is grayscale, N3 should initially focus on grayscale and orientation-based statistics. A genuine color-processing branch can be introduced only when the input contract supports color information.

**Possible mathematical operations**

Local mean:

\[
\mu_R=
\frac{1}{|R|}
\sum_{(x,y)\in R}F(x,y)
\]

Local variance:

\[
\sigma_R^2=
\frac{1}{|R|}
\sum_{(x,y)\in R}
(F(x,y)-\mu_R)^2
\]

Orientation distribution:

\[
p(\theta)=
\frac{\sum_{(x,y)\in R}E_\theta(x,y)}
{\sum_\phi\sum_{(x,y)\in R}E_\phi(x,y)+\epsilon}
\]

Orientation entropy:

\[
H_R=
-\sum_\theta p(\theta)\log(p(\theta)+\epsilon)
\]

Additional candidate operations include:

- Local correlation.
- Autocorrelation.
- Frequency analysis.
- Covariance matrices between orientation channels.
- Spatial variance.
- Texture-energy pooling.

**Biological interpretation:** Integration of texture and surface-related information across visual receptive fields.

**Result:** A surface descriptor for every candidate region.

# Level B — Shape parts and relationships

## N3-09 — Identify candidate shape parts

**Purpose:** Convert the geometric structures produced by the previous operations into candidate components of larger shapes.

This is the transition from local visual features to part-based representation.

Consider a simple shape composed of several curves and straight boundaries. N3 must determine which boundaries belong together and which combinations can form meaningful components.

It should initially detect candidate parts without assigning semantic names.

**Possible mathematical operations**

Represent each fragment as a node:

\[
P_i=(x_i,y_i,A_i,\theta_i,\kappa_i,c_i)
\]

Where:

- \(x_i,y_i\): centroid.
- \(A_i\): region area.
- \(\theta_i\): predominant orientation.
- \(\kappa_i\): curvature descriptor.
- \(c_i\): confidence.

Construct an adjacency matrix:

\[
A_{ij}=
\begin{cases}
1 & \text{if parts }i,j\text{ are connected or compatible}\\
0 & \text{otherwise}
\end{cases}
\]

Candidate part grouping can use geometric and boundary compatibility.

**Additional operations**

- Connected-component analysis.
- Region aggregation.
- Boundary continuity.
- Fragment adjacency.
- Local graph traversal.

N2 already performs fragment extraction, so N3 should extend and reorganize those fragments rather than regenerate them without reason.

**Result:** A collection of candidate shape parts.

---

## N3-10 — Calculate detailed geometric descriptors for each part

**Purpose:** Describe the geometry of each candidate part in a reusable numerical form.

A part should have more than an identifier and bounding box.

N3 should extract characteristics that will allow different parts to be compared.

**Possible mathematical operations**

For each part \(P_i\):

Centroid:

\[
\bar{x}=\frac{1}{A}\sum_{(x,y)\in P_i}x
\]

\[
\bar{y}=\frac{1}{A}\sum_{(x,y)\in P_i}y
\]

Second-order central moments:

\[
\mu_{20}=\sum(x-\bar{x})^2
\]

\[
\mu_{02}=\sum(y-\bar{y})^2
\]

\[
\mu_{11}=\sum(x-\bar{x})(y-\bar{y})
\]

The covariance matrix:

\[
\Sigma=
\begin{bmatrix}
\mu_{20}/A & \mu_{11}/A\\
\mu_{11}/A & \mu_{02}/A
\end{bmatrix}
\]

Its eigenvectors provide the principal spatial directions, while its eigenvalues describe the spread along those directions.

Additional descriptors:

- Area.
- Perimeter.
- Aspect ratio.
- Boundary curvature histogram.
- Junction count.
- Number of holes.
- Convexity.
- Solidity.
- Symmetry.
- Orientation distribution.
- Bounding-box geometry.

**Biological interpretation:** Population responses may encode aspects of spatial extent, orientation, curvature, and shape configuration. The particular descriptor vector is an engineering representation, not an established neural data structure.

**Result:** A structured geometric description for every part.

## N3-11 — Encode spatial relationships between parts

**Purpose:** Represent the relationships between separate components.

A collection of parts is not yet a complete shape.

The system must determine how the parts are arranged.

For example:

- Part A is above Part B.
- Part A is connected to Part B.
- Part A is inside Part B.
- Part A is to the left of Part B.
- Part A is attached to the endpoint of Part B.
- Part A is parallel to Part B.

These relationships are important because two shapes can contain similar elementary parts while having different arrangements.

**Possible mathematical operations**

Relative displacement:

\[
\Delta x_{ij}=x_j-x_i
\]

\[
\Delta y_{ij}=y_j-y_i
\]

Relative distance:

\[
d_{ij}=
\sqrt{\Delta x_{ij}^{2}+\Delta y_{ij}^{2}}
\]

Relative angle:

\[
\phi_{ij}=
\operatorname{atan2}(\Delta y_{ij},\Delta x_{ij})
\]

Orientation difference:

\[
\Delta\theta_{ij}=
\theta_i-\theta_j
\]

Relative size:

\[
\rho_{ij}=
\frac{A_i}{A_j+\epsilon}
\]

A relationship vector could be:

\[
R_{ij}=
[
\Delta x_{ij},
\Delta y_{ij},
d_{ij},
\phi_{ij},
\Delta\theta_{ij},
\rho_{ij}
]
\]

**Result:** A spatial relationship graph in which each edge contains geometric information.

---

## N3-12 — Organize compatible parts into local shape assemblies

**Purpose:** Combine several individual parts into larger configurations.

This is where N3 begins constructing hierarchical structures.

For example:

\[
\text{Edge segments}
\rightarrow
\text{Curved boundary}
\]

\[
\text{Curved boundary}+\text{Straight boundary}
\rightarrow
\text{Shape component}
\]

\[
\text{Shape component}_1+
\text{Shape component}_2
\rightarrow
\text{Larger shape assembly}
\]

The system should use evidence such as proximity, orientation compatibility, contour continuation, and shared figure–ground ownership.

**Possible mathematical operations**

A compatibility measure:

\[
C_{ij}=
\exp\left(
-\frac{d_{ij}^2}{2\sigma_d^2}
\right)
\exp\left(
-\frac{\Delta\theta_{ij}^2}{2\sigma_\theta^2}
\right)
\]

Additional terms can encode curvature compatibility, endpoint continuity, and common region membership.

Combined compatibility:

\[
C_{ij}^{*}=
w_dC_d+w_\theta C_\theta+
w_\kappa C_\kappa+w_oC_o
\]

A grouping score:

\[
Q(G')=
\sum_{(i,j)\in E'}C_{ij}^{*}
-\lambda |E'|
\]

This rewards mutually compatible components while controlling unnecessary connections.

Possible biological analogues include:

- Horizontal cortical interactions.
- Excitatory and inhibitory competition.
- Contour grouping.
- Recurrent association between feature populations.

**Result:** A hierarchy of local shape assemblies.

---

## N3-13 — Build V4-like shape-part populations

**Purpose:** Represent more complex boundary features and their positions relative to an entire candidate shape.

This is a particularly important stage.

Research on V4 shows that neural responses can be tuned to combinations of curvature and object-relative boundary position. A population of such responses can represent complex shapes through multiple boundary features. citeturn499662search0turn499662search3turn499662search4

Instead of representing:

> A curved segment exists.

N3 should be able to represent a more detailed relationship:

> A convex curved segment occurs near the upper-right part of the candidate shape.

That representation contains both shape information and relative-position information.

**Possible mathematical operations**

First calculate the candidate object's center:

\[
c_o=(x_o,y_o)
\]

For every boundary feature \(i\):

\[
\Delta x_i=x_i-x_o
\]

\[
\Delta y_i=y_i-y_o
\]

Relative angular position:

\[
\alpha_i=
\operatorname{atan2}(\Delta y_i,\Delta x_i)
\]

Its descriptor becomes:

\[
q_i=(\alpha_i,\kappa_i)
\]

A V4-inspired feature population can respond to a preferred combination:

\[
r_k=
\exp\left[
-\frac{d_{\text{angle}}(\alpha,\mu_{\alpha,k})^2}
{2\sigma_{\alpha,k}^2}
-\frac{(\kappa-\mu_{\kappa,k})^2}
{2\sigma_{\kappa,k}^2}
\right]
\]

Here \(d_{\text{angle}}\) is circular angular distance.

This creates populations selectively responsive to particular boundary configurations.

**Result:** An object-relative population of shape-part features.

# Level C — Hierarchical shape representations

## N3-14 — Construct larger receptive-field feature populations

**Purpose:** Allow higher-level populations to combine several local shape parts.

N3 now has local parts, their geometry, and their spatial relationships.

The next operation is to build populations that integrate information over a larger region.

For example, a population can respond to:

- A combination of several curves.
- A particular arrangement of corners.
- A specific relationship between a curved and a straight boundary.
- Several parts forming a characteristic overall contour.

**Possible mathematical operations**

Convergent weighted summation:

\[
u_i^{(l+1)}=
\sum_j W_{ij}^{(l)}
h_j^{(l)}
\]

Spatially extended convolution:

\[
u_i^{(l+1)}(x,y)=
\sum_j
K_{ij}^{(l)}*h_j^{(l)}(x,y)
\]

Nonlinear transformation:

\[
h_i^{(l+1)}=
\max(0,u_i^{(l+1)}-b_i)
\]

The receptive field expands because the new population integrates inputs covering a larger portion of the visual field.

**Biological interpretation:** Increasing spatial convergence across hierarchical visual areas.

**Result:** Complex shape-feature populations with larger receptive fields.

---

## N3-15 — Build intermediate position-tolerant representations

**Purpose:** Allow the representation of a feature to remain active when its position changes within an appropriate spatial neighborhood.

An object may move slightly while remaining the same object.

A visual representation that changes completely with every small displacement would be unsuitable for recognition.

One possible solution is pooling over nearby spatial locations.

**Possible mathematical operations**

Maximum pooling:

\[
z_i(x)=
\max_{\delta\in\mathcal N}
h_i(x+\delta)
\]

Soft maximum pooling:

\[
z_i(x)=
\tau
\log
\left[
\sum_{\delta\in\mathcal N}
\exp\left(\frac{h_i(x+\delta)}{\tau}\right)
\right]
\]

Here \(\tau\) controls how closely the operation resembles maximum pooling.

- Small \(\tau\): more strongly favors the maximum response.
- Larger \(\tau\): allows more responses to contribute.

**Biological interpretation:** Converging inputs over spatially extended receptive fields and pooling of neuronal activity.

**Important ORE requirement:** Do not discard the original location. Preserve both:

\[
Z_i=\text{pooled feature activity}
\]

\[
L_i=\text{estimated feature location}
\]

This allows N3 to tolerate small displacements without losing spatial precision.

---

## N3-16 — Develop scale and orientation tolerance

**Purpose:** Allow the same shape to generate related higher-level representations despite certain changes in scale or orientation.

The brain can recognize objects under different viewing conditions. However, invariance is not unlimited, and it develops progressively across the visual pathway.

Research directly comparing V4 and IT populations found increased tolerance to position, scale, and context in IT, alongside changes in feature selectivity. citeturn715200view1

**Possible mathematical operations**

Scale pooling:

\[
z_i^{scale}=
\operatorname{LSE}_{s\in\mathcal S}
(r_i(s))
\]

Where `LSE` is log-sum-exp.

Orientation pooling:

\[
z_i^{orientation}=
\operatorname{LSE}_{\theta\in\Theta}
(r_i(\theta))
\]

A more controlled version keeps separate transformation channels:

\[
Z_i=
[
r_i(s_1,\theta_1),
r_i(s_2,\theta_1),
r_i(s_1,\theta_2),
\ldots
]
\]

**Very important for ORE:** Orientation cannot simply be discarded.

In written characters, different orientations and reflections can distinguish otherwise similar forms. For example, a horizontally or vertically reflected character may represent a different grapheme.

Therefore N3 should:

1. Retain the original orientation-specific representation.
2. Create optional tolerant representations.
3. Record which transformations were applied.
4. Never assume that rotated or reflected patterns have identical identity.

**Result:** Multiple representations with controlled, measurable transformation tolerance.

---

## N3-17 — Create an object-centered coordinate representation

**Purpose:** Describe a candidate shape relative to its own center rather than only by absolute image coordinates.

The same shape can occur at different positions in the image.

An object-centered representation helps preserve its internal configuration.

For example, suppose two copies of the same shape exist at different locations. Their internal part arrangements may be similar even though their retinotopic coordinates differ.

**Possible mathematical operations**

Centering:

\[
x_i'=x_i-\bar{x}
\]

\[
y_i'=y_i-\bar{y}
\]

Scale normalization:

\[
x_i''=\frac{x_i'}{s_o+\epsilon}
\]

\[
y_i''=\frac{y_i'}{s_o+\epsilon}
\]

Where \(s_o\) may be derived from object size.

Optional rotation alignment:

\[
\begin{bmatrix}
x_i'''\\y_i'''
\end{bmatrix}
=
\begin{bmatrix}
\cos\alpha&-\sin\alpha\\
\sin\alpha&\cos\alpha
\end{bmatrix}
\begin{bmatrix}
x_i''\\y_i''
\end{bmatrix}
\]

But this rotation normalization should be optional, and the original object orientation must be retained.

**Biological interpretation:** Object-relative coding is relevant to the representation of boundary features in visual cortex, particularly V4. The explicit normalization formula is an engineering method for building such a representation, not a proven description of the brain's exact process. citeturn499662search1

**Result:** An object-centered representation preserving the original retinotopic coordinates.

---

## N3-18 — Construct hierarchical part-to-whole shape configurations

**Purpose:** Combine shape assemblies into candidate whole shapes.

This is a central operation of N3.

The system now possesses several levels of representation:

\[
\text{Features}
\rightarrow
\text{Contour fragments}
\rightarrow
\text{Shape parts}
\rightarrow
\text{Part assemblies}
\]

N3 should combine these into candidate whole-shape structures.

**Possible mathematical operations**

Represent each candidate whole shape as a graph:

\[
H_k=(V_k,E_k)
\]

Where:

- \(V_k\) represents shape parts.
- \(E_k\) represents relationships between those parts.

Evaluate a candidate using multiple sources of evidence:

\[
Score(H_k)=
w_1F_k+
w_2R_k+
w_3B_k+
w_4G_k
\]

Where:

- \(F_k\): feature compatibility.
- \(R_k\): relational compatibility.
- \(B_k\): boundary consistency.
- \(G_k\): global geometric consistency.

A probabilistic alternative:

\[
P(H_k\mid X)\propto
P(X\mid H_k)P(H_k)
\]

Here \(P(H_k)\) represents previously learned structural regularities, if learning has been enabled.

**Biological interpretation:** Convergence of multiple shape-part signals into more complex configurations, with interaction between feedforward and recurrent neural populations.

Studies of V4 and posterior IT suggest a gradual synthesis of simpler contour components into more complex shape configurations. citeturn499662search5

**Result:** Multiple candidate whole-shape representations.

---

## N3-19 — Develop an IT-like high-level feature population

**Purpose:** Produce a more abstract representation of complex shapes.

This is the highest-level feedforward representation in the initial N3 architecture.

The goal is not to give a shape a word or semantic name.

Instead, the system should produce a stable high-dimensional neural-style representation that captures the arrangement of its visual features.

For example, two different images depicting the same simple object could produce similar high-level population patterns despite differences in position or size.

**Possible mathematical operations**

A high-level feature response:

\[
a_i=
\phi
\left(
W_i^\top z-b_i
\right)
\]

Where \(z\) contains the assembled shape features.

The complete population activity is:

\[
\mathbf a=
[a_1,a_2,\ldots,a_n]
\]

Similarity between representations:

\[
Similarity(A,B)=
\frac{A\cdot B}
{\|A\|\|B\|+\epsilon}
\]

This produces a numerical measure of how similar two shape representations are.

**Biological interpretation:** IT population activity represents complex visual information in distributed patterns. The representation should not depend upon a single special neuron for every possible object; IT population coding is much more distributed than such a simplistic model would imply. citeturn499662search7

**Result:** An IT-inspired population code for candidate shapes.

---

## N3-20 — Introduce population normalization and competition

**Purpose:** Prevent every feature population from responding excessively and help determine which candidate representations are most strongly supported.

The brain uses interactions between excitatory and inhibitory processes to regulate neuronal responses.

One particularly important candidate canonical computation is divisive normalization.

It has been studied across different levels of visual processing. citeturn699953search0turn699953search3turn699953search5

**Possible mathematical operations**

Divisive normalization:

\[
r_i=
\frac{u_i}
{
\left(
\epsilon+
\sum_jw_{ij}|u_j|^p
\right)^{1/p}
}
\]

Where:

- \(u_i\): original activation.
- \(w_{ij}\): influence of population \(j\).
- \(p\): normalization exponent.
- \(\epsilon\): numerical stability term.

Competition between candidates:

\[
P(H_i)=
\frac{\exp(S_i/T)}
{\sum_j\exp(S_j/T)}
\]

Where \(T\) is a temperature parameter.

**Additional operations**

- Inhibitory interaction.
- Winner-take-most competition.
- Lateral suppression.
- Population gain control.
- Sparse activation.

The system should not automatically force a single winner. Several candidate shapes may remain active when visual information is ambiguous.

**Result:** A controlled population representation with competing candidate activations.

---

## N3-21 — Integrate ventral and dorsal visual representations

**Purpose:** Connect shape information with spatial information without destroying the distinction between the two.

The ventral pathway is commonly associated with object and form processing, while the dorsal pathway contributes spatial and action-related visual processing.

N2 already exposes separate ventral and dorsal populations. N3 should preserve this architectural distinction.

**Possible mathematical operations**

Feature integration:

\[
Z_{combined}=
W_vZ_v+W_dZ_d
\]

However, the combined representation must not replace the original streams.

A better engineering structure is:

\[
Z=
\{
Z_v,Z_d,Z_{interaction}
\}
\]

Interaction information can encode relationships between a shape and its location:

\[
Z_{interaction}=f(Z_v,Z_d)
\]

For example:

- Shape identity candidates.
- Location of the candidate shape.
- Spatial relationships with neighboring regions.
- Orientation relative to the image.
- Relative position among other candidate shapes.

**Biological interpretation:** Interaction between interconnected visual processing streams. The exact mathematical fusion above is an ORE design choice, not a claim that the brain uses a single weighted-sum operation between the two streams.

**Result:** A combined representation retaining separate form and spatial information.

# Level D — Recurrent visual interpretation

## N3-22 — Apply attention and feature-selection modulation

**Purpose:** Allow some visual features to influence processing more strongly than others.

Attention can influence visual neural responses and the amount of information contributed by different features.

The importance of a feature can depend on:

- Its visual salience.
- Its relationship to the current candidate shape.
- Its uncertainty.
- Its location.
- Its relevance to an ongoing recognition process.

**Possible mathematical operations**

Define an attention weight:

\[
g_i=1+\alpha A_i
\]

Where \(A_i\) represents estimated attentional influence.

Modulated response:

\[
r_i'=g_i r_i
\]

Alternatively, use a normalized gain function:

\[
g_i=
\frac{\exp(a_i/T)}
{\sum_j\exp(a_j/T)}
\]

A more sophisticated implementation can combine bottom-up saliency with top-down relevance:

\[
A_i=
w_sS_i+
w_uU_i+
w_tT_i
\]

Where:

- \(S_i\): saliency.
- \(U_i\): uncertainty-related importance.
- \(T_i\): top-down relevance.

**Biological interpretation:** Gain modulation and competition between neural populations.

**Result:** A dynamically modulated visual representation.

---

## N3-23 — Execute the initial hierarchical feedforward sweep

**Purpose:** Propagate information from lower to higher visual representations to obtain an initial interpretation.

At this point, the system has already built multiple feature and shape levels.

It must now perform an ordered processing pass.

The conceptual direction is:

\[
N1\rightarrow N2\rightarrow
V2\text{-like}\rightarrow
V4\text{-like}\rightarrow
IT\text{-like}
\]

This does not mean that actual biological pathways contain only these stages. They contain many interconnected areas, and this is a functional approximation.

**Possible mathematical operations**

For every hierarchical level:

\[
h^{(l+1)}=
\phi
\left(
W^{(l)}h^{(l)}+b^{(l)}
\right)
\]

The overall feedforward transformation is:

\[
H^{(L)}=
f_L(f_{L-1}(\ldots f_2(f_1(H^{(0)}))))
\]

**Result:** An initial high-level interpretation of the visual stimulus.

This initial representation may be sufficient for easy visual recognition, while more difficult images may benefit from additional recurrent processing. Research describes early feedforward processing followed by further refinement through feedback interactions. citeturn715200view2

---

## N3-24 — Generate top-down predictions from higher visual levels

**Purpose:** Allow higher-level shape representations to influence lower-level processing.

A purely feedforward architecture cannot fully reproduce the recurrent nature of biological vision.

Suppose a higher-level candidate shape becomes active.

It can provide information about the lower-level visual structures that would be expected if that candidate were correct.

For example, a high-level shape hypothesis might predict:

- Particular contour positions.
- Particular boundary orientations.
- A particular arrangement of shape parts.
- The presence of expected junctions.

**Possible mathematical operations**

Top-down prediction:

\[
\hat h^{(l)}=
W_{fb}^{(l)}h^{(l+1)}
\]

The prediction is mapped to the representational space of the lower level.

Prediction error:

\[
e^{(l)}=
h^{(l)}-\hat h^{(l)}
\]

This error represents the difference between actual lower-level activity and the predicted activity.

**Biological interpretation:** Feedback projections from higher cortical areas can convey contextual and predictive information to lower areas.

Predictive coding is one theoretical framework for describing these interactions. It proposes hierarchical predictions and error signals, although the exact neural implementation remains an active research question. citeturn699953search9turn715200view2

**Result:** Top-down predictions and corresponding error representations.

---

## N3-25 — Perform recurrent refinement and prediction-error correction

**Purpose:** Improve an initial visual representation by repeatedly combining bottom-up evidence, local interactions, and higher-level predictions.

This is where the hierarchical visual architecture becomes recurrent rather than merely sequential.

N2 already contains a bounded recurrence operation. N3 should generalize this concept across the hierarchy.

At every iteration, lower and higher feature levels can exchange information.

**Possible mathematical operations**

A recurrent update:

\[
h_l^{t+1}=
\phi
\left(
W_{ff}f_l+
W_{lat}h_l^t+
W_{fb}h_{l+1}^t-b_l
\right)
\]

Where:

- \(f_l\): bottom-up input.
- \(h_l^t\): current activity.
- \(h_{l+1}^t\): higher-level activity.
- \(W_{ff}\): feedforward connections.
- \(W_{lat}\): lateral connections.
- \(W_{fb}\): feedback connections.

A predictive-error-based formulation can additionally define:

\[
E=
\sum_l
\epsilon_l^\top
\Pi_l
\epsilon_l
\]

Where \(\Pi_l\) controls the precision assigned to each level.

The system can update its state in the direction of reducing that energy:

\[
h^{t+1}=h^t-\eta\nabla_h E
\]

This is a model of iterative inference, not a proof that the brain literally computes this global energy function.

**Convergence measurement**

\[
\Delta_t=
\frac{\|h^{t+1}-h^t\|_2}
{\|h^t\|_2+\epsilon}
\]

Stop when:

\[
\Delta_t<\tau
\]

or when the maximum number of iterations is reached.

The system should also record whether convergence occurred, whether the result oscillated, and whether the update increased prediction error.

**Result:** A refined hierarchical representation with measurable convergence behavior.

# Level E — Learning, memory, and output

## N3-26 — Integrate temporal visual information (optional)

**Purpose:** Preserve visual information over time when N3 receives a sequence of frames.

A single image provides spatial information but cannot, by itself, establish actual visual motion.

N2 already identifies this distinction: its dorsal output does not claim to calculate motion energy from a single frame.

N3 should therefore make temporal integration optional.

**Possible mathematical operations**

Leaky temporal integration:

\[
z_t=
\alpha z_{t-1}
+(1-\alpha)r_t
\]

Where:

\[
\alpha=e^{-\Delta t/\tau}
\]

This allows a current feature representation to depend partly on its previous state.

A more general Bayesian temporal update:

\[
P(H_t\mid I_{1:t})
\propto
P(I_t\mid H_t)
\sum_{H_{t-1}}
P(H_t\mid H_{t-1})
P(H_{t-1}\mid I_{1:t-1})
\]

This represents the integration of current sensory evidence with previous hypotheses.

**Biological interpretation:** Temporal integration, persistence of neural activity, and interactions between current and preceding sensory evidence.

**Result:** A temporally informed representation when sequences are available; otherwise, this operation remains disabled.

---

## N3-27 — Implement adaptive learning of hierarchical visual features

**Purpose:** Allow N3 to learn recurring visual configurations from experience instead of depending entirely on manually predefined feature templates.

This is especially important for developing a flexible ORE architecture.

If N3 uses only manually specified templates, the number of possible configurations will become difficult to manage.

The system should eventually learn:

- Frequently occurring feature combinations.
- Typical curvature configurations.
- Relationships between shape parts.
- Repeated boundary structures.
- More complex shape assemblies.

**Possible mathematical operations**

Hebbian-like learning:

\[
\Delta w_{ij}=
\eta x_i y_j
\]

Where:

- \(x_i\): presynaptic activity.
- \(y_j\): postsynaptic activity.
- \(\eta\): learning rate.

A regularized version:

\[
\Delta w_{ij}=
\eta x_i y_j-\lambda w_{ij}
\]

Prototype adaptation:

\[
\mu_k^{new}
=
\mu_k^{old}+
\eta a_k
(z-\mu_k^{old})
\]

This gradually adjusts a learned prototype toward the observed representation.

Population stabilization can be approximated through homeostatic activity regulation:

\[
b_i^{new}
=
b_i^{old}
+
\eta_h(\bar r_i-r_{target})
\]

**Important design distinction**

N3 should initially support two separate modes:

1. **Inference mode:** Uses learned parameters without changing them.
2. **Learning mode:** Updates parameters from approved training examples.

This will make experiments repeatable and prevent the model from silently changing during normal evaluation.

**Result:** Adaptable hierarchical feature populations.

---

## N3-28 — Evaluate confidence and preserve alternative visual interpretations

**Purpose:** Determine how strongly the available visual evidence supports the current representation.

A visual system should not always assume that its most active candidate is correct.

For example, a partially obscured shape may support multiple plausible configurations.

N3 should preserve uncertainty instead of automatically converting an ambiguous image into one definite interpretation.

**Possible mathematical operations**

Normalize candidate scores:

\[
P(H_i)=
\frac{\exp(S_i/T)}
{\sum_j\exp(S_j/T)}
\]

Calculate entropy:

\[
\mathcal H=
-\sum_iP(H_i)\log(P(H_i)+\epsilon)
\]

Low entropy means that the probability distribution is concentrated around a small number of hypotheses.

High entropy indicates greater ambiguity.

Confidence can additionally depend on the strength of the sensory evidence and the prediction error:

\[
C=
f(
\text{evidence},
\text{uncertainty},
\text{prediction error},
\text{convergence}
)
\]

The precise confidence formula must be calibrated empirically.

**Result:** Candidate shape representations with confidence and uncertainty information.

## N3-29 — Produce the structured hierarchical visual output

**Purpose:** Make the N3 representation available to later ORE phases.

N3 should not simply return a single numerical feature vector.

The main outcome should be a structured description of how the visual input is organized.

A conceptual output should contain:

| Output | Description |
|---|---|
| `hierarchical_feature_maps` | Feature maps at different processing levels |
| `local_primitives` | Corners, junctions, endings, and curvature features |
| `shape_parts` | Geometric descriptions of candidate parts |
| `part_relationships` | Relative positions, distances, orientations, and connections |
| `shape_assemblies` | Groups of parts and their structural configurations |
| `shape_hypotheses` | Candidate whole-shape representations |
| `object_centered_features` | Shape features in relative coordinates |
| `transformation_codes` | Position, scale, and orientation-related representations |
| `ventral_population` | High-level form-related activity |
| `dorsal_population` | Spatial information and relationships |
| `recurrent_state` | Final recurrent activations |
| `prediction_errors` | Differences between predicted and observed activity |
| `confidence` | Candidate-level confidence estimates |
| `uncertainty` | Entropy and ambiguity measures |
| `diagnostics` | Validation, convergence, timings, and numerical records |
| `provenance` | Which N1/N2 features contributed to each higher-level representation |

At this point, ORE will possess a hierarchical representation of visual structure.

It will not yet have to decide that a particular shape is the letter A, B, C, or any other grapheme. That distinction belongs to a later identity-recognition stage.

# 3. Consolidated mathematical operations

The 29 operations above can be classified according to the mathematical families that they use.

| Mathematical family | Examples | Main purpose |
|---|---|---|
| Linear algebra | Weighted summation, matrix multiplication | Combining neural inputs |
| Convolution | Spatial filtering, receptive-field integration | Detecting local and broader features |
| Nonlinear functions | ReLU, thresholding, multiplicative gating | Feature selectivity |
| Differential calculus | First and second derivatives, curvature | Describing boundary geometry |
| Statistics | Mean, variance, covariance, entropy | Characterizing visual populations |
| Spatial geometry | Distances, angles, centroids, transformations | Describing shape and part relationships |
| Graph theory | Adjacency, graph composition, connectivity | Organizing components |
| Probability | Softmax, Bayesian inference | Representing competing interpretations |
| Optimization | Error minimization, iterative updates | Recurrent refinement |
| Temporal mathematics | Exponential integration, Bayesian filtering | Combining information across time |
| Learning rules | Hebbian updates, prototype adaptation | Learning recurring feature configurations |
| Population dynamics | Normalization, inhibition, competition | Regulating neural activity |

The most important mathematical principle is that these computations should not be treated as isolated operations. They must form a connected hierarchy, with each level transforming the representations produced by earlier levels.

# 6. Important architectural decisions for ORE

I would make the following decisions part of the N3 specification, not leave them as implementation details.

**1. Never destroy the original spatial representation.**

N1 and N2 already preserve useful spatial information. N3 may create increasingly abstract representations, but it must keep lower-level data accessible.

**2. Preserve both retinotopic and object-centered coordinates.**

The object-centered representation is useful for shape recognition, while retinotopic information is essential for locating the shape and preserving the arrangement of visual elements.

**3. Use progressive, not absolute, invariance.**

Do not make all shapes invariant to every rotation, reflection, or scale change. In orthographic processing, small geometric changes can be identity-relevant.

**4. Treat the hierarchy as interacting populations, not simply a deep CNN.**

A purely feedforward network can provide a useful first approximation, but N3 should support lateral interactions, feedback, recurrent refinement, and separate feature populations. citeturn715200view2

**5. Preserve alternatives when evidence is ambiguous.**

The architecture should represent uncertainty rather than force every image into one interpretation.

**6. Keep learning separate from inference.**

The N3 system should be capable of running with fixed parameters, while learning experiments can be enabled independently.

| Population coding | Produces finite, reproducible high-level responses |

| Integration | Preserves compatibility with existing N1 and N2 outputs |

Scientific validation should be a separate milestone. Passing synthetic software tests does not prove that N3 reproduces biological visual processing. To make physiological claims, its responses would need comparison with controlled visual stimuli and independent experimental measurements.

## Final architectural position

N1 establishes early visual feature extraction.

N2 establishes visual organization: boundaries, contours, figure–ground relationships, fragments, and structural topology.

**N3 establishes hierarchical shape representation.**

The resulting development sequence is:

\[
\boxed{
\begin{aligned}
N1 &: \text{Visual feature extraction}\\
N2 &: \text{Visual organization}\\
N3 &: \text{Hierarchical shape representation}
\end{aligned}
}
\]

N3 is therefore the bridge between visual organization and a later orthographic recognition system. It gives ORE the ability to represent a visual pattern as a structured hierarchy of parts and whole-shape configurations, while retaining the spatial and geometric evidence that a subsequent grapheme-recognition stage will need.

The canonical repository for the next implementation stage remains [wizekin/ORE-Neurocomputational](https://github.com/wizekin/ORE-Neurocomputational).

My recommendation is to treat the **29 operations above as the N3 master algorithm**, then implement them in small, independently testable groups while keeping the N1 and N2 contracts unchanged.

It describes the activation of feature population \(i\), at hierarchical level \(l\), at a particular position, scale, orientation, and iteration.

# Level A — Intermediate visual features

## N3-01 — Receive and validate the N2 visual representation

**Purpose:** Establish a reliable connection between N2's output and N3's hierarchical processing system.

N2 has already identified many local structures. N3 must not repeat the entire N1 and N2 pipeline.

Instead, it receives their outputs and prepares them for more complex processing.

**Operations:**

1. Receive the N2 result.
2. Retrieve the orientation-energy maps.
3. Retrieve multiscale information.
4. Retrieve boundaries and figure–ground evidence.
5. Retrieve shape fragments and their structural graph.
6. Retrieve the ventral and dorsal populations.
7. Preserve the association between each feature and its original spatial position.
8. Validate array dimensions and numerical values.
9. Reject missing or incompatible mandatory information.

**Possible mathematical operations**

Input validation:

\[
F \in \mathbb R^{C\times H\times W}
\]

where \(C\) is the number of orientation channels.

Numerical validation:

\[
\forall i,j,k:\quad \operatorname{isfinite}(F_{ijk})
\]

Spatial alignment:

\[
(x,y)_{N1} \longleftrightarrow (x,y)_{N2}
\]

The relationship between every N2 fragment and its corresponding location in N1 must remain available.

**Biological interpretation:** This step represents the transmission and integration of activity between connected visual cortical populations. It does not imply that the brain performs explicit software-style validation.

**Result:** A validated N3 input structure with preserved spatial provenance.

## N3-02 — Establish a multilevel receptive-field hierarchy

**Purpose:** Allow different neural populations to process different spatial extents of the same visual input.

Early visual processing is dominated by relatively localized receptive fields. As information propagates through the visual hierarchy, progressively larger regions can contribute to a neuron's response.

N3 should reproduce this principle algorithmically.

Instead of maintaining only one representation of a contour, it should create several representations at different spatial scales.

**Possible mathematical operations**

Gaussian scale-space:

\[
F_s=G_{\sigma_s}*F
\]

Where:

- \(F\) is the original feature map.
- \(G_{\sigma_s}\) is a Gaussian kernel.
- \(*\) denotes convolution.
- \(\sigma_s\) determines the spatial scale.

A larger \(\sigma_s\) produces a representation that incorporates information from a larger neighborhood.

We can define a hierarchy:

\[
F_0=F
\]

\[
F_1=D_1(G_{\sigma_1}*F_0)
\]

\[
F_2=D_2(G_{\sigma_2}*F_0)
\]

\[
F_3=D_3(G_{\sigma_3}*F_0)
\]

Here \(D_s\) is a spatial downsampling operation.

**Possible neural operations:**

- Spatial integration through converging neural inputs.
- Excitatory and inhibitory interactions.
- Receptive-field summation.
- Spatial-frequency sensitivity.
- Local and broader contextual integration.

N2 already provides multiscale processing. N3 should expand this into a hierarchy of receptive-field populations rather than simply repeat N2's scale-space calculation.

**Result:** A multiscale visual representation:

\[
\mathcal F=\{F_0,F_1,F_2,F_3,\ldots\}
\]

---

## N3-03 — Combine elementary features into more complex feature responses

**Purpose:** Detect combinations of local orientations, edges, and other elementary signals.

A single orientation-selective response describes only one component of a visual structure.

But more complex visual features can depend on several elementary responses occurring together.

For example:

- Two orientations can form a corner.
- A sequence of orientations can form a curve.
- Two approximately parallel boundaries can represent a bar.
- Several boundaries can form a contour junction.

Neurons in intermediate visual areas receive converging inputs from earlier visual populations. Recent modeling work demonstrates that combinations of V1 inputs can account for important aspects of V2 receptive-field responses. citeturn699953search2

**Possible mathematical operations**

Linear combination:

\[
u_i^{(l)}(x,y)=
\sum_j w_{ij}^{(l)}
h_j^{(l-1)}(x,y)
\]

Nonlinear activation:

\[
h_i^{(l)}(x,y)=
\max(0,u_i^{(l)}(x,y)-b_i)
\]

Where:

- \(w_{ij}\) is the connection strength.
- \(b_i\) is a threshold.
- \(h_j\) represents input feature activation.

This creates a new population that responds to a combination of earlier features.

Another possible operation is multiplicative feature conjunction:

\[
r_{ij}(x,y)=
h_i(x,y)\cdot h_j(x,y)
\]

This produces a strong response when both inputs are active.

**Biological interpretation:** Convergent synaptic inputs, nonlinear integration, thresholding, and interactions between excitation and inhibition.

**Result:** A population of more complex local visual features.

**Purpose:** Transform combinations of orientations into recognizable geometric configurations.

The system should distinguish between different ways in which boundaries meet.

For example:

These configurations are useful for describing how different contour segments are connected.

**Possible mathematical operations**

Let \(E_\theta(x,y)\) denote the activation of the orientation channel \(\theta\).

A two-orientation conjunction could be:

\[
J_{\theta_1,\theta_2}(x,y)=
E_{\theta_1}(x,y)E_{\theta_2}(x,y)
\]

A spatially separated combination could be:

\[
J(x,y)=
E_{\theta_1}(x,y)
E_{\theta_2}(x+\Delta x,y+\Delta y)
\]

We can use different spatial arrangements to represent different junction types.

A coincidence measure can also be applied:

\[
J=\min(E_{\theta_1},E_{\theta_2})
\]

This is another possible approximation to the requirement that several inputs be active simultaneously.

**Biological interpretation:** Orientation conjunctions, end-stopped responses, nonlinear summation, and local competition between differently tuned neural populations.

**Result:** Local geometric primitives that describe how boundaries meet.

## N3-05 — Calculate boundary curvature and signed curvature

**Purpose:** Detect whether contours bend, how strongly they bend, and in which direction.

This operation is important because shape recognition cannot depend only on straight-line boundaries.

A visual object may contain:

- Convex regions.
- Concave regions.
- Rounded protrusions.
- Sharp corners.
- Gradual curves.
- Changes in curvature.

V4 research has identified neural selectivity for curvature and boundary features, including their positions relative to the object. citeturn499662search1turn499662search8

**Possible mathematical operations**

First, calculate the tangent orientation:

\[
\theta(s)
\]

Where \(s\) represents distance along the contour.

Then calculate curvature:

\[
\kappa(s)=\frac{d\theta(s)}{ds}
\]

A discrete approximation is:

\[
\kappa_i\approx
\frac{\theta_{i+1}-\theta_i}
{\Delta s}
\]

Signed curvature helps distinguish different bending directions.

For a parameterized contour \(x(t),y(t)\):

\[
\kappa(t)=
\frac{x'(t)y''(t)-y'(t)x''(t)}
{(x'(t)^2+y'(t)^2)^{3/2}}
\]

The sign convention must be consistent with contour traversal direction.

**Additional operations**

- First-order spatial differentiation.
- Second-order differentiation.
- Directional derivative calculation.
- Curvature smoothing.
- Local maximum and minimum detection.
- Convexity/concavity classification.

**Result:** A curvature map containing magnitude, sign, and location information.

---

## N3-06 — Detect contour endings and shape-boundary characteristics

**Purpose:** Determine how a contour behaves at its endpoints and along its local boundary.

This operation complements curvature detection.

A contour can have:

- A sharp endpoint.
- A smooth continuation.
- An abrupt orientation change.
- A boundary that bends toward or away from a region.
- A boundary that appears to terminate against another boundary.

**Possible mathematical operations**

Contour endpoint detection:

\[
T(x,y)=
\mathbb{1}
\left[
\text{local contour connectivity}<\tau
\right]
\]

Local direction change:

\[
\Delta\theta_i=
\theta_{i+1}-\theta_i
\]

Boundary strength:

\[
B(x,y)=
\sum_\theta
w_\theta E_\theta(x,y)
\]

End-stopping can be approximated using a comparison between shorter and longer contour responses:

\[
R_{\text{end}}=
\max(0,R_{\text{short}}-\lambda R_{\text{long}})
\]

This is an engineering approximation, not a claim that all biological end-stopped neurons implement that precise subtraction.

**Biological interpretation:** Selectivity for line endings, contour termination, and more complex local boundary configurations.

**Result:** More complete geometric descriptions of the contour fragments.

---

## N3-07 — Integrate boundaries with figure–ground information

**Purpose:** Determine which contours belong to a candidate figure and how their local structure relates to its surrounding region.

N2 already estimates figure–ground organization and border ownership. N3 should use that evidence while constructing larger shape representations.

A contour should not be interpreted independently of the region that it bounds.

For example, an identical curved boundary can represent:

- A convex external boundary.
- A concave indentation.
- A boundary partly hidden by another object.

**Possible mathematical operations**

Combine boundary strength and ownership:

\[
R_{\text{boundary}}=
B(x,y)\cdot O(x,y)
\]

Combine shape probability and contour evidence:

\[
R_{\text{figure}}=
S(x,y)\cdot R_{\text{boundary}}(x,y)
\]

A more general combination is:

\[
R=
w_1B+w_2O+w_3S
\]

The weights determine how much each source contributes.

**Biological interpretation:** Interactions between contour representations, surface representations, and figure–ground signals.

**Result:** Boundaries associated with their candidate regions rather than isolated contour fragments.

## N3-08 — Extract local surface and texture statistics

**Purpose:** Describe the visual characteristics inside a region, not just its boundary.

Two regions can have similar outlines but different internal appearances.

For example:

- A uniformly filled region.
- A region containing repeated lines.
- A textured region.
- A region with strong orientation structure.

Since the current N1 input is grayscale, N3 should initially focus on grayscale and orientation-based statistics. A genuine color-processing branch can be introduced only when the input contract supports color information.

**Possible mathematical operations**

Local mean:

\[
\mu_R=
\frac{1}{|R|}
\sum_{(x,y)\in R}F(x,y)
\]

Local variance:

\[
\sigma_R^2=
\frac{1}{|R|}
\sum_{(x,y)\in R}
(F(x,y)-\mu_R)^2
\]

Orientation distribution:

\[
p(\theta)=
\frac{\sum_{(x,y)\in R}E_\theta(x,y)}
{\sum_\phi\sum_{(x,y)\in R}E_\phi(x,y)+\epsilon}
\]

Orientation entropy:

\[
H_R=
-\sum_\theta p(\theta)\log(p(\theta)+\epsilon)
\]

Additional candidate operations include:

- Local correlation.
- Autocorrelation.
- Frequency analysis.
- Covariance matrices between orientation channels.
- Spatial variance.
- Texture-energy pooling.

**Biological interpretation:** Integration of texture and surface-related information across visual receptive fields.

**Result:** A surface descriptor for every candidate region.

# Level B — Shape parts and relationships

## N3-09 — Identify candidate shape parts

**Purpose:** Convert the geometric structures produced by the previous operations into candidate components of larger shapes.

This is the transition from local visual features to part-based representation.

Consider a simple shape composed of several curves and straight boundaries. N3 must determine which boundaries belong together and which combinations can form meaningful components.

It should initially detect candidate parts without assigning semantic names.

**Possible mathematical operations**

Represent each fragment as a node:

\[
P_i=(x_i,y_i,A_i,\theta_i,\kappa_i,c_i)
\]

Where:

- \(x_i,y_i\): centroid.
- \(A_i\): region area.
- \(\theta_i\): predominant orientation.
- \(\kappa_i\): curvature descriptor.
- \(c_i\): confidence.

Construct an adjacency matrix:

\[
A_{ij}=
\begin{cases}
1 & \text{if parts }i,j\text{ are connected or compatible}\\
0 & \text{otherwise}
\end{cases}
\]

Candidate part grouping can use geometric and boundary compatibility.

**Additional operations**

- Connected-component analysis.
- Region aggregation.
- Boundary continuity.
- Fragment adjacency.
- Local graph traversal.

N2 already performs fragment extraction, so N3 should extend and reorganize those fragments rather than regenerate them without reason.

**Result:** A collection of candidate shape parts.

---

## N3-10 — Calculate detailed geometric descriptors for each part

**Purpose:** Describe the geometry of each candidate part in a reusable numerical form.

A part should have more than an identifier and bounding box.

N3 should extract characteristics that will allow different parts to be compared.

**Possible mathematical operations**

For each part \(P_i\):

Centroid:

\[
\bar{x}=\frac{1}{A}\sum_{(x,y)\in P_i}x
\]

\[
\bar{y}=\frac{1}{A}\sum_{(x,y)\in P_i}y
\]

Second-order central moments:

\[
\mu_{20}=\sum(x-\bar{x})^2
\]

\[
\mu_{02}=\sum(y-\bar{y})^2
\]

\[
\mu_{11}=\sum(x-\bar{x})(y-\bar{y})
\]

The covariance matrix:

\[
\Sigma=
\begin{bmatrix}
\mu_{20}/A & \mu_{11}/A\\
\mu_{11}/A & \mu_{02}/A
\end{bmatrix}
\]

Its eigenvectors provide the principal spatial directions, while its eigenvalues describe the spread along those directions.

Additional descriptors:

- Area.
- Perimeter.
- Aspect ratio.
- Boundary curvature histogram.
- Junction count.
- Number of holes.
- Convexity.
- Solidity.
- Symmetry.
- Orientation distribution.
- Bounding-box geometry.

**Biological interpretation:** Population responses may encode aspects of spatial extent, orientation, curvature, and shape configuration. The particular descriptor vector is an engineering representation, not an established neural data structure.

**Result:** A structured geometric description for every part.

## N3-11 — Encode spatial relationships between parts

**Purpose:** Represent the relationships between separate components.

A collection of parts is not yet a complete shape.

The system must determine how the parts are arranged.

For example:

- Part A is above Part B.
- Part A is connected to Part B.
- Part A is inside Part B.
- Part A is to the left of Part B.
- Part A is attached to the endpoint of Part B.
- Part A is parallel to Part B.

These relationships are important because two shapes can contain similar elementary parts while having different arrangements.

**Possible mathematical operations**

Relative displacement:

\[
\Delta x_{ij}=x_j-x_i
\]

\[
\Delta y_{ij}=y_j-y_i
\]

Relative distance:

\[
d_{ij}=
\sqrt{\Delta x_{ij}^{2}+\Delta y_{ij}^{2}}
\]

Relative angle:

\[
\phi_{ij}=
\operatorname{atan2}(\Delta y_{ij},\Delta x_{ij})
\]

Orientation difference:

\[
\Delta\theta_{ij}=
\theta_i-\theta_j
\]

Relative size:

\[
\rho_{ij}=
\frac{A_i}{A_j+\epsilon}
\]

A relationship vector could be:

\[
R_{ij}=
[
\Delta x_{ij},
\Delta y_{ij},
d_{ij},
\phi_{ij},
\Delta\theta_{ij},
\rho_{ij}
]
\]

**Result:** A spatial relationship graph in which each edge contains geometric information.

---

## N3-12 — Organize compatible parts into local shape assemblies

**Purpose:** Combine several individual parts into larger configurations.

This is where N3 begins constructing hierarchical structures.

For example:

\[
\text{Edge segments}
\rightarrow
\text{Curved boundary}
\]

\[
\text{Curved boundary}+\text{Straight boundary}
\rightarrow
\text{Shape component}
\]

\[
\text{Shape component}_1+
\text{Shape component}_2
\rightarrow
\text{Larger shape assembly}
\]

The system should use evidence such as proximity, orientation compatibility, contour continuation, and shared figure–ground ownership.

**Possible mathematical operations**

A compatibility measure:

\[
C_{ij}=
\exp\left(
-\frac{d_{ij}^2}{2\sigma_d^2}
\right)
\exp\left(
-\frac{\Delta\theta_{ij}^2}{2\sigma_\theta^2}
\right)
\]

Additional terms can encode curvature compatibility, endpoint continuity, and common region membership.

Combined compatibility:

\[
C_{ij}^{*}=
w_dC_d+w_\theta C_\theta+
w_\kappa C_\kappa+w_oC_o
\]

A grouping score:

\[
Q(G')=
\sum_{(i,j)\in E'}C_{ij}^{*}
-\lambda |E'|
\]

This rewards mutually compatible components while controlling unnecessary connections.

Possible biological analogues include:

- Horizontal cortical interactions.
- Excitatory and inhibitory competition.
- Contour grouping.
- Recurrent association between feature populations.

**Result:** A hierarchy of local shape assemblies.

---

## N3-13 — Build V4-like shape-part populations

**Purpose:** Represent more complex boundary features and their positions relative to an entire candidate shape.

This is a particularly important stage.

Research on V4 shows that neural responses can be tuned to combinations of curvature and object-relative boundary position. A population of such responses can represent complex shapes through multiple boundary features. citeturn499662search0turn499662search3turn499662search4

Instead of representing:

> A curved segment exists.

N3 should be able to represent a more detailed relationship:

> A convex curved segment occurs near the upper-right part of the candidate shape.

That representation contains both shape information and relative-position information.

**Possible mathematical operations**

First calculate the candidate object's center:

\[
c_o=(x_o,y_o)
\]

For every boundary feature \(i\):

\[
\Delta x_i=x_i-x_o
\]

\[
\Delta y_i=y_i-y_o
\]

Relative angular position:

\[
\alpha_i=
\operatorname{atan2}(\Delta y_i,\Delta x_i)
\]

Its descriptor becomes:

\[
q_i=(\alpha_i,\kappa_i)
\]

A V4-inspired feature population can respond to a preferred combination:

\[
r_k=
\exp\left[
-\frac{d_{\text{angle}}(\alpha,\mu_{\alpha,k})^2}
{2\sigma_{\alpha,k}^2}
-\frac{(\kappa-\mu_{\kappa,k})^2}
{2\sigma_{\kappa,k}^2}
\right]
\]

Here \(d_{\text{angle}}\) is circular angular distance.

This creates populations selectively responsive to particular boundary configurations.

**Result:** An object-relative population of shape-part features.

# Level C — Hierarchical shape representations

## N3-14 — Construct larger receptive-field feature populations

**Purpose:** Allow higher-level populations to combine several local shape parts.

N3 now has local parts, their geometry, and their spatial relationships.

The next operation is to build populations that integrate information over a larger region.

For example, a population can respond to:

- A combination of several curves.
- A particular arrangement of corners.
- A specific relationship between a curved and a straight boundary.
- Several parts forming a characteristic overall contour.

**Possible mathematical operations**

Convergent weighted summation:

\[
u_i^{(l+1)}=
\sum_j W_{ij}^{(l)}
h_j^{(l)}
\]

Spatially extended convolution:

\[
u_i^{(l+1)}(x,y)=
\sum_j
K_{ij}^{(l)}*h_j^{(l)}(x,y)
\]

Nonlinear transformation:

\[
h_i^{(l+1)}=
\max(0,u_i^{(l+1)}-b_i)
\]

The receptive field expands because the new population integrates inputs covering a larger portion of the visual field.

**Biological interpretation:** Increasing spatial convergence across hierarchical visual areas.

**Result:** Complex shape-feature populations with larger receptive fields.

---

## N3-15 — Build intermediate position-tolerant representations

**Purpose:** Allow the representation of a feature to remain active when its position changes within an appropriate spatial neighborhood.

An object may move slightly while remaining the same object.

A visual representation that changes completely with every small displacement would be unsuitable for recognition.

One possible solution is pooling over nearby spatial locations.

**Possible mathematical operations**

Maximum pooling:

\[
z_i(x)=
\max_{\delta\in\mathcal N}
h_i(x+\delta)
\]

Soft maximum pooling:

\[
z_i(x)=
\tau
\log
\left[
\sum_{\delta\in\mathcal N}
\exp\left(\frac{h_i(x+\delta)}{\tau}\right)
\right]
\]

Here \(\tau\) controls how closely the operation resembles maximum pooling.

- Small \(\tau\): more strongly favors the maximum response.
- Larger \(\tau\): allows more responses to contribute.

**Biological interpretation:** Converging inputs over spatially extended receptive fields and pooling of neuronal activity.

**Important ORE requirement:** Do not discard the original location. Preserve both:

\[
Z_i=\text{pooled feature activity}
\]

\[
L_i=\text{estimated feature location}
\]

This allows N3 to tolerate small displacements without losing spatial precision.

---

## N3-16 — Develop scale and orientation tolerance

**Purpose:** Allow the same shape to generate related higher-level representations despite certain changes in scale or orientation.

The brain can recognize objects under different viewing conditions. However, invariance is not unlimited, and it develops progressively across the visual pathway.

Research directly comparing V4 and IT populations found increased tolerance to position, scale, and context in IT, alongside changes in feature selectivity. citeturn715200view1

**Possible mathematical operations**

Scale pooling:

\[
z_i^{scale}=
\operatorname{LSE}_{s\in\mathcal S}
(r_i(s))
\]

Where `LSE` is log-sum-exp.

Orientation pooling:

\[
z_i^{orientation}=
\operatorname{LSE}_{\theta\in\Theta}
(r_i(\theta))
\]

A more controlled version keeps separate transformation channels:

\[
Z_i=
[
r_i(s_1,\theta_1),
r_i(s_2,\theta_1),
r_i(s_1,\theta_2),
\ldots
]
\]

**Very important for ORE:** Orientation cannot simply be discarded.

In written characters, different orientations and reflections can distinguish otherwise similar forms. For example, a horizontally or vertically reflected character may represent a different grapheme.

Therefore N3 should:

1. Retain the original orientation-specific representation.
2. Create optional tolerant representations.
3. Record which transformations were applied.
4. Never assume that rotated or reflected patterns have identical identity.

**Result:** Multiple representations with controlled, measurable transformation tolerance.

---

## N3-17 — Create an object-centered coordinate representation

**Purpose:** Describe a candidate shape relative to its own center rather than only by absolute image coordinates.

The same shape can occur at different positions in the image.

An object-centered representation helps preserve its internal configuration.

For example, suppose two copies of the same shape exist at different locations. Their internal part arrangements may be similar even though their retinotopic coordinates differ.

**Possible mathematical operations**

Centering:

\[
x_i'=x_i-\bar{x}
\]

\[
y_i'=y_i-\bar{y}
\]

Scale normalization:

\[
x_i''=\frac{x_i'}{s_o+\epsilon}
\]

\[
y_i''=\frac{y_i'}{s_o+\epsilon}
\]

Where \(s_o\) may be derived from object size.

Optional rotation alignment:

\[
\begin{bmatrix}
x_i'''\\y_i'''
\end{bmatrix}
=
\begin{bmatrix}
\cos\alpha&-\sin\alpha\\
\sin\alpha&\cos\alpha
\end{bmatrix}
\begin{bmatrix}
x_i''\\y_i''
\end{bmatrix}
\]

But this rotation normalization should be optional, and the original object orientation must be retained.

**Biological interpretation:** Object-relative coding is relevant to the representation of boundary features in visual cortex, particularly V4. The explicit normalization formula is an engineering method for building such a representation, not a proven description of the brain's exact process. citeturn499662search1

**Result:** An object-centered representation preserving the original retinotopic coordinates.

---

## N3-18 — Construct hierarchical part-to-whole shape configurations

**Purpose:** Combine shape assemblies into candidate whole shapes.

This is a central operation of N3.

The system now possesses several levels of representation:

\[
\text{Features}
\rightarrow
\text{Contour fragments}
\rightarrow
\text{Shape parts}
\rightarrow
\text{Part assemblies}
\]

N3 should combine these into candidate whole-shape structures.

**Possible mathematical operations**

Represent each candidate whole shape as a graph:

\[
H_k=(V_k,E_k)
\]

Where:

- \(V_k\) represents shape parts.
- \(E_k\) represents relationships between those parts.

Evaluate a candidate using multiple sources of evidence:

\[
Score(H_k)=
w_1F_k+
w_2R_k+
w_3B_k+
w_4G_k
\]

Where:

- \(F_k\): feature compatibility.
- \(R_k\): relational compatibility.
- \(B_k\): boundary consistency.
- \(G_k\): global geometric consistency.

A probabilistic alternative:

\[
P(H_k\mid X)\propto
P(X\mid H_k)P(H_k)
\]

Here \(P(H_k)\) represents previously learned structural regularities, if learning has been enabled.

**Biological interpretation:** Convergence of multiple shape-part signals into more complex configurations, with interaction between feedforward and recurrent neural populations.

Studies of V4 and posterior IT suggest a gradual synthesis of simpler contour components into more complex shape configurations. citeturn499662search5

**Result:** Multiple candidate whole-shape representations.

---

## N3-19 — Develop an IT-like high-level feature population

**Purpose:** Produce a more abstract representation of complex shapes.

This is the highest-level feedforward representation in the initial N3 architecture.

The goal is not to give a shape a word or semantic name.

Instead, the system should produce a stable high-dimensional neural-style representation that captures the arrangement of its visual features.

For example, two different images depicting the same simple object could produce similar high-level population patterns despite differences in position or size.

**Possible mathematical operations**

A high-level feature response:

\[
a_i=
\phi
\left(
W_i^\top z-b_i
\right)
\]

Where \(z\) contains the assembled shape features.

The complete population activity is:

\[
\mathbf a=
[a_1,a_2,\ldots,a_n]
\]

Similarity between representations:

\[
Similarity(A,B)=
\frac{A\cdot B}
{\|A\|\|B\|+\epsilon}
\]

This produces a numerical measure of how similar two shape representations are.

**Biological interpretation:** IT population activity represents complex visual information in distributed patterns. The representation should not depend upon a single special neuron for every possible object; IT population coding is much more distributed than such a simplistic model would imply. citeturn499662search7

**Result:** An IT-inspired population code for candidate shapes.

---

## N3-20 — Introduce population normalization and competition

**Purpose:** Prevent every feature population from responding excessively and help determine which candidate representations are most strongly supported.

The brain uses interactions between excitatory and inhibitory processes to regulate neuronal responses.

One particularly important candidate canonical computation is divisive normalization.

It has been studied across different levels of visual processing. citeturn699953search0turn699953search3turn699953search5

**Possible mathematical operations**

Divisive normalization:

\[
r_i=
\frac{u_i}
{
\left(
\epsilon+
\sum_jw_{ij}|u_j|^p
\right)^{1/p}
}
\]

Where:

- \(u_i\): original activation.
- \(w_{ij}\): influence of population \(j\).
- \(p\): normalization exponent.
- \(\epsilon\): numerical stability term.

Competition between candidates:

\[
P(H_i)=
\frac{\exp(S_i/T)}
{\sum_j\exp(S_j/T)}
\]

Where \(T\) is a temperature parameter.

**Additional operations**

- Inhibitory interaction.
- Winner-take-most competition.
- Lateral suppression.
- Population gain control.
- Sparse activation.

The system should not automatically force a single winner. Several candidate shapes may remain active when visual information is ambiguous.

**Result:** A controlled population representation with competing candidate activations.

---

## N3-21 — Integrate ventral and dorsal visual representations

**Purpose:** Connect shape information with spatial information without destroying the distinction between the two.

The ventral pathway is commonly associated with object and form processing, while the dorsal pathway contributes spatial and action-related visual processing.

N2 already exposes separate ventral and dorsal populations. N3 should preserve this architectural distinction.

**Possible mathematical operations**

Feature integration:

\[
Z_{combined}=
W_vZ_v+W_dZ_d
\]

However, the combined representation must not replace the original streams.

A better engineering structure is:

\[
Z=
\{
Z_v,Z_d,Z_{interaction}
\}
\]

Interaction information can encode relationships between a shape and its location:

\[
Z_{interaction}=f(Z_v,Z_d)
\]

For example:

- Shape identity candidates.
- Location of the candidate shape.
- Spatial relationships with neighboring regions.
- Orientation relative to the image.
- Relative position among other candidate shapes.

**Biological interpretation:** Interaction between interconnected visual processing streams. The exact mathematical fusion above is an ORE design choice, not a claim that the brain uses a single weighted-sum operation between the two streams.

**Result:** A combined representation retaining separate form and spatial information.

# Level D — Recurrent visual interpretation

## N3-22 — Apply attention and feature-selection modulation

**Purpose:** Allow some visual features to influence processing more strongly than others.

Attention can influence visual neural responses and the amount of information contributed by different features.

The importance of a feature can depend on:

- Its visual salience.
- Its relationship to the current candidate shape.
- Its uncertainty.
- Its location.
- Its relevance to an ongoing recognition process.

**Possible mathematical operations**

Define an attention weight:

\[
g_i=1+\alpha A_i
\]

Where \(A_i\) represents estimated attentional influence.

Modulated response:

\[
r_i'=g_i r_i
\]

Alternatively, use a normalized gain function:

\[
g_i=
\frac{\exp(a_i/T)}
{\sum_j\exp(a_j/T)}
\]

A more sophisticated implementation can combine bottom-up saliency with top-down relevance:

\[
A_i=
w_sS_i+
w_uU_i+
w_tT_i
\]

Where:

- \(S_i\): saliency.
- \(U_i\): uncertainty-related importance.
- \(T_i\): top-down relevance.

**Biological interpretation:** Gain modulation and competition between neural populations.

**Result:** A dynamically modulated visual representation.

---

## N3-23 — Execute the initial hierarchical feedforward sweep

**Purpose:** Propagate information from lower to higher visual representations to obtain an initial interpretation.

At this point, the system has already built multiple feature and shape levels.

It must now perform an ordered processing pass.

The conceptual direction is:

\[
N1\rightarrow N2\rightarrow
V2\text{-like}\rightarrow
V4\text{-like}\rightarrow
IT\text{-like}
\]

This does not mean that actual biological pathways contain only these stages. They contain many interconnected areas, and this is a functional approximation.

**Possible mathematical operations**

For every hierarchical level:

\[
h^{(l+1)}=
\phi
\left(
W^{(l)}h^{(l)}+b^{(l)}
\right)
\]

The overall feedforward transformation is:

\[
H^{(L)}=
f_L(f_{L-1}(\ldots f_2(f_1(H^{(0)}))))
\]

**Result:** An initial high-level interpretation of the visual stimulus.

This initial representation may be sufficient for easy visual recognition, while more difficult images may benefit from additional recurrent processing. Research describes early feedforward processing followed by further refinement through feedback interactions. citeturn715200view2

---

## N3-24 — Generate top-down predictions from higher visual levels

**Purpose:** Allow higher-level shape representations to influence lower-level processing.

A purely feedforward architecture cannot fully reproduce the recurrent nature of biological vision.

Suppose a higher-level candidate shape becomes active.

It can provide information about the lower-level visual structures that would be expected if that candidate were correct.

For example, a high-level shape hypothesis might predict:

- Particular contour positions.
- Particular boundary orientations.
- A particular arrangement of shape parts.
- The presence of expected junctions.

**Possible mathematical operations**

Top-down prediction:

\[
\hat h^{(l)}=
W_{fb}^{(l)}h^{(l+1)}
\]

The prediction is mapped to the representational space of the lower level.

Prediction error:

\[
e^{(l)}=
h^{(l)}-\hat h^{(l)}
\]

This error represents the difference between actual lower-level activity and the predicted activity.

**Biological interpretation:** Feedback projections from higher cortical areas can convey contextual and predictive information to lower areas.

Predictive coding is one theoretical framework for describing these interactions. It proposes hierarchical predictions and error signals, although the exact neural implementation remains an active research question. citeturn699953search9turn715200view2

**Result:** Top-down predictions and corresponding error representations.

---

## N3-25 — Perform recurrent refinement and prediction-error correction

**Purpose:** Improve an initial visual representation by repeatedly combining bottom-up evidence, local interactions, and higher-level predictions.

This is where the hierarchical visual architecture becomes recurrent rather than merely sequential.

N2 already contains a bounded recurrence operation. N3 should generalize this concept across the hierarchy.

At every iteration, lower and higher feature levels can exchange information.

**Possible mathematical operations**

A recurrent update:

\[
h_l^{t+1}=
\phi
\left(
W_{ff}f_l+
W_{lat}h_l^t+
W_{fb}h_{l+1}^t-b_l
\right)
\]

Where:

- \(f_l\): bottom-up input.
- \(h_l^t\): current activity.
- \(h_{l+1}^t\): higher-level activity.
- \(W_{ff}\): feedforward connections.
- \(W_{lat}\): lateral connections.
- \(W_{fb}\): feedback connections.

A predictive-error-based formulation can additionally define:

\[
E=
\sum_l
\epsilon_l^\top
\Pi_l
\epsilon_l
\]

Where \(\Pi_l\) controls the precision assigned to each level.

The system can update its state in the direction of reducing that energy:

\[
h^{t+1}=h^t-\eta\nabla_h E
\]

This is a model of iterative inference, not a proof that the brain literally computes this global energy function.

**Convergence measurement**

\[
\Delta_t=
\frac{\|h^{t+1}-h^t\|_2}
{\|h^t\|_2+\epsilon}
\]

Stop when:

\[
\Delta_t<\tau
\]

or when the maximum number of iterations is reached.

The system should also record whether convergence occurred, whether the result oscillated, and whether the update increased prediction error.

**Result:** A refined hierarchical representation with measurable convergence behavior.

# Level E — Learning, memory, and output

## N3-26 — Integrate temporal visual information (optional)

**Purpose:** Preserve visual information over time when N3 receives a sequence of frames.

A single image provides spatial information but cannot, by itself, establish actual visual motion.

N2 already identifies this distinction: its dorsal output does not claim to calculate motion energy from a single frame.

N3 should therefore make temporal integration optional.

**Possible mathematical operations**

Leaky temporal integration:

\[
z_t=
\alpha z_{t-1}
+(1-\alpha)r_t
\]

Where:

\[
\alpha=e^{-\Delta t/\tau}
\]

This allows a current feature representation to depend partly on its previous state.

A more general Bayesian temporal update:

\[
P(H_t\mid I_{1:t})
\propto
P(I_t\mid H_t)
\sum_{H_{t-1}}
P(H_t\mid H_{t-1})
P(H_{t-1}\mid I_{1:t-1})
\]

This represents the integration of current sensory evidence with previous hypotheses.

**Biological interpretation:** Temporal integration, persistence of neural activity, and interactions between current and preceding sensory evidence.

**Result:** A temporally informed representation when sequences are available; otherwise, this operation remains disabled.

---

## N3-27 — Implement adaptive learning of hierarchical visual features

**Purpose:** Allow N3 to learn recurring visual configurations from experience instead of depending entirely on manually predefined feature templates.

This is especially important for developing a flexible ORE architecture.

If N3 uses only manually specified templates, the number of possible configurations will become difficult to manage.

The system should eventually learn:

- Frequently occurring feature combinations.
- Typical curvature configurations.
- Relationships between shape parts.
- Repeated boundary structures.
- More complex shape assemblies.

**Possible mathematical operations**

Hebbian-like learning:

\[
\Delta w_{ij}=
\eta x_i y_j
\]

Where:

- \(x_i\): presynaptic activity.
- \(y_j\): postsynaptic activity.
- \(\eta\): learning rate.

A regularized version:

\[
\Delta w_{ij}=
\eta x_i y_j-\lambda w_{ij}
\]

Prototype adaptation:

\[
\mu_k^{new}
=
\mu_k^{old}+
\eta a_k
(z-\mu_k^{old})
\]

This gradually adjusts a learned prototype toward the observed representation.

Population stabilization can be approximated through homeostatic activity regulation:

\[
b_i^{new}
=
b_i^{old}
+
\eta_h(\bar r_i-r_{target})
\]

**Important design distinction**

N3 should initially support two separate modes:

1. **Inference mode:** Uses learned parameters without changing them.
2. **Learning mode:** Updates parameters from approved training examples.

This will make experiments repeatable and prevent the model from silently changing during normal evaluation.

**Result:** Adaptable hierarchical feature populations.

---

## N3-28 — Evaluate confidence and preserve alternative visual interpretations

**Purpose:** Determine how strongly the available visual evidence supports the current representation.

A visual system should not always assume that its most active candidate is correct.

For example, a partially obscured shape may support multiple plausible configurations.

N3 should preserve uncertainty instead of automatically converting an ambiguous image into one definite interpretation.

**Possible mathematical operations**

Normalize candidate scores:

\[
P(H_i)=
\frac{\exp(S_i/T)}
{\sum_j\exp(S_j/T)}
\]

Calculate entropy:

\[
\mathcal H=
-\sum_iP(H_i)\log(P(H_i)+\epsilon)
\]

Low entropy means that the probability distribution is concentrated around a small number of hypotheses.

High entropy indicates greater ambiguity.

Confidence can additionally depend on the strength of the sensory evidence and the prediction error:

\[
C=
f(
\text{evidence},
\text{uncertainty},
\text{prediction error},
\text{convergence}
)
\]

The precise confidence formula must be calibrated empirically.

**Result:** Candidate shape representations with confidence and uncertainty information.

**Purpose:** Make the N3 representation available to later ORE phases.

N3 should not simply return a single numerical feature vector.

The main outcome should be a structured description of how the visual input is organized.

A conceptual output should contain:

| Output | Description |

# 3. Consolidated mathematical operations

The 29 operations above can be classified according to the mathematical families that they use.

| Mathematical family | Examples | Main purpose |
|---|---|---|
| Linear algebra | Weighted summation, matrix multiplication | Combining neural inputs |
| Convolution | Spatial filtering, receptive-field integration | Detecting local and broader features |
| Nonlinear functions | ReLU, thresholding, multiplicative gating | Feature selectivity |
| Differential calculus | First and second derivatives, curvature | Describing boundary geometry |
| Statistics | Mean, variance, covariance, entropy | Characterizing visual populations |
| Spatial geometry | Distances, angles, centroids, transformations | Describing shape and part relationships |
| Graph theory | Adjacency, graph composition, connectivity | Organizing components |
| Probability | Softmax, Bayesian inference | Representing competing interpretations |
| Optimization | Error minimization, iterative updates | Recurrent refinement |
| Temporal mathematics | Exponential integration, Bayesian filtering | Combining information across time |
| Learning rules | Hebbian updates, prototype adaptation | Learning recurring feature configurations |
| Population dynamics | Normalization, inhibition, competition | Regulating neural activity |

The most important mathematical principle is that these computations should not be treated as isolated operations. They must form a connected hierarchy, with each level transforming the representations produced by earlier levels.

# 6. Important architectural decisions for ORE

I would make the following decisions part of the N3 specification, not leave them as implementation details.

**1. Never destroy the original spatial representation.**

N1 and N2 already preserve useful spatial information. N3 may create increasingly abstract representations, but it must keep lower-level data accessible.

**2. Preserve both retinotopic and object-centered coordinates.**

The object-centered representation is useful for shape recognition, while retinotopic information is essential for locating the shape and preserving the arrangement of visual elements.

**3. Use progressive, not absolute, invariance.**

Do not make all shapes invariant to every rotation, reflection, or scale change. In orthographic processing, small geometric changes can be identity-relevant.

**4. Treat the hierarchy as interacting populations, not simply a deep CNN.**

A purely feedforward network can provide a useful first approximation, but N3 should support lateral interactions, feedback, recurrent refinement, and separate feature populations. citeturn715200view2

**5. Preserve alternatives when evidence is ambiguous.**

The architecture should represent uncertainty rather than force every image into one interpretation.

**6. Keep learning separate from inference.**

The N3 system should be capable of running with fixed parameters, while learning experiments can be enabled independently.

| Scale tolerance | Retains selected similarities across tested size changes |

| Population coding | Produces finite, reproducible high-level responses |

| Learning | Updates parameters only when learning mode is enabled |
| Integration | Preserves compatibility with existing N1 and N2 outputs |

Scientific validation should be a separate milestone. Passing synthetic software tests does not prove that N3 reproduces biological visual processing. To make physiological claims, its responses would need comparison with controlled visual stimuli and independent experimental measurements.

---

## Final architectural position

N1 establishes early visual feature extraction.

N2 establishes visual organization: boundaries, contours, figure–ground relationships, fragments, and structural topology.

**N3 establishes hierarchical shape representation.**

The resulting development sequence is:

\[
\boxed{
\begin{aligned}
N1 &: \text{Visual feature extraction}\\
N2 &: \text{Visual organization}\\
N3 &: \text{Hierarchical shape representation}
\end{aligned}
}
\]

N3 is therefore the bridge between visual organization and a later orthographic recognition system. It gives ORE the ability to represent a visual pattern as a structured hierarchy of parts and whole-shape configurations, while retaining the spatial and geometric evidence that a subsequent grapheme-recognition stage will need.

The canonical repository for the next implementation stage remains [wizekin/ORE-Neurocomputational](https://github.com/wizekin/ORE-Neurocomputational).

My recommendation is to treat the **29 operations above as the N3 master algorithm**, then implement them in small, independently testable groups while keeping the N1 and N2 contracts unchanged.
