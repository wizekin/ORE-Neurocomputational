## 4. The most important new mathematical concept

I consider the most important N9 addition to be **hierarchical recurrent inference across different representational levels**.

Earlier stages can calculate predictions and errors within their own processing domains. N9 connects these computations.

For example:

1. Visual processing proposes that a word might be `bank`.
2. Orthographic processing checks whether its letters and order support that candidate.
3. Lexical processing retrieves its possible meanings.
4. Contextual processing determines which meaning is compatible with the surrounding text.
5. Syntactic processing determines how the word participates in the sentence.
6. Semantic processing constructs the corresponding proposition.
7. Higher-level feedback adjusts the attention and processing priorities of unresolved lower-level evidence.

The integrated system uses a free-energy-like objective:

\[
F(q)=
E_q[E(Z)]
+\beta KL(q(Z)\|p(Z|C))
+\lambda C_{\text{constraints}}
\]

This combines prediction-error energy, divergence from contextual priors and structural consistency penalties.

The posterior is then revised through bounded updates:

\[
q^{t+1}=
\operatorname{normalize}
\left[
(1-\rho)q^t+
\rho\operatorname{softmax}
(\log q^t-\eta\nabla F)
\right]
\]

This is a proposed computational implementation, not an established equation used literally by neurons.

The design is consistent with research on orthographic prediction errors, distributed visual-to-language pathways and dynamic semantic prediction/integration. <Cite refs={["turn348825search5","turn348825search1","turn114146search3","turn114146search13"]}/>

## 5. What N9 adds beyond the current N8

Three particularly important extensions are:

- **Phonological interface:** optional mapping between graphemes, pronunciation and phonological alternatives.
- **Syntactic-semantic composition:** constructing sentence structures, thematic roles and propositions rather than stopping at individual word meanings.
- **Global predictive coordination:** allowing semantic, lexical, syntactic and visual processing to exchange predictions and errors.

These are proposed N9 capabilities, not features that I am claiming the current N1–N8 implementation already possesses.

One important research principle should govern the entire implementation: **top-down expectations must never silently overwrite bottom-up visual evidence.** The system must retain competing interpretations and be capable of abstaining.

The next engineering milestone should be to implement N9's integration controller and typed cross-module interfaces before attempting to implement all 120 operations as one large Python module. This will keep the architecture testable and allow each subsystem to be evaluated independently.

- Visual evidence remains separate from top-down predictions, and uncertain recognition can abstain.
