## 2. Implemented mathematical and functional algorithms

The implementation maintains two independent representations.

**Prototype representation**

- Reliability-weighted incremental means and variances.
- Categorical feature distributions.
- Feature prevalence and diagnosticity.
- Category-level uncertainty and typicality.
- Covariance-aware exception detection using Mahalanobis distance.

**Exemplar representation**

- Individual episode storage with distinct identifiers.
- Preservation of feature combinations, context, and relations.
- Similarity-based episodic retrieval.
- Memory accessibility using exponential decay.
- Retrieval and rehearsal strength adjustments.
- Protection of unusual but informative category members.

**Hybrid classification**

The algorithm compares both representations using:

\[
d(\mathbf{x},\mathbf{p})=
\left(\sum_i w_i|x_i-p_i|^r\right)^{1/r}
\]

\[
S_P=e^{-cd_P}
\]

It also implements exemplar similarity aggregation, category-prior integration, stable softmax probabilities, and a dynamically controlled prototype/exemplar mixture:

\[
S_H=\alpha S_P+(1-\alpha)S_E
\]

The mixing coefficient is determined by a logistic controller that considers prototype reliability, exemplar evidence, typicality, exceptions, and task context.

## 3. Important mathematical algorithms

### Temporal co-occurrence

Implemented an eligibility function:

\[
e_{ij}=\exp\left(-\frac{|t_i-t_j|}{\tau}\right)
\]

It measures the temporal relationship between features from different modalities.

The association learning rule is:

\[
C_{ij}^{t+1}
=
\rho C_{ij}^{t}
+
\eta x_i x_j e_{ij}
\]

Here:
- \(\rho\): retention factor.
- \(\eta\): learning rate.
- \(x_i,x_j\): feature activation strengths.
- \(e_{ij}\): temporal eligibility.

Associations are created only when the experience contains valid modality timestamps within the configured temporal window.

### Cross-modal retrieval

Implemented spreading activation:

\[
a_j =
x_i C_{ij} g
\]

where \(g\) controls the recall strength.

This allows the model to reactivate previously associated features from a different modality.

### What was implemented

The new `ore_schema_guided_inference` package builds on Point 09's schema frames rather than duplicating schema formation.

It implements:

1. **Evidence processing:** distinguishes observed, contradicted, unknown, and unobserved information, retaining reliability and source.
2. **Schema retrieval:** activates and ranks candidate schemas using semantic cues, context, goals, and prior probabilities.
3. **Bayesian-style inference:** combines feature likelihoods, relational compatibility, context, goals, and event-transition evidence.
4. **Prediction:** infers missing properties, participant roles, relations, and likely next events, preserving inferred provenance.
5. **Hierarchical categorization:** selects a specific category, falls back to a broader category, or abstains when confidence is insufficient.
6. **Active information gathering:** selects useful queries using expected information gain, cost, and risk.
7. **Action selection:** compares expected utility and risk before recommending an action.
8. **Feedback and learning:** scores tested predictions using Brier score and surprise; reusable schema probabilities change only after explicit authorization and repeated validated cases.
9. **Evidence preservation:** keeps earlier observations and retrieved episodes separate from current evidence and schema-generated predictions.

### Biological and mathematical models

The implementation includes computational surrogates for:

- Distributed temporal-semantic activation.
- Medial prefrontal context and goal control.
- Hippocampal episodic comparison.
- Attention and conflict monitoring.
