## Biological implementation

The system includes a separate LIF (leaky integrate-and-fire) neural reference simulation with nine interacting populations:

- Orthographic input and lexical-category populations.
- Temporal syntax and frontal control populations.
- Phrase-binding and dependency-relation populations.
- Thematic-role and working-memory populations.
- Prediction-error monitoring.

It also implements mathematical operations including:

- Temperature-scaled softmax and logarithmic scoring.
- Cosine similarity for semantic compatibility.
- Weighted grammar rules and dynamic programming.
- Distance penalties and dependency-arc scoring.
- Recurrent probability updates and entropy.
- Membrane-potential integration, spike thresholds, refractory periods and firing-rate calculations.

These are biologically motivated computational approximations, not a validated reproduction of human neural activity.

**Important implementation boundary:** This is an initial, transparent, rule-based English parser. It accepts lexical and semantic evidence from upstream ORE components, preserves competing interpretations, and exposes its intermediate calculations. It is not yet a general-purpose, treebank-trained parser.

The next valuable integration step is connecting this package directly to `ore_lexical_access` and `ore_semantic`, so grammatical categories and semantic features come from the preceding ORE processing stages rather than relying on the syntax package's compact demonstration inventories.
