# Integrated Brain Sensory and Perceptual Processing Algorithm

The six processes can be organized into one large algorithm that converts raw visual and auditory input into structured representations that the language system can use.

The algorithm has **two major sensory pathways**:

1. **Visual pathway:** raw page image → text-region detection → character and letter-pattern analysis.
2. **Auditory pathway:** sound waves → auditory signal analysis → acoustic features → phonetic features → phoneme categories.

These pathways are not completely independent. Visual word recognition can activate phonological representations, while auditory speech perception can be influenced by linguistic knowledge and context. Both pathways therefore interact with higher-level language systems. [Reading review](https://doi.org/10.1146/annurev-vision-093019-113509) <Cite refs={["turn160817search0","turn160817search5"]}/>.

## 1. Important biological distinction

The brain does not execute a rigid sequence of software-like operations in which one stage finishes before the next begins.

Instead, it uses:

- Hierarchical processing: increasingly complex representations are constructed from simpler ones.
- Parallel processing: different features are analyzed simultaneously.
- Recurrent processing: higher-level interpretations send feedback to earlier processing stages.
- Population coding: information is represented by patterns of activity across groups of neurons.
- Probabilistic interpretation: uncertain sensory evidence is combined with learned knowledge and context.

The equations below are **mathematical models of plausible neural computations**. They are useful for building a biologically inspired simulation, but they should not be interpreted as exact equations that individual neurons literally calculate.

# Part I — Visual sensory and perceptual processing

<box gap={2}>
  <title size="lg">Stage 1 — Automatic text-region detection</title>
  <AsyncImage query="printed book page grayscale closeup text paragraphs lines typography" aspectRatio="16:9" width="100%" />
  <text color="secondary" size="xs">Input: an image of a page, sign, screen, or other visual scene containing possible writing.</text>
</box>

**Objective:** Determine which parts of the visual scene are likely to contain written text, before attempting to identify individual characters.

The brain initially receives a visual scene containing many things: edges, surfaces, objects, shadows, lines, and potentially written symbols. It must prioritize regions that have properties associated with text.

This is not necessarily a dedicated text-detection module. It is a combination of general visual processing, spatial attention, perceptual grouping, and learned sensitivity to familiar writing patterns.

### Step 1.1 — Receive the visual input

Light reflected from the page enters the eye and is focused onto the retina.

Photoreceptors convert light into neural signals. Retinal circuits begin processing local changes in brightness and contrast before transmitting information through the optic nerve.

**Possible mathematical operations**

Represent a simplified image as:

\[
I(x,y,c)
\]

where:

- \(x,y\) are spatial coordinates.
- \(c\) is a color channel.

A simplified luminance representation is:

\[
L(x,y)=0.299R+0.587G+0.114B
\]

The brain does not calculate these RGB coefficients. This is an engineering approximation for representing luminance in a model.

Local contrast can be approximated by:

\[
C(x,y)=
\frac{L(x,y)-\mu_{\mathcal N(x,y)}}
{\mu_{\mathcal N(x,y)}+\epsilon}
\]

where:

- \(\mu_{\mathcal N(x,y)}\) is the average luminance in a surrounding region.
- \(\epsilon\) prevents division by zero.

This represents sensitivity to a local difference between a visual location and its surroundings.

**Biological interpretation:** Retinal and early visual mechanisms emphasize local contrast, changes in luminance, and spatial structure.

### Step 1.2 — Extract primitive visual features

Signals arriving at early visual cortex are analyzed for properties such as:

- Orientation.
- Edge direction.
- Contrast.
- Spatial frequency.
- Local contours.
- Corners and line intersections.

Neurons in early visual areas have receptive fields that respond preferentially to particular visual patterns.

For example, one neural population may respond strongly to a nearly vertical edge, while another responds to a horizontal edge.

**Possible mathematical operations**

A biologically inspired model can use oriented Gabor-like filters:

\[
G_{\theta,f}(x,y)=
\exp\left(
-\frac{x'^2+\gamma^2y'^2}{2\sigma^2}
\right)
\cos(2\pi f x'+\phi)
\]

where:

\[
x'=x\cos\theta+y\sin\theta
\]

\[
y'=-x\sin\theta+y\cos\theta
\]

Here:

- \(\theta\): preferred edge orientation.
- \(f\): spatial frequency.
- \(\sigma\): receptive-field scale.
- \(\gamma\): aspect ratio.
- \(\phi\): phase.

The response of a filter is:

\[
R_{\theta,f}(x,y)=
(I*G_{\theta,f})(x,y)
\]

The symbol \(*\) means convolution.

A collection of filters produces an orientation-and-scale response map.

**Biological purpose:** Construct an early representation of the page's visual geometry. This gives later processing stages evidence about where repeated character-like structures may exist.

### Step 1.3 — Detect text-like spatial organization

Text is not simply a collection of dark pixels. It has characteristic spatial organization.

Examples include:

- Repeated small shapes.
- Nearby contours with similar heights.
- Multiple objects arranged along approximately common baselines.
- Consistent spacing patterns.
- Repeated line structures.
- Contrast patterns that differ from surrounding graphics or photographs.

The visual system can combine these cues to identify regions that deserve further analysis.

**Possible mathematical operations**

First, compute a local feature vector:

\[
\mathbf v_i =
[
e_i,o_i,s_i,d_i,c_i
]
\]

where:

- \(e_i\): edge density.
- \(o_i\): orientation distribution.
- \(s_i\): spatial frequency characteristics.
- \(d_i\): local element density.
- \(c_i\): contrast statistics.

Then estimate the likelihood that a region is text:

\[
P(T_i\mid\mathbf v_i)=
\frac{
P(\mathbf v_i\mid T_i)P(T_i)
}{
P(\mathbf v_i)
}
\]

Here \(T_i\) means that region \(i\) contains text.

In a neural simulation, this posterior probability can be approximated by a population of units with different response preferences.

For example:

\[
a_i=\sigma(\mathbf w_i^\top\mathbf v_i+b_i)
\]

where \(\sigma\) is an activation function.

The activation becomes stronger when the local pattern resembles previously learned writing patterns.

### Step 1.4 — Group neighboring text-like elements

After detecting candidate elements, the brain must determine which elements belong together.

Consider these two arrangements:

and:

Individual edges and letter-like shapes are present in both, but their spatial organization differs.

The brain uses spatial relationships and perceptual grouping to build larger structures.

**Possible mathematical operations**

For candidate elements \(i\) and \(j\), calculate a grouping score:

\[
G_{ij}=
w_dD_{ij}
+w_hH_{ij}
+w_aA_{ij}
+w_bB_{ij}
\]

where:

- \(D_{ij}\): distance between elements.
- \(H_{ij}\): similarity of heights.
- \(A_{ij}\): alignment similarity.
- \(B_{ij}\): baseline consistency.

A distance function might be:

\[
D_{ij}=
\exp\left(
-\frac{\|\mathbf p_i-\mathbf p_j\|^2}{2s^2}
\right)
\]

The system can then form groups through recurrent interactions between nearby elements.

An important qualification: the brain does not need to create explicit bounding boxes. The grouping may exist as a distributed pattern of neural activity representing spatial relationships.

### Step 1.5 — Identify probable text-region boundaries

The system estimates the spatial extent of a candidate text region.

It may distinguish:

- Text from photographs.
- Text from diagrams.
- Text from decorative borders.
- Individual text columns.
- Text lines within paragraphs.

A simplified model calculates a region-level confidence:

\[
P(T_R\mid E_R)
\]

where \(E_R\) represents all the available evidence for region \(R\).

The region receives greater priority when it has:

- Consistent visual structure.
- Repeated character-like elements.
- Regular alignment.
- Strong contrast from its surroundings.

### Step 1.6 — Direct visual attention toward the region

Once a region has been selected, attention can increase the processing priority of visual information in that location.

This does not mean that everything outside the region disappears. Rather, the selected information can receive stronger processing relative to competing information.

**Possible mathematical operations**

Let \(r_i\) represent a sensory response and \(a_i\) represent attentional gain:

\[
r_i'=a_ir_i
\]

For a competitive population:

\[
a_i=
\frac{\exp(z_i)}
{\sum_j\exp(z_j)}
\]

This softmax is a convenient mathematical model of normalized competition, not a claim that the brain uses this exact equation.

**Stage 1 output:**

\[
O_1=
\{
\text{text-region candidates},
\text{spatial boundaries},
\text{confidence values},
\text{attention priorities}
\}
\]

## Stage 2 — Automatic character segmentation from raw pages

<AsyncImage query="close up printed typography individual letters words black ink white paper" aspectRatio="16:9" width="100%" />

**Objective:** Transform the visual patterns within selected text regions into structured representations of letters and their positions.

This stage is particularly important because the brain must identify letters despite changes in font, size, spacing, position, and surrounding letters.

However, biological character segmentation is not equivalent to drawing a rectangular box around every character.

The brain can process multiple letters simultaneously, and letter representations can overlap. It is better to think of this stage as **progressive grouping and separation of letter information**.

### Step 2.1 — Detect local character-like structures

The brain analyzes the arrangement of contours within the text region.

Potential features include:

- Vertical strokes.
- Horizontal strokes.
- Curves.
- Enclosed spaces.
- Intersections.
- Diagonal lines.
- Ascenders and descenders.
- Junctions and endpoints.

**Possible mathematical operations**

For a local image region \(I_r\), calculate a set of filter responses:

\[
\mathbf f_r=
[
R_1,R_2,\ldots,R_n
]
\]

The system can compare those responses against learned visual feature combinations.

A simplified population response to a feature prototype \(\boldsymbol\mu_k\) can be:

\[
d_k=
\|\mathbf f_r-\boldsymbol\mu_k\|^2
\]

\[
a_k=
\exp\left(-\frac{d_k}{2\sigma_k^2}\right)
\]

A neuron or neuronal population would not necessarily store an explicit prototype vector. This is a computational representation of the idea that some visual patterns evoke stronger responses than others.

### Step 2.2 — Combine local features into candidate letters

Letters are not defined by individual lines or curves alone. They are defined by combinations and relationships between those features.

For example, a candidate letter may depend on:

- The number of strokes.
- The relative position of strokes.
- Whether a curve is open or closed.
- Whether two strokes intersect.
- The orientation of the main structure.

The visual system combines these features to distinguish possible letter identities.

**Possible mathematical operations**

Let a candidate letter be represented by:

\[
\mathbf c_k=
[
c_1,c_2,\ldots,c_m
]
\]

A weighted similarity score is:

\[
S_k=
\sum_{j=1}^{m}w_jf_jc_{kj}
\]

The system evaluates several candidates rather than necessarily selecting one immediately.

\[
P(C_k\mid\mathbf f)
\propto
P(\mathbf f\mid C_k)P(C_k)
\]

This allows ambiguous visual forms to remain unresolved until more evidence becomes available.

### Step 2.3 — Separate overlapping neighboring letters

Letters are close together, and their visual features can interact.

The brain must distinguish:

- Features belonging to one letter.
- Features belonging to a neighboring letter.
- Features shared by multiple possible groupings.
- Spaces that help indicate character boundaries.

This becomes especially challenging when letters are crowded or connected by handwriting and typography.

**Possible mathematical operations**

For two neighboring feature groups \(A\) and \(B\), a simplified grouping score can use spatial proximity:

\[
S(A,B)=
\alpha S_{\text{proximity}}
+\beta S_{\text{continuity}}
+\gamma S_{\text{shape}}
+\delta S_{\text{spacing}}
\]

A candidate segmentation is evaluated by how well its components explain the observed image:

\[
P(\mathcal S\mid I)
\propto
P(I\mid\mathcal S)P(\mathcal S)
\]

Here \(\mathcal S\) is a possible arrangement of character groups.

The model can maintain competing segmentation hypotheses when the image is ambiguous.

### Step 2.4 — Encode letter positions and order

Identifying the letters is not enough. Their order matters.

For example:

- FORM
- FROM

The same letters are present, but their order differs.

The visual system therefore needs a representation that retains the relative position of letters while becoming less dependent on their exact retinal coordinates.

A 2025 study using 7T fMRI and MEG reported a progression from predominantly retinal-position coding in early visual areas toward more abstract, word-centered ordinal coding in higher-level visual regions, including word-selective cortex. [2025 study](https://pmc.ncbi.nlm.nih.gov/articles/PMC12582272/) <Cite refs={["turn160817search1"]}/>

**Possible mathematical operations**

Represent each letter by a feature vector \(\mathbf l_i\) and its ordinal position \(i\):

\[
W=
\{
(\mathbf l_1,1),
(\mathbf l_2,2),
\ldots,
(\mathbf l_n,n)
\}
\]

An order-sensitive representation can be formed as:

\[
\mathbf W=
\sum_{i=1}^{n}g(i)\mathbf l_i
\]

where \(g(i)\) encodes position.

A more flexible implementation can use position-sensitive population responses:

\[
r_{ki}=
\exp\left(
-\frac{(p_i-\mu_k)^2}{2\sigma_k^2}
\right)
\]

The result is a distributed representation of both letter identity and position.

### Step 2.5 — Increase tolerance to visual variation

The same letter may appear in different fonts, sizes, weights, and positions.

A robust representation must recognize the underlying character despite some of these changes.

The brain therefore needs to preserve diagnostic features while becoming less sensitive to irrelevant variation.

**Possible mathematical operations**

Let a visual character undergo a transformation \(T\):

\[
I'=T(I)
\]

The system should retain similar character-level representations:

\[
d\bigl(F(I),F(T(I))\bigr)
\rightarrow 0
\]

for transformations that preserve identity.

This can be supported by learned invariance and pooling across multiple visual feature populations.

The invariance should not be unlimited: some transformations genuinely change a letter's identity or make it ambiguous.

### Step 2.6 — Use linguistic feedback to resolve ambiguity

Visual evidence may not fully determine the identity of a character.

The system can receive feedback from higher-level letter, word, and language representations.

For example, a partially obscured letter can be interpreted in light of the other letters in its word.

**Possible mathematical operations**

\[
P(C_i\mid I,\text{context})
\propto
P(I\mid C_i)
P(C_i\mid\text{context})
\]

The first term represents visual evidence. The second represents contextual expectations.

The result is a revised estimate of letter identity.

This is a recurrent operation: the system may update visual interpretation more than once as context becomes available.

**Stage 2 output:**

\[
O_2=
\{
\text{candidate letters},
\text{letter positions},
\text{order information},
\text{visual confidence}
\}
\]

At this point, the visual pathway has constructed prelexical orthographic information. Higher reading stages can use it to access pronunciations and meanings.

# Part II — Auditory sensory and perceptual processing

The auditory pathway works differently from the visual pathway. Instead of analyzing a two-dimensional image, it analyzes a continuously changing pressure wave.

The brain must extract useful information from this wave even when:

- The speaker changes.
- The speech rate changes.
- Other people are speaking.
- Background noise is present.
- Sounds overlap.
- Adjacent speech sounds influence one another.

The cochlea initially separates sound by frequency, and this frequency organization is maintained through important parts of the ascending auditory pathway. Higher auditory regions construct increasingly complex acoustic and phonological representations. [Auditory neural-coding review](https://pmc.ncbi.nlm.nih.gov/articles/PMC5819010/) <Cite refs={["turn986245search1","turn986245search7"]}/>.

<box gap={2}>
  <title size="lg">Stage 3 — Auditory signal processing</title>
  <AsyncImage query="human cochlea inner ear basilar membrane auditory nerve scientific anatomical illustration" aspectRatio="16:9" width="100%" />
  <text color="secondary" size="xs">Input: a continuously varying acoustic pressure signal.</text>
</box>

**Objective:** Convert incoming sound into neural activity that preserves the important frequency, intensity, and timing information.

### Step 3.1 — Receive the acoustic waveform

Sound consists of pressure variations traveling through the air.

The outer ear collects sound, the eardrum vibrates, and the middle-ear bones transmit mechanical energy to the cochlea.

A simplified representation of an acoustic signal is:

\[
x(t)=A(t)\sin(2\pi f t+\phi)
\]

where:

- \(A(t)\): amplitude.
- \(f\): frequency.
- \(t\): time.
- \(\phi\): phase.

Real speech is much more complex than a single sinusoid. It consists of changing combinations of frequencies, amplitudes, and phases.

**Possible mathematical operations**

The ear and auditory system respond to:

\[
\text{Amplitude},\quad
\text{Frequency},\quad
\text{Phase},\quad
\text{Temporal variation}
\]

The system must preserve both spectral and temporal information because different speech sounds can share some frequency characteristics while differing in their timing.

### Step 3.2 — Perform cochlear frequency separation

The basilar membrane inside the cochlea responds differently to different sound frequencies.

- Its base responds preferentially to higher frequencies.
- Its apex responds preferentially to lower frequencies.

This produces a spatial frequency map called *tonotopy*.

The cochlea therefore performs a form of biological frequency decomposition before the signal reaches the cerebral cortex.

**Possible mathematical operations**

A useful simulation is a filter bank:

\[
u_k(t)=
\int_{-\infty}^{\infty}
x(\tau)h_k(t-\tau)d\tau
\]

where:

- \(x(t)\): incoming sound.
- \(h_k\): filter representing a frequency-selective channel.
- \(u_k(t)\): channel response.

Each channel has a preferred frequency.

A simulation might use a collection of cochlear-like filters whose center frequencies are distributed along a frequency scale.

**Biological interpretation:** Different populations of hair cells and auditory neurons respond preferentially to different frequency ranges. The actual cochlear mechanics are more sophisticated than a collection of independent digital filters.

### Step 3.3 — Convert mechanical vibration into neural signals

Sound-induced movement of the basilar membrane deflects hair-cell stereocilia.

This changes the electrical state of the hair cells, affects neurotransmitter release, and changes the activity of auditory-nerve fibers.

The acoustic waveform is now represented by patterns of neural activity.

**Possible mathematical operations**

A highly simplified model of a neural response is:

\[
r_k(t)=\phi(g(u_k(t))-\theta_k)
\]

where:

- \(u_k(t)\): input to channel \(k\).
- \(g\): nonlinear transformation.
- \(\theta_k\): effective response threshold.
- \(\phi\): response function.
- \(r_k(t)\): modeled neural firing rate.

A rectifying function could be:

\[
\phi(z)=\max(0,z)
\]

A more realistic model would include adaptation, response saturation, and different neural response properties.

The important principle is that the auditory system does not transmit the original sound wave unchanged. It encodes it through neural responses.

### Step 3.4 — Preserve temporal information

Speech depends on when acoustic events occur.

For example, differences in the timing of a consonant's release and the start of vocal-fold vibration can distinguish phonetic categories.

The auditory system therefore has to retain temporal information instead of representing sound only through its average frequency content.

**Possible mathematical operations**

An approximate energy envelope can be calculated by smoothing the squared signal:

\[
E(t)=
\int_{-\infty}^{\infty}
|u(\tau)|^2K(t-\tau)d\tau
\]

where \(K\) is a temporal smoothing kernel.

A temporal derivative can indicate changes in the envelope:

\[
\Delta E(t)=E(t)-E(t-\Delta t)
\]

A larger positive value can indicate a rapid increase in acoustic energy, such as an onset.

The model may also measure:

- Inter-onset intervals.
- Duration of acoustic events.
- Rate of change in channel activity.
- Temporal synchronization between frequency channels.

**Biological interpretation:** Auditory neurons differ in their temporal response properties. Some follow relatively rapid changes, while others integrate activity over longer periods.

### Step 3.5 — Organize the incoming sound into perceptual streams

A real auditory environment can contain many simultaneous sources:

- A person speaking.
- Background music.
- Traffic.
- Other people talking.
- Mechanical noises.

The brain must determine which sound components probably belong together.

This is part of auditory scene analysis.

**Possible mathematical operations**

For two acoustic components \(i\) and \(j\), define a grouping score:

\[
S_{ij}=
w_1H_{ij}
+w_2O_{ij}
+w_3T_{ij}
+w_4L_{ij}
\]

where:

- \(H_{ij}\): harmonic relationship.
- \(O_{ij}\): onset synchronization.
- \(T_{ij}\): temporal continuity.
- \(L_{ij}\): spatial-location similarity.

Components with stronger grouping evidence are more likely to be assigned to the same auditory stream.

This is a simplified computational analogy, not a single established neural equation.

### Step 3.6 — Increase the priority of relevant auditory input

Attention can prioritize one speaker or sound source over competing sources.

For instance, when listening to one person in a crowded room, the brain gives increased processing priority to characteristics associated with that person's voice and speech stream.

**Possible mathematical operations**

For each auditory stream \(i\):

\[
R_i'=a_iR_i
\]

where \(a_i\) is an attention-related gain.

A competitive model could use:

\[
a_i=
\frac{\exp(z_i)}
{\sum_j\exp(z_j)}
\]

This represents relative prioritization rather than a literal neural calculation.

**Stage 3 output:**

\[
O_3=
\{
\text{frequency-channel activity},
\text{temporal activity},
\text{intensity information},
\text{candidate auditory streams}
\}
\]

<box gap={2}>
  <title size="lg">Stage 4 — Acoustic feature extraction</title>
  <AsyncImage query="speech acoustic spectrogram voice formants harmonic bands scientific signal visualization" aspectRatio="16:9" width="100%" />
  <text color="secondary" size="xs">Input: frequency-separated and temporally encoded auditory activity.</text>
</box>

**Objective:** Extract acoustic properties that describe the structure of the incoming sound.

Stage 3 establishes a neural representation of the sound. Stage 4 extracts more informative characteristics from that representation.

For speech, some useful characteristics include:

- Fundamental frequency.
- Harmonic structure.
- Formant frequencies.
- Spectral energy distribution.
- Acoustic onset and offset.
- Voice onset time.
- Duration.
- Amplitude envelope.
- Frequency transitions.

### Step 4.1 — Construct a time-frequency representation

The brain must distinguish which frequencies are active at different moments.

A sound's frequency composition changes throughout an utterance.

A mathematical model can use a short-time Fourier transform:

\[
X(\tau,f)=
\int_{-\infty}^{\infty}
x(t)w(t-\tau)e^{-j2\pi ft}dt
\]

where:

- \(x(t)\): sound waveform.
- \(w(t-\tau)\): temporal analysis window.
- \(\tau\): time position.
- \(f\): frequency.

The resulting representation is a spectrogram or time-frequency map.

The brain does not need to calculate a Fourier transform explicitly. Cochlear filtering and subsequent auditory processing provide frequency- and time-sensitive representations that can be modeled using related mathematical tools.

### Step 4.2 — Extract energy and spectral distribution

Different speech sounds produce different patterns of energy across the frequency spectrum.

For example:

- Some consonants create strong high-frequency noise.
- Vowels exhibit resonant spectral peaks.
- Voiced sounds often contain harmonic structures.
- Stop consonants can involve a rapid release of acoustic energy.

**Possible mathematical operations**

Spectral power:

\[
P(\tau,f)=|X(\tau,f)|^2
\]

Total energy within a frequency band \(B\):

\[
E_B(\tau)=
\int_{f\in B}P(\tau,f)\,df
\]

Spectral centroid:

\[
C(\tau)=
\frac{\sum_f fP(\tau,f)}
{\sum_f P(\tau,f)}
\]

These measurements describe different aspects of the sound's frequency distribution.

### Step 4.3 — Detect harmonic structure and pitch

For many voiced sounds, the vocal folds produce a periodic or approximately periodic signal.

Its fundamental frequency is conventionally represented as \(F_0\).

The harmonics occur approximately at:

\[
f_n=nF_0
\]

for integer \(n\).

The brain uses periodicity and harmonic relationships to estimate pitch and distinguish different kinds of vocal activity.

**Possible mathematical operations**

One way to model periodicity is autocorrelation:

\[
R(\tau)=
\int x(t)x(t-\tau)\,dt
\]

A prominent peak at a nonzero lag \(\tau_0\) can provide evidence of a repeating pattern:

\[
F_0\approx\frac{1}{\tau_0}
\]

This is one possible computational approximation of pitch extraction.

Pitch perception is not identical to estimating one frequency. Harmonic structure, auditory context, and competing sound sources can all affect the perceived pitch.

### Step 4.4 — Extract formant structure

Vowels are characterized partly by resonances of the vocal tract.

These resonances are described using formants:

\[
F_1,F_2,F_3,\ldots
\]

The first two formants are particularly useful for distinguishing many vowel categories.

A simplified representation of a vowel can be:

\[
\mathbf v=
[
F_1,F_2,F_3
]
\]

The brain analyzes the relationships between these resonances rather than simply identifying a single frequency.

For example:

- \(F_1\) often provides information related to vowel height.
- \(F_2\) often provides information related to frontness or backness.

The physical values vary between speakers, so the auditory system must avoid treating absolute formant frequencies as fixed vowel identities.

### Step 4.5 — Extract acoustic transitions

Speech sounds are dynamic. Their properties change as the vocal tract moves from one articulatory configuration to another.

The transitions between acoustic patterns are often just as important as their steady-state values.

For feature \(F_i(t)\), a simple rate-of-change estimate is:

\[
\frac{dF_i}{dt}
\approx
\frac{F_i(t+\Delta t)-F_i(t)}
{\Delta t}
\]

A system can also estimate acceleration:

\[
\frac{d^2F_i}{dt^2}
\]

These temporal derivatives can provide evidence about how a sound is developing.

### Step 4.6 — Build a combined acoustic feature vector

The extracted measurements can be combined into a time-dependent vector:

\[
\mathbf a_t=
[
F_0,
F_1,
F_2,
F_3,
E,
C,
VOT,
D,
\Delta F
]
\]

where:

- \(E\): energy.
- \(C\): spectral centroid.
- \(VOT\): voice onset time.
- \(D\): duration.
- \(\Delta F\): frequency-transition information.

The exact features required depend on the sound and language.

**Stage 4 output:**

\[
O_4=
\{
\mathbf a_1,\mathbf a_2,\ldots,\mathbf a_T
\}
\]

This is a time-dependent acoustic representation, not yet a sequence of identified phonemes.

---

<box gap={2}>
  <title size="lg">Stage 5 — Phonetic feature detection</title>
  <AsyncImage query="phonetics place manner articulation speech consonants vocal tract diagram scientific illustration" aspectRatio="16:9" width="100%" />
  <text color="secondary" size="xs">Input: acoustic features that change over time.</text>
</box>

**Objective:** Determine which speech-relevant properties are present in the acoustic signal.

This stage is different from acoustic feature extraction.

Acoustic features describe physical properties of sound. Phonetic features describe properties that help distinguish speech sounds in terms of how they are produced and perceived.

For example:

- Acoustic description: a particular pattern of energy occurs at a particular frequency.
- Phonetic interpretation: that pattern provides evidence for a fricative consonant.
- Phonological interpretation: the sound is assigned to a language-specific phoneme category.

These distinctions are useful, although the underlying biological processes interact rather than operating as completely separate modules. [Discussion of acoustic, phonetic, and phonological processing](https://pmc.ncbi.nlm.nih.gov/articles/PMC2914564/) <Cite refs={["turn986245search5"]}/>.

### Step 5.1 — Detect voicing-related characteristics

Voicing is associated with vocal-fold vibration.

The brain evaluates evidence such as:

- Periodic energy.
- Harmonic structure.
- Timing between consonant release and vocal-fold vibration.
- Low-frequency energy.
- The temporal development of the signal.

For example, /b/ and /p/ differ in important ways involving voicing and timing, although their acoustic realization varies across phonetic contexts and languages.

**Possible mathematical operations**

Estimate periodicity:

\[
V_p(t)=
\max_{\tau\in\mathcal T}
R_t(\tau)
\]

where \(R_t(\tau)\) is the local autocorrelation and \(\mathcal T\) is a relevant range of time lags.

Combine periodicity with additional acoustic evidence:

\[
P(\text{voiced}\mid\mathbf a_t)
=
\sigma(
w_1V_p+
w_2E_{\text{low}}+
w_3Q+
b
)
\]

where:

- \(V_p\): periodicity.
- \(E_{\text{low}}\): low-frequency energy.
- \(Q\): other relevant acoustic evidence.

The equation represents a possible neural population decoder.

### Step 5.2 — Detect manner of articulation

Manner of articulation describes the type of constriction or obstruction involved in producing a speech sound.

Important categories include:

| Manner | General articulatory characteristic |
|---|---|
| Stop | Complete closure followed by release |
| Fricative | Narrow constriction producing turbulent airflow |
| Nasal | Airflow passes through the nasal cavity |
| Approximant | Articulators approach without producing strong turbulent noise |
| Affricate | Stop-like closure followed by frication |

The auditory system detects acoustic patterns associated with these articulatory events.

**Possible mathematical operations**

Calculate feature evidence:

\[
\mathbf m_t=
[
E_{\text{burst}},
E_{\text{frication}},
E_{\text{nasal}},
P_{\text{periodic}},
D_{\text{closure}}
]
\]

Then estimate the probability of each manner:

\[
P(M_k\mid\mathbf m_t)
=
\frac{\exp(\mathbf w_k^\top\mathbf m_t+b_k)}
{\sum_j\exp(\mathbf w_j^\top\mathbf m_t+b_j)}
\]

This creates a distribution across possible manner categories.

It is important that the system does not simply equate one acoustic cue with one category. Different cues can support the same interpretation, and individual cues can be ambiguous.

### Step 5.3 — Detect place of articulation

Place of articulation describes where in the vocal tract a constriction occurs.

Examples include:

- Bilabial.
- Labiodental.
- Alveolar.
- Postalveolar.
- Palatal.
- Velar.
- Glottal.

The auditory system cannot directly see the speaker's articulators during ordinary listening. It must infer their movements from the acoustic consequences.

**Possible mathematical operations**

A feature vector might include:

\[
\mathbf p_t=
[
F_1^{\text{transition}},
F_2^{\text{transition}},
E_{\text{burst}},
S_{\text{spectral}},
D_{\text{transition}}
]
\]

These characteristics can be compared with learned patterns:

\[
P(P_k\mid\mathbf p_t)
\propto
P(\mathbf p_t\mid P_k)P(P_k)
\]

where \(P_k\) represents a possible place category.

The system combines evidence across multiple acoustic channels rather than relying on one measurement.

### Step 5.4 — Detect vowel-related characteristics

Vowels can be described using several important articulatory dimensions:

- Height: high, mid, or low.
- Backness: front, central, or back.
- Rounding: rounded or unrounded.
- Duration and other language-dependent properties.

These dimensions are associated with acoustic information, including formants.

**Possible mathematical operations**

Represent a vowel candidate as:

\[
\mathbf v_t=
[
F_1(t),F_2(t),F_3(t)
]
\]

A simplified vowel-height estimate might be inversely associated with \(F_1\):

\[
H\approx g_1(F_1)
\]

Likewise, vowel backness can be estimated from \(F_2\):

\[
B\approx g_2(F_2)
\]

The functions \(g_1\) and \(g_2\) are learned mappings, not universal conversion formulas.

The auditory system must also account for the speaker's vocal-tract characteristics.

### Step 5.5 — Normalize phonetic features across speakers

Two people can produce the same phoneme with substantially different absolute acoustic measurements.

Differences can arise from:

- Vocal-tract length.
- Vocal-fold characteristics.
- Age.
- Individual speaking habits.
- Vocal effort.
- Speech rate.

For example, the same vowel category can be associated with different absolute formant frequencies across speakers.

The brain therefore needs to emphasize features that remain informative despite changes in the speaker.

**Possible mathematical operations**

A basic normalization model is:

\[
F_i'=
\frac{F_i-\mu_{i,s}}
{\sigma_{i,s}+\epsilon}
\]

where:

- \(F_i\): observed acoustic measurement.
- \(\mu_{i,s}\): estimated speaker-dependent mean.
- \(\sigma_{i,s}\): estimated speaker-dependent variability.

This is only a simplified statistical model. Actual neural speaker normalization appears to involve nonlinear, context-sensitive transformations. Research has found speaker-dependent normalization of vowel-related formant representations in the superior temporal gyrus (STG). <Cite refs={["turn301219view2"]}/>

### Step 5.6 — Detect temporal relationships and coarticulation

Speech sounds are not always separated by clear acoustic boundaries.

When producing consecutive sounds, the speaker's articulators begin preparing for upcoming sounds before the current sound has completely ended.

This is called coarticulation.

For example, the acoustic realization of one consonant may change depending on the vowel that follows it.

The brain therefore needs to analyze transitions between sounds rather than treating every moment as independent.

**Possible mathematical operations**

Construct a feature trajectory:

\[
\mathbf q_t=
[
\mathbf a_t,
\mathbf a_{t-1},
\Delta\mathbf a_t
]
\]

where:

\[
\Delta\mathbf a_t=
\mathbf a_t-\mathbf a_{t-1}
\]

The system combines current information with the development of preceding and following acoustic features.

A recurrent representation could be:

\[
\mathbf h_t=
\sigma(
W_a\mathbf a_t+
W_h\mathbf h_{t-1}+
W_c\mathbf c_t
)
\]

where:

- \(\mathbf a_t\): current acoustic features.
- \(\mathbf h_{t-1}\): previous perceptual state.
- \(\mathbf c_t\): contextual information.

This provides a model of how phonetic information may depend on temporal context.

### Step 5.7 — Represent phonetic features as a distributed population pattern

The detected features are not necessarily stored in isolated, independent neural units.

Different populations in auditory cortical regions can respond to different acoustic-phonetic and prosodic characteristics.

The superior temporal gyrus contains a heterogeneous distribution of speech-sensitive neural responses. Population activity can contribute to higher-level phonemic and syllabic representations. [STG speech computation review](https://pmc.ncbi.nlm.nih.gov/articles/PMC9447996/) <Cite refs={["turn986245view1","turn301219view1"]}/>

A simplified population representation is:

\[
\mathbf r_t=
[
r_1(t),r_2(t),\ldots,r_n(t)
]
\]

Each \(r_i(t)\) represents the activity of a modeled neural population.

The combined pattern provides evidence about the phonetic characteristics of the current speech signal.

**Stage 5 output:**

\[
O_5=
\{
\text{voicing evidence},
\text{manner evidence},
\text{place evidence},
\text{vowel evidence},
\text{temporal relationships},
\text{normalized feature patterns}
\}
\]

---

<box gap={2}>
  <title size="lg">Stage 6 — Auditory phoneme identification</title>
  <AsyncImage query="phoneme speech perception auditory brain neural pathways superior temporal gyrus neuroscience illustration" aspectRatio="16:9" width="100%" />
  <text color="secondary" size="xs">Input: a time-dependent set of phonetic feature patterns.</text>
</box>

**Objective:** Determine which language-specific phoneme categories are most likely represented by the incoming speech signal.

This is the transition from relatively continuous acoustic-phonetic information to more abstract linguistic representations.

For example, a listener hearing a sound must decide whether it belongs to one phoneme category or another, despite considerable variation in how speakers produce it.

### Step 6.1 — Activate candidate phoneme categories

The brain uses learned knowledge of the sounds that distinguish words in its language.

For example, English speakers have learned distinctions involving /b/ and /p/, while other languages may organize similar acoustic information differently.

The incoming phonetic evidence activates multiple possible phoneme representations.

**Possible mathematical operations**

Suppose the system has a collection of possible phonemes:

\[
\Phi=
\{
\phi_1,\phi_2,\ldots,\phi_n
\}
\]

For each candidate, calculate an activation score:

\[
z_k=
\mathbf w_k^\top\mathbf r_t+b_k
\]

Then estimate its relative activation:

\[
P(\phi_k\mid\mathbf r_t)
=
\frac{\exp(z_k)}
{\sum_j\exp(z_j)}
\]

This is a softmax population-decoding model.

Instead of immediately committing to one phoneme, the model retains a distribution of candidate interpretations.

### Step 6.2 — Compare the acoustic evidence with learned phoneme categories

Phoneme categories are learned through exposure to a language.

A category can be represented by a distribution of possible acoustic and phonetic realizations, rather than by one fixed sound.

A simplified statistical representation is:

\[
P(\mathbf r\mid\phi_k)
\]

where \(\phi_k\) is a phoneme category.

The system evaluates how well the observed phonetic information matches each category.

Using Bayes' rule:

\[
P(\phi_k\mid\mathbf r)
=
\frac{
P(\mathbf r\mid\phi_k)P(\phi_k)
}{
P(\mathbf r)
}
\]

The prior \(P(\phi_k)\) represents the learned expectation for that category in the relevant situation.

This equation captures a useful principle: phoneme recognition depends on both sensory evidence and learned language knowledge.

### Step 6.3 — Integrate evidence over time

A phoneme is not necessarily identified from one isolated acoustic instant.

The brain can accumulate evidence as the sound unfolds.

For example:

1. An initial acoustic event suggests one phoneme.
2. A following transition provides additional information.
3. The next portion of the signal either supports or weakens the original interpretation.
4. The evolving population activity produces a more stable category estimate.

**Possible mathematical operations**

An evidence-accumulation model can be written as:

\[
L_k(t)=
L_k(t-\Delta t)
+
\log
\frac{
P(\mathbf r_t\mid\phi_k)
}{
P(\mathbf r_t\mid\phi_{\text{ref}})
}
\]

where:

- \(L_k(t)\): accumulated evidence for candidate \(k\).
- \(\phi_{\text{ref}}\): a comparison category.
- \(\mathbf r_t\): current neural feature representation.

The system can maintain competing evidence until enough information becomes available.

This is a mathematical analogy for temporal integration, not proof that the brain performs literal logarithmic calculations.

### Step 6.4 — Apply categorical perception

Acoustic speech information is often continuous, but listeners perceive many distinctions in terms of relatively discrete phoneme categories.

For instance, a series of speech sounds may gradually change from one acoustic pattern to another. Listeners can perceive a shift from one phoneme category to another across a category boundary.

This is known as categorical perception.

**Possible mathematical operations**

Let \(x\) be a continuous acoustic dimension, such as voice onset time.

A simplified category probability is:

\[
P(\phi_1\mid x)=
\frac{1}
{1+\exp[-k(x-b)]}
\]

and:

\[
P(\phi_2\mid x)=1-P(\phi_1\mid x)
\]

where:

- \(b\): category boundary.
- \(k\): boundary sharpness.

This is a simplified model. Actual categorical perception varies with language, task, context, and individual experience.

### Step 6.5 — Use phonetic and linguistic context

A sound can be acoustically ambiguous, but its surrounding context can make one interpretation more likely.

Relevant information includes:

- Earlier speech sounds.
- Following speech sounds.
- Syllable structure.
- Language-specific sound constraints.
- Word-level expectations.
- Sentence-level expectations.

The superior temporal gyrus is involved in nonlinear and context-sensitive speech processing. Research also describes interactions through which linguistic knowledge can influence the interpretation of degraded acoustic signals. <Cite refs={["turn301219view1","turn301219view3"]}/>

**Possible mathematical operations**

Combine the acoustic evidence with context:

\[
P(\phi_k\mid A,C)
\propto
P(A\mid\phi_k,C)P(\phi_k\mid C)
\]

where:

- \(A\): acoustic information.
- \(C\): linguistic context.
- \(\phi_k\): candidate phoneme.

The context does not need to determine the answer. It modifies the relative probability of each candidate.

For example, if two phoneme interpretations are acoustically similar, a familiar sound pattern or word context may help resolve the ambiguity.

### Step 6.6 — Update the phoneme interpretation through recurrent feedback

The brain's perceptual interpretation is not simply transmitted in one direction.

Higher-level linguistic representations can influence activity in auditory cortical regions, and updated auditory information can influence higher-level interpretations.

A simplified recurrent model is:

\[
\mathbf h_t^{(n+1)}
=
\sigma(
W_a\mathbf a_t+
W_p\mathbf p_t^{(n)}+
W_r\mathbf h_{t-1}^{(n+1)}
)
\]

where:

- \(\mathbf a_t\): current auditory evidence.
- \(\mathbf p_t^{(n)}\): prediction from higher-level processing.
- \(\mathbf h_{t-1}\): previous auditory state.
- \(n\): current processing iteration.

The system can repeatedly adjust its interpretation until competing representations become sufficiently stable.

### Step 6.7 — Select or retain the most likely phoneme interpretation

After sufficient evidence has accumulated, the system can produce a phoneme estimate.

A simple decision rule is:

\[
\hat{\phi}=
\arg\max_{\phi_k}
P(\phi_k\mid A,C)
\]

The system should also retain its uncertainty:

\[
U=
-\sum_kP(\phi_k)\log P(\phi_k)
\]

This entropy measure can represent uncertainty in the candidate distribution.

- Low entropy: one phoneme candidate dominates.
- High entropy: several candidates remain plausible.

A more biologically realistic simulation can preserve multiple candidates rather than force a decision at every moment.

### Step 6.8 — Construct the phoneme sequence

Speech is not only a collection of isolated phonemes. It is a temporally organized sequence.

The system must therefore preserve the relative order and timing of identified phonemes.

A simplified representation is:

\[
\mathcal P=
\{
(\hat{\phi}_1,t_1,d_1),
(\hat{\phi}_2,t_2,d_2),
\ldots,
(\hat{\phi}_n,t_n,d_n)
\}
\]

where:

- \(\hat{\phi}_i\): identified phoneme.
- \(t_i\): estimated onset time.
- \(d_i\): estimated duration.

In actual speech, phonetic boundaries are not always sharply defined. The representation should therefore allow overlapping or uncertain temporal intervals.

**Stage 6 output:**

\[
O_6=
\{
\text{phoneme candidates},
\text{phoneme probabilities},
\text{temporal ordering},
\text{confidence},
\text{uncertainty}
\}
\]

The next linguistic stage can use these representations for syllable, word, and sentence processing.

## 2. High-level algorithmic pseudocode

The following pseudocode expresses the overall flow without assuming that the biological brain uses precisely these software operations.

<CodeBlock language="python" editable>
def sensory_perceptual_algorithm(visual_input=None, auditory_input=None):
    """
    Conceptual model of visual and auditory sensory-perceptual processing.

    This is a computational architecture inspired by neuroscience,
    not a literal description of neuron-by-neuron brain execution.
    """

    results = {}

    # ==========================================
    # VISUAL PATHWAY
    # ==========================================

    if visual_input is not None:

        # Stage 1: Automatic text-region detection
        visual_features = extract_early_visual_features(visual_input)

        text_regions = detect_text_regions(
            visual_features
        )

        prioritized_regions = allocate_visual_attention(
            text_regions,
            visual_features
        )

        # Stage 2: Character segmentation
        character_features = extract_character_features(
            prioritized_regions
        )

        candidate_characters = generate_character_hypotheses(
            character_features
        )

        ordered_letters = estimate_letter_identity_and_order(
            candidate_characters
        )

        visual_results = refine_visual_representations(
            ordered_letters,
            context=None
        )

        results["visual"] = visual_results

    # ==========================================
    # AUDITORY PATHWAY
    # ==========================================

    if auditory_input is not None:

        # Stage 3: Auditory signal processing
        auditory_channels = process_auditory_signal(
            auditory_input
        )

        auditory_streams = organize_auditory_streams(
            auditory_channels
        )

        attended_streams = allocate_auditory_attention(
            auditory_streams
        )

        # Stage 4: Acoustic feature extraction
        acoustic_features = extract_acoustic_features(
            attended_streams
        )

        # Stage 5: Phonetic feature detection
        normalized_features = normalize_speaker_variation(
            acoustic_features
        )

        phonetic_features = detect_phonetic_features(
            normalized_features
        )

        # Stage 6: Auditory phoneme identification
        phoneme_candidates = generate_phoneme_candidates(
            phonetic_features
        )

        phoneme_probabilities = integrate_temporal_evidence(
            phoneme_candidates,
            phonetic_features
        )

        auditory_results = identify_phonemes(
            phoneme_probabilities
        )

        results["auditory"] = auditory_results

    # ==========================================
    # CROSS-MODAL INTERFACE
    # ==========================================

    if "visual" in results and "auditory" in results:

        results["cross_modal"] = compare_visual_and_auditory(
            results["visual"],
            results["auditory"]
        )

    return results
</CodeBlock>

The functions above are architectural placeholders. Each would need to be implemented as a collection of smaller operations, neural populations, state updates, and mathematical computations.

## 3. Important biological implementation boundaries

There are several design decisions worth preserving when converting this architecture into a Python simulation.

**First: do not treat character segmentation as conventional OCR.** The biological system can represent multiple letters simultaneously. Its internal representations need not consist of independent rectangular character crops. A model should preserve uncertainty and overlapping letter hypotheses.

**Second: do not treat speech as a sequence of clean acoustic chunks.** Coarticulation means that the acoustic evidence for a phoneme can extend into neighboring sounds. The system should represent temporal trajectories, not merely identify isolated snapshots.

**Third: keep acoustic and phonetic features separate.** Acoustic properties describe the signal; phonetic properties describe speech-relevant interpretations. This distinction is important for modeling how the auditory system transforms sound into language.

**Fourth: implement recurrent connections.** Both visual recognition and speech perception are influenced by higher-level information. A strictly one-directional processing pipeline would omit an important part of biological perceptual processing. <Cite refs={["turn160817search10","turn301219view1","turn301219view3"]}/>

**Fifth: distinguish biological evidence from computational convenience.** For example, Gabor filters, Fourier analysis, Bayesian inference, and softmax are useful computational abstractions. Their use in a simulation does not establish that the brain literally runs those exact calculations.

## 4. Suggested module boundaries for a future implementation

| Module | Main responsibility |
|---|---|
| `visual_input.py` | Visual input and early image representation |
| `text_region_detection.py` | Candidate text-region detection and attention |
| `character_perception.py` | Character features, grouping, identity and order |
| `auditory_input.py` | Acoustic reception and cochlear-inspired processing |
| `auditory_signal.py` | Frequency channels, temporal encoding and auditory streams |
| `acoustic_features.py` | Pitch, formants, spectrum, energy and temporal features |
| `phonetic_features.py` | Voicing, manner, place and vowel feature evidence |
| `phoneme_identification.py` | Phoneme categorization and temporal evidence integration |
| `perceptual_feedback.py` | Contextual prediction and recurrent updating |
| `sensory_integration.py` | Interaction between visual and auditory representations |

**The central architectural idea:** visual and auditory processing should begin with different representations of physical input, but both should gradually construct structured linguistic information. The visual pathway establishes what written symbols are present and where they occur; the auditory pathway establishes what speech sounds are present and which phoneme categories they represent. These representations can then interact with the rest of the brain's language system.

This architecture provides a foundation for a biologically inspired implementation, without confusing a useful mathematical simulation with a complete explanation of how the human brain works.

  <title size="lg">Stage 5 — Phonetic feature detection</title>
  <AsyncImage query="phonetics place manner articulation speech consonants vocal tract diagram scientific illustration" aspectRatio="16:9" width="100%" />
  <text color="secondary" size="xs">Input: acoustic features that change over time.</text>

**Objective:** Determine which speech-relevant properties are present in the acoustic signal.

This stage is different from acoustic feature extraction.

Acoustic features describe physical properties of sound. Phonetic features describe properties that help distinguish speech sounds in terms of how they are produced and perceived.

For example:

- Acoustic description: a particular pattern of energy occurs at a particular frequency.
- Phonetic interpretation: that pattern provides evidence for a fricative consonant.
- Phonological interpretation: the sound is assigned to a language-specific phoneme category.

These distinctions are useful, although the underlying biological processes interact rather than operating as completely separate modules. [Discussion of acoustic, phonetic, and phonological processing](https://pmc.ncbi.nlm.nih.gov/articles/PMC2914564/) <Cite refs={["turn986245search5"]}/>.

### Step 5.1 — Detect voicing-related characteristics

Voicing is associated with vocal-fold vibration.

The brain evaluates evidence such as:

- Periodic energy.
- Harmonic structure.
- Timing between consonant release and vocal-fold vibration.
- Low-frequency energy.
- The temporal development of the signal.

For example, /b/ and /p/ differ in important ways involving voicing and timing, although their acoustic realization varies across phonetic contexts and languages.

**Possible mathematical operations**

Estimate periodicity:

\[
V_p(t)=
\max_{\tau\in\mathcal T}
R_t(\tau)
\]

where \(R_t(\tau)\) is the local autocorrelation and \(\mathcal T\) is a relevant range of time lags.

Combine periodicity with additional acoustic evidence:

\[
P(\text{voiced}\mid\mathbf a_t)
=
\sigma(
w_1V_p+
w_2E_{\text{low}}+
w_3Q+
b
)
\]

where:

- \(V_p\): periodicity.
- \(E_{\text{low}}\): low-frequency energy.
- \(Q\): other relevant acoustic evidence.

The equation represents a possible neural population decoder.

### Step 5.2 — Detect manner of articulation

Manner of articulation describes the type of constriction or obstruction involved in producing a speech sound.

Important categories include:

| Manner | General articulatory characteristic |
|---|---|
| Stop | Complete closure followed by release |
| Fricative | Narrow constriction producing turbulent airflow |
| Nasal | Airflow passes through the nasal cavity |
| Approximant | Articulators approach without producing strong turbulent noise |
| Affricate | Stop-like closure followed by frication |

The auditory system detects acoustic patterns associated with these articulatory events.

**Possible mathematical operations**

Calculate feature evidence:

\[
\mathbf m_t=
[
E_{\text{burst}},
E_{\text{frication}},
E_{\text{nasal}},
P_{\text{periodic}},
D_{\text{closure}}
]
\]

Then estimate the probability of each manner:

\[
P(M_k\mid\mathbf m_t)
=
\frac{\exp(\mathbf w_k^\top\mathbf m_t+b_k)}
{\sum_j\exp(\mathbf w_j^\top\mathbf m_t+b_j)}
\]

This creates a distribution across possible manner categories.

It is important that the system does not simply equate one acoustic cue with one category. Different cues can support the same interpretation, and individual cues can be ambiguous.

### Step 5.3 — Detect place of articulation

Place of articulation describes where in the vocal tract a constriction occurs.

Examples include:

- Bilabial.
- Labiodental.
- Alveolar.
- Postalveolar.
- Palatal.
- Velar.
- Glottal.

The auditory system cannot directly see the speaker's articulators during ordinary listening. It must infer their movements from the acoustic consequences.

**Possible mathematical operations**

A feature vector might include:

\[
\mathbf p_t=
[
F_1^{\text{transition}},
F_2^{\text{transition}},
E_{\text{burst}},
S_{\text{spectral}},
D_{\text{transition}}
]
\]

These characteristics can be compared with learned patterns:

\[
P(P_k\mid\mathbf p_t)
\propto
P(\mathbf p_t\mid P_k)P(P_k)
\]

where \(P_k\) represents a possible place category.

The system combines evidence across multiple acoustic channels rather than relying on one measurement.

### Step 5.4 — Detect vowel-related characteristics

Vowels can be described using several important articulatory dimensions:

- Height: high, mid, or low.
- Backness: front, central, or back.
- Rounding: rounded or unrounded.
- Duration and other language-dependent properties.

These dimensions are associated with acoustic information, including formants.

**Possible mathematical operations**

Represent a vowel candidate as:

\[
\mathbf v_t=
[
F_1(t),F_2(t),F_3(t)
]
\]

A simplified vowel-height estimate might be inversely associated with \(F_1\):

\[
H\approx g_1(F_1)
\]

Likewise, vowel backness can be estimated from \(F_2\):

\[
B\approx g_2(F_2)
\]

The functions \(g_1\) and \(g_2\) are learned mappings, not universal conversion formulas.

The auditory system must also account for the speaker's vocal-tract characteristics.

### Step 5.5 — Normalize phonetic features across speakers

Two people can produce the same phoneme with substantially different absolute acoustic measurements.

Differences can arise from:

- Vocal-tract length.
- Vocal-fold characteristics.
- Age.
- Individual speaking habits.
- Vocal effort.
- Speech rate.

For example, the same vowel category can be associated with different absolute formant frequencies across speakers.

The brain therefore needs to emphasize features that remain informative despite changes in the speaker.

**Possible mathematical operations**

A basic normalization model is:

\[
F_i'=
\frac{F_i-\mu_{i,s}}
{\sigma_{i,s}+\epsilon}
\]

where:

- \(F_i\): observed acoustic measurement.
- \(\mu_{i,s}\): estimated speaker-dependent mean.
- \(\sigma_{i,s}\): estimated speaker-dependent variability.

This is only a simplified statistical model. Actual neural speaker normalization appears to involve nonlinear, context-sensitive transformations. Research has found speaker-dependent normalization of vowel-related formant representations in the superior temporal gyrus (STG). <Cite refs={["turn301219view2"]}/>

### Step 5.6 — Detect temporal relationships and coarticulation

Speech sounds are not always separated by clear acoustic boundaries.

When producing consecutive sounds, the speaker's articulators begin preparing for upcoming sounds before the current sound has completely ended.

This is called coarticulation.

For example, the acoustic realization of one consonant may change depending on the vowel that follows it.

The brain therefore needs to analyze transitions between sounds rather than treating every moment as independent.

**Possible mathematical operations**

Construct a feature trajectory:

\[
\mathbf q_t=
[
\mathbf a_t,
\mathbf a_{t-1},
\Delta\mathbf a_t
]
\]

where:

\[
\Delta\mathbf a_t=
\mathbf a_t-\mathbf a_{t-1}
\]

The system combines current information with the development of preceding and following acoustic features.

A recurrent representation could be:

\[
\mathbf h_t=
\sigma(
W_a\mathbf a_t+
W_h\mathbf h_{t-1}+
W_c\mathbf c_t
)
\]

where:

- \(\mathbf a_t\): current acoustic features.
- \(\mathbf h_{t-1}\): previous perceptual state.
- \(\mathbf c_t\): contextual information.

This provides a model of how phonetic information may depend on temporal context.

### Step 5.7 — Represent phonetic features as a distributed population pattern

The detected features are not necessarily stored in isolated, independent neural units.

Different populations in auditory cortical regions can respond to different acoustic-phonetic and prosodic characteristics.

The superior temporal gyrus contains a heterogeneous distribution of speech-sensitive neural responses. Population activity can contribute to higher-level phonemic and syllabic representations. [STG speech computation review](https://pmc.ncbi.nlm.nih.gov/articles/PMC9447996/) <Cite refs={["turn986245view1","turn301219view1"]}/>

A simplified population representation is:

\[
\mathbf r_t=
[
r_1(t),r_2(t),\ldots,r_n(t)
]
\]

Each \(r_i(t)\) represents the activity of a modeled neural population.

The combined pattern provides evidence about the phonetic characteristics of the current speech signal.

**Stage 5 output:**

\[
O_5=
\{
\text{voicing evidence},
\text{manner evidence},
\text{place evidence},
\text{vowel evidence},
\text{temporal relationships},
\text{normalized feature patterns}
\}
\]

<box gap={2}>
  <title size="lg">Stage 6 — Auditory phoneme identification</title>
  <AsyncImage query="phoneme speech perception auditory brain neural pathways superior temporal gyrus neuroscience illustration" aspectRatio="16:9" width="100%" />
  <text color="secondary" size="xs">Input: a time-dependent set of phonetic feature patterns.</text>
</box>

**Objective:** Determine which language-specific phoneme categories are most likely represented by the incoming speech signal.

This is the transition from relatively continuous acoustic-phonetic information to more abstract linguistic representations.

For example, a listener hearing a sound must decide whether it belongs to one phoneme category or another, despite considerable variation in how speakers produce it.

### Step 6.1 — Activate candidate phoneme categories

The brain uses learned knowledge of the sounds that distinguish words in its language.

For example, English speakers have learned distinctions involving /b/ and /p/, while other languages may organize similar acoustic information differently.

The incoming phonetic evidence activates multiple possible phoneme representations.

**Possible mathematical operations**

Suppose the system has a collection of possible phonemes:

\[
\Phi=
\{
\phi_1,\phi_2,\ldots,\phi_n
\}
\]

For each candidate, calculate an activation score:

\[
z_k=
\mathbf w_k^\top\mathbf r_t+b_k
\]

Then estimate its relative activation:

\[
P(\phi_k\mid\mathbf r_t)
=
\frac{\exp(z_k)}
{\sum_j\exp(z_j)}
\]

This is a softmax population-decoding model.

Instead of immediately committing to one phoneme, the model retains a distribution of candidate interpretations.

### Step 6.2 — Compare the acoustic evidence with learned phoneme categories

Phoneme categories are learned through exposure to a language.

A category can be represented by a distribution of possible acoustic and phonetic realizations, rather than by one fixed sound.

A simplified statistical representation is:

\[
P(\mathbf r\mid\phi_k)
\]

where \(\phi_k\) is a phoneme category.

The system evaluates how well the observed phonetic information matches each category.

Using Bayes' rule:

\[
P(\phi_k\mid\mathbf r)
=
\frac{
P(\mathbf r\mid\phi_k)P(\phi_k)
}{
P(\mathbf r)
}
\]

The prior \(P(\phi_k)\) represents the learned expectation for that category in the relevant situation.

This equation captures a useful principle: phoneme recognition depends on both sensory evidence and learned language knowledge.

### Step 6.3 — Integrate evidence over time

A phoneme is not necessarily identified from one isolated acoustic instant.

The brain can accumulate evidence as the sound unfolds.

For example:

1. An initial acoustic event suggests one phoneme.
2. A following transition provides additional information.
3. The next portion of the signal either supports or weakens the original interpretation.
4. The evolving population activity produces a more stable category estimate.

**Possible mathematical operations**

An evidence-accumulation model can be written as:

\[
L_k(t)=
L_k(t-\Delta t)
+
\log
\frac{
P(\mathbf r_t\mid\phi_k)
}{
P(\mathbf r_t\mid\phi_{\text{ref}})
}
\]

where:

- \(L_k(t)\): accumulated evidence for candidate \(k\).
- \(\phi_{\text{ref}}\): a comparison category.
- \(\mathbf r_t\): current neural feature representation.

The system can maintain competing evidence until enough information becomes available.

This is a mathematical analogy for temporal integration, not proof that the brain performs literal logarithmic calculations.

### Step 6.4 — Apply categorical perception

Acoustic speech information is often continuous, but listeners perceive many distinctions in terms of relatively discrete phoneme categories.

For instance, a series of speech sounds may gradually change from one acoustic pattern to another. Listeners can perceive a shift from one phoneme category to another across a category boundary.

This is known as categorical perception.

**Possible mathematical operations**

Let \(x\) be a continuous acoustic dimension, such as voice onset time.

A simplified category probability is:

\[
P(\phi_1\mid x)=
\frac{1}
{1+\exp[-k(x-b)]}
\]

and:

\[
P(\phi_2\mid x)=1-P(\phi_1\mid x)
\]

where:

- \(b\): category boundary.
- \(k\): boundary sharpness.

This is a simplified model. Actual categorical perception varies with language, task, context, and individual experience.

### Step 6.5 — Use phonetic and linguistic context

A sound can be acoustically ambiguous, but its surrounding context can make one interpretation more likely.

Relevant information includes:

- Earlier speech sounds.
- Following speech sounds.
- Syllable structure.
- Language-specific sound constraints.
- Word-level expectations.
- Sentence-level expectations.

The superior temporal gyrus is involved in nonlinear and context-sensitive speech processing. Research also describes interactions through which linguistic knowledge can influence the interpretation of degraded acoustic signals. <Cite refs={["turn301219view1","turn301219view3"]}/>

**Possible mathematical operations**

Combine the acoustic evidence with context:

\[
P(\phi_k\mid A,C)
\propto
P(A\mid\phi_k,C)P(\phi_k\mid C)
\]

where:

- \(A\): acoustic information.
- \(C\): linguistic context.
- \(\phi_k\): candidate phoneme.

The context does not need to determine the answer. It modifies the relative probability of each candidate.

For example, if two phoneme interpretations are acoustically similar, a familiar sound pattern or word context may help resolve the ambiguity.

### Step 6.6 — Update the phoneme interpretation through recurrent feedback

The brain's perceptual interpretation is not simply transmitted in one direction.

Higher-level linguistic representations can influence activity in auditory cortical regions, and updated auditory information can influence higher-level interpretations.

A simplified recurrent model is:

\[
\mathbf h_t^{(n+1)}
=
\sigma(
W_a\mathbf a_t+
W_p\mathbf p_t^{(n)}+
W_r\mathbf h_{t-1}^{(n+1)}
)
\]

where:

- \(\mathbf a_t\): current auditory evidence.
- \(\mathbf p_t^{(n)}\): prediction from higher-level processing.
- \(\mathbf h_{t-1}\): previous auditory state.
- \(n\): current processing iteration.

The system can repeatedly adjust its interpretation until competing representations become sufficiently stable.

### Step 6.7 — Select or retain the most likely phoneme interpretation

After sufficient evidence has accumulated, the system can produce a phoneme estimate.

A simple decision rule is:

\[
\hat{\phi}=
\arg\max_{\phi_k}
P(\phi_k\mid A,C)
\]

The system should also retain its uncertainty:

\[
U=
-\sum_kP(\phi_k)\log P(\phi_k)
\]

This entropy measure can represent uncertainty in the candidate distribution.

- Low entropy: one phoneme candidate dominates.
- High entropy: several candidates remain plausible.

A more biologically realistic simulation can preserve multiple candidates rather than force a decision at every moment.

### Step 6.8 — Construct the phoneme sequence

Speech is not only a collection of isolated phonemes. It is a temporally organized sequence.

The system must therefore preserve the relative order and timing of identified phonemes.

A simplified representation is:

\[
\mathcal P=
\{
(\hat{\phi}_1,t_1,d_1),
(\hat{\phi}_2,t_2,d_2),
\ldots,
(\hat{\phi}_n,t_n,d_n)
\}
\]

where:

- \(\hat{\phi}_i\): identified phoneme.
- \(t_i\): estimated onset time.
- \(d_i\): estimated duration.

In actual speech, phonetic boundaries are not always sharply defined. The representation should therefore allow overlapping or uncertain temporal intervals.

**Stage 6 output:**

\[
O_6=
\{
\text{phoneme candidates},
\text{phoneme probabilities},
\text{temporal ordering},
\text{confidence},
\text{uncertainty}
\}
\]

The next linguistic stage can use these representations for syllable, word, and sentence processing.

## 2. High-level algorithmic pseudocode

The following pseudocode expresses the overall flow without assuming that the biological brain uses precisely these software operations.

<CodeBlock language="python" editable>
def sensory_perceptual_algorithm(visual_input=None, auditory_input=None):
    """
    Conceptual model of visual and auditory sensory-perceptual processing.

    This is a computational architecture inspired by neuroscience,
    not a literal description of neuron-by-neuron brain execution.
    """

    results = {}

    # ==========================================
    # VISUAL PATHWAY
    # ==========================================

    if visual_input is not None:

        # Stage 1: Automatic text-region detection
        visual_features = extract_early_visual_features(visual_input)

        text_regions = detect_text_regions(
            visual_features
        )

        prioritized_regions = allocate_visual_attention(
            text_regions,
            visual_features
        )

        # Stage 2: Character segmentation
        character_features = extract_character_features(
            prioritized_regions
        )

        candidate_characters = generate_character_hypotheses(
            character_features
        )

        ordered_letters = estimate_letter_identity_and_order(
            candidate_characters
        )

        visual_results = refine_visual_representations(
            ordered_letters,
            context=None
        )

        results["visual"] = visual_results

    # ==========================================
    # AUDITORY PATHWAY
    # ==========================================

    if auditory_input is not None:

        # Stage 3: Auditory signal processing
        auditory_channels = process_auditory_signal(
            auditory_input
        )

        auditory_streams = organize_auditory_streams(
            auditory_channels
        )

        attended_streams = allocate_auditory_attention(
            auditory_streams
        )

        # Stage 4: Acoustic feature extraction
        acoustic_features = extract_acoustic_features(
            attended_streams
        )

        # Stage 5: Phonetic feature detection
        normalized_features = normalize_speaker_variation(
            acoustic_features
        )

        phonetic_features = detect_phonetic_features(
            normalized_features
        )

        # Stage 6: Auditory phoneme identification
        phoneme_candidates = generate_phoneme_candidates(
            phonetic_features
        )

        phoneme_probabilities = integrate_temporal_evidence(
            phoneme_candidates,
            phonetic_features
        )

        auditory_results = identify_phonemes(
            phoneme_probabilities
        )

        results["auditory"] = auditory_results

    # ==========================================
    # CROSS-MODAL INTERFACE
    # ==========================================

    if "visual" in results and "auditory" in results:

        results["cross_modal"] = compare_visual_and_auditory(
            results["visual"],
            results["auditory"]
        )

    return results
</CodeBlock>

The functions above are architectural placeholders. Each would need to be implemented as a collection of smaller operations, neural populations, state updates, and mathematical computations.

## 3. Important biological implementation boundaries

There are several design decisions worth preserving when converting this architecture into a Python simulation.

**First: do not treat character segmentation as conventional OCR.** The biological system can represent multiple letters simultaneously. Its internal representations need not consist of independent rectangular character crops. A model should preserve uncertainty and overlapping letter hypotheses.

**Second: do not treat speech as a sequence of clean acoustic chunks.** Coarticulation means that the acoustic evidence for a phoneme can extend into neighboring sounds. The system should represent temporal trajectories, not merely identify isolated snapshots.

**Third: keep acoustic and phonetic features separate.** Acoustic properties describe the signal; phonetic properties describe speech-relevant interpretations. This distinction is important for modeling how the auditory system transforms sound into language.

**Fourth: implement recurrent connections.** Both visual recognition and speech perception are influenced by higher-level information. A strictly one-directional processing pipeline would omit an important part of biological perceptual processing. <Cite refs={["turn160817search10","turn301219view1","turn301219view3"]}/>

**Fifth: distinguish biological evidence from computational convenience.** For example, Gabor filters, Fourier analysis, Bayesian inference, and softmax are useful computational abstractions. Their use in a simulation does not establish that the brain literally runs those exact calculations.

## 4. Suggested module boundaries for a future implementation

| Module | Main responsibility |
|---|---|
| `visual_input.py` | Visual input and early image representation |
| `text_region_detection.py` | Candidate text-region detection and attention |
| `character_perception.py` | Character features, grouping, identity and order |
| `auditory_input.py` | Acoustic reception and cochlear-inspired processing |
| `auditory_signal.py` | Frequency channels, temporal encoding and auditory streams |
| `acoustic_features.py` | Pitch, formants, spectrum, energy and temporal features |
| `phonetic_features.py` | Voicing, manner, place and vowel feature evidence |
| `phoneme_identification.py` | Phoneme categorization and temporal evidence integration |
| `perceptual_feedback.py` | Contextual prediction and recurrent updating |
| `sensory_integration.py` | Interaction between visual and auditory representations |

**The central architectural idea:** visual and auditory processing should begin with different representations of physical input, but both should gradually construct structured linguistic information. The visual pathway establishes what written symbols are present and where they occur; the auditory pathway establishes what speech sounds are present and which phoneme categories they represent. These representations can then interact with the rest of the brain's language system.

This architecture provides a foundation for a biologically inspired implementation, without confusing a useful mathematical simulation with a complete explanation of how the human brain works.
