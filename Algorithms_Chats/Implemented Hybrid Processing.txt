# Master algorithm: Amodal semantic processing through the anterior temporal lobe (ATL)

## 1. What the algorithm is intended to model

The central hypothesis is that the brain does not store the meaning of a word only in the region that processes its sound or visual form. Instead, information from different sensory and language systems converges on a shared semantic representation, with the **anterior temporal lobes (ATLs)** playing an important hub-like role.

For example, the brain should be able to reach a related concept when it receives any of these inputs:

- The written word `DOG`.
- The spoken word “dog”.
- A picture of a dog.
- The sound of a dog barking.

These inputs begin with different sensory information, but they can eventually activate overlapping conceptual knowledge.

There is evidence supporting this proposal. Visser, Jefferies and Lambon Ralph's meta-analysis examined 164 neuroimaging studies. It found that ATL activation was more reliably detected when imaging methods adequately covered the region, and that spoken words, written words and pictures produced overlapping ATL activation peaks. The study also found that stimulus and task type did not explain the likelihood of finding ATL activation. <Cite refs={["turn416355search0","turn416355search2"]}/>

The wider hub-and-spoke framework proposes that modality-specific cortical regions contribute sensory, motor and other experiential information, while the bilateral ATL helps integrate it into coherent, generalizable concepts. <Cite refs={["turn584567view2"]}/>

**Important distinction:** the studies establish patterns of neural activity and support certain theoretical roles for the ATL. They do not reveal the exact equations used by neurons. The mathematical operations below are therefore computational models of plausible neural operations—not claims that the brain literally calculates these equations.

## 2. Basic mathematical model

Before defining the stages, we need a common representation for the information flowing through the system.

Imagine that every cortical population produces a pattern of neural activation. In a computational model, we can represent that pattern as a vector.

For example:

\[
\mathbf{x}_{visual} =
\begin{bmatrix}
0.2\\
0.8\\
0.4\\
\vdots
\end{bmatrix}
\]

This vector does not literally correspond to a list of neurons with known numerical values. It is an abstraction representing the activation pattern of a neural population.

The algorithm uses the following variables:

| Symbol | Meaning |
|---|---|
| \(\mathbf{x}_m\) | Input from sensory modality \(m\) |
| \(\mathbf{s}_m\) | Extracted semantic features from that modality |
| \(\mathbf{h}\) | ATL hub activation |
| \(\mathbf{z}\) | Integrated semantic representation |
| \(\mathbf{n}\) | Representation of a noun |
| \(\mathbf{a}\) | Representation of an adjective |
| \(\mathbf{p}\) | Composed phrase representation |
| \(W\) | Connection-strength matrix |
| \(\sigma\) | Nonlinear activation function |
| \(\odot\) | Element-wise multiplication |

We can use functions such as sigmoid, tanh or other nonlinear activation functions to model the way neuronal populations respond to their inputs.

# Part A — Accessing an amodal semantic representation

## Stage 1. Receive information through different sensory channels

The brain first receives information through one or more sensory systems.

Possible inputs include:

1. Written words.
2. Spoken words.
3. Pictures of objects.
4. Sounds produced by objects.
5. Information obtained through touch.
6. Information associated with bodily actions.

Consider the concept of a dog.

The brain could receive:

- The written word `DOG`.
- The spoken sound “dog”.
- A photograph of a dog.
- A barking sound.
- The experience of touching a dog's fur.

These inputs are physically and neurally different, even though they may eventually lead to the same conceptual representation.

**Possible mathematical operations**

The input can initially be represented as:

\[
X =
\{X_{visual}, X_{auditory}, X_{tactile}, X_{motor}, X_{linguistic}\}
\]

Each input is processed separately:

\[
X_m \longrightarrow \text{neural activation pattern}_m
\]

At this point, there is no requirement that the representations already have identical structures.

**Biological interpretation:** different sensory and language systems receive and initially process their respective inputs.

## Stage 2. Extract modality-specific features

Each sensory system extracts information appropriate to its modality.

For example:

**Visual processing**

When seeing a dog, the visual system may extract:

- Shape.
- Size.
- Color.
- Body structure.
- Facial characteristics.
- Movement.

**Auditory processing**

When hearing a dog bark, the auditory system may extract:

- Frequency.
- Amplitude.
- Pitch.
- Temporal pattern.
- Sound characteristics.

**Motor and action-related processing**

Information about dogs may also activate learned knowledge about:

- How dogs move.
- How humans interact with dogs.
- Actions commonly performed by dogs.

The important point is that the different systems initially contribute different kinds of information.

**Possible mathematical operations**

Each modality can be represented by a different feature-extraction transformation:

\[
\mathbf{s}_m = \phi(W_m\mathbf{x}_m+\mathbf{b}_m)
\]

Where:

- \(\mathbf{x}_m\) is the original input.
- \(W_m\) represents learned connections.
- \(\mathbf{b}_m\) represents baseline activation or bias.
- \(\phi\) represents nonlinear neural processing.
- \(\mathbf{s}_m\) is the extracted feature pattern.

For example:

\[
\mathbf{s}_{visual}=f_{visual}(\mathbf{x}_{visual})
\]

\[
\mathbf{s}_{auditory}=f_{auditory}(\mathbf{x}_{auditory})
\]

The functions are different because visual and auditory information require different initial transformations.

## Stage 3. Activate distributed semantic spokes

The brain does not necessarily rely on one isolated location to represent every characteristic of an object.

Instead, the relevant information can be distributed among multiple modality-related systems.

For a dog, different populations may contribute:

| Feature | Possible participating system |
|---|---|
| Appearance | Visual association cortex |
| Sound | Auditory association cortex |
| Movement | Motor-related cortex |
| Touch | Somatosensory association cortex |
| Emotional significance | Affect-related systems |
| Actions and uses | Distributed action and functional networks |

These are examples of the hub-and-spoke interpretation of semantic representation. The exact localization of every individual feature is more complicated than this simplified table.

The feature pattern could be represented as:

\[
\mathbf{S}=
\begin{bmatrix}
\mathbf{s}_{visual}\\
\mathbf{s}_{auditory}\\
\mathbf{s}_{motor}\\
\mathbf{s}_{tactile}\\
\mathbf{s}_{affective}\\
\mathbf{s}_{functional}
\end{bmatrix}
\]

Not all components need to be active during every encounter.

For example, reading the word `DOG` may initially activate linguistic and associated semantic information more strongly than tactile information.

**Possible mathematical operations**

The brain can be modeled as distributing activation across connected populations:

\[
A_i = f\left(\sum_j w_{ji}A_j\right)
\]

Where \(w_{ji}\) represents the strength of the connection from population \(j\) to population \(i\).

This models the spread of activation through a distributed network.

## Stage 4. Normalize and weight incoming feature information

Different sensory signals have different strengths and reliability.

A photograph might provide strong information about an object's appearance but little information about its sound.

An environmental sound might provide strong auditory information while providing no direct visual information.

The brain must therefore combine information without allowing one particularly strong input to overwhelm everything else.

**Possible mathematical operations**

One possible normalization operation is:

\[
\hat{\mathbf{s}}_m =
\frac{\mathbf{s}_m-\boldsymbol{\mu}_m}
{\boldsymbol{\sigma}_m+\epsilon}
\]

Where:

- \(\boldsymbol{\mu}_m\) is the average activity.
- \(\boldsymbol{\sigma}_m\) represents variation in activity.
- \(\epsilon\) prevents division by zero.

The system can also assign a dynamic contribution weight:

\[
g_m =
\frac{e^{r_m}}
{\sum_j e^{r_j}}
\]

Here, \(r_m\) represents the relevance or reliability of modality \(m\).

The weights satisfy:

\[
\sum_m g_m=1
\]

This is a computational approximation of dynamic weighting, not evidence that neurons literally perform softmax calculations.

## Stage 5. Transmit distributed information toward the ATL

After initial processing, information from the different systems reaches interconnected temporal regions, including anterior temporal regions.

The essential computational operation is convergence.

Different patterns must be able to influence a common semantic processing system.

For example:

\[
\mathbf{s}_{visual}
\rightarrow ATL
\]

\[
\mathbf{s}_{auditory}
\rightarrow ATL
\]

\[
\mathbf{s}_{linguistic}
\rightarrow ATL
\]

The connections need not have identical strengths.

The ATL's connections with the rest of the brain are heterogeneous, and different ATL subdivisions have different connectivity profiles.

**Possible mathematical operations**

Represent the incoming pathways by different connection matrices:

\[
\mathbf{u}_{ATL} =
W_v\mathbf{s}_{visual}
+
W_a\mathbf{s}_{auditory}
+
W_l\mathbf{s}_{linguistic}
+
W_m\mathbf{s}_{motor}
\]

This is a weighted summation operation.

Each matrix transforms its own modality-specific representation into a pattern that can contribute to ATL processing.

## Stage 6. Integrate information within the bilateral ATL

<badge color="info">Central semantic integration stage</badge>

This is the central stage of the amodal semantic hub hypothesis.

The ATL receives information originating from different sensory and linguistic systems.

The proposed function is to combine these different sources into coherent conceptual representations.

For example, different inputs concerning dogs may contribute:

- A particular shape.
- Four-legged body structure.
- Barking sounds.
- Animal movement.
- A relationship with humans.

Rather than treating each property as an isolated representation, the ATL is hypothesized to help establish a coherent representation of the concept.

**Possible mathematical operations**

A recurrent integration model is:

\[
\mathbf{h}_{t+1} =
\sigma
\left(
W_{hh}\mathbf{h}_{t}
+
\sum_m g_m W_m\mathbf{s}_m
+
W_c\mathbf{c}_t
\right)
\]

Where:

- \(\mathbf{h}_t\) is the current ATL activation.
- \(W_{hh}\) represents recurrent connections.
- \(W_m\) represents incoming modality-specific connections.
- \(g_m\) controls each modality's contribution.
- \(\mathbf{c}_t\) represents contextual input.

The recurrence means that the newly calculated activation becomes part of the input to the next processing cycle.

This creates the possibility of iterative integration instead of a single instantaneous calculation.

A more simplified model of activation accumulation is:

\[
\mathbf{h}_{t+1}
=
(1-\alpha)\mathbf{h}_t
+
\alpha\mathbf{u}_{ATL}
\]

Here, \(\alpha\) controls how rapidly the new information changes the existing activation.

This is similar to a leaky integrator.

## Stage 7. Establish a common semantic representation

After integration, the brain is hypothesized to produce a representation that is less dependent on the particular sensory form through which the concept was encountered.

This is the essential meaning of *amodal* in the hub-and-spoke hypothesis.

For example, the representation of a dog reached through a picture should overlap substantially with the representation reached through the spoken word “dog”.

The input patterns are different, but the conceptual content can converge.

**Possible mathematical operations**

We can represent the transformation as:

\[
\mathbf{z}=F_{ATL}(\mathbf{h})
\]

Where \(\mathbf{z}\) is the integrated semantic representation.

The representations obtained through different modalities should have high similarity when they concern the same concept:

\[
Similarity(\mathbf{z}_{visual},\mathbf{z}_{auditory})
\rightarrow 1
\]

One possible similarity measure is cosine similarity:

\[
CosSim(\mathbf{a},\mathbf{b}) =
\frac{\mathbf{a}\cdot\mathbf{b}}
{\|\mathbf{a}\|\|\mathbf{b}\|}
\]

The result approaches 1 when the vectors point in similar directions.

This does not mean the two neural patterns must be identical. Their shared semantic information can be represented through overlapping dimensions while modality-specific information remains available elsewhere.

## Stage 8. Perform cross-modal generalization

A semantic hub should allow knowledge acquired through one modality to contribute to understanding through another.

For example:

- Learning what a dog looks like helps interpret a description of a dog.
- Learning the meaning of the word `DOG` helps identify a dog in a picture.
- Hearing a barking sound can activate knowledge of dogs even without seeing one.

This is an important consequence of a shared conceptual system.

**Possible mathematical operations**

The semantic system can compare the current representation with stored concept representations:

\[
Score(c_i)=CosSim(\mathbf{z},\boldsymbol{\mu}_{c_i})
\]

Where \(\boldsymbol{\mu}_{c_i}\) is the learned representation of concept \(c_i\).

The system can then calculate candidate probabilities:

\[
P(c_i|\mathbf{z})=
\frac{e^{\beta Score(c_i)}}
{\sum_j e^{\beta Score(c_j)}}
\]

Where \(\beta\) determines how strongly the system favors the best-matching concepts.

The highest-scoring concept becomes the leading candidate, subject to the strength and reliability of the available evidence.

## Stage 9. Complete the semantic representation using feedback

The hub-and-spoke model is not necessarily a one-way system.

The ATL can be modeled as interacting with the distributed feature systems that contribute to semantic knowledge.

For example, when a person hears “dog,” the system may activate the concept and then partially reactivate associated information about its appearance, sound or behavior.

This is a useful way to model semantic completion.

**Possible mathematical operations**

We can model feedback as:

\[
\hat{\mathbf{s}}_m=V_m\mathbf{z}
\]

Where \(V_m\) reconstructs the expected feature pattern in modality \(m\).

The difference between an incoming feature pattern and a reconstructed pattern is:

\[
\mathbf{e}_m =
\mathbf{s}_m-\hat{\mathbf{s}}_m
\]

A computational system may use this difference to refine its interpretation:

\[
\mathbf{z}_{t+1} =
\mathbf{z}_t+\eta G(\mathbf{e})
\]

This is a candidate error-correction mechanism. It is not a specific operation demonstrated by the imaging studies cited here.

## Stage 10. Retrieve the concept for semantic understanding

At this stage, the semantic system has developed an integrated representation that can be used for comprehension.

For a single word, the system can retrieve its conceptual meaning.

For example:

\[
DOG \rightarrow \text{semantic representation of DOG}
\]

This representation contains information associated with the concept, rather than merely its spelling or pronunciation.

An important distinction:

- The orthographic system can identify the written word.
- The phonological system can identify the spoken form.
- The semantic system activates the conceptual knowledge associated with that form.

The same ATL-related semantic machinery may also contribute when the input is a nonverbal object or sound.

# Part B — Using the same ATL system to construct phrase meaning

The next stages explain how the proposed semantic hub participates in combining words into larger meaningful structures.

This is particularly relevant because a word's meaning and the meaning of a phrase containing that word are not necessarily identical.

For example:

- `diamond`
- `real diamond`
- `fake diamond`

The noun remains recognizable, but the adjective changes the interpretation of the complete phrase.

## Stage 11. Activate the noun's semantic representation

Suppose the brain receives the adjective–noun phrase:

**fake diamond**

The noun is `diamond`.

First, the semantic system activates the concept represented by the noun.

Let:

\[
\mathbf{n}=
F_{ATL}(\text{diamond})
\]

The representation may contain properties such as:

- Hardness.
- Appearance.
- Crystal structure.
- Typical uses.
- Value.
- Relationships to other minerals and objects.

The noun representation establishes the initial conceptual structure upon which further information can operate.

**Possible mathematical operations**

The noun representation can be treated as an activation vector:

\[
\mathbf{n}=
[n_1,n_2,\ldots,n_k]
\]

Its components represent different semantic dimensions.

The strength of each dimension can vary.

The vector does not need to be a list of explicitly named properties. It can represent distributed information encoded across a population.

## Stage 12. Maintain the noun representation while processing subsequent information

When an adjective is encountered, the brain must retain relevant noun information so that the adjective can be interpreted in relation to it.

For example, understanding `fake diamond` requires maintaining the concept of diamond while processing the adjective `fake`.

The noun should not simply disappear when the next word is received.

**Possible mathematical operations**

One possible model of temporal maintenance is:

\[
\mathbf{n}_{t+1} =
\rho\mathbf{n}_{t}
+
(1-\rho)\mathbf{n}_{new}
\]

Where:

- \(\rho\) determines how strongly previous noun information is retained.
- \(\mathbf{n}_{new}\) is newly processed noun-related information.

A relatively high \(\rho\) models a stable representation over time.

This is a computational analogy for maintaining semantic information, not a literal model of a single neural memory buffer.

**Evidence from Law et al. (2026):** noun concreteness information was relatively stable in ATL neural decoding and remained decodable for around 300 milliseconds in their experiment. This should not be interpreted as a universal duration for every noun or every comprehension task. <Cite refs={["turn516298search0","turn516298search1"]}/>

## Stage 13. Process the adjective's semantic information

Now the brain receives the adjective `fake`.

The adjective has its own semantic representation.

For instance:

\[
\mathbf{a}=F_{ATL}(\text{fake})
\]

This representation conveys information about falseness, imitation or lack of authenticity.

However, the adjective is not yet fully interpreted as part of the complete phrase.

The adjective must be interpreted in relation to the noun.

For example:

- `fake diamond`
- `fake painting`
- `fake passport`

The adjective has related meaning in all three expressions, but its consequences for the resulting interpretation depend on the noun.

**Possible mathematical operations**

The adjective can be encoded into a separate activation vector:

\[
\mathbf{a}=[a_1,a_2,\ldots,a_k]
\]

Its activation can change dynamically as more information arrives:

\[
\mathbf{a}_{t+1} =
f(\mathbf{a}_t,\mathbf{context}_t)
\]

This allows the semantic representation of the adjective to be influenced by the surrounding conceptual context.

**Evidence from Law et al. (2026):** adjective semantics showed a time-varying representational format in ATL decoding, whereas noun concreteness representations were more stable. <Cite refs={["turn516298search0","turn516298search37"]}/>

## Stage 14. Establish the relationship between adjective and noun

The brain must recognize that the adjective modifies the noun.

The combination is not simply:

\[
\mathbf{a}+\mathbf{n}
\]

There is a relationship between them.

For example:

- `red car`: the adjective specifies a color characteristic of the car.
- `small dog`: the adjective specifies a size characteristic of the dog.
- `fake diamond`: the adjective changes whether the described object qualifies as a genuine diamond.

Therefore, the semantic system must represent not only the two concepts, but also their relationship.

**Possible mathematical operations**

Represent the relationship as:

\[
\mathbf{r}=R(\mathbf{a},\mathbf{n})
\]

A simple interaction could be:

\[
\mathbf{r}=\mathbf{a}\odot\mathbf{n}
\]

Element-wise multiplication allows each adjective dimension to interact with the corresponding noun dimension.

A more expressive operation would be a learned bilinear transformation:

\[
r_k =
\sum_{i,j}T_{kij}a_i n_j
\]

Where \(T\) represents learned interactions between adjective and noun dimensions.

This allows the same adjective to influence different nouns in different ways.

## Stage 15. Construct the combined semantic representation

Now the brain can integrate the noun, adjective and their relationship.

The resulting phrase representation is not simply a concatenation of two independent word meanings.

It is a new semantic state representing the complete expression.

For `fake diamond`:

\[
\mathbf{p}
=
F(\mathbf{n},\mathbf{a},\mathbf{r})
\]

One possible implementation is:

\[
\boxed{
\mathbf{p}
=
\sigma
\left(
W_n\mathbf{n}
+
W_a\mathbf{a}
+
W_r\mathbf{r}
+
\mathbf{b}
\right)
}
\]

This formula contains four important operations:

1. Preserve information from the noun.
2. Incorporate information from the adjective.
3. Incorporate the relationship between them.
4. Apply a nonlinear transformation to construct the phrase representation.

The result is a representation of `fake diamond`, not merely separate representations of `fake` and `diamond`.

This is the central computational idea of semantic composition.

## Stage 16. Determine how the adjective changes the noun's denotation

This stage is especially important because not all adjectives modify nouns in the same way.

Law et al. (2026) examined the difference between *subsective* and *privative* adjectives.

**Subsective adjective**

A subsective adjective produces a phrase whose referents remain members of the noun category.

Example:

`small diamond`

A small diamond is still a diamond.

The phrase describes a subset of the broader diamond category.

In set notation:

\[
D_{\text{small diamond}}
\subseteq
D_{\text{diamond}}
\]

**Privative adjective**

A privative adjective produces an expression whose referents need not be members of the noun category.

Example:

`fake diamond`

A fake diamond may look like a diamond but is not a genuine diamond.

Thus:

\[
D_{\text{fake diamond}}
\not\subseteq
D_{\text{diamond}}
\]

The semantic system must therefore distinguish between two things:

- How similar the described object is to the original noun concept.
- Whether the described object actually belongs to the noun's category.

These are not necessarily the same.

A fake diamond may be extremely similar to a real diamond in appearance while failing to qualify as a genuine diamond.

**Possible mathematical operations**

We can model this with two separate scores:

\[
Similarity(\mathbf{p},\boldsymbol{\mu}_{diamond})
\]

and

\[
Membership(\mathbf{p},D_{diamond})
\]

The first measures conceptual resemblance.

The second estimates category membership.

A subsective phrase should generally retain high category membership.

A privative phrase can retain high resemblance while producing lower category membership.

This distinction is essential. A system that only measures vector similarity may incorrectly interpret `fake diamond` as a genuine diamond.

## Stage 17. Dynamically refine the phrase representation

Phrase comprehension is a process that unfolds over time.

The brain does not necessarily complete the interpretation as soon as the adjective is encountered.

It can update its representation as the relationship between the adjective and noun becomes clearer.

For example:

At the beginning:

\[
\mathbf{p}_0 \approx \mathbf{n}
\]

As adjective information is processed:

\[
\mathbf{p}_1=F(\mathbf{n},\mathbf{a})
\]

After the relationship is resolved:

\[
\mathbf{p}_2=F(\mathbf{n},\mathbf{a},\mathbf{r})
\]

The final semantic representation becomes more specific than the initial noun representation.

**Possible mathematical operations**

A recurrent update could be:

\[
\mathbf{p}_{t+1}
=
(1-\alpha)\mathbf{p}_t
+
\alpha F(\mathbf{n}_t,\mathbf{a}_t,\mathbf{r}_t)
\]

Where \(\alpha\) determines how strongly new information modifies the previous phrase representation.

An additional component could track uncertainty:

\[
H(\mathbf{p})=
-\sum_i P(p_i)\log P(p_i)
\]

Here, \(H\) represents entropy. It can be used as a computational measure of uncertainty about the resulting interpretation.

As the semantic relationship becomes clearer, uncertainty may decrease.

**Evidence from Law et al. (2026):** the researchers found that noun concreteness decoding generalized better between single-word and phrase conditions when the adjective was subsective than when it was privative. This indicates that the adjective can change the neural representation of the noun, rather than merely adding an independent semantic feature. <Cite refs={["turn516298search0","turn516298search1"]}/>

## Stage 18. Produce a unified semantic representation for the entire expression

At this point, the system has combined the available linguistic and conceptual information.

For a single word:

\[
DOG\rightarrow\mathbf{z}_{dog}
\]

For a phrase:

\[
SMALL\ DOG\rightarrow\mathbf{p}_{small,dog}
\]

For a different phrase:

\[
FAKE\ DIAMOND\rightarrow\mathbf{p}_{fake,diamond}
\]

The same general semantic system is involved, but the phrase representation contains additional information and relationships.

This is important because it suggests that semantic memory and semantic composition need not be implemented as completely separate semantic systems.

Instead, they may share underlying ATL-related representational and computational mechanisms.

The Law et al. study, published on 9 February 2026, provides evidence supporting this possibility: bilateral ATL signals responded more strongly to phrases at multiple time points, irrespective of noun concreteness, and both noun and adjective information could be decoded from ATL activity. <Cite refs={["turn516298search0","turn516298search1"]}/>

# Part C — Learning and maintaining the amodal semantic system

The previous stages describe processing once semantic knowledge is already available. A complete model also needs to explain how experience establishes the connections that permit information from different modalities to converge.

## Stage 19. Strengthen cross-modal semantic connections through experience

Imagine a child repeatedly encountering dogs in different situations.

The child:

- Sees dogs.
- Hears dogs barking.
- Touches dogs.
- Hears people use the word “dog”.
- Observes dogs running and interacting with people.

These experiences allow different neural populations to become associated with a common concept.

The proposed semantic network gradually learns which patterns belong together.

**Possible mathematical operations**

A simplified Hebbian learning rule is:

\[
\Delta W_{ij} =
\eta x_i y_j
\]

Where:

- \(x_i\) is the activation of one neural population.
- \(y_j\) is the activation of another.
- \(\eta\) controls the learning rate.

This can be extended with decay or regularization:

\[
\boxed{
\Delta W_{ij}
=
\eta x_i y_j-\lambda W_{ij}
}
\]

The first component strengthens connections between co-active populations. The second limits unbounded growth.

A more sophisticated learning model could also use an error signal:

\[
\Delta W =
\eta\mathbf{e}\mathbf{x}^{T}
\]

The error represents the difference between an expected and actual pattern.

These are possible computational approaches for learning convergent representations. The ATL imaging findings alone do not establish which plasticity rule is used in the brain.

## 4. Important biological and scientific qualifications

There are three distinctions worth preserving when translating this evidence into an AI architecture.

**First: the imaging limitations are not brain processing stages.**

Older fMRI studies sometimes failed to detect ATL activation because of signal distortion and dropout in this region. Visser et al.'s meta-analysis identified several factors affecting detection, including PET versus fMRI, whole-brain field of view greater than 15 cm, the use of a sufficiently demanding baseline task and explicit ATL region-of-interest analysis. These are experimental measurement conditions, not operations performed by the brain. <Cite refs={["turn416355search0","turn416355search2"]}/>

**Second: the ATL should not necessarily be modeled as one homogeneous processing unit.**

Persichetti et al. (2021) identified at least 34 functionally distinct parcels in their ATL connectivity analysis, with differing relationships to wider brain networks. This challenges the idea that every part of the ATL performs an identical semantic operation. <Cite refs={["turn516298search2","turn516298search3"]}/>

For an AI implementation, I would therefore represent the ATL as a collection of cooperating subregions with different connection strengths, rather than one isolated node.

**Third: distinguish experimentally observed activity from proposed computation.**

For example:

| Experimental observation | Computational interpretation |
|---|---|
| Overlapping ATL responses to words and pictures | Convergence into a shared semantic representation |
| ATL activity for different kinds of semantic input | Cross-modal semantic processing |
| Bilateral ATL responses to phrases | ATL participation in semantic composition |
| Dynamic adjective representations | Time-dependent modification of semantic state |
| Relatively stable noun-concreteness decoding | Maintenance of noun information |
| Different effects of subsective and privative adjectives | Semantic transformation must preserve category-membership distinctions |

The right column consists of proposed computational explanations, not direct measurements of individual neural calculations.

## 2. Basic mathematical model

Before defining the stages, we need a common representation for the information flowing through the system.

Imagine that every cortical population produces a pattern of neural activation. In a computational model, we can represent that pattern as a vector.

For example:

\[
\mathbf{x}_{visual} =
\begin{bmatrix}
0.2\\
0.8\\
0.4\\
\vdots
\end{bmatrix}
\]

This vector does not literally correspond to a list of neurons with known numerical values. It is an abstraction representing the activation pattern of a neural population.

The algorithm uses the following variables:

| Symbol | Meaning |
|---|---|
| \(\mathbf{x}_m\) | Input from sensory modality \(m\) |
| \(\mathbf{s}_m\) | Extracted semantic features from that modality |
| \(\mathbf{h}\) | ATL hub activation |
| \(\mathbf{z}\) | Integrated semantic representation |
| \(\mathbf{n}\) | Representation of a noun |
| \(\mathbf{a}\) | Representation of an adjective |
| \(\mathbf{p}\) | Composed phrase representation |
| \(W\) | Connection-strength matrix |
| \(\sigma\) | Nonlinear activation function |

We can use functions such as sigmoid, tanh or other nonlinear activation functions to model the way neuronal populations respond to their inputs.

# Part A — Accessing an amodal semantic representation

## Stage 1. Receive information through different sensory channels

The brain first receives information through one or more sensory systems.

Possible inputs include:

1. Written words.
2. Spoken words.
3. Pictures of objects.
4. Sounds produced by objects.
5. Information obtained through touch.
6. Information associated with bodily actions.

Consider the concept of a dog.

The brain could receive:

- The written word `DOG`.
- The spoken sound “dog”.
- A photograph of a dog.
- A barking sound.
- The experience of touching a dog's fur.

These inputs are physically and neurally different, even though they may eventually lead to the same conceptual representation.

**Possible mathematical operations**

The input can initially be represented as:

\[
X =
\{X_{visual}, X_{auditory}, X_{tactile}, X_{motor}, X_{linguistic}\}
\]

Each input is processed separately:

\[
X_m \longrightarrow \text{neural activation pattern}_m
\]

At this point, there is no requirement that the representations already have identical structures.

**Biological interpretation:** different sensory and language systems receive and initially process their respective inputs.

## Stage 2. Extract modality-specific features

Each sensory system extracts information appropriate to its modality.

For example:

**Visual processing**

When seeing a dog, the visual system may extract:

- Shape.
- Size.
- Color.
- Body structure.
- Facial characteristics.
- Movement.

**Auditory processing**

When hearing a dog bark, the auditory system may extract:

- Frequency.
- Amplitude.
- Pitch.
- Temporal pattern.
- Sound characteristics.

**Motor and action-related processing**

Information about dogs may also activate learned knowledge about:

- How dogs move.
- How humans interact with dogs.
- Actions commonly performed by dogs.

The important point is that the different systems initially contribute different kinds of information.

**Possible mathematical operations**

Each modality can be represented by a different feature-extraction transformation:

\[
\mathbf{s}_m = \phi(W_m\mathbf{x}_m+\mathbf{b}_m)
\]

Where:

- \(\mathbf{x}_m\) is the original input.
- \(W_m\) represents learned connections.
- \(\mathbf{b}_m\) represents baseline activation or bias.
- \(\phi\) represents nonlinear neural processing.
- \(\mathbf{s}_m\) is the extracted feature pattern.

For example:

\[
\mathbf{s}_{visual}=f_{visual}(\mathbf{x}_{visual})
\]

\[
\mathbf{s}_{auditory}=f_{auditory}(\mathbf{x}_{auditory})
\]

The functions are different because visual and auditory information require different initial transformations.

## Stage 3. Activate distributed semantic spokes

The brain does not necessarily rely on one isolated location to represent every characteristic of an object.

Instead, the relevant information can be distributed among multiple modality-related systems.

For a dog, different populations may contribute:

| Feature | Possible participating system |
|---|---|
| Appearance | Visual association cortex |
| Sound | Auditory association cortex |
| Movement | Motor-related cortex |
| Touch | Somatosensory association cortex |
| Emotional significance | Affect-related systems |
| Actions and uses | Distributed action and functional networks |

These are examples of the hub-and-spoke interpretation of semantic representation. The exact localization of every individual feature is more complicated than this simplified table.

The feature pattern could be represented as:

\[
\mathbf{S}=
\begin{bmatrix}
\mathbf{s}_{visual}\\
\mathbf{s}_{auditory}\\
\mathbf{s}_{motor}\\
\mathbf{s}_{tactile}\\
\mathbf{s}_{affective}\\
\mathbf{s}_{functional}
\end{bmatrix}
\]

Not all components need to be active during every encounter.

For example, reading the word `DOG` may initially activate linguistic and associated semantic information more strongly than tactile information.

**Possible mathematical operations**

The brain can be modeled as distributing activation across connected populations:

\[
A_i = f\left(\sum_j w_{ji}A_j\right)
\]

Where \(w_{ji}\) represents the strength of the connection from population \(j\) to population \(i\).

This models the spread of activation through a distributed network.

## Stage 4. Normalize and weight incoming feature information

Different sensory signals have different strengths and reliability.

A photograph might provide strong information about an object's appearance but little information about its sound.

An environmental sound might provide strong auditory information while providing no direct visual information.

The brain must therefore combine information without allowing one particularly strong input to overwhelm everything else.

**Possible mathematical operations**

One possible normalization operation is:

\[
\hat{\mathbf{s}}_m =
\frac{\mathbf{s}_m-\boldsymbol{\mu}_m}
{\boldsymbol{\sigma}_m+\epsilon}
\]

Where:

- \(\boldsymbol{\mu}_m\) is the average activity.
- \(\boldsymbol{\sigma}_m\) represents variation in activity.
- \(\epsilon\) prevents division by zero.

The system can also assign a dynamic contribution weight:

\[
g_m =
\frac{e^{r_m}}
{\sum_j e^{r_j}}
\]

Here, \(r_m\) represents the relevance or reliability of modality \(m\).

The weights satisfy:

\[
\sum_m g_m=1
\]

This is a computational approximation of dynamic weighting, not evidence that neurons literally perform softmax calculations.

## Stage 5. Transmit distributed information toward the ATL

After initial processing, information from the different systems reaches interconnected temporal regions, including anterior temporal regions.

The essential computational operation is convergence.

Different patterns must be able to influence a common semantic processing system.

For example:

\[
\mathbf{s}_{visual}
\rightarrow ATL
\]

\[
\mathbf{s}_{auditory}
\rightarrow ATL
\]

\[
\mathbf{s}_{linguistic}
\rightarrow ATL
\]

The connections need not have identical strengths.

The ATL's connections with the rest of the brain are heterogeneous, and different ATL subdivisions have different connectivity profiles.

**Possible mathematical operations**

Represent the incoming pathways by different connection matrices:

\[
\mathbf{u}_{ATL} =
W_v\mathbf{s}_{visual}
+
W_a\mathbf{s}_{auditory}
+
W_l\mathbf{s}_{linguistic}
+
W_m\mathbf{s}_{motor}
\]

This is a weighted summation operation.

Each matrix transforms its own modality-specific representation into a pattern that can contribute to ATL processing.

## Stage 6. Integrate information within the bilateral ATL

<badge color="info">Central semantic integration stage</badge>

This is the central stage of the amodal semantic hub hypothesis.

The ATL receives information originating from different sensory and linguistic systems.

The proposed function is to combine these different sources into coherent conceptual representations.

For example, different inputs concerning dogs may contribute:

- A particular shape.
- Four-legged body structure.
- Barking sounds.
- Animal movement.
- A relationship with humans.

Rather than treating each property as an isolated representation, the ATL is hypothesized to help establish a coherent representation of the concept.

**Possible mathematical operations**

A recurrent integration model is:

\[
\mathbf{h}_{t+1} =
\sigma
\left(
W_{hh}\mathbf{h}_{t}
+
\sum_m g_m W_m\mathbf{s}_m
+
W_c\mathbf{c}_t
\right)
\]

Where:

- \(\mathbf{h}_t\) is the current ATL activation.
- \(W_{hh}\) represents recurrent connections.
- \(W_m\) represents incoming modality-specific connections.
- \(g_m\) controls each modality's contribution.
- \(\mathbf{c}_t\) represents contextual input.

The recurrence means that the newly calculated activation becomes part of the input to the next processing cycle.

This creates the possibility of iterative integration instead of a single instantaneous calculation.

A more simplified model of activation accumulation is:

\[
\mathbf{h}_{t+1}
=
(1-\alpha)\mathbf{h}_t
+
\alpha\mathbf{u}_{ATL}
\]

Here, \(\alpha\) controls how rapidly the new information changes the existing activation.

This is similar to a leaky integrator.

## Stage 7. Establish a common semantic representation

After integration, the brain is hypothesized to produce a representation that is less dependent on the particular sensory form through which the concept was encountered.

This is the essential meaning of *amodal* in the hub-and-spoke hypothesis.

For example, the representation of a dog reached through a picture should overlap substantially with the representation reached through the spoken word “dog”.

The input patterns are different, but the conceptual content can converge.

**Possible mathematical operations**

We can represent the transformation as:

\[
\mathbf{z}=F_{ATL}(\mathbf{h})
\]

Where \(\mathbf{z}\) is the integrated semantic representation.

The representations obtained through different modalities should have high similarity when they concern the same concept:

\[
Similarity(\mathbf{z}_{visual},\mathbf{z}_{auditory})
\rightarrow 1
\]

One possible similarity measure is cosine similarity:

\[
CosSim(\mathbf{a},\mathbf{b}) =
\frac{\mathbf{a}\cdot\mathbf{b}}
{\|\mathbf{a}\|\|\mathbf{b}\|}
\]

The result approaches 1 when the vectors point in similar directions.

This does not mean the two neural patterns must be identical. Their shared semantic information can be represented through overlapping dimensions while modality-specific information remains available elsewhere.

## Stage 8. Perform cross-modal generalization

A semantic hub should allow knowledge acquired through one modality to contribute to understanding through another.

For example:

- Learning what a dog looks like helps interpret a description of a dog.
- Learning the meaning of the word `DOG` helps identify a dog in a picture.
- Hearing a barking sound can activate knowledge of dogs even without seeing one.

This is an important consequence of a shared conceptual system.

**Possible mathematical operations**

The semantic system can compare the current representation with stored concept representations:

\[
Score(c_i)=CosSim(\mathbf{z},\boldsymbol{\mu}_{c_i})
\]

Where \(\boldsymbol{\mu}_{c_i}\) is the learned representation of concept \(c_i\).

The system can then calculate candidate probabilities:

\[
P(c_i|\mathbf{z})=
\frac{e^{\beta Score(c_i)}}
{\sum_j e^{\beta Score(c_j)}}
\]

Where \(\beta\) determines how strongly the system favors the best-matching concepts.

The highest-scoring concept becomes the leading candidate, subject to the strength and reliability of the available evidence.

## Stage 9. Complete the semantic representation using feedback

The hub-and-spoke model is not necessarily a one-way system.

The ATL can be modeled as interacting with the distributed feature systems that contribute to semantic knowledge.

For example, when a person hears “dog,” the system may activate the concept and then partially reactivate associated information about its appearance, sound or behavior.

This is a useful way to model semantic completion.

**Possible mathematical operations**

We can model feedback as:

\[
\hat{\mathbf{s}}_m=V_m\mathbf{z}
\]

Where \(V_m\) reconstructs the expected feature pattern in modality \(m\).

The difference between an incoming feature pattern and a reconstructed pattern is:

\[
\mathbf{e}_m =
\mathbf{s}_m-\hat{\mathbf{s}}_m
\]

A computational system may use this difference to refine its interpretation:

\[
\mathbf{z}_{t+1} =
\mathbf{z}_t+\eta G(\mathbf{e})
\]

This is a candidate error-correction mechanism. It is not a specific operation demonstrated by the imaging studies cited here.

## Stage 10. Retrieve the concept for semantic understanding

At this stage, the semantic system has developed an integrated representation that can be used for comprehension.

For a single word, the system can retrieve its conceptual meaning.

For example:

\[
DOG \rightarrow \text{semantic representation of DOG}
\]

This representation contains information associated with the concept, rather than merely its spelling or pronunciation.

An important distinction:

- The orthographic system can identify the written word.
- The phonological system can identify the spoken form.
- The semantic system activates the conceptual knowledge associated with that form.

The same ATL-related semantic machinery may also contribute when the input is a nonverbal object or sound.

# Part B — Using the same ATL system to construct phrase meaning

The next stages explain how the proposed semantic hub participates in combining words into larger meaningful structures.

This is particularly relevant because a word's meaning and the meaning of a phrase containing that word are not necessarily identical.

For example:

- `diamond`
- `real diamond`
- `fake diamond`

The noun remains recognizable, but the adjective changes the interpretation of the complete phrase.

## Stage 11. Activate the noun's semantic representation

Suppose the brain receives the adjective–noun phrase:

**fake diamond**

The noun is `diamond`.

First, the semantic system activates the concept represented by the noun.

Let:

\[
\mathbf{n}=
F_{ATL}(\text{diamond})
\]

The representation may contain properties such as:

- Hardness.
- Appearance.
- Crystal structure.
- Typical uses.
- Value.
- Relationships to other minerals and objects.

The noun representation establishes the initial conceptual structure upon which further information can operate.

**Possible mathematical operations**

The noun representation can be treated as an activation vector:

\[
\mathbf{n}=
[n_1,n_2,\ldots,n_k]
\]

Its components represent different semantic dimensions.

The strength of each dimension can vary.

The vector does not need to be a list of explicitly named properties. It can represent distributed information encoded across a population.

## Stage 12. Maintain the noun representation while processing subsequent information

When an adjective is encountered, the brain must retain relevant noun information so that the adjective can be interpreted in relation to it.

For example, understanding `fake diamond` requires maintaining the concept of diamond while processing the adjective `fake`.

The noun should not simply disappear when the next word is received.

**Possible mathematical operations**

One possible model of temporal maintenance is:

\[
\mathbf{n}_{t+1} =
\rho\mathbf{n}_{t}
+
(1-\rho)\mathbf{n}_{new}
\]

Where:

- \(\rho\) determines how strongly previous noun information is retained.
- \(\mathbf{n}_{new}\) is newly processed noun-related information.

A relatively high \(\rho\) models a stable representation over time.

This is a computational analogy for maintaining semantic information, not a literal model of a single neural memory buffer.

**Evidence from Law et al. (2026):** noun concreteness information was relatively stable in ATL neural decoding and remained decodable for around 300 milliseconds in their experiment. This should not be interpreted as a universal duration for every noun or every comprehension task. <Cite refs={["turn516298search0","turn516298search1"]}/>

## Stage 13. Process the adjective's semantic information

Now the brain receives the adjective `fake`.

The adjective has its own semantic representation.

For instance:

\[
\mathbf{a}=F_{ATL}(\text{fake})
\]

This representation conveys information about falseness, imitation or lack of authenticity.

However, the adjective is not yet fully interpreted as part of the complete phrase.

The adjective must be interpreted in relation to the noun.

For example:

- `fake diamond`
- `fake painting`
- `fake passport`

The adjective has related meaning in all three expressions, but its consequences for the resulting interpretation depend on the noun.

**Possible mathematical operations**

The adjective can be encoded into a separate activation vector:

\[
\mathbf{a}=[a_1,a_2,\ldots,a_k]
\]

Its activation can change dynamically as more information arrives:

\[
\mathbf{a}_{t+1} =
f(\mathbf{a}_t,\mathbf{context}_t)
\]

This allows the semantic representation of the adjective to be influenced by the surrounding conceptual context.

**Evidence from Law et al. (2026):** adjective semantics showed a time-varying representational format in ATL decoding, whereas noun concreteness representations were more stable. <Cite refs={["turn516298search0","turn516298search37"]}/>

## Stage 14. Establish the relationship between adjective and noun

The brain must recognize that the adjective modifies the noun.

The combination is not simply:

\[
\mathbf{a}+\mathbf{n}
\]

There is a relationship between them.

For example:

- `red car`: the adjective specifies a color characteristic of the car.
- `small dog`: the adjective specifies a size characteristic of the dog.
- `fake diamond`: the adjective changes whether the described object qualifies as a genuine diamond.

Therefore, the semantic system must represent not only the two concepts, but also their relationship.

**Possible mathematical operations**

Represent the relationship as:

\[
\mathbf{r}=R(\mathbf{a},\mathbf{n})
\]

A simple interaction could be:

\[
\mathbf{r}=\mathbf{a}\odot\mathbf{n}
\]

Element-wise multiplication allows each adjective dimension to interact with the corresponding noun dimension.

A more expressive operation would be a learned bilinear transformation:

\[
r_k =
\sum_{i,j}T_{kij}a_i n_j
\]

Where \(T\) represents learned interactions between adjective and noun dimensions.

This allows the same adjective to influence different nouns in different ways.

## Stage 15. Construct the combined semantic representation

Now the brain can integrate the noun, adjective and their relationship.

The resulting phrase representation is not simply a concatenation of two independent word meanings.

It is a new semantic state representing the complete expression.

For `fake diamond`:

\[
\mathbf{p}
=
F(\mathbf{n},\mathbf{a},\mathbf{r})
\]

One possible implementation is:

\[
\boxed{
\mathbf{p}
=
\sigma
\left(
W_n\mathbf{n}
+
W_a\mathbf{a}
+
W_r\mathbf{r}
+
\mathbf{b}
\right)
}
\]

This formula contains four important operations:

1. Preserve information from the noun.
2. Incorporate information from the adjective.
3. Incorporate the relationship between them.
4. Apply a nonlinear transformation to construct the phrase representation.

The result is a representation of `fake diamond`, not merely separate representations of `fake` and `diamond`.

This is the central computational idea of semantic composition.

## Stage 16. Determine how the adjective changes the noun's denotation

This stage is especially important because not all adjectives modify nouns in the same way.

Law et al. (2026) examined the difference between *subsective* and *privative* adjectives.

**Subsective adjective**

A subsective adjective produces a phrase whose referents remain members of the noun category.

Example:

`small diamond`

A small diamond is still a diamond.

The phrase describes a subset of the broader diamond category.

In set notation:

\[
D_{\text{small diamond}}
\subseteq
D_{\text{diamond}}
\]

**Privative adjective**

A privative adjective produces an expression whose referents need not be members of the noun category.

Example:

`fake diamond`

A fake diamond may look like a diamond but is not a genuine diamond.

Thus:

\[
D_{\text{fake diamond}}
\not\subseteq
D_{\text{diamond}}
\]

The semantic system must therefore distinguish between two things:

- How similar the described object is to the original noun concept.
- Whether the described object actually belongs to the noun's category.

These are not necessarily the same.

A fake diamond may be extremely similar to a real diamond in appearance while failing to qualify as a genuine diamond.

**Possible mathematical operations**

We can model this with two separate scores:

\[
Similarity(\mathbf{p},\boldsymbol{\mu}_{diamond})
\]

and

\[
Membership(\mathbf{p},D_{diamond})
\]

The first measures conceptual resemblance.

The second estimates category membership.

A subsective phrase should generally retain high category membership.

A privative phrase can retain high resemblance while producing lower category membership.

This distinction is essential. A system that only measures vector similarity may incorrectly interpret `fake diamond` as a genuine diamond.

## Stage 17. Dynamically refine the phrase representation

Phrase comprehension is a process that unfolds over time.

The brain does not necessarily complete the interpretation as soon as the adjective is encountered.

It can update its representation as the relationship between the adjective and noun becomes clearer.

For example:

At the beginning:

\[
\mathbf{p}_0 \approx \mathbf{n}
\]

As adjective information is processed:

\[
\mathbf{p}_1=F(\mathbf{n},\mathbf{a})
\]

After the relationship is resolved:

\[
\mathbf{p}_2=F(\mathbf{n},\mathbf{a},\mathbf{r})
\]

The final semantic representation becomes more specific than the initial noun representation.

**Possible mathematical operations**

A recurrent update could be:

\[
\mathbf{p}_{t+1}
=
(1-\alpha)\mathbf{p}_t
+
\alpha F(\mathbf{n}_t,\mathbf{a}_t,\mathbf{r}_t)
\]

Where \(\alpha\) determines how strongly new information modifies the previous phrase representation.

An additional component could track uncertainty:

\[
H(\mathbf{p})=
-\sum_i P(p_i)\log P(p_i)
\]

Here, \(H\) represents entropy. It can be used as a computational measure of uncertainty about the resulting interpretation.

As the semantic relationship becomes clearer, uncertainty may decrease.

**Evidence from Law et al. (2026):** the researchers found that noun concreteness decoding generalized better between single-word and phrase conditions when the adjective was subsective than when it was privative. This indicates that the adjective can change the neural representation of the noun, rather than merely adding an independent semantic feature. <Cite refs={["turn516298search0","turn516298search1"]}/>

## Stage 18. Produce a unified semantic representation for the entire expression

At this point, the system has combined the available linguistic and conceptual information.

For a single word:

\[
DOG\rightarrow\mathbf{z}_{dog}
\]

For a phrase:

\[
SMALL\ DOG\rightarrow\mathbf{p}_{small,dog}
\]

For a different phrase:

\[
FAKE\ DIAMOND\rightarrow\mathbf{p}_{fake,diamond}
\]

The same general semantic system is involved, but the phrase representation contains additional information and relationships.

This is important because it suggests that semantic memory and semantic composition need not be implemented as completely separate semantic systems.

Instead, they may share underlying ATL-related representational and computational mechanisms.

The Law et al. study, published on 9 February 2026, provides evidence supporting this possibility: bilateral ATL signals responded more strongly to phrases at multiple time points, irrespective of noun concreteness, and both noun and adjective information could be decoded from ATL activity. <Cite refs={["turn516298search0","turn516298search1"]}/>

# Part C — Learning and maintaining the amodal semantic system

The previous stages describe processing once semantic knowledge is already available. A complete model also needs to explain how experience establishes the connections that permit information from different modalities to converge.

## Stage 19. Strengthen cross-modal semantic connections through experience

Imagine a child repeatedly encountering dogs in different situations.

The child:

- Sees dogs.
- Hears dogs barking.
- Touches dogs.
- Hears people use the word “dog”.
- Observes dogs running and interacting with people.

These experiences allow different neural populations to become associated with a common concept.

The proposed semantic network gradually learns which patterns belong together.

**Possible mathematical operations**

A simplified Hebbian learning rule is:

\[
\Delta W_{ij} =
\eta x_i y_j
\]

Where:

- \(x_i\) is the activation of one neural population.
- \(y_j\) is the activation of another.
- \(\eta\) controls the learning rate.

This can be extended with decay or regularization:

\[
\boxed{
\Delta W_{ij}
=
\eta x_i y_j-\lambda W_{ij}
}
\]

The first component strengthens connections between co-active populations. The second limits unbounded growth.

A more sophisticated learning model could also use an error signal:

\[
\Delta W =
\eta\mathbf{e}\mathbf{x}^{T}
\]

The error represents the difference between an expected and actual pattern.

These are possible computational approaches for learning convergent representations. The ATL imaging findings alone do not establish which plasticity rule is used in the brain.

## 4. Important biological and scientific qualifications

There are three distinctions worth preserving when translating this evidence into an AI architecture.

**First: the imaging limitations are not brain processing stages.**

Older fMRI studies sometimes failed to detect ATL activation because of signal distortion and dropout in this region. Visser et al.'s meta-analysis identified several factors affecting detection, including PET versus fMRI, whole-brain field of view greater than 15 cm, the use of a sufficiently demanding baseline task and explicit ATL region-of-interest analysis. These are experimental measurement conditions, not operations performed by the brain. <Cite refs={["turn416355search0","turn416355search2"]}/>

**Second: the ATL should not necessarily be modeled as one homogeneous processing unit.**

Persichetti et al. (2021) identified at least 34 functionally distinct parcels in their ATL connectivity analysis, with differing relationships to wider brain networks. This challenges the idea that every part of the ATL performs an identical semantic operation. <Cite refs={["turn516298search2","turn516298search3"]}/>

For an AI implementation, I would therefore represent the ATL as a collection of cooperating subregions with different connection strengths, rather than one isolated node.

**Third: distinguish experimentally observed activity from proposed computation.**

For example:

| Experimental observation | Computational interpretation |
|---|---|
| Overlapping ATL responses to words and pictures | Convergence into a shared semantic representation |
| ATL activity for different kinds of semantic input | Cross-modal semantic processing |
| Bilateral ATL responses to phrases | ATL participation in semantic composition |
| Dynamic adjective representations | Time-dependent modification of semantic state |
| Relatively stable noun-concreteness decoding | Maintenance of noun information |
| Different effects of subsective and privative adjectives | Semantic transformation must preserve category-membership distinctions |

The right column consists of proposed computational explanations, not direct measurements of individual neural calculations.

## 5. How I would represent this in a Python neurocomputational architecture

I would divide the implementation into these cooperating modules:

| Module | Responsibility |
|---|---|
| `ModalityEncoder` | Transform visual, auditory and linguistic inputs into initial feature representations |
| `SemanticSpokeNetwork` | Maintain distributed modality-related feature activations |
| `ATLConnectivityMap` | Represent graded connections between semantic spoke systems and ATL subregions |
| `ATLConvergenceEngine` | Integrate incoming feature patterns |
| `AmodalRepresentationEngine` | Construct common semantic representations |
| `CrossModalGeneralizer` | Compare representations across input modalities |
| `SemanticFeedbackEngine` | Reactivate associated conceptual features |
| `ConceptRetrievalEngine` | Retrieve the most relevant concept |
| `NounRepresentationMaintainer` | Retain noun-related semantic activation |
| `AdjectiveRepresentationEngine` | Represent adjective semantics dynamically |
| `SemanticCompositionEngine` | Combine noun, adjective and their relationship |
| `DenotationConstraintEngine` | Distinguish subsective from privative interpretations |
| `TemporalSemanticIntegrator` | Update representations as new information arrives |
| `SemanticLearningEngine` | Adjust connections based on experience |

**My main architectural recommendation:** do not implement the ATL as a dictionary lookup that maps a word directly to a concept. Implement it as a recurrent convergence system in which multiple distributed feature representations can jointly influence a semantic state, and that semantic state can also influence phrase construction.

That is the computational distinction between simply retrieving a stored word definition and modeling a semantic hub.
